# 3. Rational Numbers

## Definition

A rational number is any number that can be expressed in the form:

```math
p/q, q ≠ 0
```

where **p** and **q** are integers.

### Examples

- 5 = 5/1
- -3 = -3/1
- 3/8
- 0.75 = 3/4
- 0.333... = 1/3

### Characteristics

- Can be positive, negative, or zero.
- Decimal expansion is either terminating or non-terminating repeating.

---

# 4. Irrational Numbers

## Definition

An irrational number cannot be expressed as **p/q**.

Its decimal expansion is:

- Non-terminating
- Non-repeating

### Examples

- √2
- √5
- π
- √7

---

# 5. Rational vs Irrational Numbers

| Rational                      | Irrational               |
| ----------------------------- | ------------------------ |
| Can be written as p/q         | Cannot be written as p/q |
| Decimal terminates or repeats | Decimal never repeats    |
| Examples: 2/5, 4, 0.125       | Examples: √2, π          |

# 7. Converting Repeating Decimals into Fractions

### Example

Convert **0.666...** into p/q.

Let:

```text
x = 0.666...
10x = 6.666...

10x − x = 6
9x = 6
x = 2/3
```

Therefore:

**0.666... = 2/3**

# Introduction

In mathematics, we often use letters such as **x, y, a,** and **b** to represent unknown quantities. Expressions formed using these variables, numbers, and arithmetic operations are called **algebraic expressions**. A special type of algebraic expression that satisfies certain conditions is known as a **polynomial**.

Polynomials are one of the most important topics in algebra. They provide the foundation for solving equations, graphing functions, coordinate geometry, calculus, and many advanced mathematical concepts. They are also widely used in physics, engineering, economics, statistics, and computer science.

The word **polynomial** comes from two words:

- **Poly** means _many_.
- **Nomial** means _terms_.

Thus, a polynomial is an algebraic expression consisting of one or more terms connected by addition or subtraction.

---

# 1. Algebraic Expressions

An **algebraic expression** is a combination of variables, constants, and arithmetic operations such as addition, subtraction, multiplication, and division.

Examples:

```

```

```

```

```

```

```

However, not every algebraic expression is a polynomial.

```

```

Variable has a fractional exponent.

```
x⁻²
```

Variable has a negative exponent.

```
5/(x+1)
```

Variable appears in the denominator.

---

# 2. What is a Polynomial?

A **polynomial** is an algebraic expression in which:

- Variables have only whole number exponents.
- Coefficients are real numbers.
- Variables do not appear in denominators.
- Variables are not inside square roots.
- Variables do not have negative or fractional powers.

The general form of a polynomial is

```
aₙxⁿ + aₙ₋₁xⁿ⁻¹ + aₙ₋₂xⁿ⁻² + ... + a₁x + a₀
```

where

- **aₙ ≠ 0**
- **n** is a whole number.

# 9. Factor Theorem

The **Factor Theorem** provides an easy method to check whether a given expression is a factor of a polynomial.

### Statement

If

```
p(a)=0
```

then

```
(x−a)
```

is a factor of the polynomial.

If

```
p(a)≠0
```

then

```
(x−a)
```

is not a factor.

---

### Example

Check whether

```
x−2
```

is a factor of

```
x²−5x+6
```

Substitute

```
x=2
```

```
2²−5(2)+6
```

```
=4−10+6
```

```
=0
```

Hence,

```
x−2
```

is a factor.

# Introduction

In everyday life, we often observe patterns and arrangements of numbers. For example:

- The odd numbers: 1, 3, 5, 7, 9, ...
- The even numbers: 2, 4, 6, 8, 10, ...
- Multiples of 5: 5, 10, 15, 20, ...

Such ordered collections of numbers are called **sequences**. When the numbers in a sequence follow a specific rule, the sequence becomes a **progression**.

Sequences and progressions help us identify patterns, predict future terms, and solve practical problems in mathematics, science, finance, and computer programming.

---

# 1. Sequence

A **sequence** is an ordered list of numbers arranged according to a definite rule.

Each number in a sequence is called a **term**.

Examples:

```
2, 4, 6, 8, 10, ...
```

```
5, 10, 15, 20, ...
```

```
1, 4, 9, 16, 25, ...
```

The position of each term is important. Changing the order changes the sequence.

---

## Types of Sequences

### Finite Sequence

A sequence having a limited number of terms.

Example

```
3, 6, 9, 12
```

---

### Infinite Sequence

A sequence that continues indefinitely.

Example

```
1, 2, 3, 4, 5, ...
```

---

A **progression** is a sequence in which the terms follow a fixed mathematical rule.

# 4. Arithmetic Progression (AP)

An **Arithmetic Progression (AP)** is a sequence in which the difference between consecutive terms remains constant.

This constant difference is called the **Common Difference (d)**.

### General Form

```
a, a + d, a + 2d, a + 3d, ...
```

where

- **a** = First term
- **d** = Common difference

---

## Finding the Common Difference

Formula

```
d = Second Term − First Term
```

or

```
d = a₂ − a₁
```

---

### Example 1

```
2, 5, 8, 11, 14
```

```
d = 5 − 2 = 3
```

Common Difference = **3**

---

### Example 2

```
20, 17, 14, 11
```

```
d = 17 − 20 = -3
```

Common Difference = **−3**

---

### Example 3

```
7, 7, 7, 7
```

Common Difference

```
=0
```

This is also an arithmetic progression.

---

# 5. General Term of an AP

The **nth term** of an Arithmetic Progression is given by

```
aₙ = a + (n − 1)d
```

where

- a = First term
- d = Common difference
- n = Position of the term

---

### Example

Find the 10th term of

```
3, 7, 11, 15, ...
```

Here

```
a = 3
```

```
d = 4
```

Using the formula

```
a₁₀ = 3 + (10−1)(4)
```

```
=3+36
```

```
=39
```

Answer

```
39
```

---

# 6. Identifying an Arithmetic Progression

A sequence is an AP if the difference between every pair of consecutive terms is the same.

### Example

```
4, 9, 14, 19
```

Differences

```
9−4=5
```

```
14−9=5
```

```
19−14=5
```

Hence,

This is an Arithmetic Progression.

---

### Example

```
2, 5, 10, 17
```

Differences

```
3
```

```
5
```

```
7
```

Since the differences are not equal,

It is **not** an Arithmetic Progression.

---

# 7. Increasing and Decreasing AP

### Increasing AP

If

```

```

the terms increase continuously.

Example

```

```

---

### Decreasing AP

If

```

```

the terms decrease continuously.

Example

```

```

---

### Constant AP

If

```
d = 0
```

all terms remain equal.

Example

```

```

# Introduction

Algebraic identities are special algebraic equations that are true for **all values** of the variables involved. Unlike ordinary equations, identities do not depend on finding the value of a variable; they remain true regardless of the values substituted.

Algebraic identities simplify calculations, help in factorization, and form the foundation for solving quadratic equations, polynomial multiplication, and many advanced mathematical concepts.

For example,

```
(a + b)² = a² + 2ab + b²
```

This identity is true for every value of **a** and **b**.

---

# 1. What is an Algebraic Identity?

An **algebraic identity** is an equality that holds true for every permissible value of the variables.

### Example

```
(a + b)² = a² + 2ab + b²
```

Let

```
a = 2
```

```
b = 3
```

LHS

```
(2 + 3)² = 25
```

RHS

```
2² + 2(2)(3) + 3²
```

```
=4+12+9
```

```
=25
```

Hence,

```
LHS = RHS
```

---

# 2. Difference Between an Identity and an Equation

| Equation                        | Identity                    |
| ------------------------------- | --------------------------- |
| True only for particular values | True for all values         |
| May have one or more solutions  | Always true                 |
| Example: x + 2 = 7              | Example: (a+b)² = a²+2ab+b² |

---

# 3. Square of a Binomial

One of the most important identities is the square of a sum.

# Introduction

In many real-life situations, two quantities are related to each other. For example, the cost of buying books depends on the number of books purchased, and the distance travelled depends on speed and time. Such relationships can often be represented using **linear equations in two variables**.

A **linear equation in two variables** contains two unknown quantities (usually represented by **x** and **y**) and each variable has the highest power of **1**. These equations represent straight lines when plotted on a graph and are widely used in mathematics, science, economics, engineering, and statistics.

---

Examples:

```

```

```

```

A **constant** is a fixed numerical value.

Examples:

```

```

```

```

In the equation

```
3x + 2y = 12
```

- Variables: **x, y**
- Constants: **3, 2, 12**

---

# 2. Linear Equation in Two Variables

A **linear equation in two variables** is an equation of the form

```
ax + by + c = 0
```

where

- **a**, **b**, and **c** are real numbers.
- **a** and **b** are not both zero.

Examples:

```
2x + 3y = 6
```

```

```

```

```

Non-examples:

```

```

```

```

```

These are not linear equations because the variables have powers greater than 1, are multiplied together, or appear under radicals.

A **solution** of a linear equation is an ordered pair **(x, y)** that satisfies the equation.

```

```

```

```

```
=7
```

```
(2,1)
```

is a solution.

# Introduction

Coordinate Geometry is a branch of mathematics that combines **algebra** and **geometry**. It provides a systematic way of locating points on a plane using numbers called **coordinates**.

The concept of coordinate geometry was developed by the French mathematician **René Descartes**, who introduced a method of representing geometric figures using algebraic equations. Because of his contribution, the coordinate system is also known as the **Cartesian Coordinate System**.

Coordinate geometry is widely used in engineering, physics, computer graphics, navigation, architecture, robotics, and mapping.

---

# 1. Cartesian Coordinate System

A **Cartesian Coordinate System** consists of two perpendicular number lines that intersect at a point called the **Origin**.

The two number lines are:

- Horizontal axis (**X-axis**)
- Vertical axis (**Y-axis**)

These axes divide the plane into four regions called **quadrants**.

```
             Y-axis
               ↑
        II     |      I
               |
---------------O--------------→ X-axis
               |
       III     |      IV
               |
               ↓
```

The point **O** is called the **Origin**.

---

# 2. Coordinate Axes

## X-axis

The horizontal number line is called the **X-axis**.

- Positive direction → Right
- Negative direction → Left

Examples of points on the X-axis:

```
(3,0)
```

```
(-5,0)
```

---

## Y-axis

The vertical number line is called the **Y-axis**.

- Positive direction → Upward
- Negative direction → Downward

Examples of points on the Y-axis:

```
(0,4)
```

```
(0,-6)
```

---

# 3. Origin

The point where the X-axis and Y-axis intersect is called the **Origin**.

Its coordinates are

```
(0,0)
```

The origin acts as the reference point for locating every other point on the plane.

---

```

- **x** represents the horizontal distance from the origin.

# Introduction

Geometry is one of the oldest branches of mathematics. The word **Geometry** is derived from the Greek words **Geo** meaning _Earth_ and **Metron** meaning _Measurement_. It originated from the need to measure land, construct buildings, and study shapes.

One of the greatest contributors to geometry was the Greek mathematician **Euclid**, who lived around **300 BCE**. He is known as the **Father of Geometry** because he organized the existing knowledge of geometry into a logical system in his famous book **Elements**.

Euclid's geometry is based on a few basic assumptions called **definitions**, **axioms**, and **postulates**. Using these fundamental truths, more complex geometric results can be proved logically.

---

# 1. Euclid and His Contribution

**Euclid** was a Greek mathematician who taught at Alexandria in Egypt.

His famous work, **Elements**, consists of **13 books** covering topics such as:

- Plane Geometry
- Number Theory
- Solid Geometry
- Proportion
- Measurement

The _Elements_ remained the standard textbook for geometry for more than two thousand years.

### Importance of Euclid's Work

- Introduced a logical approach to geometry.
- Organized mathematical ideas systematically.
- Established the axiomatic method of mathematics.
- Laid the foundation for modern geometry.

---

# 2. Basic Geometrical Ideas

Geometry begins with a few basic concepts that are accepted without formal definitions.

## Point

A **point** represents an exact position.

- It has **no length**, **breadth**, or **thickness**.
- It is usually represented by a capital letter.

Examples:

```
A
```

```
B
```

```
P
```

---

## Line

A **line** is a straight path extending endlessly in both directions.

Properties:

- Has length but no thickness.
- Contains infinitely many points.
- Extends without end.

Example:

```
←──────────────→
       A     B
```

---

## Line Segment

A **line segment** is a part of a line with two fixed endpoints.

Example:

```
A────────B
```

The length of a line segment can be measured.

---

## Ray

A **ray** starts from one point and extends infinitely in one direction.

Example:

```
A────────────→
```

Point **A** is called the initial point.

---

## Plane

A **plane** is a flat two-dimensional surface extending infinitely in all directions.

Examples:

- Surface of a table
- Sheet of paper
- Blackboard

---

# 3. Definitions

A **definition** explains the meaning of a mathematical term.

Examples:

- A point indicates an exact location.
- A line is a straight path extending indefinitely.
- A circle is the set of all points at a fixed distance from a given point.

Definitions help us understand geometric concepts clearly.

---

# 4. Axioms

An **axiom** is a statement accepted as true without proof.

Euclid's axioms are universal and apply to all branches of mathematics.

### Euclid's Common Axioms

### Axiom 1

Things equal to the same thing are equal to one another.

Example:

If

```
a = b
```

and

```
b = c
```

then

```
a = c
```

---

### Axiom 2

If equals are added to equals, the wholes are equal.

Example:

```
5 + 3 = 8
```

```
7 + 3 = 10
```

Since equal quantities are added, equality is preserved.

---

### Axiom 3

If equals are subtracted from equals, the remainders are equal.

Example:

```
12 − 5 = 7
```

```
15 − 8 = 7
```

---

### Axiom 4

Things which coincide with one another are equal to one another.

If two objects exactly overlap, they are equal.

---

### Axiom 5

The whole is greater than the part.

Example:

A complete line segment is longer than any of its proper parts.

---

### Axiom 6

Things which are double of the same things are equal.

---

### Axiom 7

Things which are halves of the same things are equal.

---

# 5. Postulates

A **postulate** is a statement accepted without proof that applies specifically to geometry.

Euclid proposed **five postulates**.

---

## First Postulate

A straight line can be drawn joining any two points.

Example:

Any two distinct points can always be connected by exactly one straight line.

---

## Second Postulate

A finite straight line can be extended indefinitely in a straight line.

This means every line segment can be extended without limit.

---

## Third Postulate

A circle can be drawn with any centre and any radius.

Example:

Using a compass, we can draw circles of different radii.

---

## Fourth Postulate

All right angles are equal to one another.

Every right angle measures

```
90°
```

---

## Fifth Postulate

If a straight line falling on two straight lines makes the interior angles on the same side less than two right angles, then the two lines, if extended indefinitely, meet on that side.

This postulate forms the basis of the concept of **parallel lines**.

---

# 6. Difference Between Axioms and Postulates

| Axioms                                    | Postulates                  |
| ----------------------------------------- | --------------------------- |
| Applicable to all branches of mathematics | Applicable only to geometry |
| Universal truths                          | Geometrical truths          |
| Used in arithmetic, algebra, and geometry | Used mainly in geometry     |

---

# 7. Theorems

A **theorem** is a mathematical statement that is proved using definitions, axioms, postulates, and previously proved theorems.

Example:

"The sum of the angles of a triangle is 180°."

This statement requires proof and is therefore a theorem.

---

# 8. Importance of Euclid's Geometry

Euclid's geometry is important because it:

- Develops logical reasoning.
- Introduces proof-based mathematics.
- Forms the basis of modern geometry.
- Helps understand constructions and measurements.
- Is used in architecture, engineering, surveying, and design.

# Introduction

Geometry helps us understand the shapes and structures around us. Two of the most fundamental concepts in geometry are **lines** and **angles**. Roads intersect at junctions, railway tracks run parallel to each other, and the corners of buildings form different angles. Understanding these concepts is essential for studying triangles, polygons, circles, and other geometric figures.

In this chapter, we learn about different types of lines and angles, the relationship between angles formed by intersecting and parallel lines, and important angle properties used in geometric proofs.

---

# 1. Basic Concepts

## Line

A **line** is a straight path that extends infinitely in both directions.

Properties:

- Has no endpoints.
- Has infinite length.
- Can be named using two points.

Example:

```
←──────────────→
A              B
```

---

## Line Segment

A **line segment** is a part of a line with two fixed endpoints.

Example:

```
A────────B
```

Unlike a line, a line segment has a definite length.

---

## Ray

A **ray** starts from one fixed point and extends infinitely in one direction.

Example:

```
A────────────→
```

Point **A** is called the initial point of the ray.

---

# 2. Angles

An **angle** is formed when two rays meet at a common endpoint.

The common endpoint is called the **vertex**.

Example:

```
      B
     /
    /
A──O
```

Here,

- **OA** and **OB** are the arms of the angle.
- **O** is the vertex.

---

# 3. Types of Angles

## Acute Angle

An angle measuring **less than 90°**.

Example:

```
35°
```

```
60°
```

---

## Right Angle

An angle measuring exactly

```
90°
```

Example:

```
∟
```

---

## Obtuse Angle

An angle measuring **more than 90° but less than 180°**.

Examples:

```
120°
```

```
145°
```

---

## Straight Angle

An angle measuring exactly

```
180°
```

It forms a straight line.

---

## Reflex Angle

An angle measuring **greater than 180° but less than 360°**.

Example:

```
240°
```

---

## Complete Angle

An angle measuring

```
360°
```

It represents one complete revolution.

---

# 4. Pair of Angles

## Adjacent Angles

Two angles are adjacent if:

- They have a common vertex.
- They share a common arm.
- Their interiors do not overlap.

Example:

```
∠AOB and ∠BOC
```

---

## Linear Pair

A **linear pair** consists of two adjacent angles whose non-common arms form a straight line.

Property:

```
Sum of angles = 180°
```

### Example

If one angle is

```
70°
```

then the other angle is

```
180°−70°=110°
```

---

## Vertically Opposite Angles

When two lines intersect, opposite angles are called **vertically opposite angles**.

Property:

```
Vertically opposite angles are equal.
```

Example:

If one angle is

```
50°
```

then its vertically opposite angle is also

```
50°
```

---

# 5. Parallel Lines and a Transversal

Two lines are **parallel** if they never meet, even when extended indefinitely.

A **transversal** is a line that intersects two or more lines at distinct points.

```
l₁  ─────────────

        /

       /

l₂  ─────────────
```

The slanting line is the transversal.

---

# 6. Angles Formed by a Transversal

When a transversal cuts two parallel lines, several pairs of angles are formed.

---

## Corresponding Angles

These occupy the same relative position.

Property:

```
Corresponding angles are equal.
```

---

## Alternate Interior Angles

These lie inside the parallel lines on opposite sides of the transversal.

Property:

```
Alternate interior angles are equal.
```

---

## Alternate Exterior Angles

These lie outside the parallel lines on opposite sides of the transversal.

Property:

```
Alternate exterior angles are equal.
```

---

## Interior Angles on the Same Side of the Transversal

These are also called **co-interior angles**.

Property:

```
Sum = 180°
```

---

# 7. Criteria for Parallel Lines

If a transversal intersects two lines and any one of the following conditions is true, then the lines are parallel.

- Corresponding angles are equal.
- Alternate interior angles are equal.
- Alternate exterior angles are equal.
- Interior angles on the same side add up to

```
180°
```

---

Lines and angles are used in:

- Bridge design.
- Navigation.
- Computer graphics.

# Introduction

A **triangle** is one of the simplest and most important geometric figures. It is a closed polygon formed by joining three non-collinear points with three line segments. Triangles are widely used in architecture, engineering, surveying, construction, navigation, and computer graphics because of their strength and stability.

Every triangle has **three sides**, **three angles**, and **three vertices**. Many important geometric properties and theorems are based on triangles, making them a fundamental topic in mathematics.

---

# 1. Triangle

A **triangle** is a polygon with three sides and three angles.

Example:

```
      A
     / \
    /   \
   /     \
  B-------C
```

Here,

- Vertices: **A, B, C**
- Sides: **AB, BC, AC**
- Angles: **∠A, ∠B, ∠C**

---

# 2. Classification of Triangles

Triangles can be classified based on their **sides** and **angles**.

## Based on Sides

### Equilateral Triangle

An **equilateral triangle** has all three sides equal.

Properties:

- All sides are equal.
- All angles are equal.
- Each angle measures **60°**.

---

### Isosceles Triangle

An **isosceles triangle** has two equal sides.

Properties:

- Two sides are equal.
- Angles opposite the equal sides are equal.

---

### Scalene Triangle

A **scalene triangle** has all sides of different lengths.

Properties:

- No sides are equal.
- No angles are equal.

---

# 3. Classification Based on Angles

## Acute-Angled Triangle

All three angles are less than

```
90°
```

---

## Right-Angled Triangle

One angle is exactly

```
90°
```

The side opposite the right angle is called the **hypotenuse**.

---

## Obtuse-Angled Triangle

One angle is greater than

```
90°
```

---

# 4. Angle Sum Property

The sum of the three interior angles of a triangle is always

```
180°
```

Mathematically,

```
∠A + ∠B + ∠C = 180°
```

### Example

If

```
∠A = 60°
```

```
∠B = 50°
```

Then

```
∠C = 180° − (60° + 50°)
```

```
=70°
```

---

# 5. Exterior Angle Property

An **exterior angle** of a triangle is equal to the sum of the two opposite interior angles.

Mathematically,

```
Exterior Angle = Interior Angle 1 + Interior Angle 2
```

### Example

If the opposite interior angles are

```
45°
```

and

```
65°
```

Then

```
Exterior Angle = 45° + 65°
```

```
=110°
```

---

# 6. Congruence of Triangles

Two triangles are **congruent** if they have the same shape and the same size.

Congruent triangles have:

- Equal corresponding sides.
- Equal corresponding angles.

Symbol:

```
≅
```

Example

```
△ABC ≅ △PQR
```

---

# 7. Criteria for Congruence

## SSS (Side-Side-Side)

If the three sides of one triangle are equal to the three corresponding sides of another triangle, then the triangles are congruent.

---

## SAS (Side-Angle-Side)

If two sides and the included angle of one triangle are equal to the corresponding parts of another triangle, then they are congruent.

---

## ASA (Angle-Side-Angle)

If two angles and the included side are equal, the triangles are congruent.

---

## RHS (Right Angle-Hypotenuse-Side)

Applicable only for right-angled triangles.

If:

- One right angle is equal,
- Hypotenuse is equal,
- One corresponding side is equal,

then the triangles are congruent.

---

# 8. Inequalities in a Triangle

## Triangle Inequality Property

The sum of any two sides of a triangle is always greater than the third side.

For triangle ABC:

```
AB + BC > AC
```

```
BC + AC > AB
```

```
AC + AB > BC
```

---

## Largest Side and Largest Angle

- The longest side lies opposite the largest angle.
- The shortest side lies opposite the smallest angle.

---

# 9. Medians of a Triangle

A **median** joins a vertex to the midpoint of the opposite side.

Properties:

- Every triangle has three medians.
- The three medians meet at one point called the **centroid**.

---

# 10. Altitudes of a Triangle

An **altitude** is a perpendicular drawn from a vertex to the opposite side.

Properties:

- Every triangle has three altitudes.
- The three altitudes meet at a point called the **orthocentre**.

---

- A triangle is a three-sided polygon with three vertices and three angles.
- Triangles are classified based on their sides as **equilateral, isosceles,** and **scalene**.
- Based on angles, they are **acute-angled, right-angled,** and **obtuse-angled**.
- The sum of the interior angles of a triangle is always **180°**.
- An exterior angle equals the sum of the two opposite interior angles.
- Congruent triangles have the same shape and size and satisfy one of the congruence criteria: **SSS, SAS, ASA,** or **RHS**.
- The sum of any two sides of a triangle is always greater than the third side.
- Every triangle has three medians meeting at the **centroid** and three altitudes meeting at the **orthocentre**.
- Triangles are fundamental to geometry and have numerous applications in engineering, architecture, navigation, and design.

# Introduction

A **quadrilateral** is a closed polygon formed by joining four line segments. The word _quadrilateral_ comes from the Latin words **quadri** (four) and **latus** (side), meaning "a figure with four sides."

Quadrilaterals are commonly seen in everyday life, such as in doors, windows, books, computer screens, tiles, and fields. Different types of quadrilaterals have different properties based on the lengths of their sides, the measures of their angles, and the relationship between their diagonals.

Understanding quadrilaterals helps in solving geometrical problems and is useful in architecture, engineering, construction, and design.

---

# 1. Quadrilateral

A **quadrilateral** is a polygon having:

- Four sides
- Four vertices
- Four angles
- Two diagonals

Example:

```
A────────B
│        │
│        │
D────────C
```

Here,

- Vertices: **A, B, C, D**
- Sides: **AB, BC, CD, DA**
- Diagonals: **AC** and **BD**

---

# 2. Angle Sum Property of a Quadrilateral

The sum of the interior angles of every quadrilateral is

```
360°
```

Mathematically,

```
∠A + ∠B + ∠C + ∠D = 360°
```

### Example

If three angles are

```
80°
```

```
95°
```

```
105°
```

Then,

```
Fourth Angle
= 360° − (80° + 95° + 105°)
```

```
=360°−280°
```

```
=80°
```

---

# 3. Types of Quadrilaterals

## Parallelogram

A **parallelogram** is a quadrilateral in which both pairs of opposite sides are parallel.

### Properties

- Opposite sides are equal.
- Opposite sides are parallel.
- Opposite angles are equal.
- Adjacent angles are supplementary.
- Diagonals bisect each other.

---

## Rectangle

A **rectangle** is a parallelogram with four right angles.

### Properties

- Opposite sides are equal and parallel.
- Each angle measures **90°**.
- Diagonals are equal.
- Diagonals bisect each other.

---

## Square

A **square** is a rectangle with all sides equal.

### Properties

- All sides are equal.
- All angles are **90°**.
- Opposite sides are parallel.
- Diagonals are equal.
- Diagonals bisect each other at right angles.

---

## Rhombus

A **rhombus** is a parallelogram with all sides equal.

### Properties

- All sides are equal.
- Opposite angles are equal.
- Opposite sides are parallel.
- Diagonals bisect each other at right angles.
- Diagonals are generally not equal.

---

## Trapezium

A **trapezium** is a quadrilateral with one pair of opposite sides parallel.

### Properties

- Exactly one pair of opposite sides is parallel.
- The non-parallel sides are called **legs**.

---

## Kite

A **kite** is a quadrilateral having two pairs of adjacent equal sides.

### Properties

- Two pairs of adjacent sides are equal.
- One pair of opposite angles is equal.
- Diagonals intersect at right angles.
- One diagonal bisects the other.

---

# 4. Parallelogram and Its Properties

A parallelogram has several important properties.

### Opposite Sides

---

### Adjacent Angles

```

---

### Diagonals

The diagonals of a parallelogram bisect each other.

If diagonals **AC** and **BD** intersect at **O**, then

```
AO = OC
```

```
BO = OD
```

---

# 5. Midpoint Theorem

**Statement**

The line segment joining the midpoints of any two sides of a triangle is:

- Parallel to the third side.
- Equal to half the length of the third side.

This theorem is useful in proving properties of quadrilaterals and other geometric figures.

---

# 6. Converse of the Midpoint Theorem

**Statement**

A line drawn through the midpoint of one side of a triangle and parallel to another side bisects the third side.

# Introduction

A **circle** is one of the most important geometric figures. It is the collection of all points in a plane that are at a fixed distance from a fixed point. The fixed point is called the **centre**, and the fixed distance is called the **radius**.

Circles are found everywhere in daily life, such as in wheels, clocks, coins, rings, and planets. They are widely used in engineering, architecture, astronomy, and design.

In this chapter, we study the different parts of a circle and the relationships between chords, arcs, and angles.

---

# 1. Circle

A **circle** is the set of all points in a plane that are at an equal distance from a fixed point.

Example:

```
          •
      *       *
    *     O     *
      *       *
          •
```

Here,

- **O** is the centre.
- Every point on the boundary is at the same distance from **O**.

---

# 2. Centre

The **centre** is the fixed point inside the circle from which every point on the circle is equidistant.

Example:

```
O
```

---

# 3. Radius

A **radius** is the line segment joining the centre of the circle to any point on the circle.

Example:

```
OA
```

Properties:

- All radii of a circle are equal.
- Radius is half of the diameter.

Relationship:

```
Radius = Diameter ÷ 2
```

---

# 4. Diameter

A **diameter** is a chord that passes through the centre of the circle.

Properties:

- It is the longest chord of the circle.
- It divides the circle into two equal parts called semicircles.

Relationship:

```
Diameter = 2 × Radius
```

---

# 5. Chord

A **chord** is a line segment joining any two points on the circle.

Properties:

- Every diameter is a chord.
- Every chord is not a diameter.

---

# 6. Arc

An **arc** is a part of the circumference of a circle.

Types of arcs:

### Minor Arc

The smaller arc between two points.

### Major Arc

The larger arc between the same two points.

### Semicircular Arc

An arc formed by a diameter.

Its measure is

```
180°
```

---

# 7. Circumference

The **circumference** is the boundary or perimeter of a circle.

It is the complete distance around the circle.

---

# 8. Sector

A **sector** is the region enclosed by two radii and the intercepted arc.

Types:

- Minor Sector
- Major Sector

---

# 9. Segment

A **segment** is the region enclosed by a chord and its corresponding arc.

Types:

- Minor Segment
- Major Segment

---

# 10. Concentric Circles

Two or more circles having the same centre but different radii are called **concentric circles**.

Example:

```
     _______
   /         \
  |  _____    |
  | /     \   |
  | \_____/   |
   \_________/
```

Both circles have the same centre.

---

# 11. Equal Chords and Equal Arcs

### Property 1

Equal chords of the same circle subtend equal arcs.

### Property 2

Equal arcs of the same circle correspond to equal chords.

---

# 12. Angle Subtended by a Chord

A chord of a circle forms an angle at the centre.

### Property

Equal chords subtend equal angles at the centre.

Conversely,

Equal angles at the centre stand on equal chords.

---

# 13. Perpendicular from the Centre to a Chord

### Theorem

The perpendicular drawn from the centre of a circle to a chord bisects the chord.

If **OM** is perpendicular to chord **AB**, then

```
AM = MB
```

# Introduction

In geometry, **perimeter** and **area** are two important measurements used to describe plane figures.

- **Area** is the amount of surface enclosed by a closed figure.

These concepts are widely used in everyday life, such as measuring land, designing parks, constructing buildings, laying tiles, fencing gardens, and estimating the amount of paint required for walls.

# 1. Perimeter

The **perimeter** of a closed figure is the total length of its boundary.

The **area** of a closed figure is the region enclosed within its boundary.

The unit of area is measured in **square units**, such as:

- cm²
- m²

# 3. Perimeter and Area of a Rectangle

A **rectangle** has opposite sides equal and all angles equal to **90°**.

A **square** has all sides equal.

A **parallelogram** is a quadrilateral with opposite sides parallel.

The area depends on its **base** and **height**.

### Formula

The height must always be **perpendicular** to the base.

---

# 6. Area of a Triangle

The area of a triangle depends on its base and the corresponding perpendicular height.

### Formula

```
Area = ½ × Base × Height
```

The height is the perpendicular distance from the vertex to the base.

A **rhombus** is a quadrilateral with all sides equal.

Its area can be found using its diagonals.

### Formula

```

```

# 8. Area of a Trapezium

A **trapezium** has one pair of opposite sides parallel.

### Formula

```

Always convert the given values to the same unit before calculation.

# Introduction

Many objects around us, such as boxes, cans, balls, cones, and water tanks, are **three-dimensional (3D) shapes**. Unlike plane figures, these solids have **length, breadth, and height**.

The **surface area** of a solid is the total area covered by all its outer surfaces, while the **volume** is the amount of space occupied by the solid.

The study of surface areas and volumes is useful in architecture, engineering, packaging, construction, manufacturing, and everyday life.

---

# 1. Three-Dimensional Solids

A **three-dimensional solid** has:

- Length
- Breadth (or Width)
- Height

Common solids include:

- Cuboid
- Cube
- Cylinder
- Cone
- Sphere
- Hemisphere

---

# 2. Cuboid

A **cuboid** is a solid bounded by six rectangular faces.

Examples:

- Brick
- Book
- Matchbox
- Room

### Dimensions

- Length (**l**)
- Breadth (**b**)
- Height (**h**)

### Total Surface Area (TSA)

```
TSA = 2(lb + bh + hl)
```

### Lateral Surface Area (LSA)

```
LSA = 2h(l + b)
```

### Volume

```
Volume = l × b × h
```

---

A **cube** is a cuboid in which all edges are equal.

Examples:

- Dice
- Ice cube
- Rubik's Cube

Let each edge be **a**.

```
TSA = 6a²
```

### Lateral Surface Area

```
LSA = 4a²
```

### Volume

```
Volume = a³
```

---

A **cylinder** has two equal circular bases connected by a curved surface.

- Water pipe
- Tin can
- Glass

- Radius = **r**
- Height = **h**

### Volume

```

- Funnel

TSA = πr(l + r)

```

TSA = 3πr²
```

### Volume

Volume = ⅔πr³
```

# Introduction

Probability is the branch of mathematics that deals with **chance** or the **likelihood of an event occurring**. It helps us predict how likely an event is to happen, although it does not guarantee the outcome.

In everyday life, probability is used in weather forecasting, sports, insurance, medical research, genetics, economics, games, and decision-making.

The value of probability always lies between **0 and 1**, where **0** indicates an impossible event and **1** indicates a certain event.

---

# 1. Random Experiment

A **random experiment** is an experiment whose outcome cannot be predicted with certainty in advance.

### Examples

- Tossing a coin.

An **outcome** is a possible result of a random experiment.

Possible outcomes are

```

```

```

# 8. Properties of Probability

For any event **E**,

```
0 ≤ P(E) ≤ 1
```

Special cases:

Impossible event

```
P(E)=0
```

Certain event

```
P(E)=1
```

---

# 9. Complementary Events

The complement of an event **E** is the event that **E does not occur**.

If

```
P(E)
```

is the probability of an event,

then

```
P(Not E)=1−P(E)
```

---

### Example

If

```
P(Rain)=0.3
```

then

```
P(No Rain)
```

```
=1−0.3
```

```
=0.7
```

# Common Mistakes

- Confusing experimental probability with theoretical probability.
- Forgetting to list all possible outcomes in the sample space.
- Counting favourable outcomes incorrectly.
- Writing probabilities greater than **1** or less than **0**.
- Assuming every event is equally likely without checking the conditions.
- Forgetting to simplify probability fractions.

# Formula Sheet

| Concept                  | Formula                                       |
| ------------------------ | --------------------------------------------- |
| Theoretical Probability  | `P(E) = Favourable Outcomes / Total Outcomes` |
| Experimental Probability | `Number of Successful Trials / Total Trials`  |
| Impossible Event         | `P(E) = 0`                                    |
| Certain Event            | `P(E) = 1`                                    |
| Complement of an Event   | `P(Not E) = 1 − P(E)`                         |
| Range of Probability     | `0 ≤ P(E) ≤ 1`                                |

# Chapter Summary

- Probability measures the likelihood of an event occurring.
- A **random experiment** is one whose outcome cannot be predicted with certainty.
- The **sample space** is the set of all possible outcomes of an experiment.
- An **event** is a subset of the sample space.
- Theoretical probability is calculated using equally likely outcomes.
- Experimental probability is calculated using actual observations from repeated experiments.
- The probability of an impossible event is **0**, while the probability of a certain event is **1**.
- The probability of any event always lies between **0** and **1**.
- The complement of an event is given by **1 − P(E)**.
- Probability is widely used in science, economics, medicine, engineering, weather forecasting, and everyday decision-making.
