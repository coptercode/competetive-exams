# Introduction

Real numbers include all rational and irrational numbers. They are used in almost every branch of mathematics and in daily life. This chapter introduces the **Fundamental Theorem of Arithmetic**, methods of finding the **HCF** and **LCM** of numbers, and explains why numbers such as **√2** are irrational.

---

# 1. Real Numbers

A **real number** is any number that can be represented on the number line.

Real numbers include:

- Natural numbers
- Whole numbers
- Integers
- Rational numbers
- Irrational numbers

### Classification

```
                Real Numbers
               /            \
        Rational         Irrational
```

### Examples

**Rational Numbers**

```
3, -5, 7/8, 0.25
```

**Irrational Numbers**

```
√2, √3, π
```

---

# 2. Rational Numbers

A **rational number** can be written in the form

```
p/q
```

where

- **p** and **q** are integers.
- **q ≠ 0**.

### Properties

- Decimal expansion is either **terminating** or **non-terminating recurring**.

### Examples

```
5 = 5/1
```

```
7/4 = 1.75
```

```
1/3 = 0.3333...
```

---

# 3. Irrational Numbers

An **irrational number** cannot be expressed in the form

```
p/q
```

where **p** and **q** are integers.

### Properties

- Decimal expansion is **non-terminating**.
- Decimal expansion is **non-recurring**.

### Examples

```
√2
√5
π
```

---

# 4. Prime Numbers

A **prime number** is a natural number greater than **1** that has exactly **two factors**:

- 1
- Itself

### Examples

```
2, 3, 5, 7, 11, 13
```

---

# 5. Composite Numbers

A **composite number** has more than two factors.

### Examples

```
4, 6, 8, 9, 10
```

---

# 6. Prime Factorization

Prime factorization means expressing a number as the product of its prime factors.

### Example

Find the prime factorization of **84**.

```
84 = 2 × 42
```

```
42 = 2 × 21
```

```
21 = 3 × 7
```

Therefore,

```
84 = 2² × 3 × 7
```

---

# 7. Fundamental Theorem of Arithmetic

## Statement

> **Every composite number can be expressed as a product of prime numbers, and this factorization is unique except for the order of the prime factors.**

### Example

```
60
```

Prime factorization:

```
60 = 2² × 3 × 5
```

No other set of prime factors can represent **60**.

---

# 8. Highest Common Factor (HCF)

The **Highest Common Factor (HCF)** is the greatest number that divides two or more numbers exactly.

### Method: Prime Factorization

### Example

Find the HCF of **36** and **48**.

Prime factorization:

```
36 = 2² × 3²
```

```
48 = 2⁴ × 3
```

Take the common factors with the **smallest powers**.

```
HCF = 2² × 3
```

```
= 12
```

---

# 9. Lowest Common Multiple (LCM)

The **Lowest Common Multiple (LCM)** is the smallest positive number that is exactly divisible by all the given numbers.

### Method: Prime Factorization

### Example

Find the LCM of **36** and **48**.

Prime factorization:

```
36 = 2² × 3²
```

```
48 = 2⁴ × 3
```

Take all prime factors with the **greatest powers**.

```
LCM = 2⁴ × 3²
```

```
= 16 × 9
```

```
= 144
```

---

# 10. Relationship Between HCF and LCM

For any two positive integers,

```
HCF × LCM
=
Product of the Numbers
```

or

```
HCF × LCM = a × b
```

### Example

Numbers:

```
12 and 18
```

```
HCF = 6
```

```
LCM = 36
```

Verification:

```
6 × 36 = 216
```

```
12 × 18 = 216
```

Hence verified.

# 12. Condition for Terminating Decimal Expansion

Suppose

```
p/q
```

is in its lowest form.

Its decimal expansion terminates **only if** the prime factors of **q** are **2** and/or **5**.

### Examples

```
3/20
```

```
20 = 2² × 5
```

Terminating decimal.

---

```
7/18
```

```
18 = 2 × 3²
```

Since **3** is present,

```
Non-terminating recurring decimal.
```

# 13. Proving √2 is Irrational

## Theorem

**√2 is an irrational number.**

### Proof (By Contradiction)

Assume

```
√2 = p/q
```

where

- **p** and **q** are integers.
- They have no common factor.

Squaring both sides,

```
2 = p²/q²
```

```
p² = 2q²
```

Therefore,

```
p²
```

is even.

Hence,

```
p
```

is also even.

Let

```
p = 2k
```

Substitute:

```
(2k)² = 2q²
```

```
4k² = 2q²
```

```
q² = 2k²
```

Thus,

```
q
```

is also even.

Therefore, both **p** and **q** are even.

This contradicts the assumption that **p** and **q** have no common factor.

Hence,

```
√2 is irrational.
```

The same method can be used to prove that **√3**, **√5**, and other non-perfect square roots are irrational.

# Common Mistakes

- Confusing **prime numbers** with **odd numbers** (2 is the only even prime number).
- Forgetting to write numbers in **lowest form** before checking decimal expansion.
- Taking the **largest powers** while finding the HCF instead of the smallest powers.
- Taking the **smallest powers** while finding the LCM instead of the largest powers.
- Assuming every non-terminating decimal is irrational (recurring decimals are rational).
- Missing the contradiction step while proving **√2** is irrational.
- Forgetting that the **Fundamental Theorem of Arithmetic** applies only to **composite numbers**.

# Chapter Summary

- **Real numbers** include both **rational** and **irrational** numbers.
- A **rational number** can be expressed in the form **p/q**, while an **irrational number** cannot.
- Every composite number has a **unique prime factorization**, according to the **Fundamental Theorem of Arithmetic**.
- The **HCF** is found by taking the common prime factors with the **smallest powers**, whereas the **LCM** is found by taking all prime factors with the **greatest powers**.
- For any two positive integers, **HCF × LCM = Product of the numbers**.
- A rational number has a **terminating decimal expansion** only if, in its lowest form, the denominator has no prime factors other than **2** and/or **5**.
- Numbers such as **√2**, **√3**, and **√5** are **irrational**, and this can be proved using the method of contradiction.
- Understanding prime factorization and the properties of real numbers forms the foundation for many advanced mathematical concepts.

# Introduction

A **polynomial** is an algebraic expression consisting of variables and constants combined using addition, subtraction, and multiplication, where the exponents of the variables are non-negative integers.

Polynomials are used in algebra, geometry, physics, economics, and engineering. This chapter explains the **zeroes of polynomials**, their **geometrical meaning**, the relationship between the **zeroes and coefficients of quadratic polynomials**, and methods for finding the **sum** and **product** of roots.

---

# 1. Polynomial

A **polynomial** in one variable is an expression of the form

```
aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀
```

where:

- **a₀, a₁, ..., aₙ** are constants.
- **aₙ ≠ 0**
- The exponents are whole numbers.

### Examples

```
3x² + 5x + 2
```

```
x³ - 4x + 7
```

```
5
```

---

# 2. Degree of a Polynomial

The **degree** of a polynomial is the highest power of the variable.

### Examples

| Polynomial    | Degree |
| ------------- | ------ |
| `5`           | 0      |
| `2x + 3`      | 1      |
| `x² - 4`      | 2      |
| `4x³ + x - 1` | 3      |

---

# 3. Types of Polynomials Based on Degree

| Degree | Name                 |
| ------ | -------------------- |
| 0      | Constant Polynomial  |
| 1      | Linear Polynomial    |
| 2      | Quadratic Polynomial |
| 3      | Cubic Polynomial     |

### Examples

Linear:

```
2x + 5
```

Quadratic:

```
x² + 3x + 2
```

Cubic:

```
x³ - 4x + 1
```

---

# 4. Zeroes of a Polynomial

A **zero** (or root) of a polynomial is the value of the variable that makes the polynomial equal to zero.

If

```
p(x) = 0
```

then **x** is called a zero of the polynomial.

### Example

Find the zero of

```
p(x) = x - 5
```

```
x - 5 = 0
```

```
x = 5
```

Hence,

```
5
```

is the zero.

---

# 5. Geometrical Meaning of Zeroes

The zeroes of a polynomial are the **x-coordinates** of the points where its graph intersects the **x-axis**.

### Cases

### One Zero

The graph cuts the x-axis at one point.

```
      |
      |
------●---------
      |
      |
```

Number of zeroes = **1**

---

### Two Zeroes

The graph cuts the x-axis at two points.

```
     ∪
----●---●-------
```

Number of zeroes = **2**

---

### Three Zeroes

The graph cuts the x-axis at three points.

```
   /\
--●--●--●------
```

Number of zeroes = **3**

---

### No Real Zero

The graph does not touch the x-axis.

```
     ∪
------------
```

Number of real zeroes = **0**

---

# 6. Number of Zeroes from Graphs

The number of zeroes of a polynomial is equal to the number of times its graph intersects the x-axis.

| Graph                 | Number of Zeroes |
| --------------------- | ---------------- |
| Does not touch x-axis | 0                |
| Touches once          | 1                |
| Cuts twice            | 2                |
| Cuts three times      | 3                |

# Introduction

A **pair of linear equations in two variables** consists of two linear equations involving the same two variables. These equations represent two straight lines on a graph. The solution of the pair is the point where the two lines intersect.

This chapter explains the **graphical method**, **substitution method**, **elimination method**, conditions for **consistent** and **inconsistent** systems, and their applications in solving real-life problems.

---

# 1. Linear Equation in Two Variables

A **linear equation in two variables** is an equation of the form

```
ax + by + c = 0
```

where

- **a, b, c** are real numbers.
- **a** and **b** are not both zero.

### Examples

```
2x + 3y = 12
```

```
x - y = 4
```

---

# 2. Pair of Linear Equations

A pair of linear equations is written as

```
a₁x + b₁y + c₁ = 0
```

```
a₂x + b₂y + c₂ = 0
```

The solution is the ordered pair

```
(x, y)
```

that satisfies both equations.

---

# 3. Graphical Representation

Each linear equation represents a **straight line**.

The solution depends on the position of the two lines.

---

## Case 1: Intersecting Lines

The lines intersect at one point.

```
\     /
 \   /
  \ /
  / \
 /   \
```

### Result

- One unique solution.
- The equations are **consistent**.

---

## Case 2: Parallel Lines

The lines never meet.

```
---------
---------
```

### Result

- No solution.
- The equations are **inconsistent**.

---

## Case 3: Coincident Lines

Both equations represent the same line.

```
---------
```

### Result

- Infinitely many solutions.
- The equations are **consistent** and **dependent**.

---

# 4. Conditions for Consistency

For the equations

```
a₁x + b₁y + c₁ = 0
```

```
a₂x + b₂y + c₂ = 0
```

### Unique Solution

```
a₁/a₂ ≠ b₁/b₂
```

The lines intersect.

---

### No Solution

```
a₁/a₂ = b₁/b₂ ≠ c₁/c₂
```

The lines are parallel.

---

### Infinitely Many Solutions

```
a₁/a₂ = b₁/b₂ = c₁/c₂
```

The lines coincide.

---

# 5. Graphical Method of Solving

### Steps

1. Convert each equation into a convenient form.
2. Find at least two points for each equation.
3. Plot the points on graph paper.
4. Draw the straight lines.
5. Identify the point of intersection.

### Example

Solve graphically:

```
x + y = 5
```

```
x - y = 1
```

Adding the equations,

```
2x = 6
```

```
x = 3
```

Substitute in

```
x + y = 5
```

```
3 + y = 5
```

```
y = 2
```

Solution

```
(3, 2)
```

---

# 6. Substitution Method

One variable is expressed in terms of the other and substituted into the second equation.

### Steps

1. Express one variable from one equation.
2. Substitute into the second equation.
3. Solve for one variable.
4. Find the other variable.

---

### Example

Solve

```
x + y = 8
```

```
x - y = 2
```

From the first equation,

```
x = 8 - y
```

Substitute into the second equation,

```
8 - y - y = 2
```

```
8 - 2y = 2
```

```
2y = 6
```

```
y = 3
```

```
x = 5
```

Solution

```
(5, 3)
```

---

# 7. Elimination Method

In this method, one variable is eliminated by adding or subtracting the equations.

### Steps

1. Make the coefficients of one variable equal.
2. Add or subtract the equations.
3. Solve for one variable.
4. Substitute to obtain the second variable.

---

### Example

Solve

```
2x + y = 8
```

```
3x - y = 7
```

Add the equations,

```
5x = 15
```

```
x = 3
```

Substitute into

```
2x + y = 8
```

```
6 + y = 8
```

```
y = 2
```

Solution

```
(3, 2)
```

---

# 8. Verification of Solution

After solving,

Substitute the values of

```
x
```

and

```
y
```

into both equations.

If both equations are satisfied, the solution is correct.

            ↓

```

```

### Formula

x = ----------------------

```

```
          (my₂ + ny₁)
y = ----------------------
             (m + n)
```

Therefore,

```
P
=
(
(mx₂ + nx₁)/(m+n),
(my₂ + ny₁)/(m+n)
)
```

# Introduction

Triangles are one of the most important geometrical figures. In this chapter, we study the **similarity of triangles**, the **Basic Proportionality Theorem (BPT)**, its proof, and the criteria for similarity such as **AAA**, **SAS**, and **SSS**. These concepts are widely used in geometry, surveying, architecture, engineering, and trigonometry.

---

# 1. Similar Figures

Two figures are said to be **similar** if:

- Their corresponding angles are equal.
- Their corresponding sides are proportional.

### Example

Two squares of different sizes are similar because:

- All angles are **90°**.
- Corresponding sides are proportional.

---

# 2. Similar Triangles

Two triangles are said to be **similar** if:

- Their corresponding angles are equal.
- Their corresponding sides are in the same ratio.

### Notation

```
△ABC ∼ △DEF
```

This means

```
∠A = ∠D
```

```
∠B = ∠E
```

```
∠C = ∠F
```

and

```
AB/DE = BC/EF = AC/DF
```

---

# 3. Basic Proportionality Theorem (BPT)

### Statement

> **If a line is drawn parallel to one side of a triangle to intersect the other two sides, then it divides those two sides in the same ratio.**

### Figure

```
        A
       /\
      /  \
     D----E
    /      \
   /        \
  B----------C

DE || BC
```

Then,

```
AD/DB = AE/EC
```

---

# 4. Proof of the Basic Proportionality Theorem

### Given

In

```
△ABC
```

```
DE || BC
```

where

- D lies on AB.
- E lies on AC.

### To Prove

```
AD/DB = AE/EC
```

### Proof

Since

```
DE || BC
```

Triangles

```
△ADE
```

and

```
△BDE
```

have the same altitude from point **E**.

Therefore,

```
Area(△ADE)
-----------
Area(△BDE)

=

AD
---
DB
```

Similarly,

Triangles

```
△ADE
```

and

```
△CDE
```

have the same altitude from point **D**.

Therefore,

```
Area(△ADE)
-----------
Area(△CDE)

=

AE
---
EC
```

Since triangles

```
△BDE
```

and

```
△CDE
```

have the same base **DE** and lie between the same parallels,

```
Area(△BDE)
=
Area(△CDE)
```

Hence,

```
AD/DB = AE/EC
```

Therefore,

```
Basic Proportionality Theorem is proved.
```

---

# 5. Converse of the Basic Proportionality Theorem

### Statement

> **If a line divides any two sides of a triangle in the same ratio, then the line is parallel to the third side.**

If

```
AD/DB = AE/EC
```

then

```
DE || BC
```

---

# 6. AAA Similarity Criterion

### Statement

> **If the corresponding angles of two triangles are equal, then the triangles are similar.**

### Condition

```
∠A = ∠D
```

```
∠B = ∠E
```

```
∠C = ∠F
```

Then,

```
△ABC ∼ △DEF
```

### Result

Corresponding sides are proportional.

```
AB/DE = BC/EF = AC/DF
```

---

# 7. SAS Similarity Criterion

### Statement

> **If one angle of a triangle is equal to one angle of another triangle and the sides including those angles are proportional, then the triangles are similar.**

### Condition

```
∠A = ∠D
```

and

```
AB/DE = AC/DF
```

Then,

```
△ABC ∼ △DEF
```

---

# 8. SSS Similarity Criterion

### Statement

> **If the corresponding sides of two triangles are proportional, then the triangles are similar.**

### Condition

```
AB/DE = BC/EF = AC/DF
```

Then,

```
△ABC ∼ △DEF
```

- The **ratio of the areas** of similar triangles is equal to the **square of the ratio of their corresponding sides**.
- Similarity is widely used in geometry, surveying, architecture, engineering, and in measuring inaccessible distances and heights.

# Introduction

A **circle** is a simple closed curve consisting of all points in a plane that are at a fixed distance from a fixed point called the **centre**. This chapter focuses on the properties of **tangents** to a circle and the relationship between the radius and the tangent. These concepts are useful in geometry, engineering, architecture, and design.

---

# 1. Circle

A **circle** is the set of all points in a plane that are at the same distance from a fixed point.

### Parts of a Circle

- **Centre** – Fixed point of the circle.
- **Radius** – Line segment joining the centre to any point on the circle.
- **Diameter** – Chord passing through the centre.
- **Chord** – Line segment joining any two points on the circle.
- **Arc** – A part of the circumference.
- **Circumference** – Boundary of the circle.

### Figure

```
          A
      *-------*
    *           *
   *      O      *
    *           *
      *-------*
          B
```

Here,

- O = Centre
- OA = Radius
- AB = Diameter (if it passes through O)

---

# 2. Tangent to a Circle

A **tangent** is a straight line that touches a circle at exactly one point.

The point where the tangent touches the circle is called the **point of contact**.

### Figure

```
          |
          |
----------P----------
         /
      ( O )
```

- O = Centre
- P = Point of contact
- The horizontal line is the tangent.

---

# 3. Secant

A **secant** is a line that intersects the circle at two distinct points.

### Figure

```
      *---------*
    *             *
---*---------------*---
    *             *
      *---------*
```

The line cuts the circle at two points.

---

# 4. Number of Tangents from a Point

The number of tangents depends on the position of the point.

| Position of Point  | Number of Tangents |
| ------------------ | ------------------ |
| Inside the circle  | 0                  |
| On the circle      | 1                  |
| Outside the circle | 2                  |

---

# 5. Tangent is Perpendicular to the Radius

### Theorem

> **The tangent at any point of a circle is perpendicular to the radius through the point of contact.**

### Figure

```
           Tangent
----------------P
                |
                |
                |
                O
```

Here,

```
OP ⟂ Tangent
```

Therefore,

```
∠OPT = 90°
```

---

# 6. Proof of the Theorem

### Given

- O is the centre of the circle.
- PT is the tangent.
- P is the point of contact.

### To Prove

```
OP ⟂ PT
```

### Proof

Suppose the tangent is **not** perpendicular to the radius.

Then another point on the tangent would lie closer to the centre than point P.

This point would lie inside the circle, which means the tangent would intersect the circle at another point.

This contradicts the definition of a tangent, which touches the circle at only one point.

Hence,

```
OP ⟂ PT
```

Therefore,

```
The radius through the point of contact is perpendicular to the tangent.
```

---

# 7. Converse of the Theorem

### Statement

> **A line drawn perpendicular to the radius of a circle at its outer endpoint is a tangent to the circle.**

If

```
OP ⟂ PT
```

and

```
P
```

lies on the circle,

then

```
PT
```

is a tangent.

---

# 8. Lengths of Tangents from an External Point

### Theorem

> **The lengths of two tangents drawn from an external point to a circle are equal.**

### Figure

```
          A
         / \
        /   \
       P     O
        \   /
         \ /
          B
```

From external point

```
P
```

Tangents

```
PA
```

and

```
PB
```

are drawn.

Then,

```
PA = PB
```

---

# 9. Proof of Equal Tangents

### Given

- PA and PB are tangents.
- O is the centre.

### Proof

Join

```
OA
```

```
OB
```

and

```
OP
```

Since the radius is perpendicular to the tangent,

```
OA ⟂ PA
```

```
OB ⟂ PB
```

In right triangles

```
△OAP
```

and

```
△OBP
```

- OA = OB (Radii)
- OP = OP (Common side)
- Right angles are equal.

Therefore,

```
△OAP ≅ △OBP
```

(RHS Congruence)

Hence,

```
PA = PB
```

---

Tangents are used in:

- Construction of roads.
- Circular tracks.
- Mechanical engineering.
- Wheel design.
- Architecture.
- Satellite communication.
- Optics.

- Confusing a **tangent** with a **secant**.
- Assuming a tangent cuts the circle at two points.

- A **circle** is the set of all points at a fixed distance from a fixed point called the **centre**.

- A **secant** intersects the circle at **two points**.
- A point **inside** the circle has **no tangents**, a point **on** the circle has **one tangent**, and a point **outside** the circle has **two tangents**.

- Properties of tangents are widely used in geometry, engineering, architecture, transportation, and various scientific applications.

# Introduction

**Trigonometry** is the branch of mathematics that studies the relationship between the angles and sides of a triangle. The word _Trigonometry_ is derived from the Greek words:

- Using trigonometric identities without checking the correct formula.
- Assuming that **tan 90°** or **sec 90°** is equal to zero; both are **not defined**.
- Mixing up complementary angle identities, such as `sin(90° − θ)` and `cos(90° − θ)`.
- Forgetting to simplify surds correctly while evaluating expressions.

# Chapter Summary

- **Trigonometry** studies the relationship between the angles and sides of a right-angled triangle.
- The six trigonometric ratios are **sin, cos, tan, cosec, sec,** and **cot**.
- The ratios are defined using the **perpendicular**, **base**, and **hypotenuse** of a right triangle.
- The trigonometric ratios of the standard angles **0°, 30°, 45°, 60°,** and **90°** are important and should be memorized.
- The reciprocal relationships connect **sin–cosec**, **cos–sec**, and **tan–cot**.
- The three fundamental identities are:
  - `sin²θ + cos²θ = 1`
  - `1 + tan²θ = sec²θ`
  - `1 + cot²θ = cosec²θ`
- Complementary angle identities simplify many trigonometric expressions.
- Trigonometry has extensive applications in surveying, navigation, astronomy, engineering, architecture, and science.

| Cube                 | TSA = `6a²`, LSA = `4a²`                   | `a³`        |
| Cuboid               | TSA = `2(lb + bh + hl)`, LSA = `2h(l + b)` | `lbh`       |
| Cylinder             | CSA = `2πrh`, TSA = `2πr(r+h)`             | `πr²h`      |
| Cone                 | CSA = `πrl`, TSA = `πr(l+r)`               | `(1/3)πr²h` |
| Sphere               | `4πr²`                                     | `(4/3)πr³`  |
| Hemisphere           | CSA = `2πr²`, TSA = `3πr²`                 | `(2/3)πr³`  |
| Slant Height of Cone | `l = √(r² + h²)`                           |

---

# Chapter Summary

- Three-dimensional solids such as **cubes, cuboids, cylinders, cones, spheres,** and **hemispheres** have measurable **surface areas** and **volumes**.
- The **surface area** represents the total area covered by the outer surfaces of a solid.
- The **volume** represents the space occupied by a solid.
- Different solids have different formulas for calculating their **Curved Surface Area (CSA)**, **Lateral Surface Area (LSA)**, **Total Surface Area (TSA)**, and **Volume**.
- The **slant height** of a cone is found using the Pythagoras Theorem.
- In conversion (melting and recasting) problems, the **volume remains unchanged**.
- Complex objects can be divided into combinations of simple solids to calculate their total surface area or volume.
- Surface area and volume concepts are widely used in engineering, architecture, packaging, manufacturing, construction, and storage design.

# Introduction

**Statistics** is the branch of mathematics that deals with the **collection, organization, presentation, analysis, and interpretation of data**. In this chapter, we learn how to determine the **mean**, **median**, and **mode** of grouped data, construct cumulative frequency tables, draw **ogives**, and understand the empirical relationship among the three measures of central tendency.

---

# 1. Data

**Data** is a collection of facts or numerical information gathered for a specific purpose.

### Types of Data

- **Ungrouped Data** – Individual observations are listed separately.
- **Grouped Data** – Observations are arranged into class intervals.

### Example

**Ungrouped Data**

```
12, 15, 18, 20, 22
```

**Grouped Data**

| Class Interval | Frequency |
| -------------- | --------: |
| 10–20          |         6 |
| 20–30          |         9 |
| 30–40          |         5 |

---

# 2. Frequency Distribution

A **frequency distribution table** shows how many observations fall into each class interval.

### Example

| Marks | Frequency |
| ----- | --------: |
| 0–10  |         2 |
| 10–20 |         5 |
| 20–30 |         8 |
| 30–40 |         6 |

---

# 3. Class Interval

A **class interval** is the range of values included in one class.

### Example

```
20–30
```

Here,

- Lower limit = 20
- Upper limit = 30

---

# 4. Class Mark

The **class mark** is the midpoint of a class interval.

### Formula

```
Class Mark

=

(Lower Limit + Upper Limit)/2
```

### Example

Find the class mark of

```
20–30
```

**Solution**

```
= (20 + 30)/2
```

```

# 5. Mean of Grouped Data

The **mean** is the average value of the observations.

There are three methods to calculate the mean:

- Direct Method
- Assumed Mean Method
- Step Deviation Method

---

## (A) Direct Method

### Formula

```
Mean

=

Σ(fx) / Σf
```

where

- **f** = Frequency
- **x** = Class mark

---

### Example

|   x |   f |  fx |
| --: | --: | --: |
|  10 |   2 |  20 |
|  20 |   3 |  60 |
|  30 |   5 | 150 |

```
Σf = 10
```

```
Σfx = 230
```

Mean

```
= 230/10
```

```
= 23
```

---

## (B) Assumed Mean Method

Choose an assumed mean

```
A
```

Let

```
d = x − A
```

### Formula

```
Mean

=

A + (Σfd / Σf)
```

---

## (C) Step Deviation Method

Let

```
u = (x − A)/h
```

where

```
h
```

is the common class size.

### Formula

```
Mean

=

A + (Σfu / Σf) × h
```

---

# 6. Median

The **median** is the middle value of a distribution.

For grouped data,

### Formula

```
Median

=

l + [(N/2 − cf)/f] × h
```

where

- **l** = Lower boundary of the median class
- **N** = Total frequency
- **cf** = Cumulative frequency before the median class
- **f** = Frequency of the median class
- **h** = Class width

---

# 7. Cumulative Frequency

The **cumulative frequency** is obtained by adding frequencies successively.

### Example

| Frequency | Cumulative Frequency |
| --------: | -------------------: |
|         4 |                    4 |
|         6 |                   10 |
|         8 |                   18 |
|         5 |                   23 |

---

# 8. Mode

The **mode** is the value that occurs most frequently.

For grouped data,

### Formula

```
Mode

=

l + [(f₁ − f₀)/(2f₁ − f₀ − f₂)] × h
```

where

- **l** = Lower boundary of the modal class
- **f₁** = Frequency of the modal class
- **f₀** = Frequency of the class preceding the modal class
- **f₂** = Frequency of the class succeeding the modal class
- **h** = Class width

---

# 9. Empirical Relationship

When the distribution is moderately symmetrical,

### Formula

```
Mode

=

3 × Median − 2 × Mean
```

or

```
Mean − Mode

=

3(Mean − Median)
```

---

# 10. Ogive (Cumulative Frequency Curve)

An **ogive** is the graph of cumulative frequencies.

Types:

- Less Than Ogive
- More Than Ogive

The point where the two ogives intersect gives the

```
Median.
```
