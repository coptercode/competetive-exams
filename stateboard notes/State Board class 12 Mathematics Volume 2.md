# Introduction

Differential calculus studies the rate of change of quantities.

Applications of derivatives help us to:

- Find maximum and minimum values
- Study increasing and decreasing functions
- Determine tangent behaviour
- Analyse curves
- Solve optimisation problems

---

# 1. Rate of Change

If:

\[
y=f(x)
\]

then the rate of change of y with respect to x is:

\[
\boxed{
\frac{dy}{dx}
}
\]

---

# 2. Increasing and Decreasing Functions

A function is studied using its first derivative.

---

# Increasing Function

A function is increasing in an interval if:

\[
\boxed{
f'(x)>0
}
\]

---

# Decreasing Function

A function is decreasing in an interval if:

\[
\boxed{
f'(x)<0
}
\]

---

# 3. Critical Points

## Definition

A point where:

\[
\boxed{
f'(x)=0
}
\]

or derivative does not exist is called a critical point.

---

Critical points are used to find:

- Maximum values
- Minimum values
- Points of inflection

---

# 4. Mean Value Theorems

Mean Value Theorems connect the value of a function at two points with its derivative at an intermediate point.

Two important theorems:

1. Rolle's Theorem
2. Lagrange's Mean Value Theorem

---

# 5. Rolle's Theorem

## Statement

If a function f(x) satisfies:

### Condition 1:

f(x) is continuous in:

\[
[a,b]
\]

---

### Condition 2:

f(x) is differentiable in:

\[
(a,b)
\]

---

### Condition 3:

\[
\boxed{
f(a)=f(b)
}
\]

---

Then there exists at least one point:

\[
c\in(a,b)
\]

such that:

\[
\boxed{
f'(c)=0
}
\]

---

# Geometrical Meaning

The tangent at some point between a and b becomes parallel to the x-axis.

---

# Example

Verify Rolle's theorem for:

\[
f(x)=x^2-4x+3
\]

in:

\[
[1,3]
\]

---

Check:

\[
f(1)=0
\]

\[
f(3)=0
\]

Conditions satisfied.

Derivative:

\[
f'(x)=2x-4
\]

For Rolle's theorem:

\[
f'(c)=0
\]

\[
2c-4=0
\]

\[
\boxed{c=2}
\]

---

# 6. Lagrange's Mean Value Theorem (LMVT)

## Statement

If f(x) is:

1. Continuous in:

\[
[a,b]
\]

2. Differentiable in:

\[
(a,b)
\]

then there exists:

\[
c\in(a,b)
\]

such that:

\[
\boxed{
f'(c)=
\frac{f(b)-f(a)}{b-a}
}
\]

---

# Geometrical Meaning

There exists a point where:

\[
\text{tangent slope}
=

\text{chord slope}
\]

---

# 7. Extrema of Functions

## Definition

The maximum or minimum values of a function are called extrema.

Types:

1. Local maximum
2. Local minimum
3. Absolute maximum
4. Absolute minimum

---

# 8. Local Maximum

A function has local maximum at:

\[
x=a
\]

if:

\[
f(a)>f(x)
\]

for nearby values of x.

---

Condition:

\[
\boxed{
f'(a)=0
}
\]

and:

\[
\boxed{
f''(a)<0
}
\]

---

# 9. Local Minimum

A function has local minimum at:

\[
x=a
\]

if:

\[
f(a)<f(x)
\]

for nearby values.

---

Condition:

\[
\boxed{
f'(a)=0
}
\]

and:

\[
\boxed{
f''(a)>0
}
\]

---

# 10. First Derivative Test

Steps:

### Step 1

Find:

\[
f'(x)=0
\]

---

### Step 2

Find critical points.

---

### Step 3

Check sign changes.

---

If:

\[
+\rightarrow-
\]

then:

\[
\boxed{\text{Maximum}}
\]

---

If:

\[
-\rightarrow+
\]

then:

\[
\boxed{\text{Minimum}}
\]

---

# 11. Second Derivative Test

At critical point:

\[
f'(a)=0
\]

---

## Case 1

If:

\[
\boxed{
f''(a)<0
}
\]

Function has maximum.

---

## Case 2

If:

\[
\boxed{
f''(a)>0
}
\]

Function has minimum.

---

## Case 3

If:

\[
f''(a)=0
\]

Test fails.

---

# 12. Concavity

Concavity describes the shape of a curve.

---

# Concave Upward

If:

\[
\boxed{
f''(x)>0
}
\]

Curve bends upward.

---

# Concave Downward

If:

\[
\boxed{
f''(x)<0
}
\]

Curve bends downward.

---

# 13. Point of Inflection

## Definition

A point where the curve changes its concavity is called a point of inflection.

---

Condition:

\[
\boxed{
f''(x)=0
}
\]

with change in sign of second derivative.

---

# Example

For:

\[
f(x)=x^3
\]

First derivative:

\[
f'(x)=3x^2
\]

Second derivative:

\[
f''(x)=6x
\]

At:

\[
x=0
\]

\[
f''(0)=0
\]

Concavity changes.

Therefore:

\[
\boxed{x=0\text{ is point of inflection}}
\]

---

# 14. Optimisation Problems

Differentiation helps find maximum or minimum values in real situations.

Applications:

- Maximum area
- Minimum cost
- Maximum profit
- Minimum distance

---

# Steps for Optimisation

### Step 1

Define the variable.

---

### Step 2

Form the required function.

---

### Step 3

Differentiate.

---

### Step 4

Set:

\[
f'(x)=0
\]

---

### Step 5

Use second derivative test.

---

# Important Formula Sheet

## Increasing Function

\[
f'(x)>0
\]

---

## Decreasing Function

\[
f'(x)<0
\]

---

## Critical Point

\[
f'(x)=0
\]

---

## Rolle's Theorem

\[
f'(c)=0
\]

---

## Lagrange Mean Value Theorem

\[
f'(c)=
\frac{f(b)-f(a)}{b-a}
\]

---

## Maximum Condition

\[
f'(a)=0,\quad f''(a)<0
\]

---

## Minimum Condition

\[
f'(a)=0,\quad f''(a)>0
\]

---

## Inflection Point

\[
f''(x)=0
\]

with sign change.

---

# Solved Examples

## Example 1

Find maximum/minimum of:

\[
f(x)=x^2-4x+5
\]

Derivative:

\[
f'(x)=2x-4
\]

Set:

\[
2x-4=0
\]

\[
x=2
\]

Second derivative:

\[
f''(x)=2
\]

Since:

\[
f''(2)>0
\]

minimum occurs.

Value:

\[
f(2)=4-8+5
\]

\[
\boxed{=1}
\]

Minimum value:

\[
\boxed{1}
\]

---

## Example 2

Find intervals where:

\[
f(x)=x^3
\]

is increasing.

Derivative:

\[
f'(x)=3x^2
\]

Since:

\[
3x^2\geq0
\]

function is increasing for:

\[
\boxed{(-\infty,\infty)}
\]

---

## Example 3

Verify Rolle's theorem for:

\[
f(x)=x^2-1
\]

in:

\[
[-1,1]
\]

Since:

\[
f(-1)=f(1)=0
\]

Derivative:

\[
f'(x)=2x
\]

\[
2c=0
\]

\[
\boxed{c=0}
\]

---

# Common Mistakes

- Forgetting continuity and differentiability conditions in Mean Value Theorems.
- Using second derivative test without checking:

\[
f'(x)=0
\]

- Confusing maximum with minimum.
- Assuming:

\[
f''(x)=0
\]

always gives inflection point.

- Forgetting sign change requirement for inflection points.
- Making errors in optimisation function formation.

---

# Chapter Summary

- Derivatives help study the behaviour of functions.
- Rolle's theorem states that a horizontal tangent exists when endpoint values are equal.
- Lagrange's theorem connects average and instantaneous rates of change.
- First and second derivatives help find maxima and minima.
- The second derivative determines concavity.
- Points of inflection occur when concavity changes.
- Differential calculus has major applications in optimisation problems.

\[
\boxed{
\text{Derivative is the tool for analysing change and optimisation.}
}
\]

# Introduction

Differential calculus deals with small changes in variables and functions.

This chapter introduces:

- Differentials
- Linear approximation
- Error estimation
- Partial derivatives
- Chain rule
- Euler's theorem for homogeneous functions

These concepts are widely used in:

- Physics
- Engineering
- Economics
- Statistics
- Computer science

---

# PART A: DIFFERENTIALS

---

# 1. Differential of a Function

If:

\[
y=f(x)
\]

then the differential of y is:

\[
\boxed{
dy=f'(x)dx
}
\]

where:

- \(dx\) = small change in x
- \(dy\) = corresponding change in y

---

# 2. Difference and Differential

Actual change:

\[
\Delta y=f(x+\Delta x)-f(x)
\]

---

Differential change:

\[
\boxed{
dy=f'(x)dx
}
\]

For very small changes:

\[
\boxed{
\Delta y\approx dy
}
\]

---

# 3. Rules of Differentials

---

## Constant Function

If:

\[
y=c
\]

then:

\[
\boxed{
dy=0
}
\]

---

## Sum Rule

If:

\[
y=u+v
\]

then:

\[
\boxed{
dy=du+dv
}
\]

---

## Product Rule

If:

\[
y=uv
\]

then:

\[
\boxed{
dy=u\,dv+v\,du
}
\]

---

## Quotient Rule

If:

\[
y=\frac uv
\]

then:

\[
\boxed{
dy=
\frac{vdu-udv}{v^2}
}
\]

---

# 4. Linear Approximation

## Definition

Linear approximation estimates the value of a function near a known point using tangent line.

---

For:

\[
y=f(x)
\]

near:

\[
x=a
\]

the approximation is:

\[
\boxed{
f(x)\approx f(a)+f'(a)(x-a)
}
\]

---

# Example

Approximate:

\[
\sqrt{4.1}
\]

Take:

\[
f(x)=\sqrt{x}
\]

Near:

\[
a=4
\]

\[
f(4)=2
\]

Derivative:

\[
f'(x)=\frac1{2\sqrt{x}}
\]

\[
f'(4)=\frac14
\]

Therefore:

\[
f(4.1)\approx2+\frac14(0.1)
\]

\[
\boxed{
\sqrt{4.1}\approx2.025
}
\]

---

# 5. Errors and Approximations

The difference between actual and measured value is called error.

---

# Absolute Error

\[
\boxed{
\text{Absolute Error}
=

|\text{True value}-\text{Measured value}|
}
\]

---

# Relative Error

\[
\boxed{
\frac{\text{Absolute Error}}
{\text{True Value}}
}
\]

---

# Percentage Error

\[
\boxed{
\text{Percentage Error}
=

\text{Relative Error}\times100
}
\]

---

# 6. Error Using Differentials

If:

\[
y=f(x)
\]

then:

\[
\boxed{
\Delta y\approx dy=f'(x)dx
}
\]

---

Relative error:

\[
\boxed{
\frac{dy}{y}
}
\]

---

Percentage error:

\[
\boxed{
\frac{dy}{y}\times100
}
\]

---

# PART B: PARTIAL DERIVATIVES

---

# 7. Functions of Several Variables

A function containing more than one independent variable is called a function of several variables.

Example:

\[
z=f(x,y)
\]

---

Here:

- x and y are independent variables.
- z depends on both.

---

# 8. Partial Derivative

## Definition

The derivative of a function with respect to one variable while keeping other variables constant is called partial derivative.

Symbol:

\[
\boxed{
\frac{\partial z}{\partial x}
}
\]

---

# 9. Partial Derivative with Respect to x

For:

\[
z=x^2y+xy^2
\]

Treat y as constant.

\[
\frac{\partial z}{\partial x}
=

2xy+y^2
\]

---

# 10. Partial Derivative with Respect to y

Treat x as constant.

\[
\frac{\partial z}{\partial y}
=

x^2+2xy
\]

---

# 11. Second Order Partial Derivatives

First derivatives can be differentiated again.

---

Example:

\[
z=x^3y^2
\]

First derivative:

\[
\frac{\partial z}{\partial x}
=

3x^2y^2
\]

Second derivative:

\[
\boxed{
\frac{\partial^2z}{\partial x^2}
=

6xy^2
}
\]

---

# 12. Mixed Partial Derivatives

Differentiating with respect to different variables.

---

Example:

\[
\frac{\partial^2z}{\partial x\partial y}
\]

---

For continuous functions:

\[
\boxed{
\frac{\partial^2z}{\partial x\partial y}
=

\frac{\partial^2z}{\partial y\partial x}
}
\]

---

# 13. Chain Rule for Partial Derivatives

If:

\[
z=f(x,y)
\]

and:

\[
x=x(t),\quad y=y(t)
\]

then:

\[
\boxed{
\frac{dz}{dt}
=

\frac{\partial z}{\partial x}
\frac{dx}{dt} +
\frac{\partial z}{\partial y}
\frac{dy}{dt}
}
\]

---

# Example

Given:

\[
z=x^2+y^2
\]

where:

\[
x=t^2,\ y=t
\]

---

Partial derivatives:

\[
\frac{\partial z}{\partial x}=2x
\]

\[
\frac{\partial z}{\partial y}=2y
\]

---

Therefore:

\[
\frac{dz}{dt}
=

2x(2t)+2y(1)
\]

Substitute:

\[
x=t^2,y=t
\]

\[
\boxed{
\frac{dz}{dt}=4t^3+2t
}
\]

---

# 14. Homogeneous Functions

## Definition

A function is homogeneous if every term has the same total degree.

---

Example:

\[
f(x,y)=x^2+2xy+y^2
\]

Degree:

\[
2
\]

Therefore homogeneous of degree 2.

---

# 15. Euler's Theorem on Homogeneous Functions

## Statement

If:

\[
z=f(x,y)
\]

is homogeneous of degree n, then:

\[
\boxed{
x\frac{\partial z}{\partial x} +
y\frac{\partial z}{\partial y}
=

nz
}
\]

---

# Example

Verify Euler theorem for:

\[
z=x^2+y^2
\]

Degree:

\[
n=2
\]

---

Partial derivatives:

\[
\frac{\partial z}{\partial x}=2x
\]

\[
\frac{\partial z}{\partial y}=2y
\]

---

Left side:

\[
x(2x)+y(2y)
\]

\[
=2x^2+2y^2
\]

\[
=2(x^2+y^2)
\]

\[
=2z
\]

Hence proved.

---

# Introduction

Integration is the inverse process of differentiation.

Applications of integration help us to find:

- Area under curves
- Area between two curves
- Volume of solids
- Surface measurements

---

# PART A: DEFINITE INTEGRALS

---

# 1. Definite Integral

## Definition

A definite integral is an integral with fixed limits.

It is written as:

\[
\boxed{
\int_a^b f(x)\,dx
}
\]

where:

- a = lower limit
- b = upper limit

---

# 2. Fundamental Theorem of Calculus

If:

\[
F'(x)=f(x)
\]

then:

\[
\boxed{
\int_a^b f(x)dx
=

F(b)-F(a)
}
\]

---

# 3. Properties of Definite Integrals

---

# Property 1

\[
\boxed{
\int_a^b f(x)dx
=

-\int_b^a f(x)dx
}
\]

---

# Property 2

\[
\boxed{
\int_a^a f(x)dx=0
}
\]

---

# Property 3

If:

\[
a<b<c
\]

then:

\[
\boxed{
\int_a^c f(x)dx
=

\int_a^b f(x)dx+
\int_b^c f(x)dx
}
\]

---

# Property 4

For symmetric limits:

\[
\boxed{
\int_{-a}^{a}f(x)dx
=

2\int_0^a f(x)dx
}
\]

when f(x) is even.

---

# Property 5

If f(x) is odd:

\[
\boxed{
\int_{-a}^{a}f(x)dx=0
}
\]

---

# 4. Even and Odd Functions

---

# Even Function

A function is even if:

\[
\boxed{
f(-x)=f(x)
}
\]

Example:

\[
x^2
\]

---

# Odd Function

A function is odd if:

\[
\boxed{
f(-x)=-f(x)
}
\]

Example:

\[
x^3
\]

---

# 5. Change of Variable in Definite Integration

If:

\[
x=g(t)
\]

then:

\[
dx=g'(t)dt
\]

Limits must also be changed.

---

# Example

Evaluate:

\[
\int_0^1 2x\,dx
\]

Integration:

\[
=x^2
\]

Limits:

\[
[0,1]
\]

Therefore:

\[
=1^2-0^2
\]

\[
\boxed{=1}
\]

---

# PART B: AREA USING INTEGRATION

---

# 6. Area Under a Curve

If a curve:

\[
y=f(x)
\]

lies above x-axis from:

\[
x=a\text{ to }x=b
\]

then:

\[
\boxed{
A=\int_a^b f(x)dx
}
\]

---

# 7. Area Between Two Curves

If:

Upper curve:

\[
y=f(x)
\]

Lower curve:

\[
y=g(x)
\]

then:

\[
\boxed{
A=
\int_a^b[f(x)-g(x)]dx
}
\]

---

# 8. Area with Respect to y-axis

If curves are written as:

\[
x=f(y)
\]

then:

\[
\boxed{
A=
\int_c^d[x_{right}-x_{left}]dy
}
\]

---

# 9. Area Bounded by Straight Lines

For a line:

\[
y=mx+c
\]

area is found using:

\[
\boxed{
A=\int y\,dx
}
\]

---

# 10. Area of Circle

For circle:

\[
x^2+y^2=a^2
\]

Upper half:

\[
y=\sqrt{a^2-x^2}
\]

Area:

\[
A=
2\int_{-a}^{a}\sqrt{a^2-x^2}dx
\]

Result:

\[
\boxed{
A=\pi a^2
}
\]

---

# 11. Area of Parabola

For:

\[
y^2=4ax
\]

the area enclosed by latus rectum and parabola:

\[
\boxed{
\frac{8a^2}{3}
}
\]

---

When a curve rotates about an axis, it forms a solid.

# 13. Rotation About x-axis

When rotating about y-axis:

\boxed{

}

For radius:

\[
a
\]

\boxed{

\boxed{

Order:

\boxed{2}

# 17. Tautology

## Definition

A proposition that is always true is called a tautology.

---

Example:

\[
\boxed{
p\lor\neg p
}
\]

Truth table:

| p   | ¬p  | p∨¬p |
| --- | --- | ---- |
| T   | F   | T    |
| F   | T   | T    |

---

# 18. Contradiction

## Definition

A proposition that is always false is called a contradiction.

---

Example:

\[
\boxed{
p\land\neg p
}
\]

---

# 19. Logical Equivalence

Two statements are logically equivalent if they have the same truth values.

Symbol:

\[
\boxed{
p\equiv q
}
\]

---

# Important Logical Laws

---

# Identity Laws

\[
\boxed{
p\land T=p
}
\]

\[
\boxed{
p\lor F=p
}
\]

---

# Domination Laws

\[
\boxed{
p\lor T=T
}
\]

\[
\boxed{
p\land F=F
}
\]

---

# Idempotent Laws

\[
\boxed{
p\lor p=p
}
\]

\[
\boxed{
p\land p=p
}
\]

---

# Complement Laws

\[
\boxed{
p\lor\neg p=T
}
\]

\[
\boxed{
p\land\neg p=F
}
\]

---

# De Morgan's Laws

## First Law

\[
\boxed{
\neg(p\land q)=\neg p\lor\neg q
}
\]

---

## Second Law

\[
\boxed{
\neg(p\lor q)=\neg p\land\neg q
}
\]

---

# Comparison Tables

## Group vs Abelian Group

| Group                         | Abelian Group       |
| ----------------------------- | ------------------- |
| Has inverse                   | Has inverse         |
| May not be commutative        | Must be commutative |
| \(a*b\) may not equal \(b*a\) | \(a*b=b*a\)         |

---

## Tautology vs Contradiction

| Tautology         | Contradiction     |
| ----------------- | ----------------- |
| Always true       | Always false      |
| Truth value T     | Truth value F     |
| Example: \(p∨¬p\) | Example: \(p∧¬p\) |

# Solved Examples

## Example 1

Check whether subtraction is commutative.

Take:

\[
5-3=2
\]

but:

\[
3-5=-2
\]

Therefore:

\[
\boxed{\text{subtraction is not commutative}}
\]

---

## Example 2

Find identity element for multiplication.

Need:

\[
a*e=a
\]

For multiplication:

\[
a\times1=a
\]

Therefore:

\[
\boxed{e=1}
\]

## Example 4

Find inverse of 5 under addition.

Identity:

\[

\]

\[

# Common Mistakes

- Forgetting closure condition in binary operations.
- Confusing identity and inverse.
- Assuming every operation is commutative.
- Mixing logical AND and OR truth tables.
- Forgetting implication is false only when:

\[
T\rightarrow F
\]

- Confusing tautology with contradiction.
- Applying De Morgan's laws incorrectly.

---
