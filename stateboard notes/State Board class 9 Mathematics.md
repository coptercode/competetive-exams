> **Subject:** Mathematics  
> **Class:** 9  
> **Chapter:** Set Language

---

# Introduction

A set is one of the basic concepts in mathematics. It helps us group objects with common properties and perform operations on collections of objects.

This chapter covers:

- Definition of sets
- Set notation
- Types of sets
- Set operations
- Properties of set operations
- De Morgan's laws
- Cardinality of sets

---

# PART A: INTRODUCTION TO SETS

---

# 1. Set

## Definition

A set is a well-defined collection of distinct objects.

The objects in a set are called **elements** or **members**.

---

Example:

Set of vowels:

\[
A=\{a,e,i,o,u\}
\]

Here:

Elements of A are:

\[
a,e,i,o,u
\]

---

# 2. Representation of Sets

Sets can be represented in two ways:

1. Roster form
2. Set-builder form

---

# 3. Roster Form

## Definition

A set is represented by listing all its elements inside curly brackets.

---

Example:

\[
A=\{2,4,6,8\}
\]

---

# 4. Set-builder Form

## Definition

A set is represented by stating the common property of its elements.

---

Example:

\[
A=\{x:x\text{ is an even number less than }10\}
\]

---

# 5. Symbols Used in Sets

| Symbol | Meaning            |
| ------ | ------------------ |
| ∈      | Belongs to         |
| ∉      | Does not belong to |
| ⊂      | Subset             |
| ∪      | Union              |
| ∩      | Intersection       |
| ∅      | Empty set          |

---

Example:

If:

\[
A=\{1,2,3\}
\]

Then:

\[
2\in A
\]

and

\[
5\notin A
\]

---

# PART B: TYPES OF SETS

---

# 6. Empty Set

## Definition

A set having no elements is called an empty set.

---

Symbol:

\[
\boxed{\emptyset}
\]

---

Example:

\[
A=\{x:x\text{ is a natural number between 1 and 2}\}
\]

No such number exists.

Therefore:

\[
A=\emptyset
\]

---

# 7. Singleton Set

## Definition

A set containing only one element is called a singleton set.

---

Example:

\[
A=\{5\}
\]

---

# 8. Finite Set

## Definition

A set containing a limited number of elements is called a finite set.

---

Example:

\[
A=\{1,2,3,4\}
\]

---

# 9. Infinite Set

## Definition

A set containing unlimited elements is called an infinite set.

---

Example:

Natural numbers:

\[
N=\{1,2,3,4,...\}
\]

---

# 10. Equal Sets

## Definition

Two sets are equal if they contain exactly the same elements.

---

Example:

\[
A=\{1,2,3\}
\]

\[
B=\{3,2,1\}
\]

Therefore:

\[
\boxed{A=B}
\]

---

# 11. Universal Set

## Definition

The set containing all objects under consideration is called the universal set.

---

Symbol:

\[
\boxed{U}
\]

---

Example:

If considering numbers from 1 to 10:

\[
U=\{1,2,3,...,10\}
\]

---

# 12. Subset

## Definition

A set A is called a subset of B if every element of A is also an element of B.

---

Symbol:

\[
\boxed{A\subseteq B}
\]

---

Example:

\[
A=\{1,2\}
\]

\[
B=\{1,2,3,4\}
\]

Therefore:

\[
A\subseteq B
\]

---

# 13. Proper Subset

A subset that is not equal to the original set is called a proper subset.

---

Example:

\[
\{1,2\}\subset\{1,2,3\}
\]

---

# 14. Power Set

## Definition

The set containing all possible subsets of a set is called its power set.

---

Symbol:

\[
\boxed{P(A)}
\]

---

Example:

If:

\[
A=\{1,2\}
\]

Subsets:

\[
\emptyset,\{1\},\{2\},\{1,2\}
\]

Therefore:

\[
P(A)=
\{\emptyset,\{1\},\{2\},\{1,2\}\}
\]

---

Number of subsets:

\[
\boxed{
2^n
}
\]

where n = number of elements.

---

# PART C: SET OPERATIONS

---

# 15. Union of Sets

## Definition

The union of two sets contains all elements from both sets.

---

Symbol:

\[
\boxed{\cup}
\]

---

Formula:

\[
A\cup B
\]

---

Example:

\[
A=\{1,2,3\}
\]

\[
B=\{3,4,5\}
\]

Then:

\[
A\cup B=\{1,2,3,4,5\}
\]

---

# 16. Intersection of Sets

## Definition

The intersection of two sets contains only common elements.

---

Symbol:

\[
\boxed{\cap}
\]

---

Example:

\[
A\cap B=\{3\}
\]

---

# 17. Difference of Sets

## Definition

Elements present in one set but not in another set.

---

Formula:

\[
A-B
\]

---

Example:

\[
A=\{1,2,3\}
\]

\[
B=\{2,3,4\}
\]

Then:

\[
A-B=\{1\}
\]

---

# 18. Complement of a Set

## Definition

The complement of a set contains elements of the universal set that are not in the given set.

---

Formula:

\[
\boxed{
A'=U-A
}
\]

---

Example:

\[
U=\{1,2,3,4,5\}
\]

\[
A=\{1,2\}
\]

Then:

\[
A'=\{3,4,5\}
\]

---

# PART D: PROPERTIES OF SET OPERATIONS

---

# 19. Commutative Property

For union:

\[
\boxed{
A\cup B=B\cup A
}
\]

For intersection:

\[
\boxed{
A\cap B=B\cap A
}
\]

---

# 20. Associative Property

Union:

\[
(A\cup B)\cup C
=

A\cup(B\cup C)
\]

---

Intersection:

\[
(A\cap B)\cap C
=

A\cap(B\cap C)
\]

---

# 21. Distributive Property

Union over intersection:

\[
A\cup(B\cap C)
=

(A\cup B)\cap(A\cup C)
\]

---

Intersection over union:

\[
A\cap(B\cup C)
=

(A\cap B)\cup(A\cap C)
\]

---

# PART E: DE MORGAN'S LAWS

---

# 22. De Morgan's First Law

\[
\boxed{
(A\cup B)'=A'\cap B'
}
\]

---

Meaning:

Complement of union equals intersection of complements.

---

# 23. De Morgan's Second Law

\[
\boxed{
(A\cap B)'=A'\cup B'
}
\]

---

Meaning:

Complement of intersection equals union of complements.

---

# PART F: CARDINALITY OF SETS

---

# 24. Cardinality

## Definition

The number of elements in a set is called its cardinality.

---

Symbol:

\[
\boxed{n(A)}
\]

---

Example:

\[
A=\{1,2,3,4\}
\]

Therefore:

\[
n(A)=4
\]

---

# 25. Formula for Union of Two Sets

\[
\boxed{
n(A\cup B)
=

n(A)+n(B)-n(A\cap B)
}
\]

---

# Example

Given:

\[
n(A)=20
\]

\[
n(B)=15
\]

\[
n(A\cap B)=5
\]

Find:

\[
n(A\cup B)
\]

Solution:

\[
=20+15-5
\]

\[
\boxed{30}
\]

---

# Important Formula Sheet

## Number of subsets

\[
\boxed{
2^n
}
\]

---

## Complement

\[
\boxed{
A'=U-A
}
\]

---

## Union Cardinality

\[
\boxed{
n(A\cup B)
=

n(A)+n(B)-n(A\cap B)
}
\]

---

## De Morgan's Laws

\[
\boxed{
(A\cup B)'=A'\cap B'
}
\]

\[
\boxed{
(A\cap B)'=A'\cup B'
}
\]

---

# Common Mistakes

- Forgetting that sets contain distinct elements.
- Confusing union and intersection.
- Forgetting subtraction of common elements in cardinality formula.
- Mixing subset and element symbols.
- Forgetting empty set is a subset of every set.

---

# Chapter Summary

- A set is a collection of well-defined objects.
- Sets can be represented using roster and set-builder forms.
- Different types of sets include empty, finite, infinite and subsets.
- Set operations combine or compare sets.
- De Morgan's laws connect union, intersection and complements.
- Cardinality gives the number of elements in a set.

\[
\boxed{
\text{Set language provides the foundation for modern mathematics.}
}
\]

# Introduction

Real numbers are all numbers that can be represented on the number line.

This chapter covers:

- Rational and irrational numbers
- Real number system
- Laws of exponents
- Fractional exponents
- Scientific notation

---

# PART A: NUMBER SYSTEM

---

# 1. Natural Numbers

## Definition

Numbers used for counting are called natural numbers.

---

Set of natural numbers:

\[
\boxed{
N=\{1,2,3,4,5,\dots\}
}
\]

---

# 2. Whole Numbers

## Definition

Natural numbers together with zero are called whole numbers.

---

\[
\boxed{
W=\{0,1,2,3,4,\dots\}
}
\]

---

# 3. Integers

## Definition

Numbers containing positive numbers, negative numbers and zero are called integers.

---

\[
\boxed{
Z=\{\dots,-3,-2,-1,0,1,2,3,\dots\}
}
\]

---

# 4. Rational Numbers

## Definition

A number that can be expressed in the form:

\[
\boxed{
\frac pq
}
\]

where:

- p and q are integers
- q ≠ 0

is called a rational number.

---

Examples:

\[
\frac12,\frac{-3}{5},4
\]

---

Decimal expansion:

Rational numbers have:

- Terminating decimals

Example:

\[
\frac12=0.5
\]

- Non-terminating repeating decimals

Example:

\[
\frac13=0.333...
\]

---

# 5. Irrational Numbers

## Definition

Numbers that cannot be expressed as a ratio of two integers are called irrational numbers.

---

Examples:

\[
\sqrt2,\sqrt3,\pi
\]

---

Decimal expansion:

\[
\boxed{\text{Non-terminating and non-repeating}}
\]

---

# PART B: REAL NUMBERS

---

# 6. Real Numbers

## Definition

The collection of all rational and irrational numbers is called real numbers.

---

Symbol:

\[
\boxed R
\]

---

Relationship:

\[
\boxed{
\text{Real Numbers}
=

\text{Rational Numbers} +
\text{Irrational Numbers}
}
\]

---

# 7. Hierarchy of Real Numbers

\[
\boxed{
Natural
\subset
Whole
\subset
Integers
\subset
Rational
\subset
Real
}
\]

---

# PART C: REPRESENTATION ON NUMBER LINE

---

# 8. Number Line

A straight line on which numbers are represented according to their values is called a number line.

---

Properties:

- Positive numbers lie on right side of zero.
- Negative numbers lie on left side of zero.

---

# 9. Representation of Irrational Numbers

Example:

Representation of:

\[
\sqrt2
\]

Steps:

1. Draw a right-angled triangle with sides 1 unit.
2. Find hypotenuse using Pythagoras theorem.
3. Use compass to locate √2 on number line.

---

# PART D: LAWS OF EXPONENTS

---

# 10. Exponent

## Definition

An exponent shows how many times a number is multiplied by itself.

---

Example:

\[
2^3=2\times2\times2
\]

---

Here:

2 = base

3 = exponent

---

# 11. Laws of Exponents

---

# Law 1: Product of Powers

\[
\boxed{
a^m\times a^n=a^{m+n}
}
\]

---

Example:

\[
2^3\times2^2
\]

\[
=2^{3+2}
\]

\[
=2^5
\]

---

# Law 2: Division of Powers

\[
\boxed{
\frac{a^m}{a^n}=a^{m-n}
}
\]

---

Example:

\[
\frac{x^5}{x^2}=x^3
\]

---

# Law 3: Power of a Power

\[
\boxed{
(a^m)^n=a^{mn}
}
\]

---

Example:

\[
(2^3)^2=2^6
\]

---

# Law 4: Zero Exponent

\[
\boxed{
a^0=1
}
\]

where:

\[
a\neq0
\]

---

# Law 5: Negative Exponent

\[
\boxed{
a^{-n}=\frac1{a^n}
}
\]

---

Example:

\[
2^{-3}=\frac1{8}
\]

---

# PART E: FRACTIONAL EXPONENTS

---

# 12. Fractional Powers

Fractional exponents represent roots.

---

Formula:

\[
\boxed{
a^{\frac1n}=\sqrt[n]{a}
}
\]

---

Examples:

\[
16^{1/2}=\sqrt{16}=4
\]

---

# 13. General Fractional Exponent

\[
\boxed{
a^{\frac mn}
=

\sqrt[n]{a^m}
}
\]

---

Example:

\[
8^{2/3}
\]

\[
=(\sqrt[3]{8})^2
\]

\[
=2^2
\]

\[
=4
\]

---

# Introduction

Algebra is the branch of mathematics that uses letters and symbols to represent unknown quantities and relationships.

This chapter covers:

- Polynomials
- Types and degree of polynomials
- Operations on polynomials
- Factorisation
- Linear equations in two variables
- Simultaneous equations
- Linear inequalities

---

# PART A: POLYNOMIALS

---

# 1. Polynomial

## Definition

A polynomial is an algebraic expression containing variables and coefficients, where the powers of variables are whole numbers.

---

General form:

\[
\boxed{
a_nx^n+a_{n-1}x^{n-1}+...+a_1x+a_0
}
\]

---

Examples:

\[
3x^2+5x+2
\]

\[
x^3-4x+7
\]

---

# 2. Terms of a Polynomial

A polynomial consists of terms separated by addition or subtraction signs.

Example:

\[
5x^2+3x-7
\]

Terms:

\[
5x^2,\ 3x,\ -7
\]

---

# 3. Coefficient

## Definition

The numerical factor of a term is called its coefficient.

---

Example:

In:

\[
6x^2
\]

Coefficient:

\[
\boxed{6}
\]

---

# 4. Degree of a Polynomial

## Definition

The highest power of the variable in a polynomial is called its degree.

---

Examples:

\[
5x^3+2x+1
\]

Degree:

\[
\boxed{3}
\]

---

# 5. Types of Polynomials Based on Degree

| Degree | Name      | Example |
| ------ | --------- | ------- |
| 0      | Constant  | 5       |
| 1      | Linear    | x+2     |
| 2      | Quadratic | x²+3x+2 |
| 3      | Cubic     | x³+x+1  |

---

# 6. Types Based on Number of Terms

---

## Monomial

A polynomial with one term.

Example:

\[
5x
\]

---

## Binomial

A polynomial with two terms.

Example:

\[
x+3
\]

---

## Trinomial

A polynomial with three terms.

Example:

\[
x^2+2x+1
\]

---

# PART B: OPERATIONS ON POLYNOMIALS

---

# 7. Addition of Polynomials

Like terms are added together.

Example:

\[
(2x+3)+(5x+4)
\]

\[
=7x+7
\]

---

# 8. Subtraction of Polynomials

Change signs of the second polynomial and add.

Example:

\[
(5x+3)-(2x+1)
\]

\[
=5x+3-2x-1
\]

\[
\boxed{3x+2}
\]

---

# 9. Multiplication of Polynomials

Multiply every term of one polynomial with every term of another.

---

Example:

\[
(x+2)(x+3)
\]

\[
=x^2+3x+2x+6
\]

\[
\boxed{x^2+5x+6}
\]

---

# PART C: FACTORISATION

---

# 10. Factorisation

## Definition

Writing an algebraic expression as a product of its factors is called factorisation.

---

Example:

\[
x^2+5x+6
\]

Factors:

\[
(x+2)(x+3)
\]

---

# 11. Common Factor Method

Take the common factor outside.

Example:

\[
6x+12
\]

Common factor:

\[
6
\]

Therefore:

\[
\boxed{
6(x+2)
}
\]

---

# 12. Factorisation by Grouping

Example:

\[
ax+ay+bx+by
\]

Grouping:

\[
a(x+y)+b(x+y)
\]

Taking common factor:

\[
\boxed{(a+b)(x+y)}
\]

---

# 13. Quadratic Factorisation

Form:

\[
x^2+bx+c
\]

Find two numbers whose:

Sum = b

Product = c

---

Example:

\[
x^2+5x+6
\]

Numbers:

2 and 3

Therefore:

\[
\boxed{
(x+2)(x+3)
}
\]

---

# PART D: LINEAR EQUATIONS IN TWO VARIABLES

---

# 14. Linear Equation

## Definition

An equation involving two variables with highest power 1 is called a linear equation.

---

General form:

\[
\boxed{
ax+by+c=0
}
\]

---

Example:

\[
2x+3y=6
\]

---

# 15. Solution of Linear Equation

A pair of values of x and y satisfying the equation is called a solution.

---

Example:

For:

\[
x+y=5
\]

Possible solutions:

\[
(1,4),(2,3),(3,2)
\]

---

# 16. Graph of Linear Equation

Steps:

1. Find two or more solutions.
2. Plot points on coordinate plane.
3. Join the points.

The graph is a straight line.

---

# PART E: SIMULTANEOUS LINEAR EQUATIONS

---

Two equations containing the same variables are called simultaneous equations.

---

Example:

\[
x+y=5
\]

\[
x-y=1
\]

---

Methods of solving:

1. Substitution method
2. Elimination method
3. Graphical method

x+y=5
\]

x-y=1
\]

2x=6
\]

\[
x=3
\]

Then:

\[
y=2
\]

\[

\]

- Forgetting to combine only like terms.
- Confusing coefficient and power.
- Changing signs incorrectly during subtraction.
- Incorrect factor pairs in quadratic expressions.
- Reversing inequality signs during multiplication by negative numbers.

# Chapter Summary

- Polynomials contain variables and coefficients.
- Degree determines the type of polynomial.
- Factorisation expresses polynomials as products.
- Linear equations represent relationships between variables.

# 3. Line Segment

## Definition

A part of a line having two endpoints is called a line segment.

---

Symbol:

# 1. Area of Triangle

}

---

But when all three sides are known, Heron's formula is used.

---

# 2. Heron's Formula

## Definition

Heron's formula is used to find the area of a triangle when the lengths of all three sides are known.

---

Let sides of triangle be:

\[
a,\ b,\ c
\]

---

# 3. Semi-Perimeter

## Definition

Half of the perimeter of a triangle is called semi-perimeter.

---

Formula:

\[
\boxed{
s=\frac{a+b+c}{2}
}
\]

---

# 4. Heron's Formula

\[
\boxed{
Area=\sqrt{s(s-a)(s-b)(s-c)}
}
\]

---

Where:

s = semi-perimeter

a, b, c = sides of triangle

---

# Example

Find area of a triangle with sides:

\[
5cm,\ 6cm,\ 7cm
\]

---

Step 1:

Find semi-perimeter:

\[
s=\frac{5+6+7}{2}
\]

\[
s=\frac{18}{2}=9
\]

---

Step 2:

Apply Heron's formula:

\[
Area=\sqrt{9(9-5)(9-6)(9-7)}
\]

\[
=\sqrt{9\times4\times3\times2}
\]

\[
=\sqrt{216}
\]

\[
\boxed{Area=6\sqrt6\ cm^2}
\]

# 4. Secondary Data

# PART C: ARITHMETIC MEAN

---

# 8. Mean

## Definition

The average value of a set of observations is called arithmetic mean.

---

Formula for ungrouped data:

\[
\boxed{
Mean=\frac{\text{Sum of observations}}{\text{Number of observations}}
}
\]

---

Symbol:

\[
\boxed{\bar{x}}
\]

---

# 9. Mean of Ungrouped Data

Formula:

\[
\boxed{
\bar{x}=\frac{\sum x}{n}
}
\]

---

Where:

\[
\sum x=\text{sum of values}
\]

\[
n=\text{number of values}
\]

---

# Example

Find mean of:

\[

\]

\[

\]

\[
=\frac{32}{4}
\]

\[
\boxed{8}
\]

---

# PART D: MEAN OF GROUPED DATA

---

# 10. Mean Using Frequency

Formula:

\[
\boxed{
\bar{x}=\frac{\sum fx}{\sum f}
}
\]

---

Where:

f = frequency

x = observation

---

# Example

| x   | f   | fx  |
| --- | --- | --- |
| 2   | 3   | 6   |
| 4   | 2   | 8   |
| 6   | 5   | 30  |

\[
\sum f=10
\]

\[
\sum fx=44
\]

Mean:

\[
=\frac{44}{10}
\]

\[
\boxed{4.4}
\]

# Introduction

Probability is the branch of mathematics that deals with the chance or likelihood of occurrence of events.

This chapter covers:

- Random experiments
- Sample space
- Events
- Classical probability
- Experimental probability

---

# PART A: BASIC CONCEPTS OF PROBABILITY

---

# 1. Random Experiment

## Definition

An experiment whose outcome cannot be predicted with certainty before performing it is called a random experiment.

---

Examples:

- Tossing a coin
- Rolling a die
- Drawing a card

---

# 2. Outcome

## Definition

A possible result of a random experiment is called an outcome.

---

Example:

When a coin is tossed:

Possible outcomes:

\[
\boxed{H,T}
\]

---

# 3. Sample Space

## Definition

The set of all possible outcomes of a random experiment is called the sample space.

---

Symbol:

\[
\boxed{S}
\]

---

Example:

For tossing a coin:

\[
S=\{H,T\}
\]

---

For throwing a die:

\[
S=\{1,2,3,4,5,6\}
\]

---

# 4. Event

## Definition

A collection of one or more outcomes of a sample space is called an event.

---

Symbol:

\[
\boxed{E}
\]

---

Example:

Rolling an even number on a die:

\[
E=\{2,4,6\}
\]

---

# PART B: TYPES OF EVENTS

---

# 5. Simple Event

## Definition

An event containing only one outcome is called a simple event.

---

Example:

Getting 5 when a die is thrown.

\[
E=\{5\}
\]

---

# 6. Compound Event

## Definition

An event containing more than one outcome is called a compound event.

---

Example:

Getting an even number on a die.

\[
E=\{2,4,6\}
\]

---

# 7. Sure Event

## Definition

An event that always occurs is called a sure event.

---

Probability:

\[
\boxed{1}
\]

---

Example:

Getting a number between 1 and 6 when a die is thrown.

---

# 8. Impossible Event

## Definition

An event that can never occur is called an impossible event.

---

Probability:

\[
\boxed{0}
\]

---

Example:

Getting 7 on a normal die.

---

# PART C: CLASSICAL APPROACH TO PROBABILITY

---

# 9. Classical Probability

## Definition

Probability based on equally likely outcomes is called classical probability.

---

Formula:

\[
\boxed{
P(E)=
\frac{\text{Number of favourable outcomes}}
{\text{Total number of outcomes}}
}
\]

---

Where:

\[
0\leq P(E)\leq1
\]

---

# 10. Probability of an Event

If:

n(E) = number of favourable outcomes

n(S) = total number of outcomes

Then:

\[
\boxed{
P(E)=\frac{n(E)}{n(S)}
}
\]

---

# 15. Experimental Probability

Probability calculated from actual experiments is called experimental probability.

---

Formula:

---

Example:

Experimental probability:

\[
\boxed{0.55}

| ---------------------------- | --------------------------- |

| Uses equally likely outcomes | Uses observed results       |
| Calculated before experiment | Calculated after experiment |
