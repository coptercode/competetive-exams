# Introduction

Numbers are the foundation of mathematics. They are classified into different types based on their properties. The **Real Number System** consists of **Rational Numbers** and **Irrational Numbers**. This chapter explains their definitions, decimal representations, operations on surds, rationalization of denominators, proofs of irrationality, and representation of irrational numbers on the number line.

---

# 1. Real Number System

The **Real Number System** consists of all numbers that can be represented on the number line.

```
Real Numbers
│
├── Rational Numbers (Q)
│
└── Irrational Numbers
```

---

## Natural Numbers (N)

Counting numbers beginning from 1.

```
N = {1, 2, 3, 4, ...}
```

---

## Whole Numbers (W)

Natural numbers together with zero.

```
W = {0, 1, 2, 3, ...}
```

---

## Integers (Z)

Positive numbers, negative numbers, and zero.

```
Z = {...,-3,-2,-1,0,1,2,3,...}
```

---

## Rational Numbers (Q)

A **rational number** is any number that can be expressed in the form

```
p/q
```

where

- **p** and **q** are integers.
- **q ≠ 0**

### Examples

```
3/4

-5/7

8

0

2.75
```

---

## Decimal Representation of Rational Numbers

A rational number has either:

- Terminating decimal expansion

Example

```
3/8 = 0.375
```

or

- Non-terminating recurring decimal expansion

Example

```
1/3 = 0.3333...
```

---

## Irrational Numbers

An **irrational number** cannot be expressed as

```
p/q
```

Its decimal expansion is:

- Non-terminating
- Non-recurring

### Examples

```
√2

√3

√5

π

e
```

---

# 2. Rationalization

## Rationalization

Rationalization is the process of removing irrational numbers from the denominator of a fraction.

---

## Conjugate

The conjugate of

```
a + √b
```

is

```
a - √b
```

Similarly,

```
a - √b
```

has conjugate

```
a + √b
```

---

## Rationalizing Simple Surds

### Example

Simplify

```
1/√2
```

Multiply numerator and denominator by

```
√2
```

```
= √2/2
```

---

## Rationalizing Binomial Surds

### Example

```
1/(3 + √2)
```

Multiply numerator and denominator by the conjugate.

```
(3 - √2)
```

```
= (3 - √2)/(9 - 2)

= (3 - √2)/7
```

# 3. Irrationality Proofs

Some numbers cannot be expressed as fractions.

---

## Proof that √2 is Irrational

### Method

Proof by contradiction.

Assume

```
√2 = p/q
```

where

- p and q have no common factor.

Squaring both sides,

```
2 = p²/q²
```

```
p² = 2q²
```

Hence,

```
p²
```

is even.

Therefore,

```
p
```

is even.

Let

```
p = 2k
```

Substitute,

```
4k² = 2q²
```

```
q² = 2k²
```

Hence,

```
q
```

is also even.

Thus,

```
p
```

and

```
q
```

are both even.

This contradicts the assumption that they have no common factor.

Therefore,

```
√2 is irrational.
```

---

## Similar Irrational Numbers

The same method can prove:

```
√3

√5

√7

√11
```

are irrational.

# 4. Surds

A **surd** is an irrational root that cannot be simplified further.

---

## Pure Surds

Contain only the irrational part.

Examples

```
√2

√5

√11
```

---

## Mixed Surds

Contain both rational and irrational parts.

Examples

```
3√2

5√7

8√3
```

---

## Like Surds

Surds having the same irrational part.

Examples

```
4√3

7√3

−2√3
```

---

## Unlike Surds

Surds having different irrational parts.

Examples

```
√2

√5

√7
```

---

## Addition of Surds

Only like surds can be added.

Example

```
3√5 + 4√5

= 7√5
```

---

## Subtraction of Surds

Example

```
9√7 − 2√7

= 7√7
```

---

## Multiplication of Surds

Example

```
√3 × √12

= √36

= 6
```

---

## Division of Surds

Example

```
√18/√2

= √9

= 3
```

---

## Comparing Surds

Square both surds.

Example

Compare

```
√5 and √7
```

Since

```
5 < 7
```

Therefore,

```
√5 < √7
```

# 5. Representation of Irrational Numbers on the Number Line

Irrational numbers can be represented using geometric constructions.

---

## Construction of √2

### Steps

1. Draw a number line.
2. Mark point **O** at 0.
3. Mark point **A** at 1.
4. Draw a perpendicular at **A** of length 1.
5. Join the end point to **O**.
6. The length obtained is

```
√2
```

7. With **O** as centre, draw an arc cutting the number line.

The point obtained represents

```
√2
```

---

## Construction of √3

Construct

```
√2
```

first.

Then construct another perpendicular of unit length.

The new hypotenuse gives

```
√3
```

---

## Applications of Pythagoras Theorem

Used for constructing

```
√2

√3

√5

√10
```

on the number line.

# Common Mistakes

- Confusing **terminating decimals** with **recurring decimals**.
- Assuming every square root is irrational (e.g., **√25 = 5**, which is rational).
- Forgetting to multiply both numerator and denominator during rationalization.
- Adding unlike surds directly.
- Confusing **surds** with all irrational numbers.
- Writing **q = 0** in the definition of rational numbers.
- Incorrectly simplifying square roots.
- Assuming π has a repeating decimal expansion.

# Chapter Summary

- **Real numbers** consist of **rational** and **irrational** numbers.
- A **rational number** can be expressed in the form **p/q**, where **q ≠ 0**.
- Rational numbers have **terminating** or **recurring** decimal expansions.
- **Irrational numbers** have **non-terminating** and **non-recurring** decimal expansions.
- **Rationalization** removes surds from the denominator by multiplying by a suitable surd or conjugate.
- **Surds** are irrational roots that cannot be simplified further and can be added or subtracted only when they are like surds.
- The irrationality of numbers such as **√2** can be proved using the **method of contradiction**.
- Irrational numbers can be represented accurately on the number line using the **Pythagoras theorem**.
- Understanding rational and irrational numbers is essential for algebra, geometry, trigonometry, and higher mathematics.

# Introduction

Commercial Mathematics deals with the mathematical concepts used in business, trade, banking, and finance. It includes calculations involving **Profit and Loss, Discount, Compound Interest, Depreciation, Population Growth, Taxation**, and other financial transactions encountered in daily life.

---

# 1. Profit, Loss and Discount

## Cost Price (CP)

The **Cost Price (CP)** is the price at which an article is purchased.

---

## Selling Price (SP)

The **Selling Price (SP)** is the price at which an article is sold.

---

## Profit (Gain)

A **profit** occurs when the selling price is greater than the cost price.

### Formula

```
Profit = SP − CP
```

---

## Loss

A **loss** occurs when the selling price is less than the cost price.

### Formula

```
Loss = CP − SP
```

---

## Profit Percentage

```
Profit % = (Profit / CP) × 100
```

---

## Loss Percentage

```
Loss % = (Loss / CP) × 100
```

---

## Selling Price Formula

### When Profit is Given

```
SP = CP × (100 + Profit%)/100
```

---

### When Loss is Given

```
SP = CP × (100 − Loss%)/100
```

---

# 2. Discount

## Marked Price (MP)

The **Marked Price** is the price printed on the article before any discount.

---

## Discount

The reduction offered on the marked price is called **Discount**.

### Formula

```
Discount = MP − SP
```

---

## Discount Percentage

```
Discount % = (Discount / MP) × 100
```

---

## Selling Price After Discount

```
SP = MP × (100 − Discount%)/100
```

---

## Successive Discounts

If two discounts are offered successively:

```
Net Discount

= a + b − (ab/100)
```

where

- **a** = First discount (%)
- **b** = Second discount (%)

---

# 3. Compound Interest

## Compound Interest (CI)

Compound Interest is the interest calculated on both the **principal** and the **accumulated interest**.

---

## Terms Used

- **P** = Principal
- **R** = Rate of Interest (% per annum)
- **T** = Time (years)
- **A** = Amount
- **CI** = Compound Interest

---

## Amount Formula

For annual compounding:

```
A = P(1 + R/100)^T
```

---

## Compound Interest

```
CI = A − P
```

---

## Year-by-Year Method

Interest is added after every year.

Example:

```
Principal

↓

Interest

↓

New Principal

↓

Next Year's Interest
```

---

## Difference Between SI and CI

| Simple Interest              | Compound Interest                             |
| ---------------------------- | --------------------------------------------- |
| Calculated only on principal | Calculated on principal and previous interest |
| Same interest every year     | Interest increases every year                 |
| Simpler calculations         | Faster growth                                 |

---

# 4. Half-Yearly and Variable Rate Compound Interest

## Half-Yearly Compounding

If interest is compounded every six months:

### Rate

```
R/2
```

### Time

```
2T
```

### Formula

```
A = P(1 + R/200)^(2T)
```

---

## Quarterly Compounding

### Rate

```
R/4
```

### Time

```
4T
```

### Formula

```
A = P(1 + R/400)^(4T)
```

---

## Variable Rate Compound Interest

If the rate changes every year:

```
A = P × (1 + R₁/100)
      × (1 + R₂/100)
      × (1 + R₃/100)
```

---

### Example

Rates:

```
8%

10%

12%
```

Multiply each year's growth separately.

---

# 5. Depreciation, Population Growth and Taxation

## Depreciation

Depreciation is the decrease in the value of an asset over time.

### Formula

```
Value = P(1 − R/100)^T
```

---

## Applications

- Vehicles
- Machines
- Electronic goods
- Buildings

---

## Population Growth

Population increases according to compound growth.

### Formula

```
Population

= P(1 + R/100)^T
```

---

## Population Decline

```
Population

= P(1 − R/100)^T
```

---

## Taxation

Tax is an amount paid to the government on goods, services, or income.

---

## Goods and Services Tax (GST)

GST is charged on the selling price of goods.

### GST Amount

```
GST = (GST% × Taxable Amount)/100
```

---

## Bill Amount

```
Total Bill

= Taxable Amount + GST
```

# Common Mistakes

- Confusing **Cost Price** with **Marked Price**.
- Calculating profit percentage using the **Selling Price** instead of the **Cost Price**.
- Forgetting to subtract the principal while finding Compound Interest.

# Introduction

Algebraic expansions are used to multiply algebraic expressions quickly using standard identities instead of long multiplication. These identities simplify calculations, help in solving equations, factorization, and evaluating numerical expressions efficiently. This chapter covers quadratic and cubic identities, conditional expansions, reciprocal expressions, and numerical applications.

---

# 1. Quadratic Identities

Quadratic identities are formulas used to expand the square of algebraic expressions.

---

## Identity 1

### Square of a Sum

```
(a + b)² = a² + 2ab + b²
```

### Example

Expand

```
(x + 5)²
```

```
= x² + 2(x)(5) + 25

= x² + 10x + 25
```

---

## Identity 2

### Square of a Difference

```
(a − b)² = a² − 2ab + b²
```

### Example

Expand

```
(y − 3)²
```

```
= y² − 6y + 9
```

---

## Identity 3

### Product of Sum and Difference

```
(a + b)(a − b)

= a² − b²
```

### Example

```
(x + 4)(x − 4)

= x² − 16
```

---

## Identity 4

### Square of Three Terms

```
(a + b + c)²

= a² + b² + c²

+ 2ab + 2bc + 2ca
```

### Example

Expand

```
(x + y + 2)²
```

```
= x² + y² + 4

+ 2xy + 4x + 4y
```

---

# 2. Cubic Identities

Cubic identities are used to expand expressions involving cubes.

---

## Identity 1

### Cube of a Sum

```
(a + b)³

= a³ + 3a²b

+ 3ab² + b³
```

### Example

Expand

```
(x + 2)³
```

```
= x³ + 6x²

+ 12x + 8
```

---

## Identity 2

### Cube of a Difference

```
(a − b)³

= a³ − 3a²b

+ 3ab² − b³
```

### Example

Expand

```
(x − 1)³
```

```
= x³ − 3x²

+ 3x − 1
```

---

## Identity 3

### Sum of Cubes

```
a³ + b³

= (a + b)

(a² − ab + b²)
```

---

## Identity 4

### Difference of Cubes

```
a³ − b³

= (a − b)

(a² + ab + b²)
```

---

# Introduction

**Factorization** is the process of expressing an algebraic expression as the product of two or more simpler algebraic expressions called **factors**. It is the reverse process of expansion and is widely used in simplifying expressions, solving equations, and higher algebra.

---

# 1. Factorization by Common Factor

A common factor is the greatest algebraic term that is present in every term of the expression.

---

## Steps

1. Find the greatest common factor (GCF).
2. Take it outside the bracket.
3. Divide each term by the common factor.

---

## Formula

```
ab + ac = a(b + c)
```

---

## Example 1

Factorize

```
6x + 12
```

Solution

```
= 6(x + 2)
```

---

## Example 2

Factorize

```
15xy + 20x
```

Solution

```
= 5x(3y + 4)
```

---

## Example 3

Factorize

```
8a²b + 12ab²
```

Solution

```
= 4ab(2a + 3b)
```

---

# 2. Difference of Two Squares

Expressions of the form

```

```
a² − b²

```

```

```

```

```

# 3. Splitting the Middle Term

Quadratic expressions of the form

```
ax² + bx + c
```

can be factorized by splitting the middle term.

---

## Steps

1. Multiply

```
a × c
```

2. Find two numbers whose:

- Product = ac
- Sum = b

3. Split the middle term.

4. Factor by grouping.

---

## Example 1

Factorize

```
x² + 7x + 12
```

Numbers required:

```
3 and 4
```

Solution

```
= x² + 3x + 4x + 12

= x(x + 3)

+4(x + 3)

=(x + 3)(x + 4)
```

---

## Example 2

Factorize

```

```

Required numbers:

```
6 and 1
```

Solution

```
=2x²+6x+x+3

=2x(x+3)

+1(x+3)

=(2x+1)(x+3)
```

```

Expressions can be rewritten as a perfect square and then factorized.

# Introduction

A **simultaneous linear equation** is a set of two or more linear equations involving the same variables. The values of the variables that satisfy all the equations simultaneously are called the **solution** of the system. These equations are widely used to solve problems involving age, numbers, speed, cost, mixtures, and geometry.

---

# 1. Linear Equations in Two Variables

A linear equation in two variables has the general form:

```
ax + by + c = 0
```

where

- **a, b, c** are constants.
- **a** and **b** are not both zero.

### Examples

```
2x + 3y = 7
```

```
5x − 2y = 9
```

---

## Simultaneous Linear Equations

Two equations involving the same variables are called simultaneous equations.

Example

```
2x + y = 7

x − y = 2
```

The values of **x** and **y** satisfying both equations are the solution.

---

# 2. Substitution Method

In this method, one variable is expressed in terms of the other and substituted into the second equation.

---

## Steps

1. Express one variable from one equation.
2. Substitute it into the other equation.
3. Solve for the remaining variable.
4. Substitute back to find the other variable.

---

## Example

Solve

```
x + y = 8

x − y = 2
```

From the first equation,

```
x = 8 − y
```

Substitute into the second equation:

```
(8 − y) − y = 2

8 − 2y = 2

2y = 6

y = 3
```

Substitute in the first equation:

```
x + 3 = 8

x = 5
```

### Answer

```
x = 5

y = 3
```

---

# 3. Elimination Method

The elimination method removes one variable by making its coefficients equal.

---

## Steps

1. Multiply one or both equations if necessary.
2. Make the coefficients of one variable equal.
3. Add or subtract the equations.
4. Solve for one variable.
5. Substitute to find the other.

---

## Example

Solve

```
2x + y = 9

3x − y = 6
```

Add both equations:

```
5x = 15

x = 3
```

Substitute into the first equation:

```
2(3) + y = 9

6 + y = 9

y = 3
```

### Answer

```
x = 3

y = 3
```

---

# 4. Cross-Multiplication Method

The cross-multiplication method provides a direct formula for solving simultaneous equations.

---

## Standard Form

```
a₁x + b₁y + c₁ = 0

a₂x + b₂y + c₂ = 0
```

---

## Formula

```
x / (b₁c₂ − b₂c₁)

=

y / (c₁a₂ − c₂a₁)

=

1 / (a₁b₂ − a₂b₁)
```

---

### Example

Solve

```
2x + y − 7 = 0

x − y − 1 = 0
```

Using the cross-multiplication formula,

```
x = 2

y = 3
```

---

## Advantages

- Fast for standard-form equations.
- Avoids repeated substitutions.
- Useful in examinations.

---

# 5. Nature of Solutions and Word Problems

## Consistency of a Pair of Linear Equations

The nature of solutions depends on the coefficients.

---

### Unique Solution (Consistent)

Condition

```
a₁/a₂ ≠ b₁/b₂
```

The lines intersect at one point.

---

### No Solution (Inconsistent)

Condition

```
a₁/a₂ = b₁/b₂ ≠ c₁/c₂
```

The lines are parallel.

---

### Infinitely Many Solutions

Condition

```
a₁/a₂ = b₁/b₂ = c₁/c₂
```

The lines coincide.

---

## Graphical Interpretation

| Type of Lines | Number of Solutions |
| ------------- | ------------------- |
| Intersecting  | One                 |
| Parallel      | None                |
| Coincident    | Infinite            |

---

- A **simultaneous linear equation** is a system of two or more linear equations with the same variables.

- These equations are widely used to solve practical problems involving **ages**, **numbers**, **costs**, **speed**, **mixtures**, and **geometry**.
- Always verify the obtained solution by substituting it back into the original equations.
- Mastering simultaneous linear equations forms the foundation for higher algebra and coordinate geometry.

# Introduction

**Indices** (also called **Exponents** or **Powers**) provide a convenient way of representing repeated multiplication of the same number or variable. The laws of indices simplify calculations involving multiplication, division, powers, roots, and algebraic expressions. This chapter also covers negative and fractional exponents, exponential equations, and conversions between radical and exponential forms.

---

# 1. Basics of Indices

## Exponent

An exponent indicates how many times a base is multiplied by itself.

### General Form

```
aⁿ
```

where

- **a** = Base
- **n** = Exponent (Index)

### Example

```
2⁴ = 2 × 2 × 2 × 2

= 16
```

---

## Terms

| Term     | Meaning                                |
| -------- | -------------------------------------- |
| Base     | Number being multiplied                |
| Exponent | Number of times the base is multiplied |
| Power    | Complete expression (aⁿ)               |

---

## Examples

```
5² = 25

3³ = 27

10¹ = 10

7⁰ = 1
```

---

# 2. Laws of Indices

These laws simplify calculations involving exponents.

---

## Law 1: Product of Powers

When multiplying powers with the same base, add the exponents.

### Formula

```
aᵐ × aⁿ = aᵐ⁺ⁿ
```

### Example

```
2³ × 2²

= 2⁵

= 32
```

---

## Law 2: Quotient of Powers

When dividing powers with the same base, subtract the exponents.

### Formula

```
aᵐ ÷ aⁿ = aᵐ⁻ⁿ
```

### Example

```
5⁷ ÷ 5³

= 5⁴

= 625
```

---

## Law 3: Power of a Power

Multiply the exponents.

### Formula

```
(aᵐ)ⁿ = aᵐⁿ
```

### Example

```
(3²)⁴

= 3⁸
```

---

## Law 4: Power of a Product

Raise each factor separately.

### Formula

```
(ab)ⁿ = aⁿbⁿ
```

### Example

```
(2 × 5)²

= 2² × 5²

= 4 × 25

= 100
```

---

## Law 5: Power of a Quotient

### Formula

```
(a/b)ⁿ

= aⁿ/bⁿ
```

### Example

```
(3/4)²

= 9/16
```

---

## Law 6: Zero Exponent

Any non-zero number raised to zero equals one.

### Formula

```
a⁰ = 1

(a ≠ 0)
```

### Example

```
9⁰ = 1
```

---

## Law 7: Exponent One

### Formula

```
a¹ = a
```

### Example

```
15¹ = 15
```

# Introduction

**Logarithms** are the inverse operation of exponents (indices). They simplify calculations involving very large or very small numbers and are widely used in mathematics, science, engineering, and finance. This chapter introduces the definition of logarithms, conversion between exponential and logarithmic forms, laws of logarithms, change of base, common logarithms, and solving logarithmic equations.

# 1. Introduction to Logarithms

## Definition

If

```

aˣ = b

```

then

```

logₐ b = x

```

where

- **a** = Base (**a > 0**, **a ≠ 1**)
- **b** = Argument (**b > 0**)
- **x** = Logarithm

---

## Relationship Between Exponential and Logarithmic Forms

### Exponential Form

```

2³ = 8

```

### Logarithmic Form

```

log₂ 8 = 3

```

---

### Example

```

10² = 100

```

Therefore,

```

log₁₀ 100 = 2

```

---

## Converting Between Forms

### Exponential → Logarithmic

```

5³ = 125

```

becomes

```

log₅ 125 = 3

```

---

### Logarithmic → Exponential

```

log₄ 64 = 3

```

becomes

```

4³ = 64

```

---

# 2. Laws of Logarithms

The laws of logarithms simplify multiplication, division, and powers.

---

## Law 1: Product Rule

The logarithm of a product equals the sum of the logarithms.

### Formula

```

logₐ(MN)

= logₐ M + logₐ N

```

### Example

```

log₂(8 × 4)

= log₂8 + log₂4

= 3 + 2

= 5

```

---

## Law 2: Quotient Rule

The logarithm of a quotient equals the difference of the logarithms.

### Formula

```

logₐ(M/N)

= logₐM − logₐN

```

### Example

```

log₁₀(1000/10)

= 3 − 1

= 2

```

---

## Law 3: Power Rule

The exponent becomes the coefficient.

### Formula

```

logₐ(Mⁿ)

= n logₐM

```

### Example

```

log₂(8²)

= 2 log₂8

= 2 × 3

= 6

```

---

## Law 4: Logarithm of One

```

logₐ1 = 0

```

because

```

a⁰ = 1

```

---

## Law 5: Logarithm of the Base

```

logₐa = 1

```

because

```

a¹ = a

```

# Introduction

A **triangle** is a three-sided polygon and one of the most important figures in geometry. Two triangles are said to be **congruent** if they are exactly equal in shape and size. Congruency helps in proving many geometric properties and theorems. This chapter covers the criteria for congruency, properties of isosceles triangles, the Midpoint Theorem, the Intercept Theorem, and inequalities related to triangles.

---

# 1. Congruency of Triangles

## Congruent Triangles

Two triangles are **congruent** if all their corresponding sides and corresponding angles are equal.

### Symbol

```

ΔABC ≅ ΔPQR

```

---

## Corresponding Parts of Congruent Triangles (CPCT)

If two triangles are congruent, then their corresponding sides and corresponding angles are equal.

### Example

If

```

ΔABC ≅ ΔPQR

```

Then

```

AB = PQ

BC = QR

AC = PR

∠A = ∠P

∠B = ∠Q

∠C = ∠R

```

---

# 2. Criteria for Congruency

---

## SSS (Side-Side-Side)

If the three sides of one triangle are equal to the three corresponding sides of another triangle, then the triangles are congruent.

### Condition

```

AB = PQ

BC = QR

AC = PR

```

Therefore,

```

ΔABC ≅ ΔPQR

```

---

## SAS (Side-Angle-Side)

If two sides and the included angle of one triangle are equal to the corresponding parts of another triangle, then the triangles are congruent.

### Condition

```

AB = PQ

∠B = ∠Q

BC = QR

```

---

## ASA (Angle-Side-Angle)

If two angles and the included side are equal, then the triangles are congruent.

---

## AAS (Angle-Angle-Side)

If two angles and one corresponding side are equal, then the triangles are congruent.

---

## RHS (Right Angle-Hypotenuse-Side)

Applicable only for right-angled triangles.

If

- One right angle
- Hypotenuse
- One corresponding side

are equal, then the triangles are congruent.

---

```

ΔABC

```

```

```

# 4. Midpoint Theorem

## Statement

The line joining the midpoints of two sides of a triangle is:

    /  \

- Coordinate geometry

AE/EC

```

---

## Converse

```

Then

```

DE || BC

```

---

## Applications

- Similar figures
- Ratio problems
- Construction
- Coordinate geometry

# 6. Triangle Inequalities

## Triangle Inequality Theorem

The sum of any two sides of a triangle is greater than the third side.

```

AB + BC > AC

AB + AC > BC

```

The greater side lies opposite the greater angle.

```

```

---

## Converse

The greater angle lies opposite the greater side.

---

## Exterior Angle Property

An exterior angle of a triangle is greater than either of its opposite interior angles.

# Introduction

A **circle** is a set of all points in a plane that are at a fixed distance from a fixed point called the **centre**. Circle geometry studies the properties of circles, chords, arcs, radii, diameters, and the theorems related to them. These theorems are useful in solving geometrical problems and proving various properties of figures.

---

# 1. Basic Terms Related to a Circle

## Circle

A circle is the collection of all points at a constant distance from a fixed point.

---

## Centre

The fixed point inside the circle.

Represented by

```

O

```

---

## Radius

A line segment joining the centre to any point on the circle.

### Symbol

```

r

```

---

## Diameter

A chord passing through the centre.

### Formula

```

Diameter = 2 × Radius

```

```

d = 2r

```

---

## Chord

A line segment joining any two points on the circle.

---

## Arc

A part of the circumference of a circle.

Types:

- Minor Arc
- Major Arc
- Semicircle

---

## Circumference

The boundary of a circle.

### Formula

```

C = 2πr

```

---

# 2. Chords and Perpendiculars

## Theorem 1

**The perpendicular drawn from the centre of a circle to a chord bisects the chord.**

---

### Diagram

```

        A
      •────• B
         |
         |
         O

```

If

```

OM ⟂ AB

```

Then

```

AM = MB

```

---

## Converse

If a line from the centre bisects a chord,

then it is perpendicular to the chord.

---

## Applications

- Finding chord lengths
- Geometry proofs
- Construction problems

---

# 3. Equal Chords and Equal Distances

## Theorem 2

Equal chords are equidistant from the centre.

---

If

```

AB = CD

```

Then

```

OM = ON

```

where

```

OM

and

ON

```

are perpendicular distances from the centre.

---

## Converse

If two chords are equidistant from the centre,

then they are equal.

---

### Applications

- Construction
- Proofs
- Finding unknown lengths

---

# 4. Arc and Chord Relations

## Theorem

Equal chords subtend equal arcs.

---

If

```

AB = CD

```

Then

```

Arc AB = Arc CD

```

---

## Converse

Equal arcs subtend equal chords.

---

## Central Angle Property

Equal chords subtend equal angles at the centre.

If

```

AB = CD

```

Then

```

∠AOB = ∠COD

```

---

## Converse

Equal central angles stand on equal chords.

---

# 5. Concyclic Points

## Definition

Points lying on the same circle are called **concyclic points**.

---

## Important Theorem

One and only one circle passes through three non-collinear points.

---

### Diagram

```

        A

• •

B C

       O

```

Only one circle can pass through

```

A

B

C

```

---

## Applications

- Geometry proofs
- Circle construction
- Coordinate geometry

---

# 6. Construction of Circles and Regular Polygons

## Construction of a Circle

### Given

Centre

```

O

```

Radius

```

r

```

### Steps

1. Place the compass at the centre.
2. Open it to the required radius.
3. Rotate the compass through 360°.
4. Obtain the circle.

---

## Constructing Equal Chords

1. Draw a circle.
2. Set the compass to the required chord length.
3. Mark equal points on the circumference.
4. Join the points.

---

## Constructing a Regular Hexagon

Since

```

Side = Radius

```

Steps

1. Draw a circle.
2. With the same radius, mark six equal points.
3. Join adjacent points.

---

## Applications

- Engineering drawing
- Architecture
- Surveying
- Geometrical designs

# Common Mistakes

- Confusing a **radius** with a **diameter**.
- Assuming every chord passes through the centre.
- Forgetting that only the **perpendicular** from the centre bisects a chord.
- Mixing up the theorems on equal chords and equal arcs.
- Assuming more than one circle can pass through three non-collinear points.
- Confusing a chord with an arc.
- Using the circumference formula instead of the diameter formula.
- Drawing inaccurate constructions with a compass.

# Chapter Summary

- A **circle** is the set of all points equidistant from a fixed point called the **centre**.
- The **radius**, **diameter**, **chord**, and **arc** are the basic parts of a circle.
- A **perpendicular** drawn from the centre to a chord **bisects** the chord, and the converse is also true.
- **Equal chords** are **equidistant** from the centre, and equal distances imply equal chords.
- **Equal chords**, **equal arcs**, and **equal central angles** are closely related.
- Exactly **one circle** can be drawn through **three non-collinear points**.
- Compass constructions of circles and regular polygons are based on these geometric properties.
- Circle geometry forms the foundation for advanced topics such as tangents, cyclic quadrilaterals, and coordinate geometry.

# Introduction

**Mensuration** is the branch of mathematics that deals with the measurement of geometric figures. It involves calculating the **area, perimeter, surface area, and volume** of two-dimensional (2D) and three-dimensional (3D) figures. This chapter focuses on triangles, quadrilaterals, circles, cubes, and cuboids, along with practical applications.

---

# 1. Area of Triangles

## Area Using Base and Height

The area of a triangle is half the product of its base and corresponding height.

### Formula

```

Area = ½ × Base × Height

```

### Example

```

Base = 12 cm

Height = 8 cm

```

```

Area

= ½ × 12 × 8

= 48 cm²

```

---

## Heron's Formula

Used when all three sides of a triangle are known.

### Step 1: Find Semi-Perimeter

```

s = (a + b + c)/2

```

where

- **a, b, c** are the sides of the triangle.

---

### Step 2: Apply Heron's Formula

```

Area

= √[s(s − a)(s − b)(s − c)]

```

---

### Example

Sides

```

5 cm

12 cm

13 cm

```

```

s

= (5 + 12 + 13)/2

= 15

```

```

Area

= √[15 × 10 × 3 × 2]

= √900

= 30 cm²

```

---

# 2. Area of Quadrilaterals and Paths

## Rectangle

### Perimeter

```

P = 2(l + b)

```

### Area

```

A = l × b

```

---

## Square

### Perimeter

```

P = 4a

```

### Area

```

A = a²

```

---

## Parallelogram

### Area

```

A = Base × Height

```

---

## Rhombus

### Area

```

A = ½ × d₁ × d₂

```

where

- **d₁** and **d₂** are the diagonals.

---

## Trapezium

### Area

```

A

= ½(a + b) × h

```

where

- **a** and **b** are parallel sides.
- **h** is the height.

---

## Area of Paths

### Outside Path

```

Area of Path

= Outer Area − Inner Area

```

### Inside Path

```

Area Remaining

= Total Area − Path Area

```

---

# 4. Surface Area of Cubes and Cuboids

## Cube

A solid with six equal square faces.

---

```

```

---

### Lateral Surface Area (LSA)

```

```

---

## Cuboid

A solid having length, breadth, and height.

---

```

TSA

---

### Lateral Surface Area

```

LSA

```

---

### Body Diagonal

d

# Common Mistakes

- Forgetting to divide by **2** while finding the area of a triangle.
- Using **diameter instead of radius** in circle formulas.
- Confusing **circumference** with **area**.
- Using incorrect units (cm instead of cm² or cm³).

- Mixing up **Total Surface Area (TSA)** and **Lateral Surface Area (LSA)**.
- Using the wrong formula for trapeziums and rhombuses.
- Forgetting to convert **litres to cubic centimetres** when calculating capacity.

- **Mensuration** deals with the measurement of lengths, areas, surface areas, and volumes of geometric figures.

# Introduction

**Trigonometry** is the branch of mathematics that studies the relationship between the angles and sides of a triangle. It is mainly applied to **right-angled triangles**. Trigonometry is widely used in surveying, engineering, astronomy, navigation, architecture, and physics. This chapter introduces trigonometric ratios, identities, standard angle values, complementary angle relationships, and solving right triangles.

---

# 1. Right-Angled Triangle

A **right-angled triangle** is a triangle in which one angle is **90°**.

### Parts of a Right Triangle

```

          C
          |\
          | \

Opposite | \ Hypotenuse
|θ \
| \
|_____\
A Adjacent B

```

For angle **θ**:

- **Hypotenuse** → Side opposite the right angle
- **Opposite Side** → Side opposite angle θ
- **Adjacent Side** → Side next to angle θ (excluding the hypotenuse)

---

# 2. Trigonometric Ratios

There are six basic trigonometric ratios.

---

## Sine (sin)

### Formula

```

sin θ

=

Opposite / Hypotenuse

```

---

## Cosine (cos)

### Formula

```

cos θ

=

Adjacent / Hypotenuse

```

---

## Tangent (tan)

### Formula

```

tan θ

=

Opposite / Adjacent

```

---

## Cosecant (cosec)

### Formula

```

cosec θ

=

Hypotenuse / Opposite

```

---

## Secant (sec)

### Formula

```

sec θ

=

Hypotenuse / Adjacent

```

---

## Cotangent (cot)

### Formula

```

cot θ

=

Adjacent / Opposite

```

---

## Reciprocal Relationships

```

cosec θ = 1/sin θ

```

```

sec θ = 1/cos θ

```

```

cot θ = 1/tan θ

```

---

# 3. Fundamental Trigonometric Identities

Trigonometric identities are equations that are always true.

---

## Identity 1

```

sin² θ + cos² θ = 1

```

---

## Identity 2

```

tan θ = sin θ / cos θ

```

---

## Identity 3

```

cot θ = cos θ / sin θ

```

---

## Identity 4

```

tan θ × cot θ = 1

```

---

## Identity 5

```

sec θ = 1 / cos θ

```

---

## Identity 6

```

cosec θ = 1 / sin θ

```

---

# Introduction

**Coordinate Geometry**, also known as **Analytical Geometry**, is the branch of mathematics that studies geometric figures using a coordinate system. Every point on a plane is represented by an **ordered pair (x, y)**. Coordinate geometry helps in locating points, measuring distances, finding midpoints, and solving geometrical problems using algebra.

---

# 1. Cartesian Coordinate System

## Definition

The **Cartesian Coordinate System** consists of two mutually perpendicular number lines:

- Horizontal Axis → **X-axis**
- Vertical Axis → **Y-axis**

These axes intersect at a point called the **Origin**.

---

## Origin

The point where the X-axis and Y-axis meet.

```

Origin

O(0,0)

```

---

## Coordinate Plane

```

            Y-axis
              ↑
      II      |      I
              |

--------------O--------------→ X-axis
|
III | IV
|
↓

```

The plane is divided into **four quadrants**.

---

A point is represented by an ordered pair.

```

```

- **x** → x-coordinate (abscissa)
- **y** → y-coordinate (ordinate)

```

```

```

```

# 5. Distance Between Two Points

The distance between two points is obtained using the **Distance Formula**.

---

## Formula

If

```

A(x₁,y₁)

and

B(x₂,y₂)

```

then

```

AB

=

√[(x₂ − x₁)² + (y₂ − y₁)²]

```

---

## Example

Find the distance between

```

A(2,3)

B(5,7)

```

```

AB

=

√[(5−2)² + (7−3)²]

=

√(9+16)

=

√25

=

5 units

```

---

# 6. Midpoint of a Line Segment

The midpoint divides a line segment into two equal parts.

---

## Formula

If

```

A(x₁,y₁)

B(x₂,y₂)

```

then midpoint

```

M

=

((x₁+x₂)/2 ,

(y₁+y₂)/2)

```

---

## Example

Find the midpoint of

```

A(2,4)

B(8,10)

```

```

M

=

((2+8)/2 ,

(4+10)/2)

=

(5,7)

```

P

((mx₂+nx₁)/(m+n),

```

# Common Mistakes

- Confusing the **x-coordinate** with the **y-coordinate**.
- Forgetting that the **origin** is **(0,0)**.
- Plotting points in the wrong quadrant due to incorrect signs.
- Using incorrect subtraction while applying the **Distance Formula**.
- Forgetting to square the differences in coordinates.
- Mixing up the formulas for **midpoint** and **distance**.
- Assuming points on the axes belong to a quadrant (they do not).
- Writing coordinates in the wrong order as **(y, x)** instead of **(x, y)**.

# Chapter Summary

- **Coordinate Geometry** represents geometric figures using the **Cartesian Coordinate System**.
- Every point is represented by an **ordered pair (x, y)**, where **x** is the abscissa and **y** is the ordinate.
- The coordinate plane is divided into **four quadrants**, each identified by the signs of the coordinates.
- Points can be accurately **plotted** using their coordinates.
- The **Distance Formula** is used to calculate the distance between two points.
- The **Midpoint Formula** determines the point that divides a line segment into two equal parts.
- The **Section Formula** is used to divide a line segment in a given ratio.
- Coordinate Geometry is widely applied in engineering, navigation, computer graphics, robotics, architecture, and many real-world fields.
