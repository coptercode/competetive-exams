# Introduction

**Indices** (also called **Exponents** or **Powers**) provide a convenient way of representing repeated multiplication of the same number or variable. The laws of indices simplify calculations involving multiplication, division, powers, roots, and algebraic expressions. This chapter also covers negative and fractional exponents, exponential equations, and conversions between radical and exponential forms.

---

# 1. Basics of Indices

## Exponent

An exponent indicates how many times a base is multiplied by itself.

### General Form

```
aⁿ
```

where

- **a** = Base
- **n** = Exponent (Index)

### Example

```
2⁴ = 2 × 2 × 2 × 2

= 16
```

---

## Terms

| Term     | Meaning                                |
| -------- | -------------------------------------- |
| Base     | Number being multiplied                |
| Exponent | Number of times the base is multiplied |
| Power    | Complete expression (aⁿ)               |

---

## Examples

```
5² = 25

3³ = 27

10¹ = 10

7⁰ = 1
```

# 2. Laws of Indices

These laws simplify calculations involving exponents.

---

## Law 1: Product of Powers

When multiplying powers with the same base, add the exponents.

### Formula

```
aᵐ × aⁿ = aᵐ⁺ⁿ
```

### Example

```
2³ × 2²

= 2⁵

= 32
```

---

## Law 2: Quotient of Powers

When dividing powers with the same base, subtract the exponents.

### Formula

```
aᵐ ÷ aⁿ = aᵐ⁻ⁿ
```

### Example

```
5⁷ ÷ 5³

= 5⁴

= 625
```

---

## Law 3: Power of a Power

Multiply the exponents.

### Formula

```
(aᵐ)ⁿ = aᵐⁿ
```

### Example

```
(3²)⁴

= 3⁸
```

---

## Law 4: Power of a Product

Raise each factor separately.

### Formula

```
(ab)ⁿ = aⁿbⁿ
```

### Example

```
(2 × 5)²

= 2² × 5²

= 4 × 25

= 100
```

---

## Law 5: Power of a Quotient

### Formula

```
(a/b)ⁿ

= aⁿ/bⁿ
```

### Example

```
(3/4)²

= 9/16
```

---

## Law 6: Zero Exponent

Any non-zero number raised to zero equals one.

### Formula

```
a⁰ = 1

(a ≠ 0)
```

### Example

```
9⁰ = 1
```

---

## Law 7: Exponent One

### Formula

```
a¹ = a
```

### Example

```
15¹ = 15
```

# 3. Negative and Fractional Indices

---

## Negative Exponents

A negative exponent represents the reciprocal.

### Formula

```
a⁻ⁿ = 1/aⁿ
```

### Example

```
2⁻³

= 1/2³

= 1/8
```

---

### Example

```
5⁻²

= 1/25
```

---

## Fractional Exponents

Fractional exponents represent roots.

### Formula

```
a¹⁄² = √a
```

---

### Formula

```
a¹⁄³ = ∛a
```

---

### General Formula

```
aᵐ⁄ⁿ

= ⁿ√(aᵐ)
```

---

### Examples

```
16¹⁄²

= 4
```

```
27¹⁄³

= 3
```

```
64²⁄³

=(∛64)²

=4²

=16
```

# 4. Exponential Equations

Equations involving exponents are called exponential equations.

---

## Method 1

Convert both sides to the same base.

### Example

Solve

```
2ˣ = 32
```

Since

```
32 = 2⁵
```

Therefore,

```
x = 5
```

---

## Example

Solve

```
9ˣ = 81
```

```
9 = 3²

81 = 3⁴
```

```
3²ˣ = 3⁴
```

```
2x = 4
```

```
x = 2
```

---

## Method 2

Use the laws of indices to simplify before solving.

### Example

```
5ˣ × 5² = 5⁷
```

```
5ˣ⁺² = 5⁷
```

Therefore,

```
x = 5
```

---

```

# Common Mistakes

- Adding exponents while dividing powers instead of subtracting them.
- Multiplying exponents instead of adding them in the product rule.
- Forgetting that **a⁰ = 1** only when **a ≠ 0**.
- Treating negative exponents as negative numbers instead of reciprocals.
- Confusing fractional exponents with ordinary fractions.
- Applying index laws to expressions with different bases.
- Forgetting to convert both sides to the same base before solving exponential equations.
- Making arithmetic errors while simplifying powers.

# Chapter Summary

- **Indices (Exponents)** represent repeated multiplication of the same base.
- The **laws of indices** simplify multiplication, division, powers, and algebraic expressions.
- A **negative exponent** represents the reciprocal of the corresponding positive power.
- A **fractional exponent** represents roots, providing a connection between exponents and radicals.
- **Exponential equations** are solved by expressing both sides with the same base and applying the laws of indices.
- Converting between **radical** and **exponential** forms simplifies calculations and algebraic manipulation.
- Index laws are fundamental tools used throughout algebra, trigonometry, logarithms, and higher mathematics.
