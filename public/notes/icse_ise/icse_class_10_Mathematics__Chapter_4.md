# Introduction

A **Linear Inequation** is an algebraic statement that compares two expressions using inequality symbols instead of the equality sign. It contains one variable whose highest power is **1**. The solution of a linear inequation is a **set of values** that satisfy the given inequality. These solutions can be represented on a **number line** or in **interval notation**.

---

# 1. Linear Inequations

## Definition

A **Linear Inequation** is an inequality involving a variable of degree **1**.

---

## Inequality Symbols

| Symbol | Meaning                  |
| ------ | ------------------------ |
| **<**  | Less than                |
| **>**  | Greater than             |
| **≤**  | Less than or equal to    |
| **≥**  | Greater than or equal to |
| **≠**  | Not equal to             |

---

## Examples

```
x + 5 > 10
```

```
3x − 7 ≤ 14
```

```
5x + 2 ≥ 17
```

# 2. Rules for Solving Linear Inequations

The same operations performed on equations can also be applied to inequations.

---

## Rule 1: Addition

Adding the same number to both sides does **not** change the inequality.

Example

```
x − 5 > 7
```

Add 5 to both sides.

```
x > 12
```

---

## Rule 2: Subtraction

Subtracting the same number from both sides does **not** change the inequality.

Example

```
x + 8 ≤ 20
```

Subtract 8.

```
x ≤ 12
```

---

## Rule 3: Multiplication

Multiplying both sides by a **positive number** does **not** change the inequality.

Example

```
x/3 > 4
```

Multiply by 3.

```
x > 12
```

---

## Rule 4: Division

Dividing both sides by a **positive number** does **not** change the inequality.

Example

```
4x ≥ 20
```

Divide by 4.

```
x ≥ 5
```

---

# 3. Reversal of Inequality

## Important Rule

Whenever both sides are multiplied or divided by a **negative number**, the inequality sign **must be reversed**.

---

### Example 1

```
−3x > 9
```

Divide by

```
−3
```

Reverse the sign.

```
x < −3
```

---

### Example 2

```
−5x ≤ 25
```

Divide by

```
−5
```

```
x ≥ −5
```

---

## Remember

```
×

Positive Number

→ No Change
```

```
×

Negative Number

→ Reverse Sign
```

# 6. Interval Notation

Solutions over real numbers are often written using interval notation.

| Inequality    | Interval |
| ------------- | -------- |
| **x > a**     | (a, ∞)   |
| **x ≥ a**     | [a, ∞)   |
| **x < a**     | (−∞, a)  |
| **x ≤ a**     | (−∞, a]  |
| **a < x < b** | (a, b)   |
| **a ≤ x ≤ b** | [a, b]   |

---

## Meaning of Brackets

```
( )

Open Interval

Endpoint NOT Included
```

```
[ ]

Closed Interval

Endpoint Included
```

# Common Mistakes

- Forgetting to **reverse the inequality sign** when multiplying or dividing by a negative number.
- Confusing **<** with **≤** and **>** with **≥**.
- Using a **closed circle** instead of an **open circle** on the number line.
- Writing incorrect interval notation.
- Ignoring the specified domain (Natural Numbers, Integers, or Real Numbers).
- Treating inequalities exactly like equations without considering inequality rules.
- Including excluded endpoints in the solution set.
- Making sign errors during algebraic simplification.

# Chapter Summary

- A **Linear Inequation** is an algebraic inequality involving a variable of degree **1**.
- Linear inequations are solved using the same algebraic operations as equations, except when multiplying or dividing by a **negative number**, where the **inequality sign must be reversed**.
- The set of all values satisfying an inequation is called the **solution set**.
- Solutions can be expressed using **set notation**, **interval notation**, or represented graphically on a **number line**.
- Domain restrictions such as **Natural Numbers (ℕ)**, **Integers (ℤ)**, and **Real Numbers (ℝ)** help determine the valid solutions.
- Correct use of **open and closed intervals** is essential while writing interval notation.
- Linear inequations have practical applications in business, economics, engineering, and optimization problems.
- Understanding inequality rules and careful sign handling are key to solving ICSE Class 10 examination questions accurately.
