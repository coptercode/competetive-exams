# Introduction

Algebraic expansions are used to multiply algebraic expressions quickly using standard identities instead of long multiplication. These identities simplify calculations, help in solving equations, factorization, and evaluating numerical expressions efficiently. This chapter covers quadratic and cubic identities, conditional expansions, reciprocal expressions, and numerical applications.

---

# 1. Quadratic Identities

Quadratic identities are formulas used to expand the square of algebraic expressions.

---

## Identity 1

### Square of a Sum

```
(a + b)² = a² + 2ab + b²
```

### Example

Expand

```
(x + 5)²
```

```
= x² + 2(x)(5) + 25

= x² + 10x + 25
```

---

## Identity 2

### Square of a Difference

```
(a − b)² = a² − 2ab + b²
```

### Example

Expand

```
(y − 3)²
```

```
= y² − 6y + 9
```

---

## Identity 3

### Product of Sum and Difference

```
(a + b)(a − b)

= a² − b²
```

### Example

```
(x + 4)(x − 4)

= x² − 16
```

---

## Identity 4

### Square of Three Terms

```
(a + b + c)²

= a² + b² + c²

+ 2ab + 2bc + 2ca
```

### Example

Expand

```
(x + y + 2)²
```

```
= x² + y² + 4

+ 2xy + 4x + 4y
```

---

# 2. Cubic Identities

Cubic identities are used to expand expressions involving cubes.

---

## Identity 1

### Cube of a Sum

```
(a + b)³

= a³ + 3a²b

+ 3ab² + b³
```

### Example

Expand

```
(x + 2)³
```

```
= x³ + 6x²

+ 12x + 8
```

---

## Identity 2

### Cube of a Difference

```
(a − b)³

= a³ − 3a²b

+ 3ab² − b³
```

### Example

Expand

```
(x − 1)³
```

```
= x³ − 3x²

+ 3x − 1
```

---

## Identity 3

### Sum of Cubes

```
a³ + b³

= (a + b)

(a² − ab + b²)
```

---

## Identity 4

### Difference of Cubes

```
a³ − b³

= (a − b)

(a² + ab + b²)
```

---

# 3. Conditional Expansions

Certain identities are useful when variables satisfy special conditions.

---

## Identity

If

```
a + b + c = 0
```

then

```
a³ + b³ + c³

= 3abc
```

---

### Example

If

```
a + b + c = 0
```

and

```
abc = 12
```

Find

```
a³ + b³ + c³
```

Solution

```
= 3 × 12

= 36
```

---

## Another Useful Identity

```
(a + b)²

= (a − b)²

+ 4ab
```

---

# 4. Reciprocal Operations

Expressions involving

```
x + 1/x
```

or

```
x − 1/x
```

can be simplified using identities.

---

## Identity 1

If

```
x + 1/x = a
```

then

```
x² + 1/x²

= a² − 2
```

---

## Identity 2

If

```
x − 1/x = a
```

then

```
x² + 1/x²

= a² + 2
```

---

## Identity 3

If

```
x + 1/x = a
```

then

```
x³ + 1/x³

= a³ − 3a
```

---

### Example

Given

```
x + 1/x = 4
```

Find

```
x² + 1/x²
```

Solution

```
= 4² − 2

= 16 − 2

= 14
```

# 5. Numerical Applications

Algebraic identities simplify calculations without direct multiplication.

---

## Example 1

Find

```
103²
```

Solution

```
= (100 + 3)²

= 10000

+ 600

+ 9

= 10609
```

---

## Example 2

Find

```
97²
```

Solution

```
= (100 − 3)²

= 10000

− 600

+ 9

= 9409
```

---

## Example 3

Find

```
98 × 102
```

Solution

```
= (100 − 2)

(100 + 2)

= 100² − 2²

= 10000 − 4

= 9996
```

---

## Example 4

Find

```
51³
```

Solution

```
= (50 + 1)³

= 125000

+ 7500

+ 150

+ 1

= 132651
```

# Solved Examples

## Example 1

### Question

Expand

```
(2x + 5)²
```

### Solution

Using

```
(a + b)²
```

```
= (2x)²

+ 2(2x)(5)

+ 25

= 4x² + 20x + 25
```

### Answer

```
4x² + 20x + 25
```

---

Expand

```
(a − 6)³
```

### Solution

Using

```
(a − b)³
```

```
= a³

− 18a²

+ 108a

− 216
```

### Answer

```
a³ − 18a² + 108a − 216
```

Evaluate

```
99 × 101
```

# Common Mistakes

- Forgetting the **2ab** term while expanding **(a + b)²**.
- Using incorrect signs in **(a − b)²** and **(a − b)³**.
- Confusing **sum of cubes** with **difference of cubes** identities.
- Omitting cross-product terms in **(a + b + c)²**.
- Applying reciprocal identities without checking the given condition.
- Making arithmetic mistakes while expanding numerical expressions.
- Forgetting to simplify like terms after expansion.
- Using the wrong identity for the given expression.

# Chapter Summary

- **Algebraic identities** simplify multiplication and expansion of expressions.
- The identities **(a ± b)²**, **(a ± b)³**, and **(a + b + c)²** are fundamental for expanding algebraic expressions.
- The **sum and difference of cubes** identities help simplify cubic expressions and are useful in later factorization.
- Special identities such as **a³ + b³ + c³ = 3abc** (when **a + b + c = 0**) reduce complex calculations.
- Reciprocal expressions involving **x + 1/x** or **x − 1/x** can be evaluated efficiently using standard identities.
- Algebraic identities are widely used for **mental calculations**, **factorization**, **equation solving**, and **higher mathematics**.
- Mastering these identities improves speed, accuracy, and problem-solving skills in algebra.
