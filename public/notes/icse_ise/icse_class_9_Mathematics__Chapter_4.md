# Introduction

**Factorization** is the process of expressing an algebraic expression as the product of two or more simpler algebraic expressions called **factors**. It is the reverse process of expansion and is widely used in simplifying expressions, solving equations, and higher algebra.

---

# 1. Factorization by Common Factor

A common factor is the greatest algebraic term that is present in every term of the expression.

---

## Steps

1. Find the greatest common factor (GCF).
2. Take it outside the bracket.
3. Divide each term by the common factor.

---

## Formula

```
ab + ac = a(b + c)
```

---

## Example 1

Factorize

```
6x + 12
```

Solution

```
= 6(x + 2)
```

---

## Example 2

Factorize

```
15xy + 20x
```

Solution

```
= 5x(3y + 4)
```

---

## Example 3

Factorize

```
8a²b + 12ab²
```

Solution

```
= 4ab(2a + 3b)
```

---

# 2. Difference of Two Squares

Expressions of the form

```
a² − b²
```

can be factorized using the identity.

---

## Identity

```
a² − b²

= (a + b)(a − b)
```

---

## Example 1

Factorize

```
x² − 16
```

Solution

```
= (x + 4)(x − 4)
```

---

## Example 2

Factorize

```
49a² − 25b²
```

Solution

```
= (7a + 5b)(7a − 5b)
```

---

## Example 3

Factorize

```
81 − y²
```

Solution

```
= (9 + y)(9 − y)
```

---

# 3. Splitting the Middle Term

Quadratic expressions of the form

```
ax² + bx + c
```

can be factorized by splitting the middle term.

---

## Steps

1. Multiply

```
a × c
```

2. Find two numbers whose:

- Product = ac
- Sum = b

3. Split the middle term.

4. Factor by grouping.

---

## Example 1

Factorize

```
x² + 7x + 12
```

Numbers required:

```
3 and 4
```

Solution

```
= x² + 3x + 4x + 12

= x(x + 3)

+4(x + 3)

=(x + 3)(x + 4)
```

---

## Example 2

Factorize

```
2x² + 7x + 3
```

Required numbers:

```
6 and 1
```

Solution

```
=2x²+6x+x+3

=2x(x+3)

+1(x+3)

=(2x+1)(x+3)
```

# 4. Sum and Difference of Cubes

Special identities help factorize cubic expressions.

---

## Sum of Cubes

### Identity

```
a³+b³

=(a+b)

(a²−ab+b²)
```

---

### Example

Factorize

```
x³+27
```

Since

```
27=3³
```

Solution

```
=(x+3)

(x²−3x+9)
```

---

## Difference of Cubes

### Identity

```
a³−b³

=(a−b)

(a²+ab+b²)
```

---

### Example

Factorize

```
8x³−125
```

Solution

```
=(2x−5)

(4x²+10x+25)
```

---

# 5. Grouping and Perfect Square Method

Sometimes expressions are rearranged into groups before factorization.

---

## Factorization by Grouping

### Formula

```
ab+ac+bd+cd

=(a+d)(b+c)
```

---

### Example

Factorize

```
xy+x+3y+3
```

Solution

```
=x(y+1)

+3(y+1)

=(x+3)(y+1)
```

---

## Completing a Perfect Square

Expressions can be rewritten as a perfect square and then factorized.

---

### Example

Factorize

```
x²+6x+9−16
```

Solution

```
=(x+3)²−4²

=(x+3+4)

(x+3−4)

=(x+7)(x−1)
```

---

## Difference Between Expansion and Factorization

| Expansion                 | Factorization                   |
| ------------------------- | ------------------------------- |
| Multiplies expressions    | Splits expressions into factors |
| Uses identities to expand | Uses identities to factor       |
| Example: (x+2)² → x²+4x+4 | Example: x²+4x+4 → (x+2)²       |

# Common Mistakes

- Forgetting to take the **greatest common factor** first.
- Confusing the identities for **sum of cubes** and **difference of cubes**.
- Incorrectly splitting the middle term in quadratic expressions.
- Missing negative signs while factorizing.
- Applying the **difference of squares** identity to expressions that are not perfect squares.
- Forgetting to rearrange terms before grouping.
- Making arithmetic errors while identifying suitable numbers for middle-term splitting.
- Not verifying the answer by multiplying the factors back.

# Chapter Summary

- **Factorization** is the reverse process of expansion and expresses an algebraic expression as a product of simpler factors.
- The simplest method is **factorization by taking the common factor**.
- Expressions of the form **a² − b²** are factorized using the **difference of two squares** identity.
- Quadratic expressions can be factorized by **splitting the middle term**.
- Cubic expressions are factorized using the **sum and difference of cubes** identities.
- More complex expressions can be factorized using **grouping** or by **completing a perfect square**.
- Always verify factorization by expanding the obtained factors.
- Factorization is an essential technique used in solving equations, simplifying algebraic expressions, and advanced mathematics.
