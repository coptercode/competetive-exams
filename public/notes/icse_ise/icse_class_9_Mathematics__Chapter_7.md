# Introduction

**Logarithms** are the inverse operation of exponents (indices). They simplify calculations involving very large or very small numbers and are widely used in mathematics, science, engineering, and finance. This chapter introduces the definition of logarithms, conversion between exponential and logarithmic forms, laws of logarithms, change of base, common logarithms, and solving logarithmic equations.

---

# 1. Introduction to Logarithms

## Definition

If

```

aˣ = b

```

then

```

logₐ b = x

```

where

- **a** = Base (**a > 0**, **a ≠ 1**)
- **b** = Argument (**b > 0**)
- **x** = Logarithm

---

## Relationship Between Exponential and Logarithmic Forms

### Exponential Form

```

2³ = 8

```

### Logarithmic Form

```

log₂ 8 = 3

```

---

### Example

```

10² = 100

```

Therefore,

```

log₁₀ 100 = 2

```

---

## Converting Between Forms

### Exponential → Logarithmic

```

5³ = 125

```

becomes

```

log₅ 125 = 3

```

---

### Logarithmic → Exponential

```

log₄ 64 = 3

```

becomes

```

4³ = 64

```

---

# 2. Laws of Logarithms

The laws of logarithms simplify multiplication, division, and powers.

---

## Law 1: Product Rule

The logarithm of a product equals the sum of the logarithms.

### Formula

```

logₐ(MN)

= logₐ M + logₐ N

```

### Example

```

log₂(8 × 4)

= log₂8 + log₂4

= 3 + 2

= 5

```

---

## Law 2: Quotient Rule

The logarithm of a quotient equals the difference of the logarithms.

### Formula

```

logₐ(M/N)

= logₐM − logₐN

```

### Example

```

log₁₀(1000/10)

= 3 − 1

= 2

```

---

## Law 3: Power Rule

The exponent becomes the coefficient.

### Formula

```

logₐ(Mⁿ)

= n logₐM

```

### Example

```

log₂(8²)

= 2 log₂8

= 2 × 3

= 6

```

---

## Law 4: Logarithm of One

```

logₐ1 = 0

```

because

```

a⁰ = 1

```

---

## Law 5: Logarithm of the Base

```

logₐa = 1

```

because

```

a¹ = a

```

---

# 3. Change of Base Formula

Sometimes logarithms must be converted into another base.

---

## Formula

```

logₐb

= log_cb / log_ca

```

where

- **c** is any positive base.

---

### Example

Find

```

log₂8

```

using common logarithms.

```

log₂8

= log10 8 / log10 2

```

Using calculator values,

```

= 0.9031 / 0.3010

= 3

```

# 4. Common Logarithms

A logarithm with base **10** is called a **Common Logarithm**.

---

## Notation

```

log x

```

means

```

log₁₀x

```

---

### Examples

```

log10 = 1

```

```

log100 = 2

```

```

log1000 = 3

```

```

log1 = 0

```

---

## Characteristic and Mantissa

A common logarithm has two parts.

### Characteristic

The integer part.

### Mantissa

The decimal part.

Example

```

log50

≈ 1.6990

```

Characteristic

```

1

```

Mantissa

```

0.6990

```

---

## Antilogarithm

The inverse of a logarithm is called the **antilogarithm**.

Example

```

log₁₀x = 2

```

Then

```

x = 100

```

# 5. Solving Logarithmic Equations

Logarithmic equations are solved using the laws of logarithms and the relationship between logarithms and exponents.

---

## Method 1

Convert logarithmic form into exponential form.

### Example

Solve

```

log₂x = 5

```

Solution

```

x = 2⁵

= 32

```

---

## Method 2

Use logarithmic laws.

### Example

Solve

```

log₁₀x + log₁₀2 = 2

```

Using the product rule,

```

log₁₀(2x) = 2

```

Convert into exponential form.

```

2x = 100

```

```

x = 50

```

---

## Method 3

Quotient Rule

### Example

Solve

```

log₃27 − log₃x = 2

```

Using the quotient rule,

```

log₃(27/x) = 2

```

```

27/x = 9

```

```

x = 3

```

# Common Mistakes

- Confusing the **base** with the **argument**.
- Forgetting that the argument of a logarithm must always be **positive**.
- Using incorrect logarithmic laws for multiplication and division.
- Assuming

```

log(a + b)

= log a + log b

```

which is **incorrect**.
- Ignoring the change of base formula when required.
- Forgetting that

```

logₐ1 = 0

```

and

```

logₐa = 1

```
- Making errors while converting between logarithmic and exponential forms.

# Chapter Summary

- **Logarithms** are the inverse of exponential functions.
- Any exponential equation can be written in logarithmic form and vice versa.
- The **laws of logarithms** simplify multiplication, division, and powers of numbers.
- The **change of base formula** allows conversion of logarithms from one base to another.
- **Common logarithms** have base **10** and are widely used in scientific calculations.
- Logarithmic equations are solved by converting them into equivalent exponential equations.
- Logarithms have numerous applications in science, engineering, finance, computer science, and everyday calculations.
- A solid understanding of logarithms forms the foundation for higher mathematics and advanced problem-solving.
