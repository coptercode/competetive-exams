# Introduction

The **Goods and Services Tax (GST)** is an indirect tax introduced in India on **1 July 2017**. It replaced multiple indirect taxes such as VAT, Excise Duty, Service Tax, and Entry Tax with a single tax system.

GST is collected at every stage of the supply chain, but the burden of tax is ultimately borne by the **final consumer**. Businesses can reduce their tax liability through the **Input Tax Credit (ITC)** mechanism.

---

# 1. Goods and Services Tax (GST)

## Definition

**GST (Goods and Services Tax)** is a destination-based indirect tax imposed on the supply of goods and services.

---

## Features of GST

- Single indirect tax system
- Eliminates cascading (tax on tax)
- Collected at every stage of supply
- Final tax burden is on the consumer
- Promotes transparency
- Supports Input Tax Credit (ITC)

---

## Components of GST

GST is divided into three parts:

### CGST (Central Goods and Services Tax)

Collected by the Central Government on **intra-state** transactions.

---

### SGST (State Goods and Services Tax)

Collected by the State Government on **intra-state** transactions.

---

### IGST (Integrated Goods and Services Tax)

Collected by the Central Government on **inter-state** transactions.

---

# 2. Intra-State Transactions

## Definition

When the seller and buyer are located in the **same state**, GST is divided equally into:

- CGST
- SGST

---

## Formula

```
CGST

=

GST Rate / 2
```

```
SGST

=

GST Rate / 2
```

---

## Total GST

```
GST

=

CGST + SGST
```

---

### Example

Selling Price

```
₹40,000
```

GST Rate

```
18%
```

CGST

```
= 9%
```

SGST

```
= 9%
```

CGST Amount

```
= 9% of ₹40,000

= ₹3,600
```

SGST Amount

```
= ₹3,600
```

Total GST

```
₹7,200
```

Invoice Value

```
₹40,000 + ₹7,200

= ₹47,200
```

---

# 3. Inter-State Transactions

## Definition

When goods move from one state to another, **IGST** is charged instead of CGST and SGST.

---

## Formula

```
IGST

=

GST Rate × Taxable Value
```

---

### Example

Taxable Value

```
₹60,000
```

GST

```
18%
```

IGST

```
18%

of

₹60,000

=

₹10,800
```

Invoice Value

```
₹60,000

+

₹10,800

=

₹70,800
```

---

# 4. Input Tax Credit (ITC)

## Definition

Input Tax Credit allows a registered business to reduce the GST already paid on purchases from the GST payable on sales.

---

## Formula

```
Net GST Payable

=

Output GST

−

Input GST
```

---

### Example

GST Paid on Purchases

```
₹8,000
```

GST Collected on Sales

```
₹12,500
```

Net GST

```
₹12,500

−

₹8,000

=

₹4,500
```

---

## Advantages of ITC

- Prevents double taxation
- Reduces overall tax burden
- Encourages proper invoicing
- Improves tax compliance

# Common Mistakes

- Confusing **CGST/SGST** with **IGST**.
- Applying **CGST and SGST** to inter-state transactions instead of **IGST**.
- Forgetting to divide the GST rate equally for intra-state sales.
- Calculating GST on the invoice value instead of the taxable value.
- Ignoring the **Input Tax Credit (ITC)** while computing the net tax payable.
- Adding GST twice in multi-stage supply chain problems.
- Forgetting that the **final consumer cannot claim ITC**.
- Using incorrect GST percentages in calculations.

# Formula Sheet

| Formula                                  | Description      |
| ---------------------------------------- | ---------------- |
| **GST = Taxable Value × GST Rate / 100** | GST Amount       |
| **Invoice Value = Taxable Value + GST**  | Final Price      |
| **Taxable Value = Invoice Value − GST**  | Before Tax       |
| **CGST = GST ÷ 2**                       | Intra-State Tax  |
| **SGST = GST ÷ 2**                       | Intra-State Tax  |
| **IGST = Entire GST Amount**             | Inter-State Tax  |
| **Net GST = Output GST − Input GST**     | Tax Liability    |
| **ITC = GST Paid on Purchases**          | Input Tax Credit |

# Chapter Summary

- **GST (Goods and Services Tax)** is a destination-based indirect tax levied on the supply of goods and services.
- **Intra-state transactions** attract **CGST and SGST**, each charged at half of the total GST rate.
- **Inter-state transactions** attract **IGST**, which is equal to the full GST rate.
- **Input Tax Credit (ITC)** enables businesses to deduct the GST paid on purchases from the GST collected on sales.
- The **Net Tax Liability** is calculated by subtracting the **Input Tax Credit** from the **Output GST**.
- In a **multi-stage supply chain**, each dealer pays GST only on the value added, while the **final consumer bears the entire tax burden**.
- Correct use of GST formulas is essential for preparing invoices and solving board examination problems.
- GST simplifies taxation, reduces cascading taxes, and improves transparency in the tax system.
