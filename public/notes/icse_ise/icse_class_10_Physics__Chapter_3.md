# Introduction

A **machine** is a device that makes work easier by multiplying force, changing the direction of force, increasing speed, or transferring force from one place to another. Machines do not reduce the total work done; instead, they help us perform work more conveniently and efficiently. This chapter covers **Mechanical Advantage (MA), Velocity Ratio (VR), Efficiency (η), Levers, Pulleys, and Block and Tackle Systems**.

---

# 1. Machine

## Definition

A **machine** is a device that helps us do work with less effort by changing the magnitude or direction of the applied force.

---

## Functions of a Machine

- Multiplies force.
- Changes the direction of force.
- Increases speed.
- Transfers force from one point to another.

---

# 2. Effort and Load

## Effort (E)

The force applied to operate a machine.

---

## Load (L)

The resistance or weight lifted by the machine.

---

# 3. Mechanical Advantage (MA)

## Definition

**Mechanical Advantage** is the ratio of the load lifted by a machine to the effort applied.

---

## Formula

```
          Load
MA = -------------
         Effort
```

or

```
MA = L / E
```

---

## SI Unit

```
No unit (Dimensionless)
```

---

## Interpretation

- MA > 1 → Machine multiplies force.
- MA = 1 → No force multiplication.
- MA < 1 → Machine increases speed instead of force.

---

# 4. Velocity Ratio (VR)

## Definition

**Velocity Ratio** is the ratio of the distance moved by the effort to the distance moved by the load.

---

## Formula

```
              Distance moved by Effort
VR = -----------------------------------------
              Distance moved by Load
```

or

```
VR = DE / DL
```

---

## SI Unit

```
No unit
```

---

# 5. Efficiency (η)

## Definition

Efficiency is the percentage of input work converted into useful output work.

---

## Formula

```
               Output Work
η = ---------------------------- × 100%
               Input Work
```

---

## Relation Between MA and VR

```
           MA
η = --------------- × 100%
           VR
```

or

```
MA = η × VR
```

(Here, η is expressed as a decimal in the second equation.)

---

## Important Points

- Efficiency can never exceed **100%**.
- Due to friction, practical machines always have efficiency less than 100%.

---

# 6. Lever

## Definition

A **lever** is a rigid bar capable of rotating about a fixed point called the **fulcrum**.

---

## Parts of a Lever

- **Fulcrum (F):** Fixed point.
- **Effort (E):** Applied force.
- **Load (L):** Resistance lifted.

---

# Principle of Lever

```
Effort × Effort Arm

=

Load × Load Arm
```

---

## Formula

```
E × EA = L × LA
```

---

# 7. Types of Levers

---

## (i) Class I Lever

### Arrangement

```
Effort ─ Fulcrum ─ Load

E ─ F ─ L
```

Fulcrum lies between effort and load.

---

### Examples

- Seesaw.
- Scissors.
- Crowbar.
- Beam balance.

---

## (ii) Class II Lever

### Arrangement

```
Fulcrum ─ Load ─ Effort

F ─ L ─ E
```

Load lies between fulcrum and effort.

---

### Examples

- Wheelbarrow.
- Nutcracker.
- Bottle opener.

---

## (iii) Class III Lever

### Arrangement

```
Fulcrum ─ Effort ─ Load

F ─ E ─ L
```

Effort lies between fulcrum and load.

---

### Examples

- Human forearm.
- Fishing rod.
- Tweezers.

---

# Comparison of Levers

| Class I                | Class II         | Class III        |
| ---------------------- | ---------------- | ---------------- |
| Fulcrum in middle      | Load in middle   | Effort in middle |
| MA may be <, =, or > 1 | MA > 1           | MA < 1           |
| Changes direction      | Multiplies force | Multiplies speed |

---

# 8. Pulley

## Definition

A **pulley** is a simple machine consisting of a grooved wheel over which a rope passes.

---

# (i) Single Fixed Pulley

## Characteristics

- Changes direction of effort.
- Does not multiply force.

---

## Formulae

```
MA = 1

VR = 1

η = MA/VR ×100%
```

---

## Example

```
Drawing water from a well.
```

---

# (ii) Single Movable Pulley

## Characteristics

- Multiplies force.
- Effort acts upward.

---

## Formulae

```
MA = 2

VR = 2
```

(Ideal machine)

---

## Example

```
Construction cranes.
```

---

# (iii) Block and Tackle System

## Definition

A combination of fixed and movable pulleys used to lift heavy loads.

---

## Velocity Ratio

```
VR = Number of supporting rope segments
```

or

```
VR = Number of pulleys supporting the load
```

---

## Characteristics

- High mechanical advantage.
- Suitable for lifting heavy loads.

---

## Applications

- Cranes.
- Elevators.
- Dockyards.
- Construction sites.

---

# Difference Between Fixed and Movable Pulley

| Fixed Pulley           | Movable Pulley   |
| ---------------------- | ---------------- |
| Fixed to support       | Moves with load  |
| Changes direction only | Multiplies force |
| MA = 1                 | MA = 2 (Ideal)   |
| VR = 1                 | VR = 2           |

---

# Difference Between Machine and Lever

| Machine                  | Lever                  |
| ------------------------ | ---------------------- |
| General device           | Type of simple machine |
| Many forms               | Rigid bar              |
| May use gears or pulleys | Uses fulcrum           |

# Solved Examples

## Example 1

### Question

A machine lifts a **200 N** load using an effort of **50 N**. Calculate its Mechanical Advantage.

### Solution

```
MA = L/E

= 200/50

= 4
```

### Answer

```
MA = 4
```

---

## Example 2

### Question

A machine has **MA = 4** and **VR = 5**. Find its efficiency.

### Solution

```
η = MA/VR ×100

= 4/5 ×100

= 80%
```

### Answer

```
80%
```

---

## Example 3

### Question

Identify the class of lever in which the load lies between the fulcrum and effort.

### Solution

The arrangement is:

```
F ─ L ─ E
```

### Answer

```
Class II Lever
```

---

## Example 4

### Question

What are the Mechanical Advantage and Velocity Ratio of an ideal single fixed pulley?

### Solution

A fixed pulley changes only the direction of force.

### Answer

```
MA = 1

VR = 1
```

---

## Example 5

### Question

A block and tackle system has **6 supporting rope segments**. Determine its Velocity Ratio.

### Solution

```
VR = Number of supporting rope segments

VR = 6
```

### Answer

```
VR = 6
```

# Common Mistakes

- Confusing **Mechanical Advantage (MA)** with **Velocity Ratio (VR)**.
- Forgetting that **efficiency is always less than or equal to 100%**.
- Mixing up the positions of **fulcrum, effort, and load** in different classes of levers.
- Assuming a **fixed pulley multiplies force** (it only changes the direction of effort).
- Using incorrect units for MA and VR (both are **dimensionless**).
- Forgetting that friction reduces the efficiency of real machines.

---

# Quick Revision

- Machine → Makes work easier.
- Mechanical Advantage → **MA = L/E**.
- Velocity Ratio → **VR = DE/DL**.
- Efficiency → **η = (MA/VR) × 100%**.
- Lever Principle → **E × EA = L × LA**.
- Class I Lever → **Fulcrum in middle**.
- Class II Lever → **Load in middle**.
- Class III Lever → **Effort in middle**.
- Single Fixed Pulley → **MA = 1, VR = 1**.
- Single Movable Pulley → **MA = 2, VR = 2 (ideal)**.
- Block and Tackle → **VR = Number of supporting rope segments**.

# Chapter Summary

- A **machine** is a device that makes work easier by multiplying force, changing its direction, increasing speed, or transferring force efficiently.
- The performance of a machine is measured using **Mechanical Advantage (MA)**, **Velocity Ratio (VR)**, and **Efficiency (η)**. These quantities are related by **η = (MA/VR) × 100%**.
- A **lever** is a simple machine that works on the **Principle of Moments**, where the effort moment equals the load moment.
- Levers are classified into **Class I, Class II, and Class III** based on the positions of the fulcrum, load, and effort, each suited for different practical applications.
- **Pulleys** are simple machines used to lift loads. A **single fixed pulley** changes the direction of effort, while a **single movable pulley** and a **block and tackle system** provide force multiplication.
- Machines are widely used in engineering, construction, transportation, manufacturing, and daily life to perform work more efficiently and safely.
