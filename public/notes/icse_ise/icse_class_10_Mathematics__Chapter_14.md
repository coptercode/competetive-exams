# Introduction

A **Circle** is one of the most important geometrical figures. It is the set of all points in a plane that are at a constant distance from a fixed point called the **centre**. Circles are widely used in engineering, architecture, astronomy, transportation, construction, and computer graphics. Understanding the properties and theorems related to circles helps in solving many geometrical problems.

---

# 1. Circle

## Definition

A **Circle** is the collection of all points in a plane that are at an equal distance from a fixed point called the **Centre**.

---

## Parts of a Circle

- Centre
- Radius
- Diameter
- Chord
- Arc
- Sector
- Segment
- Tangent
- Secant

---

# 2. Radius

## Definition

A **Radius** is the line segment joining the centre of the circle to any point on the circle.

---

## Symbol

```
r
```

---

# 3. Diameter

## Definition

A **Diameter** is a chord that passes through the centre of the circle.

---

## Formula

```
Diameter = 2 × Radius
```

or

```
d = 2r
```

---

# 4. Chord

## Definition

A **Chord** is a line segment joining any two points on the circumference of the circle.

### Important Fact

The **Diameter** is the longest chord of a circle.

---

# 5. Arc

## Definition

An **Arc** is a part of the circumference of a circle.

### Types

- Minor Arc
- Major Arc
- Semicircular Arc

---

# 6. Sector

## Definition

A **Sector** is the region enclosed by two radii and the intercepted arc.

### Types

- Minor Sector
- Major Sector

---

# 7. Segment

## Definition

A **Segment** is the region enclosed by a chord and its corresponding arc.

### Types

- Minor Segment
- Major Segment

---

# 8. Tangent

## Definition

A **Tangent** is a line that touches the circle at exactly one point.

This point is called the **Point of Contact**.

---

## Theorem 1

The tangent at any point of a circle is **perpendicular** to the radius through the point of contact.

### Statement

If

```
PT
```

is a tangent at

```
P
```

then

```
OP ⟂ PT
```

where

```
O
```

is the centre.

---

# 9. Secant

## Definition

A **Secant** is a line that intersects the circle at two distinct points.

---

# 10. Equal Chords Theorem

## Statement

Equal chords of a circle are equidistant from the centre.

---

## Converse

Chords equidistant from the centre are equal.

---

# 11. Perpendicular from Centre to Chord

## Theorem

The perpendicular drawn from the centre of a circle to a chord bisects the chord.

---

### Converse

The line joining the centre to the midpoint of a chord is perpendicular to the chord.

---

# 12. Angles in the Same Segment

## Theorem

Angles subtended by the same chord in the same segment are equal.

---

### Formula

If

```
∠ABC
```

and

```
∠ADC
```

stand on the same chord,

then

```
∠ABC = ∠ADC
```

---

# 13. Angle in a Semicircle

## Theorem

The angle subtended by a diameter at the circumference is always a right angle.

---

### Formula

If

```
AB
```

is a diameter,

then

```
∠ACB = 90°
```

---

# 14. Cyclic Quadrilateral

## Definition

A quadrilateral whose four vertices lie on the same circle is called a **Cyclic Quadrilateral**.

---

## Theorem

The opposite angles of a cyclic quadrilateral are supplementary.

---

## Formula

```
∠A + ∠C = 180°
```

```
∠B + ∠D = 180°
```

---

# 15. Tangents from an External Point

## Theorem

The lengths of tangents drawn from an external point to a circle are equal.

---

### Formula

If

```
PA

and

PB
```

are tangents,

then

```
PA = PB
```

# Solved Examples

## Example 1

### Question

The radius of a circle is

```
7 cm.
```

Find its diameter.

### Solution

```
d = 2r

= 2×7

=14 cm
```

### Answer

```
14 cm
```

---

## Example 2

### Question

State the angle made by a tangent with the radius at the point of contact.

### Solution

A tangent is perpendicular to the radius.

### Answer

```
90°
```

---

## Example 3

### Question

A diameter subtends an angle at the circumference.

Find the angle.

### Solution

By the theorem,

```
Angle in a semicircle

=

90°
```

### Answer

```
90°
```

---

## Example 4

### Question

In a cyclic quadrilateral,

```
∠A = 110°
```

Find

```
∠C.
```

### Solution

```
∠A + ∠C

=

180°
```

```
110° + ∠C

=

180°
```

```
∠C

=

70°
```

### Answer

```
70°
```

---

## Example 5

### Question

From an external point

```
P,
```

two tangents

```
PA

and

PB
```

are drawn.

If

```
PA = 12 cm,
```

find

```
PB.
```

### Solution

Tangents from the same external point are equal.

```
PB = PA =12 cm
```

### Answer

```
12 cm
```

# Common Mistakes

- Confusing a **Chord** with a **Diameter**.
- Assuming every secant is a tangent.
- Forgetting that the **tangent is perpendicular** to the radius at the point of contact.
- Mixing up **Sector** and **Segment**.
- Forgetting that **angles in the same segment are equal**.
- Using the cyclic quadrilateral theorem incorrectly.
- Assuming all quadrilaterals are cyclic.
- Forgetting that tangents drawn from the same external point are equal.

# Chapter Summary

- A **Circle** is the set of all points equidistant from a fixed point called the **centre**.
- The **Radius** joins the centre to a point on the circle, while the **Diameter** is the longest chord and equals **2r**.
- A **Chord** joins any two points on the circle, whereas an **Arc** is a part of the circumference.
- A **Sector** is bounded by two radii and an arc, while a **Segment** is bounded by a chord and an arc.
- A **Tangent** touches the circle at exactly one point and is always **perpendicular** to the radius at the point of contact.
- A **Secant** intersects the circle at two points.
- Important theorems include:
  - Equal chords are equidistant from the centre.
  - The perpendicular from the centre to a chord bisects the chord.
  - Angles in the same segment are equal.
  - The angle subtended by a diameter is **90°**.
  - Opposite angles of a cyclic quadrilateral are supplementary.
  - Tangents drawn from the same external point are equal.
- Circle theorems are extensively used in geometry, engineering, architecture, computer graphics, and real-world design applications.
