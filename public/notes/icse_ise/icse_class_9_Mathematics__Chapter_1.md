# Introduction

Numbers are the foundation of mathematics. They are classified into different types based on their properties. The **Real Number System** consists of **Rational Numbers** and **Irrational Numbers**. This chapter explains their definitions, decimal representations, operations on surds, rationalization of denominators, proofs of irrationality, and representation of irrational numbers on the number line.

---

# 1. Real Number System

The **Real Number System** consists of all numbers that can be represented on the number line.

```
Real Numbers
│
├── Rational Numbers (Q)
│
└── Irrational Numbers
```

---

## Natural Numbers (N)

Counting numbers beginning from 1.

```
N = {1, 2, 3, 4, ...}
```

---

## Whole Numbers (W)

Natural numbers together with zero.

```
W = {0, 1, 2, 3, ...}
```

---

## Integers (Z)

Positive numbers, negative numbers, and zero.

```
Z = {...,-3,-2,-1,0,1,2,3,...}
```

---

## Rational Numbers (Q)

A **rational number** is any number that can be expressed in the form

```
p/q
```

where

- **p** and **q** are integers.
- **q ≠ 0**

### Examples

```
3/4

-5/7

8

0

2.75
```

---

## Decimal Representation of Rational Numbers

A rational number has either:

- Terminating decimal expansion

Example

```
3/8 = 0.375
```

or

- Non-terminating recurring decimal expansion

Example

```
1/3 = 0.3333...
```

---

## Irrational Numbers

An **irrational number** cannot be expressed as

```
p/q
```

Its decimal expansion is:

- Non-terminating
- Non-recurring

### Examples

```
√2

√3

√5

π

e
```

# 2. Rationalization

## Rationalization

Rationalization is the process of removing irrational numbers from the denominator of a fraction.

---

## Conjugate

The conjugate of

```
a + √b
```

is

```
a - √b
```

Similarly,

```
a - √b
```

has conjugate

```
a + √b
```

---

## Rationalizing Simple Surds

### Example

Simplify

```
1/√2
```

Multiply numerator and denominator by

```
√2
```

```
= √2/2
```

---

## Rationalizing Binomial Surds

### Example

```
1/(3 + √2)
```

Multiply numerator and denominator by the conjugate.

```
(3 - √2)
```

```
= (3 - √2)/(9 - 2)

= (3 - √2)/7
```

# 3. Irrationality Proofs

Some numbers cannot be expressed as fractions.

---

## Proof that √2 is Irrational

### Method

Proof by contradiction.

Assume

```
√2 = p/q
```

where

- p and q have no common factor.

Squaring both sides,

```
2 = p²/q²
```

```
p² = 2q²
```

Hence,

```
p²
```

is even.

Therefore,

```
p
```

is even.

Let

```
p = 2k
```

Substitute,

```
4k² = 2q²
```

```
q² = 2k²
```

Hence,

```
q
```

is also even.

Thus,

```
p
```

and

```
q
```

are both even.

This contradicts the assumption that they have no common factor.

Therefore,

```
√2 is irrational.
```

---

## Similar Irrational Numbers

The same method can prove:

```
√3

√5

√7

√11
```

are irrational.

# 4. Surds

A **surd** is an irrational root that cannot be simplified further.

---

## Pure Surds

Contain only the irrational part.

Examples

```
√2

√5

√11
```

---

## Mixed Surds

Contain both rational and irrational parts.

Examples

```
3√2

5√7

8√3
```

---

## Like Surds

Surds having the same irrational part.

Examples

```
4√3

7√3

−2√3
```

---

## Unlike Surds

Surds having different irrational parts.

Examples

```
√2

√5

√7
```

---

## Addition of Surds

Only like surds can be added.

Example

```
3√5 + 4√5

= 7√5
```

---

## Subtraction of Surds

Example

```
9√7 − 2√7

= 7√7
```

---

## Multiplication of Surds

Example

```
√3 × √12

= √36

= 6
```

---

## Division of Surds

Example

```
√18/√2

= √9

= 3
```

---

## Comparing Surds

Square both surds.

Example

Compare

```
√5 and √7
```

Since

```
5 < 7
```

Therefore,

```
√5 < √7
```

# 5. Representation of Irrational Numbers on the Number Line

Irrational numbers can be represented using geometric constructions.

---

## Construction of √2

### Steps

1. Draw a number line.
2. Mark point **O** at 0.
3. Mark point **A** at 1.
4. Draw a perpendicular at **A** of length 1.
5. Join the end point to **O**.
6. The length obtained is

```
√2
```

7. With **O** as centre, draw an arc cutting the number line.

The point obtained represents

```
√2
```

---

## Construction of √3

Construct

```
√2
```

first.

Then construct another perpendicular of unit length.

The new hypotenuse gives

```
√3
```

---

## Applications of Pythagoras Theorem

Used for constructing

```
√2

√3

√5

√10
```

on the number line.

# Common Mistakes

- Confusing **terminating decimals** with **recurring decimals**.
- Assuming every square root is irrational (e.g., **√25 = 5**, which is rational).
- Forgetting to multiply both numerator and denominator during rationalization.
- Adding unlike surds directly.
- Confusing **surds** with all irrational numbers.
- Writing **q = 0** in the definition of rational numbers.
- Incorrectly simplifying square roots.
- Assuming π has a repeating decimal expansion.

# Chapter Summary

- **Real numbers** consist of **rational** and **irrational** numbers.
- A **rational number** can be expressed in the form **p/q**, where **q ≠ 0**.
- Rational numbers have **terminating** or **recurring** decimal expansions.
- **Irrational numbers** have **non-terminating** and **non-recurring** decimal expansions.
- **Rationalization** removes surds from the denominator by multiplying by a suitable surd or conjugate.
- **Surds** are irrational roots that cannot be simplified further and can be added or subtracted only when they are like surds.
- The irrationality of numbers such as **√2** can be proved using the **method of contradiction**.
- Irrational numbers can be represented accurately on the number line using the **Pythagoras theorem**.
- Understanding rational and irrational numbers is essential for algebra, geometry, trigonometry, and higher mathematics.
