# Introduction

A **Ratio** is a comparison of two quantities of the same kind using division. A **Proportion** is an equality of two ratios. Ratio and proportion are widely used in mathematics, business, engineering, maps, scale drawings, and scientific calculations. This chapter also includes **continued proportion**, **direct and inverse variation**, and important algebraic transformations such as **Componendo**, **Dividendo**, **Alternendo**, and **Invertendo**.

---

# 1. Ratio

## Definition

A **Ratio** is the comparison of two quantities of the same unit by division.

---

## Formula

```
Ratio

=

a : b

=

a/b
```

where

- **a** = First quantity
- **b** = Second quantity (b ≠ 0)

---

## Example

The ratio of

```
12

and

18
```

is

```
12 : 18

=

2 : 3
```

---

# 2. Proportion

## Definition

A **Proportion** is a statement that two ratios are equal.

---

## Formula

```
a : b = c : d
```

or

```
a/b = c/d
```

---

## Property of Proportion

If

```
a : b = c : d
```

then

```
ad = bc
```

This is called **Cross Multiplication**.

---

## Example

```
2 : 5 = 8 : 20
```

Since

```
2 × 20

=

5 × 8

=

40
```

the proportion is true.

---

# 3. Continued Proportion

## Definition

Three quantities are said to be in **continued proportion** if

```
a : b = b : c
```

Similarly, four quantities are in continued proportion if

```
a : b = b : c = c : d
```

---

## Property

For

```
a : b = b : c
```

```
b² = ac
```

Thus,

```
b = √ac
```

where **b** is called the **Mean Proportional**.

---

## Example

Find the mean proportional between

```
4

and

25
```

```
√(4 × 25)

=

√100

=

10
```

---

# 4. The k-Method

The **k-method** is used to simplify problems involving equal ratios.

If

```
a : b = m : n
```

then let

```
a = mk

b = nk
```

where **k** is a constant.

---

## Example

If

```
x : y = 3 : 5
```

then

```
x = 3k

y = 5k
```

---

# 5. Componendo and Dividendo

If

```
a/b = c/d
```

then

```
(a+b)/(a−b)

=

(c+d)/(c−d)
```

This result is called **Componendo and Dividendo**.

---

## Example

If

```
x/y = 2/3
```

then

```
(x+y)/(x−y)

=

(2+3)/(2−3)

=

5/−1

=

−5
```

---

# 6. Componendo

If

```
a/b = c/d
```

then

```
(a+b)/b

=

(c+d)/d
```

---

## Example

If

```
2/5 = x/y
```

then

```
7/5

=

(x+y)/y
```

---

# 7. Dividendo

If

```
a/b = c/d
```

then

```
(a−b)/b

=

(c−d)/d
```

---

# 8. Alternendo

If

```
a/b = c/d
```

then

```
a/c

=

b/d
```

---

## Example

```
6/8 = 9/12
```

Therefore

```
6/9

=

8/12
```

---

# 9. Invertendo

If

```
a/b = c/d
```

then

```
b/a

=

d/c
```

---

## Example

```
3/7 = 6/14
```

Then

```
7/3 = 14/6
```

---

# 10. Direct Variation

## Definition

Two quantities are said to vary **directly** if an increase in one causes a proportional increase in the other.

---

## Formula

```
y ∝ x
```

Therefore,

```
y = kx
```

where

```
k
```

is the constant of proportionality.

---

## Example

If

```
y ∝ x
```

and

```
x = 4

y = 20
```

then

```
20 = 4k
```

```
k = 5
```

Hence,

```
y = 5x
```

---

# 11. Inverse Variation

## Definition

Two quantities are said to vary **inversely** if one increases while the other decreases in the same proportion.

---

## Formula

```
y ∝ 1/x
```

Therefore,

```
xy = k
```

---

## Example

If

```
x = 6

y = 8
```

then

```
k = 48
```

When

```
x = 12
```

```
y

=

48/12

=

4
```

# Common Mistakes

- Comparing quantities with **different units** without converting them to the same unit.
- Forgetting to simplify ratios to their lowest terms.
- Confusing **ratio** with **proportion**.
- Applying **direct variation** instead of **inverse variation**, or vice versa.
- Using the wrong transformation for **Componendo**, **Dividendo**, **Alternendo**, or **Invertendo**.
- Making errors while using the **k-method**.
- Forgetting that the denominator of a ratio cannot be zero.
- Incorrectly performing cross multiplication in proportion problems.

# Chapter Summary

- A **Ratio** compares two quantities of the same kind, while a **Proportion** states that two ratios are equal.
- In a proportion, the product of the **extremes** equals the product of the **means** (**ad = bc**).
- In **continued proportion**, the square of the middle term equals the product of the other two terms (**b² = ac**).
- The **k-method** simplifies ratio problems by expressing quantities as multiples of a common constant.
- Algebraic transformations such as **Componendo**, **Dividendo**, **Alternendo**, **Invertendo**, and **Componendo and Dividendo** help solve complex proportional relationships.
- In **direct variation**, two quantities increase or decrease together (**y = kx**), whereas in **inverse variation**, one quantity increases as the other decreases (**xy = k**).
- Ratio and proportion have extensive applications in finance, engineering, maps, scale drawings, business, and everyday calculations.
- Mastery of proportional reasoning and correct application of formulas are essential for solving ICSE Class 10 examination questions accurately.
