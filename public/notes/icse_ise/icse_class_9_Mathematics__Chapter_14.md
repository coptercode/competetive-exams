# Introduction

**Coordinate Geometry**, also known as **Analytical Geometry**, is the branch of mathematics that studies geometric figures using a coordinate system. Every point on a plane is represented by an **ordered pair (x, y)**. Coordinate geometry helps in locating points, measuring distances, finding midpoints, and solving geometrical problems using algebra.

---

# 1. Cartesian Coordinate System

## Definition

The **Cartesian Coordinate System** consists of two mutually perpendicular number lines:

- Horizontal Axis → **X-axis**
- Vertical Axis → **Y-axis**

These axes intersect at a point called the **Origin**.

---

## Origin

The point where the X-axis and Y-axis meet.

```

Origin

O(0,0)

```

---

## Coordinate Plane

```

            Y-axis
              ↑
      II      |      I
              |

--------------O--------------→ X-axis
|
III | IV
|
↓

```

The plane is divided into **four quadrants**.

---

# 2. Ordered Pair

A point is represented by an ordered pair.

```

(x, y)

```

where

- **x** → x-coordinate (abscissa)
- **y** → y-coordinate (ordinate)

---

## Example

```

P(4,3)

```

Here,

```

x = 4

y = 3

```

# 3. Quadrants

The coordinate plane is divided into four quadrants.

| Quadrant | x-coordinate | y-coordinate |
|----------|--------------|--------------|
| **I** | Positive | Positive |
| **II** | Negative | Positive |
| **III** | Negative | Negative |
| **IV** | Positive | Negative |

# 4. Plotting Points

## Steps

1. Draw the X-axis and Y-axis.
2. Mark the origin.
3. Move along the X-axis according to the x-coordinate.
4. Move parallel to the Y-axis according to the y-coordinate.
5. Mark the point.

# 5. Distance Between Two Points

The distance between two points is obtained using the **Distance Formula**.

---

## Formula

If

```

A(x₁,y₁)

and

B(x₂,y₂)

```

then

```

AB

=

√[(x₂ − x₁)² + (y₂ − y₁)²]

```

---

## Example

Find the distance between

```

A(2,3)

B(5,7)

```

```

AB

=

√[(5−2)² + (7−3)²]

=

√(9+16)

=

√25

=

5 units

```

---

# 6. Midpoint of a Line Segment

The midpoint divides a line segment into two equal parts.

---

## Formula

If

```

A(x₁,y₁)

B(x₂,y₂)

```

then midpoint

```

M

=

((x₁+x₂)/2 ,

(y₁+y₂)/2)

```

---

## Example

Find the midpoint of

```

A(2,4)

B(8,10)

```

```

M

=

((2+8)/2 ,

(4+10)/2)

=

(5,7)

```

---

# 7. Section Formula (Internal Division)

If a point **P** divides the line joining

```

A(x₁,y₁)

and

B(x₂,y₂)

```

internally in the ratio

```

m : n

```

then

```

P

=

((mx₂+nx₁)/(m+n),

(my₂+ny₁)/(m+n))

```

---

## Special Case

When

```

m = n

```

the formula becomes the **Midpoint Formula**.

# Common Mistakes

- Confusing the **x-coordinate** with the **y-coordinate**.
- Forgetting that the **origin** is **(0,0)**.
- Plotting points in the wrong quadrant due to incorrect signs.
- Using incorrect subtraction while applying the **Distance Formula**.
- Forgetting to square the differences in coordinates.
- Mixing up the formulas for **midpoint** and **distance**.
- Assuming points on the axes belong to a quadrant (they do not).
- Writing coordinates in the wrong order as **(y, x)** instead of **(x, y)**.

# Formula Sheet

| Formula | Description |
|----------|-------------|

# Chapter Summary

- **Coordinate Geometry** represents geometric figures using the **Cartesian Coordinate System**.
- Every point is represented by an **ordered pair (x, y)**, where **x** is the abscissa and **y** is the ordinate.
- The coordinate plane is divided into **four quadrants**, each identified by the signs of the coordinates.
- Points can be accurately **plotted** using their coordinates.
- The **Distance Formula** is used to calculate the distance between two points.
- The **Midpoint Formula** determines the point that divides a line segment into two equal parts.
- The **Section Formula** is used to divide a line segment in a given ratio.
- Coordinate Geometry is widely applied in engineering, navigation, computer graphics, robotics, architecture, and many real-world fields.
