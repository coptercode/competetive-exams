# Introduction

Commercial Mathematics deals with the mathematical concepts used in business, trade, banking, and finance. It includes calculations involving **Profit and Loss, Discount, Compound Interest, Depreciation, Population Growth, Taxation**, and other financial transactions encountered in daily life.

---

# 1. Profit, Loss and Discount

## Cost Price (CP)

The **Cost Price (CP)** is the price at which an article is purchased.

---

## Selling Price (SP)

The **Selling Price (SP)** is the price at which an article is sold.

---

## Profit (Gain)

A **profit** occurs when the selling price is greater than the cost price.

### Formula

```
Profit = SP − CP
```

---

## Loss

A **loss** occurs when the selling price is less than the cost price.

### Formula

```
Loss = CP − SP
```

---

## Profit Percentage

```
Profit % = (Profit / CP) × 100
```

---

## Loss Percentage

```
Loss % = (Loss / CP) × 100
```

---

## Selling Price Formula

### When Profit is Given

```
SP = CP × (100 + Profit%)/100
```

---

### When Loss is Given

```
SP = CP × (100 − Loss%)/100
```

---

# 2. Discount

## Marked Price (MP)

The **Marked Price** is the price printed on the article before any discount.

---

## Discount

The reduction offered on the marked price is called **Discount**.

### Formula

```
Discount = MP − SP
```

---

## Discount Percentage

```
Discount % = (Discount / MP) × 100
```

---

## Selling Price After Discount

```
SP = MP × (100 − Discount%)/100
```

---

## Successive Discounts

If two discounts are offered successively:

```
Net Discount

= a + b − (ab/100)
```

where

- **a** = First discount (%)
- **b** = Second discount (%)

---

# 3. Compound Interest

## Compound Interest (CI)

Compound Interest is the interest calculated on both the **principal** and the **accumulated interest**.

---

## Terms Used

- **P** = Principal
- **R** = Rate of Interest (% per annum)
- **T** = Time (years)
- **A** = Amount
- **CI** = Compound Interest

---

## Amount Formula

For annual compounding:

```
A = P(1 + R/100)^T
```

---

## Compound Interest

```
CI = A − P
```

---

## Year-by-Year Method

Interest is added after every year.

Example:

```
Principal

↓

Interest

↓

New Principal

↓

Next Year's Interest
```

---

## Difference Between SI and CI

| Simple Interest              | Compound Interest                             |
| ---------------------------- | --------------------------------------------- |
| Calculated only on principal | Calculated on principal and previous interest |
| Same interest every year     | Interest increases every year                 |
| Simpler calculations         | Faster growth                                 |

---

# 4. Half-Yearly and Variable Rate Compound Interest

## Half-Yearly Compounding

If interest is compounded every six months:

### Rate

```
R/2
```

### Time

```
2T
```

### Formula

```
A = P(1 + R/200)^(2T)
```

---

## Quarterly Compounding

### Rate

```
R/4
```

### Time

```
4T
```

### Formula

```
A = P(1 + R/400)^(4T)
```

---

## Variable Rate Compound Interest

If the rate changes every year:

```
A = P × (1 + R₁/100)
      × (1 + R₂/100)
      × (1 + R₃/100)
```

---

### Example

Rates:

```
8%

10%

12%
```

Multiply each year's growth separately.

# 5. Depreciation, Population Growth and Taxation

## Depreciation

Depreciation is the decrease in the value of an asset over time.

### Formula

```
Value = P(1 − R/100)^T
```

---

## Applications

- Vehicles
- Machines
- Electronic goods
- Buildings

---

## Population Growth

Population increases according to compound growth.

### Formula

```
Population

= P(1 + R/100)^T
```

---

## Population Decline

```
Population

= P(1 − R/100)^T
```

---

## Taxation

Tax is an amount paid to the government on goods, services, or income.

---

## Goods and Services Tax (GST)

GST is charged on the selling price of goods.

### GST Amount

```
GST = (GST% × Taxable Amount)/100
```

---

## Bill Amount

```
Total Bill

= Taxable Amount + GST
```

# Solved Examples

## Example 1

### Question

An article is purchased for **₹1200** and sold for **₹1500**.

Find the profit and profit percentage.

### Solution

```
Profit

= 1500 − 1200

= ₹300
```

```
Profit %

= (300/1200) × 100

= 25%
```

### Answer

```
Profit = ₹300

Profit % = 25%
```

---

## Example 2

### Question

Find the compound interest on **₹5000** for **2 years** at **10% p.a.**

### Solution

```
A

= 5000(1 + 10/100)^2

= 5000(1.1)^2

= ₹6050
```

```
CI

= 6050 − 5000

= ₹1050
```

### Answer

```
Compound Interest = ₹1050
```

---

## Example 3

### Question

A television worth **₹40,000** depreciates at **10% per year**.

Find its value after **2 years**.

### Solution

```
Value

= 40000(1 − 10/100)^2

= 40000(0.9)^2

= ₹32,400
```

### Answer

```
₹32,400
```

---

## Example 4

### Question

A shirt has a marked price of **₹2000** and a discount of **15%**.

Find the selling price.

### Solution

```
SP

= 2000 × (85/100)

= ₹1700
```

### Answer

```
₹1700
```

# Common Mistakes

- Confusing **Cost Price** with **Marked Price**.
- Calculating profit percentage using the **Selling Price** instead of the **Cost Price**.
- Forgetting to subtract the principal while finding Compound Interest.
- Using the annual formula for half-yearly compounding.
- Applying depreciation as addition instead of subtraction.
- Ignoring successive discounts and simply adding percentages.
- Using incorrect time periods in compound interest calculations.
- Forgetting that GST is calculated on the taxable amount.

# Chapter Summary

- **Commercial Mathematics** applies mathematical concepts to business and finance.
- **Profit** occurs when the selling price exceeds the cost price, while **loss** occurs when the selling price is less than the cost price.
- **Discount** is the reduction offered on the marked price, and the selling price is calculated after deducting the discount.
- **Compound Interest** is calculated on both the principal and accumulated interest, resulting in faster growth than simple interest.
- Compound interest may be calculated annually, half-yearly, quarterly, or using varying interest rates.
- **Depreciation** decreases the value of an asset over time, whereas **population growth** follows the compound growth model.
- **GST** is a tax charged on goods and services and is included in the final bill amount.
- Mastering commercial mathematics helps in making informed financial decisions in everyday life.
