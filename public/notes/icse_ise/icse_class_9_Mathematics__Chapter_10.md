# Introduction

The concept of **Area** measures the surface enclosed by a plane figure. In geometry, several important theorems relate the areas of triangles and parallelograms. These theorems help in proving geometrical properties and solving problems involving parallel lines, medians, and equal-area figures.

---

# 1. Area of Plane Figures

## Definition

The **Area** of a plane figure is the amount of surface enclosed within its boundary.

### Units of Area

- Square centimetre (cm²)
- Square metre (m²)
- Square kilometre (km²)

---

## Area of a Rectangle

### Formula

```

Area = Length × Breadth

```

---

## Area of a Square

### Formula

```

Area = Side²

```

---

## Area of a Triangle

### Formula

```

Area = ½ × Base × Height

```

---

## Area of a Parallelogram

### Formula

```

Area = Base × Height

```

---

# 2. Parallelograms on the Same Base and Between the Same Parallels

## Theorem

**Parallelograms on the same base and between the same parallel lines are equal in area.**

---

### Diagram

```

A------------D
| |
| |
B------------C

A------------P
| |
| |
B------------Q

```

Both parallelograms

```

ABCD

and

ABQP

```

have

- Same base

```

AB

```

- Between the same parallel lines.

Therefore,

```

Area(ABCD)

=

Area(ABQP)

```

---

## Applications

- Comparing areas
- Geometrical proofs
- Construction problems

---

# 3. Triangles on the Same Base and Between the Same Parallels

## Theorem

**Triangles on the same base and between the same parallel lines are equal in area.**

---

### Diagram

```

      A
     /\
    /  \

/____\
B C

      D
     /\
    /  \

/____\
B C

```

Both triangles have

```

BC

```

as the common base.

Hence,

```

Area(△ABC)

=

Area(△DBC)

```

---

## Reason

Both triangles have

- Same base
- Same altitude

---

## Applications

- Proofs
- Area comparisons
- Construction

# 4. Area Relationship Between Triangle and Parallelogram

## Theorem

If a triangle and a parallelogram stand on the same base and lie between the same parallels,

then

```

Area of Triangle

=

½ × Area of Parallelogram

```

---

### Formula

```

Area(△)

=

½ × Area(▱)

```

---

### Example

Area of parallelogram

```

80 cm²

```

Area of triangle

```

= 40 cm²

```

---

## Proof

Area of triangle

```

= ½ × Base × Height

```

Area of parallelogram

```

= Base × Height

```

Therefore,

```

Area(Triangle)

=

½ Area(Parallelogram)

```

---

# 5. Median of a Triangle

## Median

A **median** is the line segment joining a vertex to the midpoint of the opposite side.

---

### Diagram

```

      A
     /\
    /  \

/ M \
/______\
B C

```

where

```

BM = MC

```

---

## Theorem

A median divides a triangle into two triangles of equal area.

---

### Result

If

```

AM

```

is a median,

then

```

Area(△ABM)

=

Area(△AMC)

```

---

## Applications

- Geometry proofs
- Coordinate geometry
- Area calculations

# 6. Applications of Area Theorems

The area theorems help solve practical geometry problems.

---

## Example 1

Two triangles have the same base

```

10 cm

```

and the same height

```

8 cm

```

Area

```

= ½ × 10 × 8

= 40 cm²

```

Both triangles have equal area.

---

## Example 2

A parallelogram has

```

Base = 12 cm

Height = 9 cm

```

Area

```

= 12 × 9

= 108 cm²

```

---

## Example 3

A triangle stands on the same base and between the same parallels as the above parallelogram.

Area

```

= 108/2

= 54 cm²

```

# Common Mistakes

- Confusing the formulas for the area of a triangle and a parallelogram.
- Forgetting to divide by **2** while finding the area of a triangle.
- Using the slant height instead of the perpendicular height.
- Assuming all triangles with equal bases have equal areas (their heights must also be equal).
- Misinterpreting the theorem on the same base and the same parallels.
- Forgetting that a median divides a triangle into **equal-area** triangles, not necessarily congruent triangles.
- Using incorrect units for area.
- Mixing up base and height in calculations.

# Chapter Summary

- **Area** is the measure of the surface enclosed by a plane figure.
- The area of a **triangle** is **½ × base × height**, while the area of a **parallelogram** is **base × height**.
- **Parallelograms** on the same base and between the same parallel lines have **equal areas**.
- **Triangles** on the same base and between the same parallel lines also have **equal areas**.
- A triangle standing on the same base and between the same parallels as a parallelogram has **half the area** of the parallelogram.
- A **median** divides a triangle into **two triangles of equal area**.
- These theorems are widely used in geometrical proofs, constructions, surveying, architecture, and higher mathematics.
- Understanding area relationships forms the basis for solving advanced geometry and mensuration problems.
