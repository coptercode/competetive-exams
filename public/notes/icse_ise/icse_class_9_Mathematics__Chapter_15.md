# Introduction

**Statistics** is the branch of mathematics that deals with the collection, organization, presentation, analysis, and interpretation of data. **Probability** measures the chance of an event occurring. These concepts are widely used in science, business, economics, sports, medicine, weather forecasting, and everyday decision-making.

---

# 1. Statistics

## Definition

Statistics is the science of collecting, organizing, presenting, analyzing, and interpreting numerical data.

---

## Types of Data

### Primary Data

Data collected directly by the investigator for a specific purpose.

**Examples**

- Survey results
- Measurements
- Interviews

---

### Secondary Data

Data collected by someone else and used for analysis.

**Examples**

- Census reports
- Government publications
- Newspapers
- Research papers

---

# 3. Measures of Central Tendency

Central tendency gives a single value representing the entire data.

---

## Mean (Average)

### Formula for Ungrouped Data

```

Mean

=

Sum of Observations

÷

Number of Observations

```

or

```

Mean

=

Σx / n

```

---

### Formula for Grouped Data

```

Mean

=

Σfx / Σf

```

where

- **f** = Frequency
- **x** = Class Mark

---

## Median

The middle observation when the data is arranged in ascending or descending order.

### Steps

- Arrange the observations.
- Find the middle value.

---

## Mode

The observation occurring **most frequently**.

---

### Example

Data

```

5, 7, 7, 8, 9

```

```

Mode = 7

```

# 5. Probability

## Definition

Probability is the measure of the likelihood of an event occurring.

---

## Formula

```

Probability

=

Number of Favourable Outcomes

÷

Total Number of Possible Outcomes

```

or

```

P(E)

=

n(E)

÷

n(S)

```

where

- **E** = Event
- **S** = Sample Space

---

## Range of Probability

```

0 ≤ P(E) ≤ 1

```

- **0** → Impossible Event
- **1** → Certain Event

---

## Impossible Event

An event that cannot occur.

```

P = 0

```

Example

Getting

```

8

```

on a standard die.

---

## Certain Event

An event that always occurs.

```

P = 1

```

Example

Getting a number less than

```

7

```

on a standard die.

# Common Mistakes

- Confusing **mean**, **median**, and **mode**.
- Forgetting to arrange the data before finding the median.
- Dividing by the wrong number while calculating the mean.
- Using the wrong frequency in grouped data.
- Assuming probability can be greater than **1**.
- Forgetting that the probability of an impossible event is **0**.
- Confusing **sample space** with **favourable outcomes**.
- Drawing histograms with gaps between adjacent bars.

# Chapter Summary

- **Statistics** involves collecting, organizing, presenting, analyzing, and interpreting data.
- Data can be **primary** or **secondary**, and is often organized into **frequency distribution tables**.
- The three common **measures of central tendency** are **mean**, **median**, and **mode**.
- Data can be represented visually using **bar graphs, histograms, frequency polygons, pie charts,** and **line graphs**.
- **Probability** measures the likelihood of an event occurring and is calculated as the ratio of favourable outcomes to total possible outcomes.
- The value of probability always lies between **0** and **1**.
- Understanding **sample space**, **events**, and probability formulas helps solve real-life situations involving uncertainty.
- Statistics and Probability are essential tools in **science, engineering, finance, business, artificial intelligence, medicine, and data analysis**.
