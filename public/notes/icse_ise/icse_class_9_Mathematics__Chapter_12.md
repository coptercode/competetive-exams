# Introduction

**Mensuration** is the branch of mathematics that deals with the measurement of geometric figures. It involves calculating the **area, perimeter, surface area, and volume** of two-dimensional (2D) and three-dimensional (3D) figures. This chapter focuses on triangles, quadrilaterals, circles, cubes, and cuboids, along with practical applications.

---

# 1. Area of Triangles

## Area Using Base and Height

The area of a triangle is half the product of its base and corresponding height.

### Formula

```

Area = ½ × Base × Height

```

### Example

```

Base = 12 cm

Height = 8 cm

```

```

Area

= ½ × 12 × 8

= 48 cm²

```

---

## Heron's Formula

Used when all three sides of a triangle are known.

### Step 1: Find Semi-Perimeter

```

s = (a + b + c)/2

```

where

- **a, b, c** are the sides of the triangle.

---

### Step 2: Apply Heron's Formula

```

Area

= √[s(s − a)(s − b)(s − c)]

```

---

### Example

Sides

```

5 cm

12 cm

13 cm

```

```

s

= (5 + 12 + 13)/2

= 15

```

```

Area

= √[15 × 10 × 3 × 2]

= √900

= 30 cm²

```

# 2. Area of Quadrilaterals and Paths

## Rectangle

### Perimeter

```

P = 2(l + b)

```

### Area

```

A = l × b

```

---

## Square

### Perimeter

```

P = 4a

```

### Area

```

A = a²

```

---

## Parallelogram

### Area

```

A = Base × Height

```

---

## Rhombus

### Area

```

A = ½ × d₁ × d₂

```

where

- **d₁** and **d₂** are the diagonals.

---

## Trapezium

### Area

```

A

= ½(a + b) × h

```

where

- **a** and **b** are parallel sides.
- **h** is the height.

---

## Area of Paths

### Outside Path

```

Area of Path

= Outer Area − Inner Area

```

### Inside Path

```

Area Remaining

= Total Area − Path Area

```

---

# 3. Circle: Area and Circumference

## Radius

Distance from the centre to any point on the circle.

---

## Diameter

```

d = 2r

```

---

## Circumference

### Formula

```

C = 2πr

```

or

```

C = πd

```

---

## Area of a Circle

### Formula

```

A = πr²

```

---

## Semicircle

### Area

```

A = ½πr²

```

### Perimeter

```

P = πr + 2r

```

---

## Quadrant

### Area

```

A = ¼πr²

```

### Perimeter

```

P = ½πr + 2r

```

---

# 4. Surface Area of Cubes and Cuboids

## Cube

A solid with six equal square faces.

---

### Total Surface Area (TSA)

```

TSA = 6a²

```

---

### Lateral Surface Area (LSA)

```

LSA = 4a²

```

---

## Cuboid

A solid having length, breadth, and height.

---

### Total Surface Area

```

TSA

= 2(lb + bh + hl)

```

---

### Lateral Surface Area

```

LSA

= 2h(l + b)

```

---

### Body Diagonal

```

d

= √(l² + b² + h²)

```

---

# 5. Volume of Cubes and Cuboids

## Volume of Cube

```

V = a³

```

---

## Volume of Cuboid

```

V = l × b × h

```

---

## Capacity

Capacity is the amount of liquid a solid can hold.

### Conversion

```

1 litre

= 1000 cm³

```

# Solved Examples

## Example 1

### Question

Find the area of a triangle with

```

Base = 16 cm

Height = 9 cm

```

### Solution

```

Area

= ½ × 16 × 9

= 72 cm²

```

### Answer

```

72 cm²

```

---

## Example 2

### Question

Find the circumference of a circle of radius

```

7 cm

```

### Solution

```

C

= 2πr

= 2 × 22/7 × 7

= 44 cm

```

### Answer

```

44 cm

```

---

## Example 3

### Question

Find the volume of a cuboid having

```

Length = 8 cm

Breadth = 5 cm

Height = 4 cm

```

### Solution

```

V

= 8 × 5 × 4

= 160 cm³

```

### Answer

```

160 cm³

```

---

## Example 4

### Question

Find the total surface area of a cube whose side is

```

6 cm

```

### Solution

```

TSA

= 6 × 6²

= 6 × 36

= 216 cm²

```

### Answer

```

216 cm²

```

# Common Mistakes

- Forgetting to divide by **2** while finding the area of a triangle.
- Using **diameter instead of radius** in circle formulas.
- Confusing **circumference** with **area**.
- Using incorrect units (cm instead of cm² or cm³).
- Forgetting to calculate the **semi-perimeter** before applying Heron's Formula.
- Mixing up **Total Surface Area (TSA)** and **Lateral Surface Area (LSA)**.
- Using the wrong formula for trapeziums and rhombuses.
- Forgetting to convert **litres to cubic centimetres** when calculating capacity.

# Chapter Summary

- **Mensuration** deals with the measurement of lengths, areas, surface areas, and volumes of geometric figures.
- The **area of a triangle** can be found using either the **base-height formula** or **Heron's Formula** when all sides are known.
- Different quadrilaterals have specific formulas for calculating their **area** and **perimeter**.
- For circles, the **circumference** is **2πr**, while the **area** is **πr²**.
- The **Total Surface Area (TSA)**, **Lateral Surface Area (LSA)**, and **Volume** of cubes and cuboids are essential concepts in three-dimensional geometry.
- Capacity calculations require conversion between **litres** and **cubic centimetres**.
- Mensuration has practical applications in engineering, construction, architecture, agriculture, and everyday measurements.
- A strong understanding of mensuration is essential for solving real-world geometry and measurement problems.
