# Introduction

**Trigonometry** is the branch of mathematics that studies the relationship between the angles and sides of a triangle. It is mainly applied to **right-angled triangles**. Trigonometry is widely used in surveying, engineering, astronomy, navigation, architecture, and physics. This chapter introduces trigonometric ratios, identities, standard angle values, complementary angle relationships, and solving right triangles.

---

# 1. Right-Angled Triangle

A **right-angled triangle** is a triangle in which one angle is **90°**.

### Parts of a Right Triangle

```

          C
          |\
          | \

Opposite | \ Hypotenuse
|θ \
| \
|_____\
A Adjacent B

```

For angle **θ**:

- **Hypotenuse** → Side opposite the right angle
- **Opposite Side** → Side opposite angle θ
- **Adjacent Side** → Side next to angle θ (excluding the hypotenuse)

---

# 2. Trigonometric Ratios

There are six basic trigonometric ratios.

---

## Sine (sin)

### Formula

```

sin θ

=

Opposite / Hypotenuse

```

---

## Cosine (cos)

### Formula

```

cos θ

=

Adjacent / Hypotenuse

```

---

## Tangent (tan)

### Formula

```

tan θ

=

Opposite / Adjacent

```

---

## Cosecant (cosec)

### Formula

```

cosec θ

=

Hypotenuse / Opposite

```

---

## Secant (sec)

### Formula

```

sec θ

=

Hypotenuse / Adjacent

```

---

## Cotangent (cot)

### Formula

```

cot θ

=

Adjacent / Opposite

```

---

## Reciprocal Relationships

```

cosec θ = 1/sin θ

```

```

sec θ = 1/cos θ

```

```

cot θ = 1/tan θ

```

---

# 3. Fundamental Trigonometric Identities

Trigonometric identities are equations that are always true.

---

## Identity 1

```

sin² θ + cos² θ = 1

```

---

## Identity 2

```

tan θ = sin θ / cos θ

```

---

## Identity 3

```

cot θ = cos θ / sin θ

```

---

## Identity 4

```

tan θ × cot θ = 1

```

---

## Identity 5

```

sec θ = 1 / cos θ

```

---

## Identity 6

```

cosec θ = 1 / sin θ

```

---

# 4. Standard Values of Trigonometric Ratios

| θ | 0° | 30° | 45° | 60° | 90° |
|----|----|------|------|------|------|
| **sin θ** | 0 | 1/2 | 1/√2 | √3/2 | 1 |
| **cos θ** | 1 | √3/2 | 1/√2 | 1/2 | 0 |
| **tan θ** | 0 | 1/√3 | 1 | √3 | Not Defined |
| **cosec θ** | Not Defined | 2 | √2 | 2/√3 | 1 |
| **sec θ** | 1 | 2/√3 | √2 | 2 | Not Defined |
| **cot θ** | Not Defined | √3 | 1 | 1/√3 | 0 |

---

## Remembering the Values

For **sin θ**

```

√0/2

√1/2

√2/2

√3/2

√4/2

```

For **cos θ**, read the values in reverse order.

# 5. Complementary Angle Identities

Two angles are complementary if their sum is **90°**.

---

## Identity 1

```

sin (90° − θ)

=

cos θ

```

---

## Identity 2

```

cos (90° − θ)

=

sin θ

```

---

## Identity 3

```

tan (90° − θ)

=

cot θ

```

---

## Identity 4

```

cot (90° − θ)

=

tan θ

```

---

## Identity 5

```

sec (90° − θ)

=

cosec θ

```

---

## Identity 6

```

cosec (90° − θ)

=

sec θ

```

# 6. Solving Right Triangles

Trigonometric ratios help determine unknown sides or angles.

---

## Finding a Side

### Example

Given

```

θ = 30°

Hypotenuse = 20 cm

```

Find the opposite side.

Using

```

sin 30°

= Opposite / 20

```

```

1/2 = Opposite / 20

```

```

Opposite = 10 cm

```

---

## Finding an Angle

Given

```

Opposite = 8 cm

Adjacent = 8 cm

```

```

tan θ = 8/8 = 1

```

From the standard table,

```

θ = 45°

```

# Common Mistakes

- Confusing the **opposite** and **adjacent** sides.
- Using the wrong trigonometric ratio for a given problem.
- Forgetting that **tan 90°** and **sec 90°** are **not defined**.
- Mixing up **reciprocal ratios** such as sec and cosec.
- Using incorrect standard values.
- Forgetting to apply complementary angle identities.
- Assuming trigonometric ratios can be used for non-right triangles without additional rules.
- Neglecting units while solving practical problems.

# Chapter Summary

- **Trigonometry** studies the relationship between the sides and angles of a **right-angled triangle**.
- The six basic trigonometric ratios are **sin, cos, tan, cosec, sec,** and **cot**.
- The **fundamental identity**, **sin²θ + cos²θ = 1**, is the basis for many trigonometric simplifications.
- The **standard values** of trigonometric ratios for **0°, 30°, 45°, 60°, and 90°** should be memorized.
- **Complementary angle identities** simplify expressions involving angles that add up to **90°**.
- Trigonometric ratios are used to determine unknown sides and angles in right triangles.
- Trigonometry has practical applications in **surveying, navigation, engineering, architecture, astronomy,** and **physics**.
- A strong understanding of trigonometric concepts forms the foundation for advanced mathematics and real-world problem-solving.
