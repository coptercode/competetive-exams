# Introduction

A **Quadratic Equation** is a polynomial equation of degree **2**. It is one of the most important topics in algebra and has applications in physics, engineering, economics, architecture, and many real-life situations. Quadratic equations can be solved using **factorization**, the **quadratic formula (Sridharacharya Formula)**, or by analyzing the **discriminant** to determine the nature of the roots.

---

# 1. Quadratic Equations

## Definition

A **Quadratic Equation** is an equation of the form

```
ax² + bx + c = 0
```

where

- **a ≠ 0**
- **a, b, c** are real numbers.

---

## Examples

```
x² + 7x + 12 = 0
```

```
2x² − 5x + 3 = 0
```

```
5x² + 8 = 0
```

---

## Standard Form

```
ax² + bx + c = 0
```

where

- **a** = Coefficient of x²
- **b** = Coefficient of x
- **c** = Constant Term

---

# 2. Factorization Method

A quadratic equation can be solved by expressing it as a product of two linear factors.

---

## Steps

1. Write the equation in standard form.
2. Find two numbers whose:
   - Product = **a × c**
   - Sum = **b**
3. Split the middle term.
4. Factor by grouping.
5. Equate each factor to zero.

---

## Example

Solve

```
x² + 7x + 12 = 0
```

Factorize

```
x² + 3x + 4x + 12 = 0
```

```
x(x+3)+4(x+3)=0
```

```
(x+3)(x+4)=0
```

Therefore,

```
x = -3

or

x = -4
```

---

# 3. Sridharacharya Formula (Quadratic Formula)

When factorization is difficult, use the quadratic formula.

---

## Formula

```
          -b ± √(b² − 4ac)
x =  --------------------------
               2a
```

---

## Steps

1. Identify

```
a, b, c
```

2. Calculate

```
b² − 4ac
```

3. Substitute into the formula.

4. Simplify.

---


# 4. Discriminant

The expression

```
D = b² − 4ac
```

is called the **Discriminant**.

It determines the nature of the roots.

---

## Formula

```
D

=

b² − 4ac
```

---

# 5. Nature of Roots

## Case 1

If

```
D > 0
```

Then

- Two distinct real roots.

---

## Case 2

If

```
D = 0
```

Then

- Two equal real roots.

---

## Case 3

If

```
D < 0
```

Then

- No real roots.
- Roots are imaginary (complex).

---

## Summary Table

| Discriminant | Nature of Roots     |
| ------------ | ------------------- |
| **D > 0**    | Real and Distinct   |
| **D = 0**    | Real and Equal      |
| **D < 0**    | Imaginary / Complex |

If the roots are

```

and

β
```

```

```

### Example

# Common Mistakes

- Forgetting to write the equation in **standard form** before solving.
- Using incorrect signs while substituting values into the quadratic formula.
- Calculating the **discriminant** incorrectly.
- Forgetting that **a ≠ 0** in a quadratic equation.
- Making errors while splitting the middle term in factorization.
- Ignoring negative roots in word problems without checking the context.
- Confusing **real equal** roots with **real distinct** roots.
- Forgetting to simplify the square root correctly.

# Chapter Summary

- A **Quadratic Equation** is an equation of degree **2** written in the form **ax² + bx + c = 0**, where **a ≠ 0**.
- Quadratic equations can be solved using **factorization** or the **Sridharacharya (Quadratic) Formula**.
- The **Discriminant (D = b² − 4ac)** helps determine whether the roots are **real and distinct**, **real and equal**, or **imaginary (complex)**.
- If the roots of a quadratic equation are known, the equation can be formed using **x² − (α + β)x + αβ = 0**.
- Quadratic equations are widely used in solving problems involving **areas, dimensions, speed, time, ages, and other real-life situations**.
- Careful substitution, correct sign handling, and proper simplification are essential for obtaining accurate solutions in ICSE Class 10 examinations.
