# Introduction

Measurements form the foundation of scientific experiments. Accurate measurement of length, mass, time, and volume allows scientists to perform experiments, compare results, and verify scientific laws. This chapter introduces SI units, measuring instruments like Vernier Callipers and Screw Gauge, and the Simple Pendulum.

---

# 1. System of Units

## CGS System

- Length → centimetre (cm)
- Mass → gram (g)
- Time → second (s)

## MKS System

- Length → metre (m)
- Mass → kilogram (kg)
- Time → second (s)

## SI System

The International System of Units (SI) is the standard system used worldwide.

| Physical Quantity | SI Unit  | Symbol |
| ----------------- | -------- | ------ |
| Length            | metre    | m      |
| Mass              | kilogram | kg     |
| Time              | second   | s      |
| Temperature       | kelvin   | K      |
| Current           | ampere   | A      |

### Rules for Writing Units

- Unit symbols are never plural.
- Do not place a full stop after a unit symbol.
- Leave one space between the number and unit.
- Symbols are written in lowercase except those named after scientists.

Example:

- ✅ 10 kg
- ❌ 10kgs

# 2. Vernier Callipers

## Parts

- Main Scale
- Vernier Scale
- Fixed Jaw
- Movable Jaw
- Depth Rod

### Least Count

Least Count = Value of 1 Main Scale Division ÷ Number of Vernier Divisions

### Measurement Formula

Reading = Main Scale Reading + (Vernier Coincidence × Least Count)

### Zero Error

#### Positive Zero Error

Instrument reads more than zero.

Correction = Observed Reading − Zero Error

#### Negative Zero Error

Instrument reads less than zero.

Correction = Observed Reading + Zero Error

# Solved Examples

## Example 1

**Question**

A Vernier Callipers has a least count of 0.01 cm. The main scale reading is 2.4 cm and the 7th Vernier division coincides.

**Solution**

Reading

= 2.4 + (7 × 0.01)

= 2.47 cm

**Answer:** 2.47 cm

# Common Mistakes

- Forgetting to apply zero error correction.
- Using incorrect least count.
- Writing SI units incorrectly.
- Ignoring unit conversions.

- SI system is the internationally accepted unit system.
