# Introduction

Many chemical reactions involve the **transfer of electrons** between substances. These reactions are known as **redox (reduction-oxidation) reactions**. Redox reactions play an important role in **combustion, corrosion, electrochemistry, metallurgy, respiration, photosynthesis, and industrial processes**.

This chapter explains oxidation, reduction, oxidation number, balancing redox reactions, oxidizing and reducing agents, and their applications.

---

# 1. Oxidation

## Definition

Oxidation is the process in which a substance:

- Loses electrons.
- Gains oxygen.
- Loses hydrogen.
- Increases its oxidation number.

---

## Example

```
Mg

→

Mg²⁺ + 2e⁻
```

Magnesium undergoes oxidation.

---

# 2. Reduction

## Definition

Reduction is the process in which a substance:

- Gains electrons.
- Loses oxygen.
- Gains hydrogen.
- Decreases its oxidation number.

---

## Example

```
Cu²⁺ + 2e⁻

↓

Cu
```

Copper ion undergoes reduction.

---

# Difference Between Oxidation and Reduction

| Oxidation                  | Reduction                  |
| -------------------------- | -------------------------- |
| Loss of electrons          | Gain of electrons          |
| Gain of oxygen             | Loss of oxygen             |
| Loss of hydrogen           | Gain of hydrogen           |
| Oxidation number increases | Oxidation number decreases |

---

# 3. Redox Reaction

## Definition

A chemical reaction in which oxidation and reduction occur simultaneously.

---

## General Representation

```
Reducing Agent

+

Oxidizing Agent

↓

Products
```

---

## Example

```
Zn + CuSO₄

↓

ZnSO₄ + Cu
```

Here,

- Zinc is oxidized.
- Copper ion is reduced.

---

# 4. Oxidizing Agent

## Definition

A substance that causes oxidation by accepting electrons.

It gets reduced.

---

## Examples

- KMnO₄
- K₂Cr₂O₇
- O₂
- Cl₂
- H₂O₂

---

# 5. Reducing Agent

## Definition

A substance that causes reduction by donating electrons.

It gets oxidized.

---

## Examples

- H₂
- CO
- Zn
- Fe
- Na

---

# Difference Between Oxidizing and Reducing Agents

| Oxidizing Agent  | Reducing Agent   |
| ---------------- | ---------------- |
| Gains electrons  | Loses electrons  |
| Gets reduced     | Gets oxidized    |
| Causes oxidation | Causes reduction |

---

# 6. Oxidation Number (Oxidation State)

## Definition

The apparent charge assigned to an atom in a compound or ion.

---

# Rules for Assigning Oxidation Number

### Rule 1

Free elements

```
Oxidation Number = 0
```

Examples

```
Na, H₂, Cl₂
```

---

### Rule 2

Simple ions

Oxidation number = Ionic charge.

Examples

```
Na⁺ = +1

Cl⁻ = -1
```

---

### Rule 3

Oxygen

Usually

```
-2
```

Exceptions

- Peroxides = -1
- OF₂ = +2

---

### Rule 4

Hydrogen

Usually

```
+1
```

Exception

Metal hydrides

```
-1
```

---

### Rule 5

Fluorine

Always

```
-1
```

---

### Rule 6

Sum of oxidation numbers

Neutral compound

```
0
```

Polyatomic ion

```
Equal to ionic charge
```

---

# Oxidation Number Examples

| Compound | Oxidation Number |
| -------- | ---------------- |
| NaCl     | Na = +1, Cl = -1 |
| H₂O      | H = +1, O = -2   |
| NH₃      | N = -3           |
| H₂SO₄    | S = +6           |
| KMnO₄    | Mn = +7          |
| K₂Cr₂O₇  | Cr = +6          |

---

# Difference Between Valency and Oxidation Number

| Valency         | Oxidation Number                    |
| --------------- | ----------------------------------- |
| No sign         | Has sign                            |
| Always positive | Positive, negative, or zero         |
| Whole number    | Integer, fractional (rare), or zero |

# 7. Types of Redox Reactions

---

## Combination Reaction

Two substances combine.

Example

```
2Mg + O₂

↓

2MgO
```

---

## Decomposition Reaction

One compound breaks down.

Example

```
2HgO

↓

2Hg + O₂
```

---

## Displacement Reaction

One element displaces another.

Example

```
Zn + CuSO₄

↓

ZnSO₄ + Cu
```

---

## Disproportionation Reaction

Same element undergoes oxidation and reduction.

Example

```
2H₂O₂

↓

2H₂O + O₂
```

---

# Difference Between Combination and Decomposition Reactions

| Combination    | Decomposition   |
| -------------- | --------------- |
| Many → One     | One → Many      |
| Product formed | Compound breaks |

---

# 8. Balancing Redox Reactions

---

# Oxidation Number Method

## Steps

```
Write Equation

↓

Assign Oxidation Numbers

↓

Identify Oxidation & Reduction

↓

Equalize Electron Change

↓

Balance Atoms

↓

Balance Charges

↓

Check Equation
```

---

# Ion-Electron Method

## Steps

```
Separate Half Reactions

↓

Balance Atoms

↓

Balance Oxygen

↓

Balance Hydrogen

↓

Balance Charge

↓

Equalize Electrons

↓

Add Half Reactions
```

---

# Difference Between Oxidation Number Method and Ion-Electron Method

| Oxidation Number Method | Ion-Electron Method      |
| ----------------------- | ------------------------ |
| Uses oxidation numbers  | Uses half reactions      |
| Suitable for all media  | Best for ionic reactions |

# Solved Examples

## Example 1

### Question

Find the oxidation number of sulfur in H₂SO₄.

### Solution

```
2(+1) + S + 4(-2) = 0

2 + S - 8 = 0

S = +6
```

### Answer

**+6**

---

## Example 2

### Question

Identify the oxidizing agent in

```
Zn + CuSO₄ → ZnSO₄ + Cu
```

### Solution

Copper ion gains electrons.

### Answer

**Cu²⁺ (CuSO₄)**

---

## Example 3

### Question

State whether oxidation or reduction occurs:

```
Fe²⁺ → Fe³⁺
```

### Solution

Oxidation number increases from +2 to +3.

### Answer

**Oxidation**

---

## Example 4

### Question

What is the oxidation number of oxygen in H₂O₂?

### Solution

Hydrogen peroxide is a peroxide.

### Answer

**−1**

---

## Example 5

### Question

Name one strong reducing agent.

### Solution

Hydrogen donates electrons readily.

### Answer

**Hydrogen (H₂)**

# Common Mistakes

- Confusing oxidation with reduction.
- Assigning oxygen as −2 in peroxides.
- Forgetting that fluorine always has an oxidation number of −1.
- Incorrectly balancing electrons in redox equations.
- Mixing up oxidizing and reducing agents.
- Ignoring the charge while calculating oxidation numbers.

# Quick Revision

- Oxidation → Loss of electrons.
- Reduction → Gain of electrons.
- Redox → Oxidation and reduction together.
- Oxidizing agent → Accepts electrons.
- Reducing agent → Donates electrons.
- Oxygen → Usually −2.
- Hydrogen → Usually +1.
- Fluorine → Always −1.
- KMnO₄ → Strong oxidizing agent.
- H₂ → Common reducing agent.

# Chapter Summary

- **Redox reactions** involve the simultaneous processes of **oxidation** (loss of electrons) and **reduction** (gain of electrons), with electrons transferred from the reducing agent to the oxidizing agent.
- The concept of **oxidation number** provides a systematic method for identifying oxidation and reduction in chemical reactions.
- Various types of redox reactions include **combination, decomposition, displacement, and disproportionation** reactions.
- Redox equations can be balanced using the **oxidation number method** or the **ion-electron (half-reaction) method**, ensuring conservation of both mass and charge.
- Redox reactions are fundamental to many natural and industrial processes such as **corrosion, combustion, metallurgy, batteries, electrolysis, respiration, and photosynthesis**.
- A thorough understanding of oxidation numbers, oxidizing and reducing agents, and balancing techniques is essential for mastering inorganic, organic, and electrochemical reactions.
