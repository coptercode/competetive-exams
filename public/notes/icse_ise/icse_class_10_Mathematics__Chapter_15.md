# Introduction

**Mensuration** is the branch of mathematics that deals with the measurement of geometric figures, including their **length, area, surface area, and volume**. It has practical applications in construction, architecture, engineering, manufacturing, agriculture, packaging, and design. In this chapter, we study the formulas for various two-dimensional (2D) and three-dimensional (3D) figures.

---

# 1. Plane Figures (2D)

## Definition

Plane figures are two-dimensional shapes having only **length** and **breadth**.

### Examples

- Square
- Rectangle
- Triangle
- Circle
- Parallelogram
- Rhombus
- Trapezium

---

# 2. Solid Figures (3D)

## Definition

Solid figures are three-dimensional objects having **length, breadth, and height**.

### Examples

- Cube
- Cuboid
- Cylinder
- Cone
- Sphere
- Hemisphere

---

# 3. Perimeter

## Definition

The **Perimeter** is the total length of the boundary of a closed figure.

### Formulae

| Figure                 | Formula       |
| ---------------------- | ------------- |
| Square                 | **4a**        |
| Rectangle              | **2(l + b)**  |
| Triangle               | **a + b + c** |
| Circle (Circumference) | **2πr**       |

---

# 4. Area of Plane Figures

## Square

### Formula

```
Area = a²
```

---

## Rectangle

### Formula

```
Area = l × b
```

---

## Triangle

### Formula

```
Area = ½ × b × h
```

---

## Heron's Formula

If the sides are

```
a, b, c
```

then

```
s = (a+b+c)/2
```

where

```
s
```

is the semi-perimeter.

Area

```
= √[s(s−a)(s−b)(s−c)]
```

---

## Parallelogram

### Formula

```
Area = Base × Height
```

---

## Rhombus

### Formula

```
Area = ½ × d₁ × d₂
```

---

## Trapezium

### Formula

```
Area

=

½ × (Sum of Parallel Sides) × Height
```

---

## Circle

### Formula

```
Area = πr²
```

Circumference

```
= 2πr
```

---

# 5. Surface Area and Volume of Solids

## Cube

### Total Surface Area (TSA)

```
6a²
```

### Lateral Surface Area (LSA)

```
4a²
```

### Volume

```
a³
```

---

## Cuboid

### Total Surface Area

```
2(lb + bh + hl)
```

### Lateral Surface Area

```
2h(l+b)
```

### Volume

```
l × b × h
```

---

## Right Circular Cylinder

### Curved Surface Area (CSA)

```
2πrh
```

### Total Surface Area (TSA)

```
2πr(h+r)
```

### Volume

```
πr²h
```

---

## Right Circular Cone

### Slant Height

```
l = √(r²+h²)
```

### Curved Surface Area

```
πrl
```

### Total Surface Area

```
πr(l+r)
```

### Volume

```
(1/3)πr²h
```

---

## Sphere

### Surface Area

```
4πr²
```

### Volume

```
(4/3)πr³
```

---

## Hemisphere

### Curved Surface Area

```
2πr²
```

### Total Surface Area

```
3πr²
```

### Volume

```
(2/3)πr³
```

# 7. Composite Solids

Many practical problems involve combinations of solids.

Examples include

- Cylinder with Hemisphere
- Cone on Cylinder
- Hollow Cylinder
- Tank Combinations

### Rule

- Add or subtract **volumes** depending on the figure.
- Add only the **exposed surface areas**.

# Solved Examples

## Example 1

### Question

Find the area of a square whose side is

```
12 cm.
```

### Solution

```
Area

=

12²

=

144 cm²
```

### Answer

```
144 cm²
```

---

## Example 2

### Question

Find the circumference of a circle whose radius is

```
7 cm.
```

### Solution

```
Circumference

=

2πr

=

2×22/7×7

=

44 cm
```

### Answer

```
44 cm
```

---

## Example 3

### Question

Find the volume of a cube having side

```
5 cm.
```

### Solution

```
Volume

=

5³

=

125 cm³
```

### Answer

```
125 cm³
```

---

## Example 4

### Question

Find the curved surface area of a cylinder having

```
r = 7 cm

h = 10 cm.
```

### Solution

```
CSA

=

2πrh

=

2×22/7×7×10

=

440 cm²
```

### Answer

```
440 cm²
```

---

## Example 5

### Question

Find the volume of a cone having

```
r = 3 cm

h = 4 cm.
```

### Solution

```
Volume

=

(1/3)πr²h

=

(1/3)×π×9×4

=

12π cm³
```

### Answer

```
12π cm³
```

# Common Mistakes

- Confusing **Surface Area** with **Volume**.
- Using **Diameter** instead of **Radius** in circle formulas.
- Forgetting to calculate the **slant height** before finding the surface area of a cone.
- Mixing up **Curved Surface Area (CSA)** and **Total Surface Area (TSA)**.
- Forgetting to convert units before solving problems.
- Using the wrong formula for a hemisphere or sphere.
- Ignoring hidden or exposed surfaces in composite solids.
- Making calculation errors involving **π**.

# Chapter Summary

- **Mensuration** deals with the measurement of lengths, areas, surface areas, and volumes of geometrical figures.
- **Plane figures (2D)** include squares, rectangles, triangles, circles, parallelograms, rhombuses, and trapeziums.
- **Solid figures (3D)** include cubes, cuboids, cylinders, cones, spheres, and hemispheres.
- The formulas for **perimeter**, **area**, **surface area**, and **volume** are essential for solving practical measurement problems.
- **Heron's Formula** is used to find the area of a triangle when all three sides are known.
- For a **cone**, the slant height must be calculated before finding the curved or total surface area.
- In **composite solids**, volumes are added or subtracted appropriately, while only the exposed surfaces are considered for surface area.
- Mensuration is widely applied in construction, engineering, architecture, agriculture, manufacturing, packaging, and everyday life, making it one of the most practical topics in ICSE Class 10 Mathematics.
