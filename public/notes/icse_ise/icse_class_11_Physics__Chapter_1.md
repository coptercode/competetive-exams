# Introduction

Physics is the branch of science that studies **matter, energy, motion, force, and the laws governing the universe**. It forms the foundation for engineering, astronomy, medicine, and modern technology.

To measure physical quantities accurately, scientists use **standard units**, **dimensional analysis**, and **error analysis**. These concepts ensure consistency, precision, and reliability in scientific measurements.

# 4. Dimensions

## Definition

Dimensions indicate the powers of fundamental quantities used to express a physical quantity.

---

# Fundamental Dimensions

| Quantity           | Dimension |
| ------------------ | --------- |
| Length             | [L]       |
| Mass               | [M]       |
| Time               | [T]       |
| Current            | [A]       |
| Temperature        | [K]       |
| Amount             | [mol]     |
| Luminous Intensity | [cd]      |

---

# Dimensional Formulae

| Quantity     | Formula          | Dimensional Formula |
| ------------ | ---------------- | ------------------- |
| Velocity     | Distance / Time  | [LT⁻¹]              |
| Acceleration | Velocity / Time  | [LT⁻²]              |
| Momentum     | mv               | [MLT⁻¹]             |
| Force        | ma               | [MLT⁻²]             |
| Work         | Force × Distance | [ML²T⁻²]            |
| Energy       | Work             | [ML²T⁻²]            |
| Power        | Work / Time      | [ML²T⁻³]            |
| Pressure     | Force / Area     | [ML⁻¹T⁻²]           |
| Density      | Mass / Volume    | [ML⁻³]              |

---

# Principle of Dimensional Homogeneity

In any correct physical equation,

```
Dimensions of LHS

=

Dimensions of RHS
```

---

# Applications of Dimensional Analysis

- Verify equations.
- Derive relations.
- Convert units.
- Find dimensions of constants.

---

# Limitations of Dimensional Analysis

- Cannot determine numerical constants.
- Cannot derive trigonometric or exponential equations.
- Cannot distinguish scalar and vector quantities.
- Cannot verify dimensionally correct but physically incorrect equations.

# 6. Significant Figures

## Definition

The meaningful digits in a measured quantity that include all certain digits and the first uncertain digit.

---

# Rules

1. All non-zero digits are significant.
2. Zeros between non-zero digits are significant.
3. Leading zeros are not significant.
4. Trailing zeros after a decimal are significant.
5. Exact numbers have infinite significant figures.

---

# Examples

| Number      | Significant Figures  |
| ----------- | -------------------- |
| 25.6        | 3                    |
| 0.0025      | 2                    |
| 1.230       | 4                    |
| 2000        | 1 (unless specified) |
| 2.000 × 10³ | 4                    |

---

# Rounding Off Rules

- Digit < 5 → Leave unchanged.
- Digit > 5 → Increase preceding digit by 1.
- Digit = 5 followed only by zeros → Round to even digit.

# Solved Examples

## Example 1

### Question

Find the dimensional formula of force.

### Solution

```
Force = Mass × Acceleration

= M × LT⁻²

= MLT⁻²
```

### Answer

**[MLT⁻²]**

---

## Example 2

### Question

Convert 5 m into centimetres.

### Solution

```
1 m = 100 cm

5 × 100 = 500 cm
```

### Answer

**500 cm**

---

## Example 3

### Question

How many significant figures are present in 0.00450?

### Solution

Leading zeros are not significant, but the trailing zero after the decimal is significant.

### Answer

**3 significant figures**

---

## Example 4

### Question

A quantity is measured as 20 ± 0.5. Find the percentage error.

### Solution

```
Percentage Error

= (0.5 / 20) × 100

= 2.5%
```

### Answer

**2.5%**

---

## Example 5

### Question

A Vernier Callipers has 1 MSD = 1 mm and 10 Vernier divisions equal 9 mm. Find its least count.

### Solution

```
1 VSD = 9/10 mm = 0.9 mm

Least Count

= 1 MSD − 1 VSD

= 1 − 0.9

= 0.1 mm
```

### Answer

**0.1 mm (0.01 cm)**

# Common Mistakes

- Confusing **units** with **dimensions**.
- Writing incorrect dimensional formulae for derived quantities.
- Ignoring significant figure rules during calculations.
- Adding percentage errors incorrectly in multiplication/division problems.
- Forgetting zero-error correction in Vernier Callipers and Screw Gauge.
- Using inconsistent units in equations.
