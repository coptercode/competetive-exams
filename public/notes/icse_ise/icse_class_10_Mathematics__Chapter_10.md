# Introduction

**Reflection** is a type of geometric transformation in which a figure is flipped over a line called the **line of reflection** to produce its mirror image. During reflection, the **shape and size of the figure remain unchanged**, but its orientation is reversed. Reflection is widely used in geometry, architecture, engineering, computer graphics, robotics, and image processing.

---

# 1. Reflection

## Definition

A **Reflection** is a transformation that produces the mirror image of a figure about a fixed line called the **Mirror Line** or **Line of Reflection**.

---

## Properties of Reflection

- Shape remains unchanged.
- Size remains unchanged.
- Corresponding angles remain equal.
- Corresponding sides remain equal.
- Image is the mirror image of the original figure.
- Distance from the mirror line remains the same.

---

# 2. Reflection in the X-axis

## Rule

When a point is reflected in the **x-axis**, only the **y-coordinate changes its sign**.

---

## Formula

```
(x, y)

↓

(x, −y)
```

---

## Examples

| Original Point | Reflected Point |
| -------------- | --------------- |
| (2, 5)         | (2, −5)         |
| (−4, 3)        | (−4, −3)        |
| (6, −8)        | (6, 8)          |

---

# 3. Reflection in the Y-axis

## Rule

When reflected in the **y-axis**, only the **x-coordinate changes its sign**.

---

## Formula

```
(x, y)

↓

(−x, y)
```

---

## Examples

| Original Point | Reflected Point |
| -------------- | --------------- |
| (5, 2)         | (−5, 2)         |
| (−3, 7)        | (3, 7)          |
| (4, −6)        | (−4, −6)        |

---

# 4. Reflection in the Origin

## Rule

Both coordinates change their signs.

---

## Formula

```
(x, y)

↓

(−x, −y)
```

---

## Examples

| Original Point | Reflected Point |
| -------------- | --------------- |
| (3, 7)         | (−3, −7)        |
| (−5, 2)        | (5, −2)         |
| (4, −8)        | (−4, 8)         |

---

# 5. Reflection in the Line y = x

## Rule

The coordinates interchange.

---

## Formula

```
(x, y)

↓

(y, x)
```

---

## Examples

| Original Point | Reflected Point |
| -------------- | --------------- |
| (2, 5)         | (5, 2)          |
| (7, 3)         | (3, 7)          |
| (−4, 1)        | (1, −4)         |

---

# 6. Reflection in the Line y = –x

## Rule

The coordinates interchange and both signs change.

---

## Formula

```
(x, y)

↓

(−y, −x)
```

---

## Examples

| Original Point | Reflected Point |
| -------------- | --------------- |
| (3, 8)         | (−8, −3)        |
| (−2, 5)        | (−5, 2)         |
| (6, −1)        | (1, −6)         |

---

# 7. Reflection in Parallel Lines

Reflection can also take place about horizontal or vertical lines other than the axes.

---

## Reflection in the Line y = a

### Formula

```
(x, y)

↓

(x, 2a − y)
```

---

### Example

Reflect

```
(4, 7)
```

in

```
y = 5
```

```
New y

=

2×5−7

=

3
```

Image

```
(4, 3)
```

---

## Reflection in the Line x = b

### Formula

```
(x, y)

↓

(2b − x, y)
```

---

### Example

Reflect

```
(6, 2)
```

in

```
x = 4
```

```
New x

=

2×4−6

=

2
```

Image

```
(2, 2)
```

---

# 8. Invariant Points

## Definition

An **Invariant Point** is a point that remains unchanged after reflection.

---

## Examples

### Reflection in the x-axis

Every point on

```
y = 0
```

remains unchanged.

---

### Reflection in the y-axis

Every point on

```
x = 0
```

remains unchanged.

---

### Reflection in the Origin

Only

```
(0,0)
```

remains unchanged.

---

### Reflection in the Line y = x

Every point satisfying

```
x = y
```

remains unchanged.

---

# 9. Reflection of Geometric Figures

Reflection of a figure is performed by reflecting each vertex individually.

---

## Example

Triangle

```
A(2,1)

B(5,3)

C(3,6)
```

Reflection in the x-axis

```
A'(2,−1)

B'(5,−3)

C'(3,−6)
```

---

## Example

Rectangle

```
P(1,2)

Q(5,2)

R(5,6)

S(1,6)
```

Reflection in the y-axis

```
P'(−1,2)

Q'(−5,2)

R'(−5,6)

S'(−1,6)
```

# Common Mistakes

- Changing **both coordinates** while reflecting in the **x-axis** or **y-axis**.
- Forgetting that reflection in the **origin** changes the sign of **both coordinates**.
- Confusing reflection in **y = x** with reflection in **y = –x**.
- Using the wrong formula for reflections about **x = a** or **y = a**.
- Forgetting to reflect **every vertex** of a geometric figure.
- Incorrectly identifying invariant points.
- Mixing up translations with reflections.
- Drawing reflected figures without maintaining equal perpendicular distances from the mirror line.

# Chapter Summary

- **Reflection** is a transformation that produces the mirror image of a figure about a fixed line called the **line of reflection**.
- Reflection preserves the **shape**, **size**, **lengths**, and **angles** of the figure, but reverses its orientation.
- Reflection in the **x-axis** changes only the **y-coordinate**, while reflection in the **y-axis** changes only the **x-coordinate**.
- Reflection in the **origin** changes the signs of both coordinates.
- Reflection in the lines **y = x** and **y = −x** involves interchanging coordinates, with sign changes in the latter case.
- Reflections about the lines **x = b** and **y = a** are performed using the formulas **(2b − x, y)** and **(x, 2a − y)** respectively.
- **Invariant points** are points that remain unchanged after reflection because they lie on the mirror line.
- Reflection has practical applications in geometry, computer graphics, robotics, engineering, architecture, and image processing.
