# Introduction

A **Straight Line** is one of the most fundamental concepts in Coordinate Geometry. Every straight line on the Cartesian plane can be represented by an algebraic equation. The equation of a line helps us determine its position, slope, intercepts, and relationship with other lines. It has numerous applications in engineering, architecture, physics, computer graphics, economics, and data analysis.

---

# 1. Straight Line

## Definition

A **Straight Line** is the shortest distance between two points and extends infinitely in both directions.

---

## General Equation

```
Ax + By + C = 0
```

where

- **A, B, C** are constants.
- **A** and **B** cannot both be zero.

---

# 2. Slope (Gradient) of a Line

## Definition

The **Slope** or **Gradient** of a line measures its inclination with respect to the positive x-axis.

It indicates how steep the line is.

---

## Formula (Using Two Points)

If

```
A(x₁,y₁)

and

B(x₂,y₂)
```

then

```
          y₂−y₁
m = ----------------
          x₂−x₁
```

provided

```
x₂ ≠ x₁
```

---

## Formula (Using Angle)

If the line makes an angle

```
θ
```

with the positive x-axis,

```
m = tan θ
```

---

## Example

Find the slope of the line joining

```
(2,3)

and

(6,11)
```

### Solution

```
m

=

11−3

──────

6−2

=

8/4

=

2
```

### Answer

```
2
```

---

# 3. Parallel and Perpendicular Lines

## Parallel Lines

Two lines are parallel if they have the same slope.

### Condition

```
m₁ = m₂
```

---

## Perpendicular Lines

Two lines are perpendicular if the product of their slopes is

```
−1
```

### Condition

```
m₁ × m₂ = −1
```

---

### Example

If

```
m₁ = 2
```

then the slope of a perpendicular line is

```
−1/2
```

---

# 4. Slope-Intercept Form

## Definition

If the slope and the y-intercept are known, the equation of the line is written in the **Slope-Intercept Form**.

---

## Formula

```
y = mx + c
```

where

- **m** = Slope
- **c** = y-intercept

---

## Example

Slope

```
3
```

y-intercept

```
−2
```

Equation

```
y = 3x − 2
```

---

# 5. Point-Slope Form

## Definition

If one point and the slope are known, use the Point-Slope Form.

---

## Formula

```
y − y₁ = m(x − x₁)
```

---

## Example

Point

```
(2,5)
```

Slope

```
4
```

Equation

```
y−5 = 4(x−2)
```

Simplifying,

```
y = 4x − 3
```

---

# 6. Two-Point Form

## Definition

If two points are given, the equation of the line can be obtained directly.

---

## Formula

```
      y−y₁       x−x₁
---------------- = -------------
      y₂−y₁       x₂−x₁
```

---

## Example

Points

```
(1,2)

and

(5,10)
```

Equation

```
y−2

────

8

=

x−1

────

4
```

Simplifying,

```
y = 2x
```

---

# 7. Intercepts of a Line

## x-intercept

The point where the line cuts the x-axis.

At this point,

```
y = 0
```

---

## y-intercept

The point where the line cuts the y-axis.

At this point,

```
x = 0
```

---

## Example

Equation

```
2x + 3y = 12
```

### x-intercept

```
y = 0
```

```
2x = 12

x = 6
```

Point

```
(6,0)
```

---

### y-intercept

```
x = 0
```

```
3y = 12

y = 4
```

Point

```
(0,4)
```

---

# 8. Intercept Form

If both intercepts are known,

```
a = x-intercept

b = y-intercept
```

then

## Formula

```
x     y
── + ── = 1
a     b
```

---

## Example

Intercepts

```
6

and

4
```

Equation

```
x     y
── + ── = 1
6     4
```

---

# 9. Line Intersections

The point where two lines meet is called their **Point of Intersection**.

It is obtained by solving the equations simultaneously.

---

## Example

Find the intersection of

```
x+y = 7
```

and

```
x−y = 1
```

### Solution

Add the equations.

```
2x = 8

x = 4
```

Substitute

```
4+y = 7
```

```
y = 3
```

### Answer

```
(4,3)
```

# Common Mistakes

- Interchanging **x₁, y₁** with **x₂, y₂** while calculating the slope.
- Forgetting that the slope is **undefined** for a vertical line.
- Confusing **parallel** and **perpendicular** conditions.
- Making sign errors while using the point-slope form.
- Incorrectly calculating the x-intercept or y-intercept.
- Forgetting to simplify the equation into the required form.
- Using the wrong denominator in the slope formula.
- Making arithmetic errors while solving simultaneous equations.

# Chapter Summary

- A **Straight Line** can be represented by an algebraic equation in the Cartesian plane.
- The **Slope (Gradient)** measures the inclination of a line and is calculated using **m = (y₂ − y₁)/(x₂ − x₁)** or **m = tan θ**.
- Two lines are **parallel** if their slopes are equal and **perpendicular** if the product of their slopes is **−1**.
- The **Slope-Intercept Form** (**y = mx + c**) is used when the slope and y-intercept are known.
- The **Point-Slope Form** and **Two-Point Form** are used to construct equations of lines from given information.
- The **Intercept Form** is useful when both the x-intercept and y-intercept are known.
- The **Point of Intersection** of two lines is found by solving their equations simultaneously.
- Equations of straight lines have wide applications in geometry, engineering, navigation, computer graphics, physics, and data analysis.
