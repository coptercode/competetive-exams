# Introduction

Motion is the change in the position of an object with respect to time. Everything around us, from moving vehicles to falling objects, exhibits motion. This chapter introduces the concepts of distance, displacement, speed, velocity, acceleration, graphical representation of motion, and equations of motion for objects moving along a straight line.

---

# 1. Kinematic Quantities

Kinematics is the branch of Physics that describes the motion of objects without considering the forces causing the motion.

## Rest

An object is said to be **at rest** if its position does not change with time relative to its surroundings.

## Motion

An object is said to be **in motion** if its position changes with time relative to its surroundings.

---

## Scalar and Vector Quantities

### Scalar Quantities

Scalar quantities have only magnitude.

Examples:

- Distance
- Speed
- Time
- Mass

### Vector Quantities

Vector quantities have both magnitude and direction.

Examples:

- Displacement
- Velocity
- Acceleration
- Force

---

## Distance

Distance is the total length of the path travelled by an object.

### SI Unit

```
metre (m)
```

### Characteristics

- Scalar quantity
- Always positive
- Depends on the actual path travelled

---

## Displacement

Displacement is the shortest straight-line distance between the initial and final positions.

### SI Unit

```
metre (m)
```

### Characteristics

- Vector quantity
- Can be positive, negative, or zero
- Independent of the path taken

---

## Speed

Speed is the distance travelled per unit time.

### Formula

```
Speed = Distance / Time
```

### SI Unit

```
m/s
```

---

## Velocity

Velocity is the displacement per unit time.

### Formula

```
Velocity = Displacement / Time
```

### SI Unit

```
m/s
```

Velocity includes direction.

---

# 2. Acceleration

Acceleration is the rate of change of velocity with time.

### Formula

```
Acceleration = (Final Velocity − Initial Velocity) / Time
```

or

```
a = (v − u)/t
```

where

- u = Initial velocity
- v = Final velocity
- a = Acceleration
- t = Time

### SI Unit

```
m/s²
```

---

## Types of Motion

### Uniform Motion

The object covers equal distances in equal intervals of time.

Characteristics:

- Constant speed
- Zero acceleration

---

### Non-Uniform Motion

The object covers unequal distances in equal intervals of time.

Characteristics:

- Variable speed
- Acceleration is present

---

### Uniform Acceleration

Velocity changes by equal amounts in equal intervals of time.

Example:

- Freely falling objects

---

### Variable Acceleration

Velocity changes by unequal amounts in equal intervals.

Example:

- Car moving through city traffic

---

### Retardation (Negative Acceleration)

Acceleration opposite to the direction of motion.

Example:

- Applying brakes to a moving vehicle

---

# 3. Distance-Time Graph

A Distance-Time Graph shows how distance changes with time.

## Characteristics

### Horizontal Line

Object is at rest.

### Straight Line

Uniform speed.

### Curved Line

Non-uniform speed.

---

## Slope of Distance-Time Graph

```
Slope = Speed
```

Greater slope means greater speed.

---

# 4. Velocity-Time Graph

A Velocity-Time Graph shows the variation of velocity with time.

---

## Slope of Velocity-Time Graph

```
Slope = Acceleration
```

Positive slope:

- Positive acceleration

Negative slope:

- Retardation

Horizontal line:

- Constant velocity

---

## Area Under Velocity-Time Graph

The area under the graph gives displacement.

```
Displacement = Area under graph
```

---

# 5. Equations of Motion

These equations apply only to uniformly accelerated motion.

---

## First Equation

```
v = u + at
```

where

- v = Final velocity
- u = Initial velocity
- a = Acceleration
- t = Time

---

## Second Equation

```
s = ut + ½at²
```

where

- s = Displacement

---

## Third Equation

```
v² = u² + 2as
```

---

## Special Cases

### Object at Rest

```
u = 0
```

Then,

```
v = at

s = ½at²

v² = 2as
```

---

# Numerical Applications

These equations help solve problems involving:

- Cars
- Trains
- Falling bodies
- Projectiles moving vertically
- Everyday transportation

# Solved Examples

## Example 1

### Question

A car travels 120 m in 10 s.

Find its speed.

### Solution

```
Speed = Distance / Time

= 120 / 10

= 12 m/s
```

### Answer

```
12 m/s
```

---

## Example 2

### Question

A body starts from rest and accelerates uniformly at 3 m/s² for 5 seconds.

Find the final velocity.

### Solution

```
u = 0

a = 3

t = 5

v = u + at

= 0 + (3 × 5)

= 15 m/s
```

### Answer

```
15 m/s
```

---

## Example 3

### Question

A train moves with an initial velocity of 8 m/s and accelerates uniformly at 2 m/s² for 6 seconds.

Find the displacement.

### Solution

```
s = ut + ½at²

= (8 × 6) + ½ × 2 × 36

= 48 + 36

= 84 m
```

### Answer

```
84 m
```

---

## Example 4

### Question

An object moves with an initial velocity of 10 m/s and reaches 30 m/s after 5 seconds.

Find its acceleration.

### Solution

```
a = (v − u)/t

= (30 − 10)/5

= 20/5

= 4 m/s²
```

### Answer

```
4 m/s²
```

# Common Mistakes

- Confusing distance with displacement.
- Treating speed and velocity as the same quantity.
- Ignoring the direction of vector quantities.
- Using equations of motion for non-uniform acceleration.
- Forgetting SI units.
- Using incorrect signs for retardation.
- Calculating slope incorrectly in graphs.
- Forgetting that the area under a velocity-time graph represents displacement.

# Chapter Summary

- Motion is the change in position of an object with time.
- Scalars have only magnitude, while vectors have both magnitude and direction.
- Distance is the total path travelled, whereas displacement is the shortest straight-line distance.
- Speed is the rate of change of distance, while velocity is the rate of change of displacement.
- Acceleration is the rate of change of velocity.
- Uniform motion has constant speed, while non-uniform motion has changing speed.
- The slope of a distance-time graph represents speed.
- The slope of a velocity-time graph represents acceleration.
- The area under a velocity-time graph gives displacement.
- The three equations of motion apply only to uniformly accelerated motion.
- Proper use of SI units and sign conventions is essential for solving numerical problems accurately.
