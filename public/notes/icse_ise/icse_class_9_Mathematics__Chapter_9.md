# Introduction

A **polygon** is a closed plane figure formed by joining three or more line segments. A **quadrilateral** is a four-sided polygon. This chapter explains the properties of polygons, the sum of interior and exterior angles, special types of quadrilaterals, diagonal properties, and geometric constructions.

---

# 1. Polygons

## Definition

A polygon is a closed figure made up of three or more line segments.

### Examples

- Triangle
- Quadrilateral
- Pentagon
- Hexagon
- Heptagon
- Octagon

---

## Types of Polygons

### Regular Polygon

A polygon in which:

- All sides are equal.
- All interior angles are equal.

Examples:

- Square
- Equilateral Triangle
- Regular Pentagon

---

### Irregular Polygon

A polygon whose sides or angles are not all equal.

---

## Number of Diagonals

The number of diagonals in an **n-sided polygon** is

```

Number of Diagonals

= n(n − 3)/2

```

### Example

For a pentagon,

```

n = 5

Diagonals

= 5(5 − 3)/2

= 5

```

---

# 2. Interior and Exterior Angles

## Sum of Interior Angles

The sum of the interior angles of an **n-sided polygon** is

### Formula

```

(n − 2) × 180°

```

### Examples

Triangle

```

(3 − 2) × 180°

= 180°

```

Quadrilateral

```

(4 − 2) × 180°

= 360°

```

Pentagon

```

(5 − 2) × 180°

= 540°

```

---

## Each Interior Angle of a Regular Polygon

```

[(n − 2) × 180°]/n

```

### Example

Regular Hexagon

```

(4 × 180)/6

= 120°

```

---

## Sum of Exterior Angles

The sum of one exterior angle at each vertex of any polygon is always

```

360°

```

---

## Each Exterior Angle of a Regular Polygon

```

360°/n

```

### Example

Regular Octagon

```

360/8

= 45°

```

---

# 3. Parallelogram and Its Properties

## Definition

A **parallelogram** is a quadrilateral in which opposite sides are parallel.

---

## Properties

1. Opposite sides are equal.

```

AB = CD

BC = AD

```

2. Opposite angles are equal.

```

∠A = ∠C

∠B = ∠D

```

3. Adjacent angles are supplementary.

```

∠A + ∠B = 180°

```

4. Diagonals bisect each other.

---

## Diagonal Property

If diagonals intersect at **O**, then

```

AO = OC

BO = OD

```

---

# 4. Special Quadrilaterals

## Rectangle

A parallelogram with four right angles.

### Properties

- Opposite sides equal
- Opposite sides parallel
- All angles are 90°
- Diagonals are equal
- Diagonals bisect each other

---

## Square

A rectangle with all four sides equal.

### Properties

- All sides equal
- All angles 90°
- Diagonals equal
- Diagonals bisect each other
- Diagonals are perpendicular
- Diagonals bisect opposite angles

---

## Rhombus

A parallelogram with all sides equal.

### Properties

- All sides equal
- Opposite angles equal
- Diagonals bisect each other
- Diagonals are perpendicular
- Diagonals bisect opposite angles

---

## Trapezium

A quadrilateral having one pair of opposite sides parallel.

### Types

- Isosceles Trapezium
- Right Trapezium

---

## Kite

A quadrilateral having two pairs of adjacent equal sides.

### Properties

- One pair of opposite angles equal
- Diagonals are perpendicular
- One diagonal bisects the other

---

# 5. Diagonal Properties and Geometrical Proofs

Diagonals help in proving many properties of quadrilaterals.

---

## Rectangle

```

AC = BD

```

Diagonals are equal.

---

## Rhombus

```

AC ⟂ BD

```

Diagonals intersect at right angles.

---

## Square

Diagonals

- are equal
- bisect each other
- are perpendicular
- bisect opposite angles

---

## Proof Using Congruent Triangles

Many properties are proved by showing two triangles are congruent using

- SSS
- SAS
- ASA
- RHS

Then applying

```

CPCT

```

# 6. Construction of Quadrilaterals

Quadrilaterals can be constructed using ruler and compass when sufficient measurements are given.

---

## Data Required

Construction is possible when enough measurements are known, such as

- Four sides and one diagonal
- Three sides and two diagonals
- Two sides and three angles
- Two diagonals and three sides

---

## General Steps

1. Draw one side.
2. Construct the required angles.
3. Mark the given lengths.
4. Join the remaining vertices.
5. Verify all measurements.

---

## Applications

- Engineering drawing
- Surveying
- Architecture
- Design and construction

# Solved Examples

## Example 1

### Question

Find the sum of the interior angles of a hexagon.

### Solution

```

(n − 2) × 180°

= (6 − 2) × 180°

= 720°

```

### Answer

```

720°

```

---

## Example 2

### Question

Find each exterior angle of a regular decagon.

### Solution

```

360/10

= 36°

```

### Answer

```

36°

```

---

## Example 3

### Question

One angle of a parallelogram is

```

70°

```

Find the adjacent angle.

### Solution

Adjacent angles are supplementary.

```

180° − 70°

= 110°

```

### Answer

```

110°

```

---

## Example 4

### Question

How many diagonals does an octagon have?

### Solution

```

n(n − 3)/2

= 8(5)/2

= 20

```

### Answer

```

20

```

# Common Mistakes

- Confusing **regular** and **irregular** polygons.
- Using the wrong formula for interior angles.
- Forgetting that the sum of exterior angles is always **360°**, irrespective of the number of sides.
- Assuming all quadrilaterals have equal diagonals.
- Confusing the properties of a square and a rhombus.
- Forgetting that adjacent angles in a parallelogram are supplementary.
- Using incorrect measurements during construction.
- Assuming every trapezium has equal sides.

# Chapter Summary

- A **polygon** is a closed figure formed by three or more line segments.
- The **sum of interior angles** of an n-sided polygon is **(n − 2) × 180°**, while the **sum of exterior angles** is always **360°**.
- A **parallelogram** has opposite sides parallel and equal, opposite angles equal, and diagonals that bisect each other.
- Special quadrilaterals such as **rectangles, squares, rhombuses, trapeziums, and kites** have unique properties based on their sides, angles, and diagonals.
- Diagonal properties and triangle congruency are essential tools for proving geometric theorems.
- Accurate geometric constructions require sufficient measurements and careful use of ruler and compass.
- Understanding polygons and quadrilaterals builds the foundation for advanced geometry, mensuration, and coordinate geometry.
