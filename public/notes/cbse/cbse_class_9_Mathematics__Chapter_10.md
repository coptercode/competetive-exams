# Introduction

A **quadrilateral** is a closed polygon formed by joining four line segments. The word _quadrilateral_ comes from the Latin words **quadri** (four) and **latus** (side), meaning "a figure with four sides."

Quadrilaterals are commonly seen in everyday life, such as in doors, windows, books, computer screens, tiles, and fields. Different types of quadrilaterals have different properties based on the lengths of their sides, the measures of their angles, and the relationship between their diagonals.

Understanding quadrilaterals helps in solving geometrical problems and is useful in architecture, engineering, construction, and design.

---

# 1. Quadrilateral

A **quadrilateral** is a polygon having:

- Four sides
- Four vertices
- Four angles
- Two diagonals

Example:

```
A────────B
│        │
│        │
D────────C
```

Here,

- Vertices: **A, B, C, D**
- Sides: **AB, BC, CD, DA**
- Diagonals: **AC** and **BD**

---

# 2. Angle Sum Property of a Quadrilateral

The sum of the interior angles of every quadrilateral is

```
360°
```

Mathematically,

```
∠A + ∠B + ∠C + ∠D = 360°
```

### Example

If three angles are

```
80°
```

```
95°
```

```
105°
```

Then,

```
Fourth Angle
= 360° − (80° + 95° + 105°)
```

```
=360°−280°
```

```
=80°
```

# 3. Types of Quadrilaterals

## Parallelogram

A **parallelogram** is a quadrilateral in which both pairs of opposite sides are parallel.

### Properties

- Opposite sides are equal.
- Opposite sides are parallel.
- Opposite angles are equal.
- Adjacent angles are supplementary.
- Diagonals bisect each other.

---

## Rectangle

A **rectangle** is a parallelogram with four right angles.

### Properties

- Opposite sides are equal and parallel.
- Each angle measures **90°**.
- Diagonals are equal.
- Diagonals bisect each other.

---

## Square

A **square** is a rectangle with all sides equal.

### Properties

- All sides are equal.
- All angles are **90°**.
- Opposite sides are parallel.
- Diagonals are equal.
- Diagonals bisect each other at right angles.

---

## Rhombus

A **rhombus** is a parallelogram with all sides equal.

### Properties

- All sides are equal.
- Opposite angles are equal.
- Opposite sides are parallel.
- Diagonals bisect each other at right angles.
- Diagonals are generally not equal.

---

## Trapezium

A **trapezium** is a quadrilateral with one pair of opposite sides parallel.

### Properties

- Exactly one pair of opposite sides is parallel.
- The non-parallel sides are called **legs**.

---

## Kite

A **kite** is a quadrilateral having two pairs of adjacent equal sides.

### Properties

- Two pairs of adjacent sides are equal.
- One pair of opposite angles is equal.
- Diagonals intersect at right angles.
- One diagonal bisects the other.

---

# 4. Parallelogram and Its Properties

A parallelogram has several important properties.

### Opposite Sides

```
AB = CD
```

```
BC = AD
```

---

### Opposite Angles

```
∠A = ∠C
```

```
∠B = ∠D
```

---

### Adjacent Angles

Adjacent angles are supplementary.

```
∠A + ∠B = 180°
```

---

### Diagonals

The diagonals of a parallelogram bisect each other.

If diagonals **AC** and **BD** intersect at **O**, then

```
AO = OC
```

```
BO = OD
```

---

# 5. Midpoint Theorem

**Statement**

The line segment joining the midpoints of any two sides of a triangle is:

- Parallel to the third side.
- Equal to half the length of the third side.

This theorem is useful in proving properties of quadrilaterals and other geometric figures.

---

# 6. Converse of the Midpoint Theorem

**Statement**

A line drawn through the midpoint of one side of a triangle and parallel to another side bisects the third side.

# Solved Examples

### Example 1

Find the fourth angle of a quadrilateral if the other three angles are

```
90°
```

```
85°
```

```
95°
```

Solution

```
Fourth Angle
=360°−(90°+85°+95°)
```

```
=360°−270°
```

```
=90°
```

---

### Example 2

One angle of a parallelogram is

```
65°
```

Find its adjacent angle.

Solution

Adjacent angles are supplementary.

```
180°−65°
```

```
=115°
```

Answer

```
115°
```

---

### Example 3

In a parallelogram,

```
AB = 12 cm
```

Find the length of

```
CD
```

Solution

Opposite sides of a parallelogram are equal.

Therefore,

```
CD = 12 cm
```

---

### Example 4

The diagonals of a parallelogram intersect at **O**.

If

```
AO = 6 cm
```

Find

```
OC
```

Solution

Diagonals bisect each other.

Hence,

```
OC = 6 cm
```

# Common Mistakes

- Forgetting that the sum of the interior angles of a quadrilateral is **360°**.
- Assuming every parallelogram is a rectangle.
- Confusing a rhombus with a square.
- Thinking the diagonals of every quadrilateral are equal.
- Forgetting that only the diagonals of a parallelogram bisect each other.
- Mixing up the properties of a kite and a rhombus.

# Chapter Summary

- A quadrilateral is a polygon with four sides, four angles, four vertices, and two diagonals.
- The sum of the interior angles of a quadrilateral is always **360°**.
- Common quadrilaterals include the **parallelogram, rectangle, square, rhombus, trapezium,** and **kite**.
- In a parallelogram, opposite sides are equal and parallel, opposite angles are equal, adjacent angles are supplementary, and diagonals bisect each other.
- A rectangle has four right angles, while a square has four equal sides and four right angles.
- A rhombus has four equal sides, and a trapezium has one pair of opposite sides parallel.
- The **Midpoint Theorem** and its converse are important results used in geometric proofs involving triangles and quadrilaterals.
- Quadrilaterals have wide applications in construction, engineering, architecture, surveying, and everyday life.
