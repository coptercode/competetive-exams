# Introduction

**Probability** is the branch of mathematics that measures the likelihood of an event occurring. It helps us predict the chances of different outcomes in situations involving uncertainty.

Probability is used in science, economics, insurance, weather forecasting, sports, games, medicine, and many other fields.

---

# 1. Experiment

An **experiment** is an activity or process that produces one or more outcomes.

### Examples

- Tossing a coin.
- Throwing a die.
- Drawing a card from a deck.
- Selecting a student from a class.

---

# 2. Trial

A **trial** is one performance of an experiment.

### Example

Throwing a die once is one trial.

---

# 3. Outcome

An **outcome** is a possible result of an experiment.

### Example

When a die is thrown,

Possible outcomes are

```
1, 2, 3, 4, 5, 6
```

---

# 4. Sample Space

The **sample space** is the set of all possible outcomes of an experiment.

It is denoted by

```
S
```

### Examples

#### Tossing a Coin

```
S = {H, T}
```

---

#### Throwing a Die

```
S = {1,2,3,4,5,6}
```

---

#### Tossing Two Coins

```
S = {HH, HT, TH, TT}
```

---

# 5. Event

An **event** is a collection of one or more outcomes from the sample space.

### Example

Throw a die.

Event

```
A = Getting an even number
```

```
A = {2,4,6}
```

---

# 6. Equally Likely Outcomes

Outcomes are **equally likely** if each has the same chance of occurring.

### Examples

- Tossing a fair coin.
- Throwing a fair die.

---

# 7. Probability of an Event

If

```
Number of favourable outcomes = n(E)
```

and

```
Total number of possible outcomes = n(S)
```

then

### Formula

```
Probability

=

n(E)/n(S)
```

or

```
P(E)

=

Number of favourable outcomes
--------------------------------
Total number of outcomes
```

---

# 8. Range of Probability

For every event,

```
0 ≤ P(E) ≤ 1
```

---

### Impossible Event

```
P(E) = 0
```

Example

Getting

```
7
```

on a standard die.

---

### Certain Event

```
P(E) = 1
```

Example

Getting a number less than

```
7
```

on a standard die.

---

# 9. Complement of an Event

The complement of an event

```
A
```

is denoted by

```
A'
```

or

```
A̅
```

It consists of all outcomes that are **not** in

```
A
```

### Formula

```
P(A')

=

1 − P(A)
```

# Common Mistakes

- Forgetting to list the complete **sample space**.
- Counting favourable outcomes incorrectly.
- Using the wrong total number of outcomes.
- Confusing an **event** with an **outcome**.
- Forgetting that the probability of an event lies between **0** and **1**.
- Calculating the complement incorrectly instead of using **1 − P(A)**.
- Assuming outcomes are equally likely when they are not.

# Chapter Summary

- **Probability** measures the chance of an event occurring.
- An **experiment** is a process that produces outcomes, and each performance is called a **trial**.
- An **outcome** is a possible result of an experiment.
- The **sample space** is the set of all possible outcomes.
- An **event** is a collection of one or more outcomes from the sample space.
- The probability of an event is calculated using **P(E) = n(E)/n(S)** when all outcomes are equally likely.
- The probability of an event always lies between **0** and **1**.
- An **impossible event** has probability **0**, while a **certain event** has probability **1**.
- The probability of the complement of an event is **1 − P(A)**.
- Probability has numerous applications in science, business, medicine, weather forecasting, sports, and everyday decision-making.
