# Introduction

A **polynomial** is an algebraic expression consisting of variables and constants combined using addition, subtraction, and multiplication, where the exponents of the variables are non-negative integers.

Polynomials are used in algebra, geometry, physics, economics, and engineering. This chapter explains the **zeroes of polynomials**, their **geometrical meaning**, the relationship between the **zeroes and coefficients of quadratic polynomials**, and methods for finding the **sum** and **product** of roots.

---

# 1. Polynomial

A **polynomial** in one variable is an expression of the form

```
aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀
```

where:

- **a₀, a₁, ..., aₙ** are constants.
- **aₙ ≠ 0**
- The exponents are whole numbers.

### Examples

```
3x² + 5x + 2
```

```
x³ - 4x + 7
```

```
5
```

---

# 2. Degree of a Polynomial

The **degree** of a polynomial is the highest power of the variable.

### Examples

| Polynomial    | Degree |
| ------------- | ------ |
| `5`           | 0      |
| `2x + 3`      | 1      |
| `x² - 4`      | 2      |
| `4x³ + x - 1` | 3      |

---

# 3. Types of Polynomials Based on Degree

| Degree | Name                 |
| ------ | -------------------- |
| 0      | Constant Polynomial  |
| 1      | Linear Polynomial    |
| 2      | Quadratic Polynomial |
| 3      | Cubic Polynomial     |

### Examples

Linear:

```
2x + 5
```

Quadratic:

```
x² + 3x + 2
```

Cubic:

```
x³ - 4x + 1
```

---

# 4. Zeroes of a Polynomial

A **zero** (or root) of a polynomial is the value of the variable that makes the polynomial equal to zero.

If

```
p(x) = 0
```

then **x** is called a zero of the polynomial.

### Example

Find the zero of

```
p(x) = x - 5
```

```
x - 5 = 0
```

```
x = 5
```

Hence,

```
5
```

is the zero.

---

# 5. Geometrical Meaning of Zeroes

The zeroes of a polynomial are the **x-coordinates** of the points where its graph intersects the **x-axis**.

### Cases

### One Zero

The graph cuts the x-axis at one point.

```
      |
      |
------●---------
      |
      |
```

Number of zeroes = **1**

---

### Two Zeroes

The graph cuts the x-axis at two points.

```
     ∪
----●---●-------
```

Number of zeroes = **2**

---

### Three Zeroes

The graph cuts the x-axis at three points.

```
   /\
--●--●--●------
```

Number of zeroes = **3**

---

### No Real Zero

The graph does not touch the x-axis.

```
     ∪
------------
```

Number of real zeroes = **0**

---

# 6. Number of Zeroes from Graphs

The number of zeroes of a polynomial is equal to the number of times its graph intersects the x-axis.

| Graph                 | Number of Zeroes |
| --------------------- | ---------------- |
| Does not touch x-axis | 0                |
| Touches once          | 1                |
| Cuts twice            | 2                |
| Cuts three times      | 3                |

---

# 7. Zeroes of Linear Polynomial

A linear polynomial has the form

```
ax + b
```

where

```
a ≠ 0
```

It always has **one zero**.

### Formula

```
Zero = -b/a
```

### Example

Find the zero of

```
2x + 6
```

```
2x + 6 = 0
```

```
2x = -6
```

```
x = -3
```

---

# 8. Zeroes of Quadratic Polynomial

A quadratic polynomial has the form

```
ax² + bx + c
```

where

```
a ≠ 0
```

A quadratic polynomial may have:

- Two distinct zeroes.
- One repeated zero.
- No real zeroes.

---

### Example

Find the zeroes of

```
x² - 5x + 6
```

Factorize:

```
(x - 2)(x - 3)
```

Therefore,

```
x = 2
```

and

```
x = 3
```

---

# 9. Relationship Between Zeroes and Coefficients

For a quadratic polynomial

```
ax² + bx + c
```

let the zeroes be

```
α and β
```

Then,

### Sum of Zeroes

```
α + β = -b/a
```

---

### Product of Zeroes

```
αβ = c/a
```

These formulas are extremely useful when the roots are not directly known.

---

# 10. Finding the Sum of Zeroes

### Example

Find the sum of the zeroes of

```
2x² + 7x + 3
```

Here,

```
a = 2
```

```
b = 7
```

Using

```
α + β = -b/a
```

```
= -7/2
```

---

# 11. Finding the Product of Zeroes

### Example

Find the product of the zeroes of

```
2x² + 7x + 3
```

Using

```
αβ = c/a
```

```
= 3/2
```

---

# 12. Verification of Relationship

Consider

```
x² - 7x + 10
```

Factorize

```
(x - 5)(x - 2)
```

Zeroes

```
5 and 2
```

### Sum

```
5 + 2 = 7
```

Formula:

```
-b/a
```

```
= -(-7)/1
```

```
= 7
```

Verified.

---

### Product

```
5 × 2 = 10
```

Formula

```
c/a
```

```
= 10/1
```

```
= 10
```

Verified.

# Common Mistakes

- Confusing the **degree** of a polynomial with the number of terms.
- Assuming the degree is equal to the number of zeroes.
- Forgetting that the **number of real zeroes** depends on the graph.
- Using incorrect signs while applying

```
α + β = -b/a
```

- Writing

```
αβ = -c/a
```

instead of

```
αβ = c/a
```

- Forgetting to write the polynomial in standard form before identifying **a**, **b**, and **c**.
- Assuming every quadratic polynomial has two distinct real zeroes.

# Chapter Summary

- A **polynomial** is an algebraic expression with variables raised to non-negative integer powers.
- The **degree** of a polynomial is the highest power of the variable.
- A **zero** of a polynomial is the value of the variable that makes the polynomial equal to zero.
- The **geometrical meaning** of a zero is the point where the graph of the polynomial intersects the **x-axis**.
- A **linear polynomial** has exactly one zero.
- A **quadratic polynomial** may have two distinct zeroes, one repeated zero, or no real zeroes.
- For a quadratic polynomial **ax² + bx + c**, the **sum of the zeroes** is **−b/a** and the **product of the zeroes** is **c/a**.
- The relationship between zeroes and coefficients helps solve polynomial problems without explicitly finding the roots.
- Understanding the graphs and properties of polynomials is essential for higher studies in algebra, coordinate geometry, and calculus.
