# Introduction

A **quadratic equation** is a polynomial equation of degree 2. Such equations arise in many real-life situations involving geometry, physics, engineering, business, and finance.

Quadratic equations can be solved by **factorization** or by using the **quadratic formula**. The **discriminant** helps determine the nature of the roots without actually solving the equation.

---

# 1. Quadratic Equation

A **quadratic equation** in one variable is an equation of the form

```
ax² + bx + c = 0
```

where

- **a, b, c** are real numbers.
- **a ≠ 0**.

### Examples

```
x² + 5x + 6 = 0
```

```
2x² - 7x + 3 = 0
```

---

# 2. Standard Form of a Quadratic Equation

The standard form is

```
ax² + bx + c = 0
```

where

- **a** = Coefficient of x²
- **b** = Coefficient of x
- **c** = Constant term

### Example

Write the equation in standard form.

```
3x(x − 2) = 15
```

**Solution**

Expand:

```
3x² − 6x = 15
```

Bring all terms to one side:

```
3x² − 6x − 15 = 0
```

Here,

```
a = 3
```

```
b = -6
```

```
c = -15
```

---

# 3. Solution (Roots) of a Quadratic Equation

The values of **x** that satisfy the quadratic equation are called its **roots** or **solutions**.

### Example

```
x² − 9 = 0
```

```
x² = 9
```

```
x = ±3
```

Thus, the roots are

```
3 and -3
```

---

# 4. Solving by Factorization

### Steps

1. Write the equation in standard form.
2. Factorize the quadratic expression.
3. Equate each factor to zero.
4. Solve for the variable.

---

### Example

Solve

```
x² + 7x + 12 = 0
```

Factorize:

```
(x + 3)(x + 4) = 0
```

Therefore,

```
x + 3 = 0
```

```
x = -3
```

or

```
x + 4 = 0
```

```
x = -4
```

Hence,

```
Roots = -3, -4
```

---

# 5. Quadratic Formula

Every quadratic equation

```
ax² + bx + c = 0
```

can be solved using the formula

```
          -b ± √(b² − 4ac)
x = --------------------------
              2a
```

This method is useful when the equation cannot be factorized easily.

---

### Example

Solve

```
2x² + x − 3 = 0
```

Here,

```
a = 2
```

```
b = 1
```

```
c = -3
```

Using the quadratic formula,

```
x = [-1 ± √(1 + 24)] / 4
```

```
= [-1 ± √25] / 4
```

```
= [-1 ± 5] / 4
```

Therefore,

```
x = 1
```

or

```
x = -3/2
```

---

# 6. Discriminant

The quantity

```
D = b² − 4ac
```

is called the **discriminant** of the quadratic equation.

The discriminant helps determine the nature of the roots.

---

# 7. Nature of Roots

### Case 1

If

```
D > 0
```

- Two distinct real roots.

---

### Case 2

If

```
D = 0
```

- Two equal (repeated) real roots.

---

### Case 3

If

```
D < 0
```

- No real roots.
- The roots are imaginary (complex).

---

# 8. Determining the Nature of Roots

### Example 1

Determine the nature of the roots of

```
x² − 5x + 6 = 0
```

Here,

```
a = 1
```

```
b = -5
```

```
c = 6
```

```
D = (-5)² − 4(1)(6)
```

```
= 25 − 24
```

```
= 1
```

Since

```
D > 0
```

The equation has

```
Two distinct real roots.
```

---

### Example 2

Determine the nature of the roots of

```
x² − 4x + 4 = 0
```

```
D = 16 − 16
```

```
= 0
```

Hence,

```
Two equal real roots.
```

---

### Example 3

Determine the nature of the roots of

```
x² + 2x + 5 = 0
```

```
D = 4 − 20
```

```
= -16
```

Hence,

```
No real roots.
```

---

# 9. Relationship Between Roots and Coefficients

If

```
α and β
```

are the roots of

```
ax² + bx + c = 0
```

then

### Sum of Roots

```
α + β = -b/a
```

### Product of Roots

```
αβ = c/a
```

# 10. Applications of Quadratic Equations

Quadratic equations are used in solving problems involving:

- Speed and time.
- Profit and loss.
- Motion under gravity.
- Number problems.
- Geometry.

# Solved Examples

### Example 1

Solve by factorization.

```
x² − 8x + 15 = 0
```

**Solution**

Factorize:

```
(x − 3)(x − 5) = 0
```

Therefore,

```
x = 3
```

or

```
x = 5
```

---

### Example 2

Solve using the quadratic formula.

```
x² + 6x + 5 = 0
```

**Solution**

```
a = 1
```

```
b = 6
```

```
c = 5
```

```
x = [-6 ± √(36 − 20)]/2
```

```
= [-6 ± 4]/2
```

```
x = -1
```

or

```
x = -5
```

---

### Example 3

Find the discriminant of

```
3x² − 2x + 1 = 0
```

**Solution**

```
D = (-2)² − 4(3)(1)
```

```
= 4 − 12
```

```
= -8
```

---

### Example 4

Determine the nature of the roots.

```
4x² − 12x + 9 = 0
```

**Solution**

```
D = (-12)² − 4(4)(9)
```

```
= 144 − 144
```

```
= 0
```

Hence,

```
Two equal real roots.
```

---

### Example 5

The product of two consecutive positive integers is **56**. Find the integers.

**Solution**

Let the integers be

```
x and x + 1
```

Then,

```
x(x + 1) = 56
```

```
x² + x − 56 = 0
```

Factorize:

```
(x + 8)(x − 7) = 0
```

```
x = 7
```

Positive integers are

```
7 and 8
```

---

### Example 6

Find the sum and product of the roots of

```
5x² − 20x + 15 = 0
```

**Solution**

```
a = 5
```

```
b = -20
```

```
c = 15
```

Sum

```
α + β = -(-20)/5
```

```
= 4
```

Product

```
αβ = 15/5
```

```
= 3
```

# Common Mistakes

- Forgetting to write the equation in **standard form** before solving.
- Making sign errors while factorizing.
- Substituting incorrect values of **a**, **b**, or **c** into the quadratic formula.
- Forgetting the **±** sign in the quadratic formula.
- Confusing the **discriminant** with the roots.
- Using incorrect signs while calculating **b² − 4ac**.
- Assuming every quadratic equation can be solved easily by factorization.

# Chapter Summary

- A **quadratic equation** is a polynomial equation of degree **2** and is written in the standard form **ax² + bx + c = 0**, where **a ≠ 0**.
- The solutions of a quadratic equation are called its **roots**.
- Quadratic equations can be solved by **factorization** or by using the **quadratic formula**.
- The **discriminant**, **D = b² − 4ac**, determines the nature of the roots.
- If **D > 0**, the equation has **two distinct real roots**.
- If **D = 0**, the equation has **two equal real roots**.
- If **D < 0**, the equation has **no real roots**.
- For a quadratic equation **ax² + bx + c = 0**, the **sum of the roots** is **−b/a** and the **product of the roots** is **c/a**.
- Quadratic equations have numerous applications in geometry, algebra, physics, engineering, and real-life problem-solving.
