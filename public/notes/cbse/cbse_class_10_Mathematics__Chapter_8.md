# Introduction

A **circle** is a simple closed curve consisting of all points in a plane that are at a fixed distance from a fixed point called the **centre**. This chapter focuses on the properties of **tangents** to a circle and the relationship between the radius and the tangent. These concepts are useful in geometry, engineering, architecture, and design.

---

# 1. Circle

A **circle** is the set of all points in a plane that are at the same distance from a fixed point.

### Parts of a Circle

- **Centre** – Fixed point of the circle.
- **Radius** – Line segment joining the centre to any point on the circle.
- **Diameter** – Chord passing through the centre.
- **Chord** – Line segment joining any two points on the circle.
- **Arc** – A part of the circumference.
- **Circumference** – Boundary of the circle.

### Figure

```
          A
      *-------*
    *           *
   *      O      *
    *           *
      *-------*
          B
```

Here,

- O = Centre
- OA = Radius
- AB = Diameter (if it passes through O)

---

# 2. Tangent to a Circle

A **tangent** is a straight line that touches a circle at exactly one point.

The point where the tangent touches the circle is called the **point of contact**.

### Figure

```
          |
          |
----------P----------
         /
      ( O )
```

- O = Centre
- P = Point of contact
- The horizontal line is the tangent.

---

# 3. Secant

A **secant** is a line that intersects the circle at two distinct points.

### Figure

```
      *---------*
    *             *
---*---------------*---
    *             *
      *---------*
```

The line cuts the circle at two points.

---

# 4. Number of Tangents from a Point

The number of tangents depends on the position of the point.

| Position of Point  | Number of Tangents |
| ------------------ | ------------------ |
| Inside the circle  | 0                  |
| On the circle      | 1                  |
| Outside the circle | 2                  |

---

# 5. Tangent is Perpendicular to the Radius

### Theorem

> **The tangent at any point of a circle is perpendicular to the radius through the point of contact.**

### Figure

```
           Tangent
----------------P
                |
                |
                |
                O
```

Here,

```
OP ⟂ Tangent
```

Therefore,

```
∠OPT = 90°
```

---

# 6. Proof of the Theorem

### Given

- O is the centre of the circle.
- PT is the tangent.
- P is the point of contact.

### To Prove

```
OP ⟂ PT
```

### Proof

Suppose the tangent is **not** perpendicular to the radius.

Then another point on the tangent would lie closer to the centre than point P.

This point would lie inside the circle, which means the tangent would intersect the circle at another point.

This contradicts the definition of a tangent, which touches the circle at only one point.

Hence,

```
OP ⟂ PT
```

Therefore,

```
The radius through the point of contact is perpendicular to the tangent.
```

---

# 7. Converse of the Theorem

### Statement

> **A line drawn perpendicular to the radius of a circle at its outer endpoint is a tangent to the circle.**

If

```
OP ⟂ PT
```

and

```
P
```

lies on the circle,

then

```
PT
```

is a tangent.

---

# 8. Lengths of Tangents from an External Point

### Theorem

> **The lengths of two tangents drawn from an external point to a circle are equal.**

### Figure

```
          A
         / \
        /   \
       P     O
        \   /
         \ /
          B
```

From external point

```
P
```

Tangents

```
PA
```

and

```
PB
```

are drawn.

Then,

```
PA = PB
```

---

# 9. Proof of Equal Tangents

### Given

- PA and PB are tangents.
- O is the centre.

### Proof

Join

```
OA
```

```
OB
```

and

```
OP
```

Since the radius is perpendicular to the tangent,

```
OA ⟂ PA
```

```
OB ⟂ PB
```

In right triangles

```
△OAP
```

and

```
△OBP
```

- OA = OB (Radii)
- OP = OP (Common side)
- Right angles are equal.

Therefore,

```
△OAP ≅ △OBP
```

(RHS Congruence)

Hence,

```
PA = PB
```

# Solved Examples

### Example 1

How many tangents can be drawn from a point inside a circle?

**Solution**

A point inside the circle has

```
0 tangents.
```

---

### Example 2

A tangent touches a circle at

```
P
```

If

```
OP
```

is the radius, find

```
∠OPT
```

**Solution**

The tangent is perpendicular to the radius.

Therefore,

```
∠OPT = 90°
```

---

### Example 3

Two tangents are drawn from an external point.

One tangent has length

```
12 cm
```

Find the length of the other tangent.

**Solution**

Tangents from an external point are equal.

Therefore,

```
Second tangent = 12 cm
```

---

### Example 4

A point lies on the circle.

How many tangents can be drawn?

**Solution**

Exactly

```
1 tangent.
```

---

### Example 5

A line cuts a circle at two points.

What is the line called?

**Solution**

Such a line is called a

```
Secant.
```

---

### Example 6

State the converse of the tangent theorem.

**Solution**

If a line is perpendicular to the radius at its endpoint on the circle, then the line is a

```
Tangent to the circle.
```

# Common Mistakes

- Confusing a **tangent** with a **secant**.
- Assuming a tangent cuts the circle at two points.
- Forgetting that the radius is perpendicular to the tangent only at the **point of contact**.
- Mixing up **radius** and **diameter**.
- Forgetting that tangents from the same external point are always equal in length.
- Drawing a tangent through a point inside the circle.
- Using tangent properties without identifying the point of contact correctly.

# Chapter Summary

- A **circle** is the set of all points at a fixed distance from a fixed point called the **centre**.
- A **tangent** touches the circle at exactly **one point**, called the **point of contact**.
- A **secant** intersects the circle at **two points**.
- A point **inside** the circle has **no tangents**, a point **on** the circle has **one tangent**, and a point **outside** the circle has **two tangents**.
- The **radius drawn to the point of contact is perpendicular to the tangent**.
- The **converse** is also true: a line perpendicular to the radius at its endpoint on the circle is a tangent.
- The **two tangents drawn from the same external point are equal in length**.
- Properties of tangents are widely used in geometry, engineering, architecture, transportation, and various scientific applications.
