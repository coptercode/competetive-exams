# Introduction

Statistics is the branch of mathematics that deals with the **collection, organization, presentation, analysis, and interpretation of data**. It helps us understand information and make informed decisions based on numerical facts.

Statistics is used in almost every field, including education, business, economics, medicine, sports, science, government surveys, and weather forecasting.

In this chapter, we learn how to organize data into tables, represent it graphically, and calculate measures such as the **mean**, **median**, and **mode**.

---

# 1. Data

**Data** is a collection of facts or numerical information gathered for a specific purpose.

### Examples

- Marks scored by students.
- Heights of plants.
- Daily temperatures.
- Monthly rainfall.
- Population of cities.

---

## Types of Data

### Primary Data

Data collected by the investigator for the first time is called **primary data**.

Examples:

- Conducting a survey.
- Measuring students' heights.

---

### Secondary Data

Data obtained from existing sources is called **secondary data**.

Examples:

- Census reports.
- Newspapers.
- Government publications.
- Books and websites.

---

# 2. Frequency

The **frequency** of an observation is the number of times it occurs in a data set.

### Example

Data:

```
2, 3, 2, 4, 5, 2, 3
```

| Observation | Frequency |
| ----------- | --------- |
| 2           | 3         |
| 3           | 2         |
| 4           | 1         |
| 5           | 1         |

---

# 3. Frequency Distribution Table

A **frequency distribution table** organizes data into observations and their corresponding frequencies.

Example:

| Marks | Frequency |
| ----- | --------- |
| 10    | 2         |
| 20    | 4         |
| 30    | 5         |
| 40    | 3         |

Such tables make data easier to understand and analyze.

---

# 4. Grouped Data

When the number of observations is very large, data is grouped into **class intervals**.

Example:

| Class Interval | Frequency |
| -------------- | --------- |
| 0–10           | 5         |
| 10–20          | 8         |
| 20–30          | 12        |
| 30–40          | 7         |

---

# 5. Mean

The **mean** is the average value of a data set.

### Formula (Ungrouped Data)

```
Mean = Sum of Observations ÷ Number of Observations
```

If the observations are

```
x₁, x₂, x₃, ...
```

then

```
Mean = (Σx) / n
```

---

### Formula (Discrete Frequency Distribution)

If **x** represents the observations and **f** their frequencies,

```
Mean = Σfx / Σf
```

---

# 6. Median

The **median** is the middle observation when the data is arranged in ascending or descending order.

### For Odd Number of Observations

```
Median = (n + 1)/2 th observation
```

### For Even Number of Observations

```
Median = Average of the two middle observations
```

---

# 7. Mode

The **mode** is the observation that occurs most frequently.

Example:

```
3, 5, 4, 3, 2, 3, 6
```

Mode =

```
3
```

because it occurs most often.

---

# 8. Graphical Representation of Data

Data can be represented graphically to make it easier to understand.

Common methods include:

### Bar Graph

Represents data using rectangular bars.

Used for comparing different categories.

---

### Histogram

Represents grouped continuous data using adjacent rectangles.

There are no gaps between the bars.

---

### Frequency Polygon

A graph obtained by joining the midpoints of the tops of histogram bars.

It shows the overall pattern of the data.

---

### Pie Chart

Represents data as sectors of a circle.

Each sector corresponds to a proportion of the whole.

# Common Mistakes

- Forgetting to arrange the data before finding the median.
- Confusing the mean with the median.
- Choosing the wrong observation as the mode.
- Ignoring frequencies while calculating the mean.
- Using the wrong graph for a given type of data.
- Making errors while adding observations or frequencies.

# Chapter Summary

- Statistics deals with the collection, organization, analysis, and interpretation of data.
- Data may be **primary** or **secondary**.
- A **frequency** tells how many times an observation occurs.
- A **frequency distribution table** organizes data systematically.
- Large data sets are grouped into **class intervals**.
- The **mean** is the average value of a data set.
- The **median** is the middle observation after arranging the data.
- The **mode** is the most frequently occurring observation.
- Graphs such as **bar graphs, histograms, frequency polygons,** and **pie charts** help represent data visually.
- Statistics is widely used in education, business, medicine, sports, science, economics, and government planning.
