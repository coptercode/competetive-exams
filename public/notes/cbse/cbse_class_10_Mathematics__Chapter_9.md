# Introduction

**Trigonometry** is the branch of mathematics that studies the relationship between the angles and sides of a triangle. The word _Trigonometry_ is derived from the Greek words:

- **Tri** = Three
- **Gon** = Angles
- **Metron** = Measure

In this chapter, we learn the six **trigonometric ratios**, their values for standard angles, important identities, and relationships between complementary angles.

---

# 1. Right-Angled Triangle

A **right-angled triangle** is a triangle in which one angle is equal to

```
90°
```

### Parts of a Right Triangle

```
          C
          |\
          | \
Opposite  |  \ Hypotenuse
          |   \
          |____\
         A      B
          Adjacent
```

For angle

```
∠A
```

- **Hypotenuse** – Side opposite the right angle.
- **Opposite (Perpendicular)** – Side opposite the given angle.
- **Adjacent (Base)** – Side next to the given angle (excluding the hypotenuse).

---

# 2. Trigonometric Ratios

There are six basic trigonometric ratios.

| Ratio     | Formula                                |
| --------- | -------------------------------------- |
| Sine      | `sin θ = Perpendicular / Hypotenuse`   |
| Cosine    | `cos θ = Base / Hypotenuse`            |
| Tangent   | `tan θ = Perpendicular / Base`         |
| Cosecant  | `cosec θ = Hypotenuse / Perpendicular` |
| Secant    | `sec θ = Hypotenuse / Base`            |
| Cotangent | `cot θ = Base / Perpendicular`         |

---

# 3. Reciprocal Relationships

The reciprocal pairs are:

```
cosec θ = 1 / sin θ
```

```
sec θ = 1 / cos θ
```

```
cot θ = 1 / tan θ
```

Similarly,

```
sin θ = 1 / cosec θ
```

```
cos θ = 1 / sec θ
```

```
tan θ = 1 / cot θ
```

---

# 4. Trigonometric Ratios of Standard Angles

| θ         |          0° |  30° |  45° |  60° |         90° |
| --------- | ----------: | ---: | ---: | ---: | ----------: |
| `sin θ`   |           0 |  1/2 | 1/√2 | √3/2 |           1 |
| `cos θ`   |           1 | √3/2 | 1/√2 |  1/2 |           0 |
| `tan θ`   |           0 | 1/√3 |    1 |   √3 | Not Defined |
| `cosec θ` | Not Defined |    2 |   √2 | 2/√3 |           1 |
| `sec θ`   |           1 | 2/√3 |   √2 |    2 | Not Defined |
| `cot θ`   | Not Defined |   √3 |    1 | 1/√3 |           0 |

---

# 5. Important Trigonometric Identities

These identities are true for all angles where the ratios are defined.

### Identity 1

```
sin²θ + cos²θ = 1
```

---

### Identity 2

```
1 + tan²θ = sec²θ
```

---

### Identity 3

```
1 + cot²θ = cosec²θ
```

---

# 6. Complementary Angles

Two angles are called **complementary** if their sum is

```
90°
```

For complementary angles,

```
sin(90° − θ) = cos θ
```

```
cos(90° − θ) = sin θ
```

```
tan(90° − θ) = cot θ
```

```
cot(90° − θ) = tan θ
```

```
sec(90° − θ) = cosec θ
```

```
cosec(90° − θ) = sec θ
```

---

# 7. Undefined Trigonometric Ratios

Some ratios are not defined because division by zero is not possible.

```
tan 90° → Not Defined
```

```
sec 90° → Not Defined
```

```
cosec 0° → Not Defined
```

```
cot 0° → Not Defined
```

# Solved Examples

### Example 1

Find

```
sin 30°
```

**Solution**

From the standard table,

```
sin 30° = 1/2
```

---

### Example 2

Find

```
cos 60°
```

**Solution**

```
cos 60° = 1/2
```

---

### Example 3

Evaluate

```
tan 45°
```

**Solution**

```
tan 45° = 1
```

---

### Example 4

Find

```
sec 60°
```

**Solution**

Using

```
sec θ = 1 / cos θ
```

```
= 1 / (1/2)
```

```
= 2
```

---

### Example 5

Verify the identity

```
sin²45° + cos²45° = 1
```

**Solution**

```
= (1/√2)² + (1/√2)²
```

```
= 1/2 + 1/2
```

```
= 1
```

Hence,

```
LHS = RHS
```

---

### Example 6

Find

```
sin 60° × cosec 60°
```

**Solution**

```
sin 60° = √3/2
```

```
cosec 60° = 2/√3
```

Therefore,

```
(√3/2) × (2/√3)
```

```
= 1
```

---

### Example 7

Evaluate

```
cos(90° − 30°)
```

**Solution**

Using the complementary angle identity,

```
cos(90° − θ) = sin θ
```

Therefore,

```
cos 60°
```

```
= sin 30°
```

```
= 1/2
```

---

### Example 8

Find

```
1 + tan²30°
```

**Solution**

Using

```
1 + tan²θ = sec²θ
```

```
tan 30° = 1/√3
```

```
1 + (1/√3)²
```

```
= 1 + 1/3
```

```
= 4/3
```

Also,

```
sec²30°
```

```
= (2/√3)²
```

```
= 4/3
```

Hence,

```
LHS = RHS
```

# Common Mistakes

- Confusing the **opposite**, **adjacent**, and **hypotenuse** with respect to the given angle.
- Memorizing the standard values incorrectly.
- Forgetting the reciprocal relationships between ratios.
- Using trigonometric identities without checking the correct formula.
- Assuming that **tan 90°** or **sec 90°** is equal to zero; both are **not defined**.
- Mixing up complementary angle identities, such as `sin(90° − θ)` and `cos(90° − θ)`.
- Forgetting to simplify surds correctly while evaluating expressions.

# Chapter Summary

- **Trigonometry** studies the relationship between the angles and sides of a right-angled triangle.
- The six trigonometric ratios are **sin, cos, tan, cosec, sec,** and **cot**.
- The ratios are defined using the **perpendicular**, **base**, and **hypotenuse** of a right triangle.
- The trigonometric ratios of the standard angles **0°, 30°, 45°, 60°,** and **90°** are important and should be memorized.
- The reciprocal relationships connect **sin–cosec**, **cos–sec**, and **tan–cot**.
- The three fundamental identities are:
  - `sin²θ + cos²θ = 1`
  - `1 + tan²θ = sec²θ`
  - `1 + cot²θ = cosec²θ`
- Complementary angle identities simplify many trigonometric expressions.
- Trigonometry has extensive applications in surveying, navigation, astronomy, engineering, architecture, and science.
