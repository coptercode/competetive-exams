# Introduction

Many objects around us, such as boxes, cans, balls, cones, and water tanks, are **three-dimensional (3D) shapes**. Unlike plane figures, these solids have **length, breadth, and height**.

The **surface area** of a solid is the total area covered by all its outer surfaces, while the **volume** is the amount of space occupied by the solid.

The study of surface areas and volumes is useful in architecture, engineering, packaging, construction, manufacturing, and everyday life.

---

# 1. Three-Dimensional Solids

A **three-dimensional solid** has:

- Length
- Breadth (or Width)
- Height

Common solids include:

- Cuboid
- Cube
- Cylinder
- Cone
- Sphere
- Hemisphere

---

# 2. Cuboid

A **cuboid** is a solid bounded by six rectangular faces.

Examples:

- Brick
- Book
- Matchbox
- Room

### Dimensions

- Length (**l**)
- Breadth (**b**)
- Height (**h**)

### Total Surface Area (TSA)

```
TSA = 2(lb + bh + hl)
```

### Lateral Surface Area (LSA)

```
LSA = 2h(l + b)
```

### Volume

```
Volume = l × b × h
```

---

# 3. Cube

A **cube** is a cuboid in which all edges are equal.

Examples:

- Dice
- Ice cube
- Rubik's Cube

Let each edge be **a**.

### Total Surface Area

```
TSA = 6a²
```

### Lateral Surface Area

```
LSA = 4a²
```

### Volume

```
Volume = a³
```

---

# 4. Right Circular Cylinder

A **cylinder** has two equal circular bases connected by a curved surface.

Examples:

- Water pipe
- Tin can
- Glass

Let

- Radius = **r**
- Height = **h**

### Curved Surface Area (CSA)

```
CSA = 2πrh
```

### Total Surface Area

```
TSA = 2πr(r + h)
```

### Volume

```
Volume = πr²h
```

---

# 5. Right Circular Cone

A **cone** has one circular base and one curved surface meeting at a point called the **vertex**.

Examples:

- Ice cream cone
- Party hat
- Funnel

Let

- Radius = **r**
- Height = **h**
- Slant Height = **l**

### Slant Height

```
l = √(r² + h²)
```

### Curved Surface Area

```
CSA = πrl
```

### Total Surface Area

```
TSA = πr(l + r)
```

### Volume

```
Volume = ⅓πr²h
```

---

# 6. Sphere

A **sphere** is a perfectly round solid in which every point on the surface is equidistant from the centre.

Examples:

- Football
- Marble
- Globe

Let the radius be **r**.

### Surface Area

```
Surface Area = 4πr²
```

### Volume

```
Volume = ⁴⁄₃πr³
```

---

# 7. Hemisphere

A **hemisphere** is half of a sphere.

Examples:

- Bowl
- Dome

Let the radius be **r**.

### Curved Surface Area

```
CSA = 2πr²
```

### Total Surface Area

```
TSA = 3πr²
```

### Volume

```
Volume = ⅔πr³
```

---

# 8. Difference Between Surface Area and Volume

| Surface Area               | Volume                      |
| -------------------------- | --------------------------- |
| Measures the outer surface | Measures the space occupied |
| Expressed in square units  | Expressed in cubic units    |
| Example: m², cm²           | Example: m³, cm³            |

---

# 9. Unit Conversions

### Length

```
1 m = 100 cm
```

### Area

```
1 m² = 10,000 cm²
```

### Volume

```
1 m³ = 1,000,000 cm³
```

Always convert all measurements into the same unit before applying formulas.

# Solved Examples

### Example 1

Find the volume of a cube whose side is

```
5 cm
```

Solution

```
Volume = 5³
```

```
=125 cm³
```

---

### Example 2

Find the total surface area of a cube having side

```
8 cm
```

Solution

```
TSA = 6 × 8²
```

```
=6×64
```

```
=384 cm²
```

---

### Example 3

Find the volume of a cuboid having

Length

```
12 cm
```

Breadth

```
5 cm
```

Height

```
4 cm
```

Solution

```
Volume = 12 × 5 × 4
```

```
=240 cm³
```

A cylinder has

```
7 cm
```

Height


Find its volume.

### Example 5

Find the surface area of a sphere having radius

```
6 cm
```

Solution

```
Surface Area = 4π × 6²
```

```
=144π cm²
```

### Example 6

Find the curved surface area of a cone having

Radius

```
5 cm
```

Slant height


Solution

```

```

# Common Mistakes

- Confusing curved surface area with total surface area.
- Using the diameter instead of the radius.
- Forgetting to square or cube the radius where required.
- Using different units without conversion.
- Writing square units instead of cubic units for volume.
- Using the height instead of the slant height while finding the curved surface area of a cone.

# Chapter Summary

- Three-dimensional solids have **length, breadth, and height**.
- The **surface area** measures the outer covering of a solid, while the **volume** measures the space occupied by it.
- A **cuboid** has rectangular faces, and a **cube** has all equal edges.
- A **cylinder** has two circular bases and one curved surface.
- A **cone** has one circular base and a curved surface meeting at a vertex.
- A **sphere** is a perfectly round solid, and a **hemisphere** is half of a sphere.
- Always distinguish between **Curved Surface Area (CSA)** and **Total Surface Area (TSA)**.
- Use appropriate units: **square units** for surface area and **cubic units** for volume.
- Surface areas and volumes have practical applications in construction, engineering, manufacturing, packaging, and daily life.
