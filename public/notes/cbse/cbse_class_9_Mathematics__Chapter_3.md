# Introduction

In everyday life, we often observe patterns and arrangements of numbers. For example:

- The odd numbers: 1, 3, 5, 7, 9, ...
- The even numbers: 2, 4, 6, 8, 10, ...
- Multiples of 5: 5, 10, 15, 20, ...

Such ordered collections of numbers are called **sequences**. When the numbers in a sequence follow a specific rule, the sequence becomes a **progression**.

Sequences and progressions help us identify patterns, predict future terms, and solve practical problems in mathematics, science, finance, and computer programming.

---

# 1. Sequence

A **sequence** is an ordered list of numbers arranged according to a definite rule.

Each number in a sequence is called a **term**.

Examples:

```
2, 4, 6, 8, 10, ...
```

```
5, 10, 15, 20, ...
```

```
1, 4, 9, 16, 25, ...
```

The position of each term is important. Changing the order changes the sequence.

---

## Types of Sequences

### Finite Sequence

A sequence having a limited number of terms.

Example

```
3, 6, 9, 12
```

---

### Infinite Sequence

A sequence that continues indefinitely.

Example

```
1, 2, 3, 4, 5, ...
```

# 3. Progression

A **progression** is a sequence in which the terms follow a fixed mathematical rule.

Every progression is a sequence, but every sequence is not necessarily a progression.

Examples

```
3, 6, 9, 12, ...
```

```
10, 7, 4, 1, ...
```

```
5, 10, 20, 40, ...
```

---

# 4. Arithmetic Progression (AP)

An **Arithmetic Progression (AP)** is a sequence in which the difference between consecutive terms remains constant.

This constant difference is called the **Common Difference (d)**.

### General Form

```
a, a + d, a + 2d, a + 3d, ...
```

where

- **a** = First term
- **d** = Common difference

---

## Finding the Common Difference

Formula

```
d = Second Term − First Term
```

or

```
d = a₂ − a₁
```

---

### Example 1

```
2, 5, 8, 11, 14
```

```
d = 5 − 2 = 3
```

Common Difference = **3**

---

### Example 2

```
20, 17, 14, 11
```

```
d = 17 − 20 = -3
```

Common Difference = **−3**

---

### Example 3

```
7, 7, 7, 7
```

Common Difference

```
=0
```

This is also an arithmetic progression.

---

# 5. General Term of an AP

The **nth term** of an Arithmetic Progression is given by

```
aₙ = a + (n − 1)d
```

where

- a = First term
- d = Common difference
- n = Position of the term

---

### Example

Find the 10th term of

```
3, 7, 11, 15, ...
```

Here

```
a = 3
```

```
d = 4
```

Using the formula

```
a₁₀ = 3 + (10−1)(4)
```

```
=3+36
```

```
=39
```

Answer

```
39
```

---

# 6. Identifying an Arithmetic Progression

A sequence is an AP if the difference between every pair of consecutive terms is the same.

### Example

```
4, 9, 14, 19
```

Differences

```
9−4=5
```

```
14−9=5
```

```
19−14=5
```

Hence,

This is an Arithmetic Progression.

---

### Example

```
2, 5, 10, 17
```

Differences

```
3
```

```
5
```

```
7
```

Since the differences are not equal,

It is **not** an Arithmetic Progression.

---

# 7. Increasing and Decreasing AP

### Increasing AP

If

```
d > 0
```

the terms increase continuously.

Example

```
5, 8, 11, 14, ...
```

---

### Decreasing AP

If

```
d < 0
```

the terms decrease continuously.

Example

```
30, 25, 20, 15, ...
```

---

### Constant AP

If

```
d = 0
```

all terms remain equal.

Example

```
6, 6, 6, 6, ...
```

---

# 8. Applications of Arithmetic Progression

Arithmetic progressions are widely used in everyday life.

Examples include:

- Numbering seats in a classroom.
- Staircase steps with equal height.
- Regular monthly savings.
- Daily increase or decrease in temperature.
- Distance covered at equal intervals.
- Calendar arrangements.

# Common Mistakes

- Confusing a sequence with a progression.
- Forgetting that the common difference can be negative.
- Using the wrong first term while applying the nth-term formula.
- Assuming every sequence is an arithmetic progression.
- Forgetting that a sequence with common difference zero is also an AP.
- Miscalculating the common difference due to sign errors.

# Chapter Summary

- A sequence is an ordered arrangement of numbers.
- Each number in a sequence is called a term.
- A progression is a sequence that follows a definite mathematical rule.
- Arithmetic Progression (AP) is the most common type of progression.
- The common difference is the difference between consecutive terms.
- The general form of an AP is **a, a + d, a + 2d, ...**
- The nth term of an AP is **aₙ = a + (n − 1)d**.
- A positive common difference produces an increasing AP.
- A negative common difference produces a decreasing AP.
- Arithmetic progressions are widely used to model patterns in mathematics and everyday life.
