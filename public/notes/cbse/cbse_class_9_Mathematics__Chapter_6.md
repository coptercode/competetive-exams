# Introduction

Coordinate Geometry is a branch of mathematics that combines **algebra** and **geometry**. It provides a systematic way of locating points on a plane using numbers called **coordinates**.

The concept of coordinate geometry was developed by the French mathematician **René Descartes**, who introduced a method of representing geometric figures using algebraic equations. Because of his contribution, the coordinate system is also known as the **Cartesian Coordinate System**.

Coordinate geometry is widely used in engineering, physics, computer graphics, navigation, architecture, robotics, and mapping.

---

# 1. Cartesian Coordinate System

A **Cartesian Coordinate System** consists of two perpendicular number lines that intersect at a point called the **Origin**.

The two number lines are:

- Horizontal axis (**X-axis**)
- Vertical axis (**Y-axis**)

These axes divide the plane into four regions called **quadrants**.

```
             Y-axis
               ↑
        II     |      I
               |
---------------O--------------→ X-axis
               |
       III     |      IV
               |
               ↓
```

The point **O** is called the **Origin**.

---

# 2. Coordinate Axes

## X-axis

The horizontal number line is called the **X-axis**.

- Positive direction → Right
- Negative direction → Left

Examples of points on the X-axis:

```
(3,0)
```

```
(-5,0)
```

---

## Y-axis

The vertical number line is called the **Y-axis**.

- Positive direction → Upward
- Negative direction → Downward

Examples of points on the Y-axis:

```
(0,4)
```

```
(0,-6)
```

---

# 3. Origin

The point where the X-axis and Y-axis intersect is called the **Origin**.

Its coordinates are

```
(0,0)
```

The origin acts as the reference point for locating every other point on the plane.

---

# 4. Coordinates of a Point

Every point on the coordinate plane is represented by an **ordered pair**.

General form

```
(x,y)
```

where

- **x** represents the horizontal distance from the origin.
- **y** represents the vertical distance from the origin.

### Example

```
(4,3)
```

means

- Move 4 units to the right.
- Move 3 units upward.

---

### Another Example

```
(-2,5)
```

means

- Move 2 units to the left.
- Move 5 units upward.

---

# 5. Quadrants

The coordinate plane is divided into **four quadrants**.

| Quadrant | Sign of x | Sign of y |
| -------- | --------- | --------- |
| I        | +         | +         |
| II       | -         | +         |
| III      | -         | -         |
| IV       | +         | -         |

---

## First Quadrant

Both coordinates are positive.

Examples

```
(2,4)
```

```
(5,1)
```

---

## Second Quadrant

x is negative.

y is positive.

Examples

```
(-3,4)
```

```
(-7,2)
```

---

## Third Quadrant

Both coordinates are negative.

Examples

```
(-4,-5)
```

```
(-2,-3)
```

---

## Fourth Quadrant

x is positive.

y is negative.

Examples

```
(6,-2)
```

```
(3,-8)
```

---

# 6. Points on the Axes

A point lying on the **X-axis** always has

```
y = 0
```

Examples

```
(4,0)
```

```
(-6,0)
```

A point lying on the **Y-axis** always has

```
x = 0
```

Examples

```
(0,7)
```

```
(0,-4)
```

---

# 7. Plotting Points

To plot a point:

1. Draw the X-axis and Y-axis.
2. Locate the x-coordinate.
3. Move parallel to the Y-axis.
4. Locate the y-coordinate.
5. Mark the required point.

### Example

Plot

```
(3,2)
```

- Move 3 units right.
- Move 2 units upward.
- Mark the point.

---

### Example

Plot

```
(-4,-3)
```

- Move 4 units left.
- Move 3 units downward.
- Mark the point.

---

# 8. Identifying Coordinates

To identify the coordinates of a point:

- Read the horizontal distance first (x-coordinate).
- Read the vertical distance second (y-coordinate).

Always write coordinates in the form

```
(x,y)
```

Never interchange the order.

Example

If a point is

- 5 units right
- 2 units down

Its coordinates are

```
(5,-2)
```

# Common Mistakes

- Writing coordinates in the wrong order.
- Confusing the X-axis with the Y-axis.
- Forgetting the signs of coordinates.
- Identifying the wrong quadrant.
- Assuming every point lies in a quadrant (points on the axes do not belong to any quadrant).
- Reading the y-coordinate before the x-coordinate.

# Chapter Summary

- Coordinate geometry combines algebra and geometry to locate points on a plane.
- The Cartesian coordinate system consists of two perpendicular axes: the X-axis and the Y-axis.
- The point where the two axes intersect is called the **Origin (0,0)**.
- Every point is represented by an ordered pair **(x, y)**.
- The coordinate plane is divided into four quadrants.
- The signs of the coordinates determine the quadrant in which a point lies.
- Points on the X-axis have **y = 0**, while points on the Y-axis have **x = 0**.
- Coordinates are always written in the order **(x-coordinate, y-coordinate)**.
- Coordinate geometry has wide applications in science, engineering, navigation, computer graphics, and many other fields.
