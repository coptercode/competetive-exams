# Introduction

Triangles are one of the most important geometrical figures. In this chapter, we study the **similarity of triangles**, the **Basic Proportionality Theorem (BPT)**, its proof, and the criteria for similarity such as **AAA**, **SAS**, and **SSS**. These concepts are widely used in geometry, surveying, architecture, engineering, and trigonometry.

---

# 1. Similar Figures

Two figures are said to be **similar** if:

- Their corresponding angles are equal.
- Their corresponding sides are proportional.

### Example

Two squares of different sizes are similar because:

- All angles are **90°**.
- Corresponding sides are proportional.

---

# 2. Similar Triangles

Two triangles are said to be **similar** if:

- Their corresponding angles are equal.
- Their corresponding sides are in the same ratio.

### Notation

```
△ABC ∼ △DEF
```

This means

```
∠A = ∠D
```

```
∠B = ∠E
```

```
∠C = ∠F
```

and

```
AB/DE = BC/EF = AC/DF
```

---

# 3. Basic Proportionality Theorem (BPT)

### Statement

> **If a line is drawn parallel to one side of a triangle to intersect the other two sides, then it divides those two sides in the same ratio.**

### Figure

```
        A
       /\
      /  \
     D----E
    /      \
   /        \
  B----------C

DE || BC
```

Then,

```
AD/DB = AE/EC
```

---

# 4. Proof of the Basic Proportionality Theorem

### Given

In

```
△ABC
```

```
DE || BC
```

where

- D lies on AB.
- E lies on AC.

### To Prove

```
AD/DB = AE/EC
```

### Proof

Since

```
DE || BC
```

Triangles

```
△ADE
```

and

```
△BDE
```

have the same altitude from point **E**.

Therefore,

```
Area(△ADE)
-----------
Area(△BDE)

=

AD
---
DB
```

Similarly,

Triangles

```
△ADE
```

and

```
△CDE
```

have the same altitude from point **D**.

Therefore,

```
Area(△ADE)
-----------
Area(△CDE)

=

AE
---
EC
```

Since triangles

```
△BDE
```

and

```
△CDE
```

have the same base **DE** and lie between the same parallels,

```
Area(△BDE)
=
Area(△CDE)
```

Hence,

```
AD/DB = AE/EC
```

Therefore,

```
Basic Proportionality Theorem is proved.
```

---

# 5. Converse of the Basic Proportionality Theorem

### Statement

> **If a line divides any two sides of a triangle in the same ratio, then the line is parallel to the third side.**

If

```
AD/DB = AE/EC
```

then

```
DE || BC
```

---

# 6. AAA Similarity Criterion

### Statement

> **If the corresponding angles of two triangles are equal, then the triangles are similar.**

### Condition

```
∠A = ∠D
```

```
∠B = ∠E
```

```
∠C = ∠F
```

Then,

```
△ABC ∼ △DEF
```

### Result

Corresponding sides are proportional.

```
AB/DE = BC/EF = AC/DF
```

---

# 7. SAS Similarity Criterion

### Statement

> **If one angle of a triangle is equal to one angle of another triangle and the sides including those angles are proportional, then the triangles are similar.**

### Condition

```
∠A = ∠D
```

and

```
AB/DE = AC/DF
```

Then,

```
△ABC ∼ △DEF
```

---

# 8. SSS Similarity Criterion

### Statement

> **If the corresponding sides of two triangles are proportional, then the triangles are similar.**

### Condition

```
AB/DE = BC/EF = AC/DF
```

Then,

```
△ABC ∼ △DEF
```

---

Area of △DEF

# Common Mistakes

- Confusing **congruent triangles** with **similar triangles**.
- Applying **AAA** instead of **AAS** or vice versa (only **AAA** is a similarity criterion).
- Forgetting that in **SAS Similarity**, the equal angle must be included between the proportional sides.
- Writing corresponding sides in the wrong order.
- Forgetting to square the side ratio while finding the ratio of areas.
- Using the **Basic Proportionality Theorem** when the line is not parallel to the third side.
- Mixing up the theorem with its converse.

# Chapter Summary

- **Similar figures** have equal corresponding angles and proportional corresponding sides.
- Two triangles are **similar** if they satisfy any one of the **AAA**, **SAS**, or **SSS** similarity criteria.
- The **Basic Proportionality Theorem (BPT)** states that a line drawn parallel to one side of a triangle divides the other two sides in the same ratio.
- The **converse of BPT** states that if two sides are divided in the same ratio, the joining line is parallel to the third side.
- In similar triangles, **corresponding angles are equal** and **corresponding sides are proportional**.
- The **ratio of the perimeters** of similar triangles equals the ratio of their corresponding sides.
- The **ratio of the areas** of similar triangles is equal to the **square of the ratio of their corresponding sides**.
- Similarity is widely used in geometry, surveying, architecture, engineering, and in measuring inaccessible distances and heights.
