# Introduction

Motion is one of the most fundamental concepts in physics. A body is said to be in motion if its position changes with time relative to a chosen reference point.

When an object moves along a **straight line**, its motion is called **one-dimensional motion** or **motion in a straight line**. Such motion can be completely described using position, displacement, velocity, and acceleration.

---

# 1. Frame of Reference

## Definition

A **frame of reference** is a coordinate system with respect to which the position and motion of an object are described.

Example

- A person standing on the ground observes a moving train.
- A passenger inside the train observes another passenger at rest.

---

## Types of Frames

### Inertial Frame

A frame in which Newton's laws of motion are valid.

Example

- Earth (approximately)
- A stationary laboratory

---

### Non-Inertial Frame

A frame accelerating with respect to an inertial frame.

Example

- Accelerating car
- Rotating merry-go-round

# 2. Position

```
Position = x
```

Unit

# 3. Distance

## Definition

Distance is the **total length of the actual path travelled** by a body.

### Characteristics

- Scalar quantity.
- Always positive.
- Depends on the actual path.

Unit

```
metre (m)
```

---

# 4. Displacement

## Definition

Displacement is the **shortest distance** between the initial and final positions of a body with a specified direction.

Formula

```
Displacement

=

Final Position

−

Initial Position
```

```
Δx = x₂ − x₁
```

### Characteristics

- Vector quantity.
- Can be positive, negative, or zero.
- Independent of the actual path.

---

# 5. Distance vs Displacement

| Distance        | Displacement                       |
| --------------- | ---------------------------------- |
| Scalar          | Vector                             |
| Path dependent  | Path independent                   |
| Always positive | May be positive, negative, or zero |
| Never decreases | Magnitude ≤ Distance               |

# 9. Acceleration

## Definition

Acceleration is the rate of change of velocity with time.

Formula

```
Acceleration

=

Change in Velocity
──────────────────
Time
```

```
a = Δv/Δt
```

or

```
a = dv/dt
```

Unit

```
m s⁻²
```

Dimension

```
[LT⁻²]
```

---

## Positive Acceleration

Velocity increases with time.

---

## Negative Acceleration (Retardation)

Velocity decreases with time.

---

## Uniform Acceleration

Equal changes in velocity occur in equal intervals of time.

---

## Non-Uniform Acceleration

Unequal changes in velocity occur in equal intervals of time.

---

# 10. Equations of Uniformly Accelerated Motion

Applicable only when acceleration is constant.

---

## First Equation

```
v = u + at
```

where

- u = Initial velocity
- v = Final velocity
- a = Acceleration
- t = Time

---

### Derivation

From the definition of acceleration,

```
a = (v − u)/t
```

Rearranging,

```
v = u + at
```

---

## Second Equation

```
s = ut + ½at²
```

where

- s = Displacement

---

### Derivation

Average velocity

```
= (u + v)/2
```

Substituting

```
v = u + at
```

into

```
s = Average Velocity × Time
```

gives

```
s = ut + ½at²
```

---

## Third Equation

```
v² = u² + 2as
```

---

### Derivation

Eliminating time from the first two equations,

```
v² = u² + 2as
```

---

# 11. Special Cases of Motion

---

## Body at Rest

```
u = 0
```

Then,

```
v = at
```

```
s = ½at²
```

```
v² = 2as
```

---

## Uniform Velocity

```
a = 0
```

Therefore,

```
v = u
```

```
s = vt
```

# 14. Freely Falling Body

For motion under gravity,

Replace

```
a
```

by

```
g
```

The equations become

```
v = u + gt
```

```
s = ut + ½gt²
```

```
v² = u² + 2gs
```

where

```
g ≈ 9.8 m s⁻²
```

# 15. Relative Velocity

## Definition

Relative velocity is the velocity of one object with respect to another.

---

## Formula

For two bodies A and B,

```
Velocity of A relative to B

=

vAB

=

vA − vB
```

---

### Same Direction

```
vAB

=

vA − vB
```

---

### Opposite Directions

```
vAB

=

vA + vB
```

---

# 16. Relative Motion in One Dimension

Example

A car moving at

```
20 m s⁻¹
```

and another at

```
15 m s⁻¹
```

in the same direction.

Relative velocity

```
20 − 15

=

5 m s⁻¹
```

# Solved Examples

### Example 1

A car travels **120 m** in **10 s**. Find its average speed.

**Solution**

Using

```
Average Speed

=

Distance / Time
```

```
= 120 / 10

= 12 m s⁻¹
```

---

### Example 2

A particle moves from **5 m** to **20 m**. Find its displacement.

**Solution**

```
Δx

=

20 − 5

=

15 m
```

---

### Example 3

A body starts from rest and accelerates uniformly at **2 m s⁻²** for **5 s**. Find the final velocity.

**Solution**

Using

```
v = u + at
```

```
u = 0

a = 2

t = 5
```

```
v

=

0 + 2 × 5

=

10 m s⁻¹
```

---

### Example 4

A vehicle moves with an initial velocity of **10 m s⁻¹** and accelerates at **3 m s⁻²** for **4 s**. Find the displacement.

**Solution**

Using

```
s = ut + ½at²
```

```
= (10 × 4)

+

½ × 3 × 16

= 40 + 24

= 64 m
```

---

### Example 5

A particle moves with **u = 5 m s⁻¹**, **a = 2 m s⁻²**, and covers **20 m**. Find the final velocity.

**Solution**

Using

```
v² = u² + 2as
```

```
v²

=

25 + 80

=

105
```

```
v

=

√105

≈ 10.25 m s⁻¹
```

---

### Example 6

Two trains move in the same direction with speeds **60 km h⁻¹** and **45 km h⁻¹**. Find their relative velocity.

**Solution**

```
Relative Velocity

=

60 − 45

=

15 km h⁻¹
```

# Common Mistakes

- Confusing **distance** with **displacement**.
- Assuming **speed** and **velocity** are always numerically equal; they differ whenever the direction changes or displacement differs from distance.
- Applying the equations of motion when **acceleration is not constant**.
- Forgetting that the **slope of an x–t graph gives velocity**, while the **slope of a v–t graph gives acceleration**.
- Mistaking the **area under a v–t graph** as velocity; it actually represents **displacement**.
- Using **g = +9.8 m s⁻²** or **−9.8 m s⁻²** without first choosing a sign convention.
- Ignoring the direction while calculating **relative velocity**.
- Mixing SI units (m, s) with non-SI units (km, h) without proper conversion.

# Chapter Summary

- Motion in a straight line is described with respect to a **frame of reference** using quantities such as **position**, **displacement**, **velocity**, and **acceleration**.
- **Distance** is a scalar quantity representing the actual path travelled, whereas **displacement** is a vector representing the shortest path between two positions.
- **Speed** is based on distance travelled, while **velocity** is based on displacement and includes direction.
- **Acceleration** is the rate of change of velocity and may be **positive**, **negative (retardation)**, **uniform**, or **non-uniform**.
- The three equations of uniformly accelerated motion—**v = u + at**, **s = ut + ½at²**, and **v² = u² + 2as**—are applicable only for **constant acceleration**.
- Motion can be effectively analyzed using **position-time**, **velocity-time**, and **acceleration-time** graphs, where slopes and areas provide important physical information.
- For freely falling bodies, acceleration is replaced by **g**, the acceleration due to gravity.
- **Relative velocity** describes the motion of one object with respect to another and depends on whether the objects move in the same or opposite directions.
- The concepts developed in this chapter form the basis for studying motion in two dimensions, Newton's laws of motion, and other advanced topics in mechanics.
