# Introduction

Many objects around us have three-dimensional shapes such as **cubes, cuboids, cylinders, cones, spheres, and hemispheres**. In this chapter, we learn how to calculate their **surface areas** and **volumes**, as well as solve problems involving combinations of these solids.

---

# 1. Three-Dimensional (3D) Shapes

Three-dimensional figures have:

- Length
- Breadth (Width)
- Height

Examples include:

- Cube
- Cuboid
- Cylinder
- Cone
- Sphere
- Hemisphere

---

# 2. Cube

A **cube** is a solid having six equal square faces.

### Properties

- Number of faces = 6
- Number of edges = 12
- Number of vertices = 8
- Length = Breadth = Height = **a**

### Formulas

| Quantity                   | Formula |
| -------------------------- | ------- |
| Lateral Surface Area (LSA) | `4a²`   |
| Total Surface Area (TSA)   | `6a²`   |
| Volume                     | `a³`    |

---

### Example

Find the volume of a cube of side

```
8 cm
```

**Solution**

```
Volume = a³
```

```
= 8³
```

```
= 512 cm³
```

---

# 3. Cuboid

A **cuboid** is a solid having six rectangular faces.

Let

- Length = **l**
- Breadth = **b**
- Height = **h**

### Formulas

| Quantity             | Formula           |
| -------------------- | ----------------- |
| Lateral Surface Area | `2h(l + b)`       |
| Total Surface Area   | `2(lb + bh + hl)` |
| Volume               | `l × b × h`       |

---

### Example

Find the volume of a cuboid with

```
l = 10 cm
```

```
b = 6 cm
```

```
h = 5 cm
```

**Solution**

```
Volume = 10 × 6 × 5
```

```
= 300 cm³
```

---

# 4. Cylinder

A **cylinder** has two circular bases connected by a curved surface.

Let

- Radius = **r**
- Height = **h**

### Formulas

| Quantity                  | Formula      |
| ------------------------- | ------------ |
| Curved Surface Area (CSA) | `2πrh`       |
| Total Surface Area (TSA)  | `2πr(r + h)` |
| Volume                    | `πr²h`       |

---

### Example

Find the volume of a cylinder of radius

```
7 cm
```

and height

```
10 cm
```

**Solution**

```
Volume = πr²h
```

```
= 22/7 × 49 × 10
```

```
= 1540 cm³
```

---

# 5. Cone

A **cone** has one circular base and one curved surface meeting at a vertex.

### Slant Height

```
l = √(r² + h²)
```

where

- **r** = Radius
- **h** = Height
- **l** = Slant height

### Formulas

| Quantity            | Formula     |
| ------------------- | ----------- |
| Curved Surface Area | `πrl`       |
| Total Surface Area  | `πr(l + r)` |
| Volume              | `(1/3)πr²h` |

---

### Example

Find the volume of a cone with

```
r = 3 cm
```

```
h = 12 cm
```

**Solution**

```
Volume

=

1/3 × π × 3² × 12
```

```
= 36π cm³
```

---

# 6. Sphere

A **sphere** is a perfectly round solid in which every point on the surface is equidistant from the centre.

### Formulas

| Quantity     | Formula    |
| ------------ | ---------- |
| Surface Area | `4πr²`     |
| Volume       | `(4/3)πr³` |

---

### Example

Find the surface area of a sphere with radius

```
7 cm
```

**Solution**

```
= 4 × 22/7 × 49
```

```
= 616 cm²
```

---

# 7. Hemisphere

A **hemisphere** is half of a sphere.

### Formulas

| Quantity            | Formula    |
| ------------------- | ---------- |
| Curved Surface Area | `2πr²`     |
| Total Surface Area  | `3πr²`     |
| Volume              | `(2/3)πr³` |

---

### Example

Find the volume of a hemisphere of radius

```
6 cm
```

**Solution**

```
Volume

=

2/3 × π × 6³
```

```
= 144π cm³
```

---

# 8. Conversion of Solids

Sometimes one solid is melted and recast into another.

### Principle

```
Volume Before

=

Volume After
```

This principle is used to solve conversion problems.

---

### Example

A cube of side

```
6 cm
```

is melted to form small cubes of side

```
2 cm
```

Find the number of cubes formed.

**Solution**

Volume of the large cube

```
= 6³
```

```
= 216 cm³
```

Volume of one small cube

```
= 2³
```

```
= 8 cm³
```

Number of cubes

```
= 216/8
```

```
= 27
```

---

# 9. Combination of Solids

Many practical objects are combinations of different solids.

Examples:

- Cylinder + Hemisphere
- Cone + Hemisphere
- Cylinder + Cone
- Cuboid + Hemisphere

To solve such problems:

1. Divide the object into known solids.
2. Find the required surface areas or volumes separately.
3. Add or subtract as required.

# Common Mistakes

- Confusing **Curved Surface Area (CSA)** with **Total Surface Area (TSA)**.
- Using the diameter instead of the radius without converting.
- Forgetting to calculate the **slant height** before finding the curved surface area of a cone.
- Using the wrong formula for a hemisphere.
- Forgetting that the **volume remains the same** when one solid is melted and recast into another.
- Mixing units while calculating surface areas and volumes.
- Using **π = 22/7** when the radius is not a multiple of 7 without checking if another approximation (such as **3.14**) is more appropriate.

# Chapter Summary

- Three-dimensional solids such as **cubes, cuboids, cylinders, cones, spheres,** and **hemispheres** have measurable **surface areas** and **volumes**.
- The **surface area** represents the total area covered by the outer surfaces of a solid.
- The **volume** represents the space occupied by a solid.
- Different solids have different formulas for calculating their **Curved Surface Area (CSA)**, **Lateral Surface Area (LSA)**, **Total Surface Area (TSA)**, and **Volume**.
- The **slant height** of a cone is found using the Pythagoras Theorem.
- In conversion (melting and recasting) problems, the **volume remains unchanged**.
- Complex objects can be divided into combinations of simple solids to calculate their total surface area or volume.
- Surface area and volume concepts are widely used in engineering, architecture, packaging, manufacturing, construction, and storage design.
