# Introduction

Coordinate Geometry, also known as **Analytical Geometry**, combines algebra and geometry to study geometric figures using coordinates. It enables us to determine the **distance** between points, locate the **midpoint**, divide a line segment in a given ratio using the **section formula**, and verify whether points are **collinear**.

---

# 1. Cartesian Coordinate System

The **Cartesian Coordinate System** consists of two mutually perpendicular number lines:

- **X-axis (Horizontal Axis)**
- **Y-axis (Vertical Axis)**

The point where they intersect is called the **Origin**.

```
          Y-axis
            ↑
      II    |    I
            |
------------O------------→ X-axis
            |
      III   |    IV
            ↓
```

The coordinates of the origin are

```
(0, 0)
```

---

# 2. Coordinates of a Point

A point is represented by an ordered pair

```
(x, y)
```

where:

- **x** = x-coordinate (abscissa)
- **y** = y-coordinate (ordinate)

### Example

For the point

```
(4, 3)
```

- Abscissa = 4
- Ordinate = 3

---

# 3. Quadrants

The coordinate plane is divided into four quadrants.

| Quadrant | Sign of Coordinates |
| -------- | ------------------- |
| I        | (+, +)              |
| II       | (-, +)              |
| III      | (-, -)              |
| IV       | (+, -)              |

# 4. Distance Formula

The **distance formula** is used to find the distance between two points.

If

```
A(x₁, y₁)
```

and

```
B(x₂, y₂)
```

then,

### Formula

```
AB = √[(x₂ − x₁)² + (y₂ − y₁)²]
```

---

### Example

Find the distance between

```
A(2, 3)
```

and

```
B(8, 11)
```

**Solution**

Using

```
AB = √[(8 − 2)² + (11 − 3)²]
```

```
= √(6² + 8²)
```

```
= √(36 + 64)
```

```
= √100
```

```
= 10 units
```

---

# 5. Distance from the Origin

If a point is

```
(x, y)
```

then its distance from the origin is

```
√(x² + y²)
```

---

### Example

Find the distance of

```
(5, 12)
```

from the origin.

**Solution**

```
= √(5² + 12²)
```

```
= √(25 + 144)
```

```
= √169
```

```
= 13 units
```

---

# 6. Section Formula

The **section formula** is used to find the coordinates of a point dividing a line segment internally in a given ratio.

Suppose point

```
P
```

divides the line joining

```
A(x₁, y₁)
```

and

```
B(x₂, y₂)
```

internally in the ratio

```
m : n
```

Then,

### Formula

```
          (mx₂ + nx₁)
x = ----------------------
             (m + n)
```

```
          (my₂ + ny₁)
y = ----------------------
             (m + n)
```

Therefore,

```
P
=
(
(mx₂ + nx₁)/(m+n),
(my₂ + ny₁)/(m+n)
)
```

---

### Example

Find the point dividing

```
A(2, 4)
```

and

```
B(8, 10)
```

in the ratio

```
1 : 2
```

**Solution**

Using the section formula,

```
x = (1×8 + 2×2)/3
```

```
= (8 + 4)/3
```

```
= 4
```

Similarly,

```
y = (1×10 + 2×4)/3
```

```
= (10 + 8)/3
```

```
= 6
```

Hence,

```
P = (4, 6)
```

---

# 7. Midpoint Formula

The midpoint is obtained when the ratio is

```
1 : 1
```

If

```
A(x₁, y₁)
```

and

```
B(x₂, y₂)
```

then the midpoint is

### Formula

```
(
(x₁ + x₂)/2 ,
(y₁ + y₂)/2
)
```

---

### Example

Find the midpoint of

```
(2, 6)
```

and

```
(8, 10)
```

**Solution**

```
x = (2 + 8)/2
```

```
= 5
```

```
y = (6 + 10)/2
```

```
= 8
```

Therefore,

```
Midpoint = (5, 8)
```

---

# 8. Collinearity of Three Points

Three points are said to be **collinear** if they lie on the same straight line.

### Method

Find the distances:

```
AB
```

```
BC
```

```
AC
```

If

```
AB + BC = AC
```

then the three points are collinear.

---

### Alternative Method

Use the **area of the triangle** formed by the three points.

If the area is

```
0
```

then the points are collinear.

# Common Mistakes

- Interchanging the **x** and **y** coordinates.
- Using the wrong order of subtraction in the distance formula.
- Forgetting to square negative numbers.
- Mixing up the **section formula** with the **midpoint formula**.
- Using an incorrect ratio in the section formula.
- Assuming points are collinear without verification.
- Making arithmetic mistakes while simplifying square roots.

# Chapter Summary

- The **Cartesian coordinate system** consists of the **x-axis**, **y-axis**, and the **origin**.
- A point is represented by an ordered pair **(x, y)**, where **x** is the abscissa and **y** is the ordinate.
- The coordinate plane is divided into **four quadrants**, each with a specific sign convention.
- The **distance formula** is used to calculate the distance between two points on the coordinate plane.
- The **distance from the origin** is found using **√(x² + y²)**.
- The **section formula** determines the coordinates of a point dividing a line segment internally in a given ratio.
- The **midpoint formula** gives the coordinates of the midpoint of a line segment.
- Three points are **collinear** if they lie on the same straight line, which can be verified using the distance method (or equivalently, by checking that the area of the triangle formed is zero).
- Coordinate Geometry has wide applications in mathematics, science, engineering, navigation, computer graphics, and architecture.
