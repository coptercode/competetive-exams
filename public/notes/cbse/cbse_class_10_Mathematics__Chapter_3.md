# Introduction

A **pair of linear equations in two variables** consists of two linear equations involving the same two variables. These equations represent two straight lines on a graph. The solution of the pair is the point where the two lines intersect.

This chapter explains the **graphical method**, **substitution method**, **elimination method**, conditions for **consistent** and **inconsistent** systems, and their applications in solving real-life problems.

---

# 1. Linear Equation in Two Variables

A **linear equation in two variables** is an equation of the form

```
ax + by + c = 0
```

where

- **a, b, c** are real numbers.
- **a** and **b** are not both zero.

### Examples

```
2x + 3y = 12
```

```
x - y = 4
```

---

# 2. Pair of Linear Equations

A pair of linear equations is written as

```
a₁x + b₁y + c₁ = 0
```

```
a₂x + b₂y + c₂ = 0
```

The solution is the ordered pair

```
(x, y)
```

that satisfies both equations.

---

# 3. Graphical Representation

Each linear equation represents a **straight line**.

The solution depends on the position of the two lines.

---

## Case 1: Intersecting Lines

The lines intersect at one point.

```
\     /
 \   /
  \ /
  / \
 /   \
```

### Result

- One unique solution.
- The equations are **consistent**.

---

## Case 2: Parallel Lines

The lines never meet.

```
---------
---------
```

### Result

- No solution.
- The equations are **inconsistent**.

---

## Case 3: Coincident Lines

Both equations represent the same line.

```
---------
```

### Result

- Infinitely many solutions.
- The equations are **consistent** and **dependent**.

---

# 4. Conditions for Consistency

For the equations

```
a₁x + b₁y + c₁ = 0
```

```
a₂x + b₂y + c₂ = 0
```

### Unique Solution

```
a₁/a₂ ≠ b₁/b₂
```

The lines intersect.

---

### No Solution

```
a₁/a₂ = b₁/b₂ ≠ c₁/c₂
```

The lines are parallel.

---

### Infinitely Many Solutions

```
a₁/a₂ = b₁/b₂ = c₁/c₂
```

The lines coincide.

---

# 5. Graphical Method of Solving

### Steps

1. Convert each equation into a convenient form.
2. Find at least two points for each equation.
3. Plot the points on graph paper.
4. Draw the straight lines.
5. Identify the point of intersection.

### Example

Solve graphically:

```
x + y = 5
```

```
x - y = 1
```

Adding the equations,

```
2x = 6
```

```
x = 3
```

Substitute in

```
x + y = 5
```

```
3 + y = 5
```

```
y = 2
```

Solution

```
(3, 2)
```

---

# 6. Substitution Method

One variable is expressed in terms of the other and substituted into the second equation.

### Steps

1. Express one variable from one equation.
2. Substitute into the second equation.
3. Solve for one variable.
4. Find the other variable.

---

### Example

Solve

```
x + y = 8
```

```
x - y = 2
```

From the first equation,

```
x = 8 - y
```

Substitute into the second equation,

```
8 - y - y = 2
```

```
8 - 2y = 2
```

```
2y = 6
```

```
y = 3
```

```
x = 5
```

Solution

```
(5, 3)
```

---

# 7. Elimination Method

In this method, one variable is eliminated by adding or subtracting the equations.

### Steps

1. Make the coefficients of one variable equal.
2. Add or subtract the equations.
3. Solve for one variable.
4. Substitute to obtain the second variable.

---

### Example

Solve

```
2x + y = 8
```

```
3x - y = 7
```

Add the equations,

```
5x = 15
```

```
x = 3
```

Substitute into

```
2x + y = 8
```

```
6 + y = 8
```

```
y = 2
```

Solution

```
(3, 2)
```

---

# 8. Verification of Solution

After solving,

Substitute the values of

```
x
```

and

```
y
```

into both equations.

If both equations are satisfied, the solution is correct.

---

# 9. Real-Life Applications

Pair of linear equations are widely used in solving practical problems.

### Examples

- Cost of two different items.
- Age problems.
- Speed and distance.
- Number problems.
- Mixture problems.
- Ticket pricing.
- Business and finance.

# Solved Examples

### Example 1

Solve using the substitution method.

```
x + y = 7
```

```
x - y = 1
```

**Solution**

From the first equation,

```
x = 7 - y
```

Substitute,

```
7 - y - y = 1
```

```
6 = 2y
```

```
y = 3
```

```
x = 4
```

Answer

```
(4, 3)
```

---

### Example 2

Solve using the elimination method.

```
3x + 2y = 16
```

```
3x - 2y = 8
```

**Solution**

Add both equations,

```
6x = 24
```

```
x = 4
```

Substitute,

```
3(4) + 2y = 16
```

```
12 + 2y = 16
```

```
2y = 4
```

```
y = 2
```

Answer

```
(4, 2)
```

---

### Example 3

Determine whether the following pair is consistent.

```
2x + y = 4
```

```
4x + 2y = 8
```

**Solution**

```
a₁/a₂ = 2/4 = 1/2
```

```
b₁/b₂ = 1/2
```

```
c₁/c₂ = -4/-8 = 1/2
```

Since

```
a₁/a₂ = b₁/b₂ = c₁/c₂
```

The equations have

```
Infinitely many solutions.
```

---

### Example 4

Determine whether the pair has a unique solution.

```
x + 2y = 5
```

```
2x - y = 4
```

**Solution**

```
a₁/a₂ = 1/2
```

```
b₁/b₂ = 2/(-1)
```

Since

```
a₁/a₂ ≠ b₁/b₂
```

The equations have

```
One unique solution.
```

---

### Example 5

The sum of two numbers is **20** and their difference is **4**. Find the numbers.

**Solution**

Let the numbers be

```
x and y
```

Equations

```
x + y = 20
```

```
x - y = 4
```

Add,

```
2x = 24
```

```
x = 12
```

```
y = 8
```

Numbers are

```
12 and 8
```

---

### Example 6

A shopkeeper sells a pen for ₹20 and a notebook for ₹50.

A customer buys **2 pens and 3 notebooks** for ₹190.

Another customer buys **3 pens and 2 notebooks** for ₹160.

Find the cost of each item.

**Solution**

Let

```
Pen = x
```

```
Notebook = y
```

Equations

```
2x + 3y = 190
```

```
3x + 2y = 160
```

Multiply the first equation by 3

```
6x + 9y = 570
```

Multiply the second equation by 2

```
6x + 4y = 320
```

Subtract

```
5y = 250
```

```
y = 50
```

Substitute,

```
3x + 100 = 160
```

```
3x = 60
```

```
x = 20
```

Therefore,

```
Pen = ₹20
```

```
Notebook = ₹50
```

# Common Mistakes

- Forgetting to write equations in the standard form before comparing coefficients.
- Using incorrect signs while eliminating variables.
- Making arithmetic errors during substitution.
- Forgetting to verify the obtained solution in both equations.
- Confusing **parallel** and **coincident** lines.
- Applying the consistency conditions incorrectly.
- Ignoring units while solving word problems.

# Chapter Summary

- A **pair of linear equations in two variables** represents two straight lines on a graph.
- The **solution** of the pair is the ordered pair that satisfies both equations.
- If the lines **intersect**, there is **one unique solution**.
- If the lines are **parallel**, there is **no solution**.
- If the lines **coincide**, there are **infinitely many solutions**.
- The **graphical method** helps visualize the nature of the solution.
- The **substitution method** solves equations by expressing one variable in terms of the other.
- The **elimination method** removes one variable to simplify the system.
- Pair of linear equations are widely used to solve real-life problems involving costs, ages, distances, mixtures, and business situations.
