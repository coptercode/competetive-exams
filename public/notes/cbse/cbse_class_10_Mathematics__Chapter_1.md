# Introduction

Real numbers include all rational and irrational numbers. They are used in almost every branch of mathematics and in daily life. This chapter introduces the **Fundamental Theorem of Arithmetic**, methods of finding the **HCF** and **LCM** of numbers, and explains why numbers such as **√2** are irrational.

---

# 1. Real Numbers

A **real number** is any number that can be represented on the number line.

Real numbers include:

- Natural numbers
- Whole numbers
- Integers
- Rational numbers
- Irrational numbers

### Classification

```
                Real Numbers
               /            \
        Rational         Irrational
```

### Examples

**Rational Numbers**

```
3, -5, 7/8, 0.25
```

**Irrational Numbers**

```
√2, √3, π
```

---

# 2. Rational Numbers

A **rational number** can be written in the form

```
p/q
```

where

- **p** and **q** are integers.
- **q ≠ 0**.

### Properties

- Decimal expansion is either **terminating** or **non-terminating recurring**.

### Examples

```
5 = 5/1
```

```
7/4 = 1.75
```

```
1/3 = 0.3333...
```

---

# 3. Irrational Numbers

An **irrational number** cannot be expressed in the form

```
p/q
```

where **p** and **q** are integers.

### Properties

- Decimal expansion is **non-terminating**.
- Decimal expansion is **non-recurring**.

### Examples

```
√2
√5
π
```

---

# 4. Prime Numbers

A **prime number** is a natural number greater than **1** that has exactly **two factors**:

- 1
- Itself

### Examples

```
2, 3, 5, 7, 11, 13
```

---

# 5. Composite Numbers

A **composite number** has more than two factors.

### Examples

```
4, 6, 8, 9, 10
```

---

# 6. Prime Factorization

Prime factorization means expressing a number as the product of its prime factors.

### Example

Find the prime factorization of **84**.

```
84 = 2 × 42
```

```
42 = 2 × 21
```

```
21 = 3 × 7
```

Therefore,

```
84 = 2² × 3 × 7
```

---

# 7. Fundamental Theorem of Arithmetic

## Statement

> **Every composite number can be expressed as a product of prime numbers, and this factorization is unique except for the order of the prime factors.**

### Example

```
60
```

Prime factorization:

```
60 = 2² × 3 × 5
```

No other set of prime factors can represent **60**.

---

# 8. Highest Common Factor (HCF)

The **Highest Common Factor (HCF)** is the greatest number that divides two or more numbers exactly.

### Method: Prime Factorization

### Example

Find the HCF of **36** and **48**.

Prime factorization:

```
36 = 2² × 3²
```

```
48 = 2⁴ × 3
```

Take the common factors with the **smallest powers**.

```
HCF = 2² × 3
```

```
= 12
```

---

# 9. Lowest Common Multiple (LCM)

The **Lowest Common Multiple (LCM)** is the smallest positive number that is exactly divisible by all the given numbers.

### Method: Prime Factorization

### Example

Find the LCM of **36** and **48**.

Prime factorization:

```
36 = 2² × 3²
```

```
48 = 2⁴ × 3
```

Take all prime factors with the **greatest powers**.

```
LCM = 2⁴ × 3²
```

```
= 16 × 9
```

```
= 144
```

---

# 10. Relationship Between HCF and LCM

For any two positive integers,

```
HCF × LCM
=
Product of the Numbers
```

or

```
HCF × LCM = a × b
```

### Example

Numbers:

```
12 and 18
```

```
HCF = 6
```

```
LCM = 36
```

Verification:

```
6 × 36 = 216
```

```
12 × 18 = 216
```

Hence verified.

# 12. Condition for Terminating Decimal Expansion

Suppose

```
p/q
```

is in its lowest form.

Its decimal expansion terminates **only if** the prime factors of **q** are **2** and/or **5**.

### Examples

```
3/20
```

```
20 = 2² × 5
```

Terminating decimal.

---

```
7/18
```

```
18 = 2 × 3²
```

Since **3** is present,

```
Non-terminating recurring decimal.
```

# 13. Proving √2 is Irrational

## Theorem

**√2 is an irrational number.**

### Proof (By Contradiction)

Assume

```
√2 = p/q
```

where

- **p** and **q** are integers.
- They have no common factor.

Squaring both sides,

```
2 = p²/q²
```

```
p² = 2q²
```

Therefore,

```
p²
```

is even.

Hence,

```
p
```

is also even.

Let

```
p = 2k
```

Substitute:

```
(2k)² = 2q²
```

```
4k² = 2q²
```

```
q² = 2k²
```

Thus,

```
q
```

is also even.

Therefore, both **p** and **q** are even.

This contradicts the assumption that **p** and **q** have no common factor.

Hence,

```
√2 is irrational.
```

The same method can be used to prove that **√3**, **√5**, and other non-perfect square roots are irrational.

# Common Mistakes

- Confusing **prime numbers** with **odd numbers** (2 is the only even prime number).
- Forgetting to write numbers in **lowest form** before checking decimal expansion.
- Taking the **largest powers** while finding the HCF instead of the smallest powers.
- Taking the **smallest powers** while finding the LCM instead of the largest powers.
- Assuming every non-terminating decimal is irrational (recurring decimals are rational).
- Missing the contradiction step while proving **√2** is irrational.
- Forgetting that the **Fundamental Theorem of Arithmetic** applies only to **composite numbers**.

# Chapter Summary

- **Real numbers** include both **rational** and **irrational** numbers.
- A **rational number** can be expressed in the form **p/q**, while an **irrational number** cannot.
- Every composite number has a **unique prime factorization**, according to the **Fundamental Theorem of Arithmetic**.
- The **HCF** is found by taking the common prime factors with the **smallest powers**, whereas the **LCM** is found by taking all prime factors with the **greatest powers**.
- For any two positive integers, **HCF × LCM = Product of the numbers**.
- A rational number has a **terminating decimal expansion** only if, in its lowest form, the denominator has no prime factors other than **2** and/or **5**.
- Numbers such as **√2**, **√3**, and **√5** are **irrational**, and this can be proved using the method of contradiction.
- Understanding prime factorization and the properties of real numbers forms the foundation for many advanced mathematical concepts.
