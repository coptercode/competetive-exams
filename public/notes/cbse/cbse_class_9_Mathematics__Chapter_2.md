# Introduction

In mathematics, we often use letters such as **x, y, a,** and **b** to represent unknown quantities. Expressions formed using these variables, numbers, and arithmetic operations are called **algebraic expressions**. A special type of algebraic expression that satisfies certain conditions is known as a **polynomial**.

Polynomials are one of the most important topics in algebra. They provide the foundation for solving equations, graphing functions, coordinate geometry, calculus, and many advanced mathematical concepts. They are also widely used in physics, engineering, economics, statistics, and computer science.

The word **polynomial** comes from two words:

- **Poly** means _many_.
- **Nomial** means _terms_.

Thus, a polynomial is an algebraic expression consisting of one or more terms connected by addition or subtraction.

# 2. What is a Polynomial?

A **polynomial** is an algebraic expression in which:

- Variables have only whole number exponents.
- Coefficients are real numbers.
- Variables do not appear in denominators.
- Variables are not inside square roots.
- Variables do not have negative or fractional powers.

The general form of a polynomial is

```
aₙxⁿ + aₙ₋₁xⁿ⁻¹ + aₙ₋₂xⁿ⁻² + ... + a₁x + a₀
```

where

- **aₙ ≠ 0**
- **n** is a whole number.

# 4. Degree of a Polynomial

The **degree** of a polynomial is the highest exponent of the variable having a non-zero coefficient.

Examples:

| Polynomial   | Degree |
| ------------ | ------ |
| 8            | 0      |
| x + 5        | 1      |
| 3x² − 7      | 2      |
| 5x³ + 2x     | 3      |
| 9x⁵ − x² + 1 | 5      |

### Important Notes

- Constant polynomial has degree **0**.
- Zero polynomial does not have a defined degree in Class 9.
- Degree depends only on the highest power.

# 6. Basic Operations on Polynomials

## Addition

Like terms are added together.

Example

```
(3x² + 4x + 5) + (2x² − x + 6)
```

```
= 5x² + 3x + 11
```

---

## Subtraction

Subtract corresponding like terms.

Example

```
(7x² + 5x − 3) − (2x² + x + 4)
```

```
= 5x² + 4x − 7
```

---

## Multiplication

Each term of one polynomial is multiplied by every term of the other polynomial.

Example

```
(x + 4)(x + 3)
```

```
= x² + 3x + 4x + 12
```

```
= x² + 7x + 12
```

---

### Multiplication of Monomials

Example

```
3x² × 4x³
```

Multiply coefficients

```
3 × 4 = 12
```

Add exponents

```
x² × x³ = x⁵
```

Answer

```
12x⁵
```

# 7. Zeroes of a Polynomial

A **zero** of a polynomial is a value of the variable for which the polynomial becomes zero.

If

```
p(a)=0
```

then **a** is called a zero of the polynomial.

### Example 1

```
p(x)=x−5
```

Put

```
p(x)=0
```

```
x−5=0
```

```
x=5
```

Hence,

**5** is the zero.

---

### Example 2

```
p(x)=4x+12
```

```
4x+12=0
```

```
4x=−12
```

```
x=−3
```

Hence,

−3 is the zero.

# 8. Factorization by Splitting the Middle Term

This method is used to factorize quadratic polynomials.

### Steps

1. Multiply coefficient of x² and constant.
2. Find two numbers whose product equals this value.
3. Their sum should equal the coefficient of x.
4. Split the middle term.
5. Take common factors.

---

### Example 1

Factorize

```
x²+7x+12
```

Required numbers

Product = 12

Sum = 7

Numbers are

```
3 and 4
```

```
=x²+3x+4x+12
```

```
=x(x+3)+4(x+3)
```

```
=(x+3)(x+4)
```

---

### Example 2

Factorize

```
x²−9x+20
```

Numbers

```
−5 and −4
```

```
=x²−5x−4x+20
```

```
=x(x−5)−4(x−5)
```

```
=(x−5)(x−4)
```

# 9. Factor Theorem

The **Factor Theorem** provides an easy method to check whether a given expression is a factor of a polynomial.

### Statement

If

```
p(a)=0
```

then

```
(x−a)
```

is a factor of the polynomial.

If

```
p(a)≠0
```

then

```
(x−a)
```

is not a factor.

---

### Example

Check whether

```
x−2
```

is a factor of

```
x²−5x+6
```

Substitute

```
x=2
```

```
2²−5(2)+6
```

```
=4−10+6
```

```
=0
```

Hence,

```
x−2
```

is a factor.

# Common Mistakes

- Writing negative exponents in a polynomial.
- Confusing coefficient with exponent.
- Forgetting signs while splitting the middle term.
- Adding unlike terms.
- Forgetting to combine like terms after multiplication.
- Incorrectly identifying the degree of a polynomial.
- Assuming every algebraic expression is a polynomial.

# Chapter Summary

- An algebraic expression with non-negative integral exponents is called a polynomial.
- Every polynomial consists of terms, coefficients, variables, and constants.
- The highest exponent determines the degree of the polynomial.
- Polynomials are classified according to their degree and the number of terms.
- Addition and subtraction involve combining like terms.
- Multiplication follows the distributive law.
- A zero of a polynomial makes its value equal to zero.
- Quadratic polynomials can be factorized by splitting the middle term.
- The Factor Theorem helps determine whether a given expression is a factor of a polynomial.
- Polynomials form the foundation of higher algebra and are widely used in mathematics and science.
