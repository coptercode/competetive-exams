# Introduction

Trigonometry is widely used to determine **heights** and **distances** that cannot be measured directly. By using trigonometric ratios along with the concepts of the **angle of elevation** and the **angle of depression**, we can solve many practical problems related to buildings, towers, mountains, bridges, and navigation.

---

# 1. Line of Sight

The **line of sight** is the straight line joining the observer's eye to the object being viewed.

### Figure

```
Observer ●----------------------● Object
             Line of Sight
```

---

# 2. Horizontal Line

The **horizontal line** is a line drawn parallel to the ground through the observer's eye.

```
----------------------------
      Horizontal Line
```

It serves as the reference line for measuring angles of elevation and depression.

---

# 3. Angle of Elevation

The **angle of elevation** is the angle formed between the horizontal line and the line of sight when the object is **above** the observer.

### Figure

```
           Object
              ●
             /
            /
           /
          /
Observer ●----------------
        θ
Horizontal Line
```

Here,

```
θ
```

is the **angle of elevation**.

---

# 4. Angle of Depression

The **angle of depression** is the angle formed between the horizontal line and the line of sight when the object is **below** the observer.

### Figure

```
Observer ●----------------
            \
             \
              \
               ● Object
         θ
```

Here,

```
θ
```

is the **angle of depression**.

---

# 5. Trigonometric Ratios Used

For solving problems involving heights and distances, the following ratios are commonly used:

### Sine

```
sin θ = Perpendicular / Hypotenuse
```

---

### Cosine

```
cos θ = Base / Hypotenuse
```

---

### Tangent

```
tan θ = Perpendicular / Base
```

The **tangent ratio** is the most frequently used because it directly relates the **height** and the **horizontal distance**.

---

# 6. Steps for Solving Problems

1. Draw a neat diagram.
2. Mark the known measurements.
3. Identify the required quantity.
4. Choose the appropriate trigonometric ratio.
5. Form the equation.
6. Solve and write the answer with proper units.

---

# 7. Heights and Distances

### Height

The **vertical measurement** of an object.

Examples:

- Height of a tower.
- Height of a building.
- Height of a tree.

---

### Distance

The **horizontal measurement** between the observer and the object.

Examples:

- Distance from a building.
- Distance between two poles.
- Distance from a lighthouse.

# Solved Examples

### Example 1

A person stands **20 m** away from a tower. The angle of elevation of the top of the tower is

```
45°
```

Find the height of the tower.

**Solution**

Given,

```
Base = 20 m
```

```
θ = 45°
```

Using,

```
tan θ = Height / Base
```

```
tan 45° = h / 20
```

```
1 = h / 20
```

```
h = 20 m
```

**Answer**

```
Height = 20 m
```

---

### Example 2

The angle of elevation of the top of a tree is

```
60°
```

from a point **15 m** away from its base.

Find the height of the tree.

**Solution**

Using,

```
tan 60° = Height / 15
```

```
√3 = h / 15
```

```
h = 15√3 m
```

---

### Example 3

A ladder **10 m** long rests against a wall.

The foot of the ladder is **6 m** from the wall.

Find the height reached by the ladder.

**Solution**

Using the Pythagoras Theorem,

```
Height² = 10² − 6²
```

```
= 100 − 36
```

```
= 64
```

```
Height = 8 m
```

---

### Example 4

The angle of depression of a boat from the top of a lighthouse is

```
30°
```

If the lighthouse is **40 m** high, find the distance of the boat from the lighthouse.

**Solution**

Angle of depression equals the angle of elevation.

Using,

```
tan 30° = 40 / Distance
```

```
1/√3 = 40 / d
```

```
d = 40√3 m
```

---

### Example 5

A kite is flying at a height of

```
50 m
```

The angle of elevation from the ground is

```
45°
```

Find the horizontal distance of the kite from the observer.

**Solution**

Using,

```
tan 45° = 50 / Distance
```

```
1 = 50 / Distance
```

```
Distance = 50 m
```

# Common Mistakes

- Confusing the **angle of elevation** with the **angle of depression**.
- Drawing an incorrect diagram before solving the problem.
- Using the wrong trigonometric ratio.
- Forgetting that the angle of depression is equal to the corresponding angle of elevation.
- Ignoring the observer's height when it is included in the question.
- Making mistakes while rationalising surds.
- Forgetting to include units in the final answer.

# Chapter Summary

- **Applications of Trigonometry** mainly involve finding unknown **heights** and **distances** using trigonometric ratios.
- The **line of sight** is the straight line joining the observer's eye and the object.
- The **horizontal line** acts as the reference line for measuring angles.
- The **angle of elevation** is formed when the observer looks **upward** at an object.
- The **angle of depression** is formed when the observer looks **downward** at an object.
- The **tangent ratio** is most commonly used because it directly relates the **height** and the **horizontal distance**.
- Drawing an accurate diagram is the first and most important step in solving application-based problems.
- Trigonometry has practical applications in surveying, construction, navigation, engineering, architecture, astronomy, and many other fields.
