# Introduction

An **Arithmetic Progression (AP)** is a sequence of numbers in which the difference between consecutive terms is constant. This constant difference is called the **common difference**.

Arithmetic progressions are widely used in mathematics, finance, economics, construction, and daily life. This chapter explains how to identify an AP, find its **nth term**, determine the **number of terms**, calculate the **sum of the first n terms**, and solve real-life problems.

---

# 2. Arithmetic Progression (AP)

A sequence is called an **Arithmetic Progression (AP)** if the difference between any two consecutive terms is the same.

### Examples

```
3, 7, 11, 15, ...
```

Common difference

```
4
```

---

```
10, 8, 6, 4, ...
```

Common difference

```
-2
```

---

# 3. First Term and Common Difference

Consider the AP

```
5, 9, 13, 17, 21, ...
```

### First Term

The first term is denoted by

```
a
```

Here,

```
a = 5
```

---

### Common Difference

The common difference is denoted by

```
d
```

Formula

```
d = Second Term − First Term
```

Here,

```
d = 9 − 5
```

```
= 4
```

---

# 4. General Term (nth Term)

The **nth term** of an AP is denoted by

```
aₙ
```

### Formula

```
aₙ = a + (n − 1)d
```

where

- **a** = First term
- **d** = Common difference
- **n** = Term number

---

### Example

Find the 10th term of

```
2, 5, 8, 11, ...
```

Here,

```
a = 2
```

```
d = 3
```

Using

```
a₁₀ = a + (10 − 1)d
```

```
= 2 + 9 × 3
```

```
= 29
```

---

# 5. Finding the Number of Terms

If the last term is known, the number of terms can be found using the nth term formula.

Given

```
aₙ = a + (n − 1)d
```

Rearranging,

```
          aₙ − a
n = ---------------- + 1
             d
```

---

### Example

How many terms are there in the AP

```
4, 7, 10, ..., 70
```

Here,

```
a = 4
```

```
d = 3
```

```
aₙ = 70
```

Using

```
70 = 4 + (n − 1)3
```

```
66 = 3(n − 1)
```

```
22 = n − 1
```

```
n = 23
```

---

# 6. Sum of the First n Terms

The sum of the first

```
n
```

terms of an AP is denoted by

```
Sₙ
```

### Formula

```
          n
Sₙ = -------- [2a + (n − 1)d]
          2
```

---

### Alternative Formula

If the last term

```
l
```

is known,

```
      n
Sₙ = --- (a + l)
      2
```

---

# 7. Sum of an Arithmetic Progression

### Example

Find the sum of the first

```
20
```

terms of

```
3, 7, 11, ...
```

Here,

```
a = 3
```

```
d = 4
```

Using

```
          20
S₂₀ = -------- [2(3) + (20 − 1)(4)]
           2
```

```
= 10 [6 + 76]
```

```
= 10 × 82
```

```
= 820
```

---

# 8. Properties of an Arithmetic Progression

- The common difference remains constant.
- If

```
d > 0
```

the AP is increasing.

- If

```
d < 0
```

the AP is decreasing.

- If

```
d = 0
```

all terms are equal.

# Common Mistakes

- Confusing the **first term** with the **common difference**.
- Using the wrong value of **n − 1** in the nth term formula.
- Forgetting to identify the common difference correctly.
- Using the sum formula instead of the nth term formula.
- Making arithmetic mistakes while simplifying expressions.
- Using the alternative sum formula without first finding the last term.
- Assuming every sequence is an arithmetic progression.

# Chapter Summary

- An **Arithmetic Progression (AP)** is a sequence in which the difference between consecutive terms is constant.
- The **first term** is denoted by **a**, and the **common difference** is denoted by **d**.
- The **nth term** of an AP is calculated using **aₙ = a + (n − 1)d**.
- The **number of terms** can be found by rearranging the nth term formula when the last term is known.
- The **sum of the first n terms** is given by **Sₙ = n/2 [2a + (n − 1)d]**.
- If the last term is known, the sum can also be calculated using **Sₙ = n/2 (a + l)**.
- Arithmetic progressions are widely used in solving practical problems involving savings, salaries, seating arrangements, construction, and numerical patterns.
- Understanding AP forms the foundation for studying more advanced sequences and series in higher mathematics.
