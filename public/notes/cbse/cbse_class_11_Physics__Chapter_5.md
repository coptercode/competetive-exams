# Introduction

Whenever a force acts on a body and produces displacement, **work** is said to be done. The ability to do work is called **energy**, while the rate at which work is done is known as **power**.

The concepts of work and energy provide an alternative and often simpler method of solving problems in mechanics compared to Newton's laws.

---

# 1. Work

## Definition

Work is said to be done when a force acting on a body produces displacement.

---

## Formula

For a constant force,

```
W = F s cosθ
```

where

- **F** = Applied force
- **s** = Displacement
- **θ** = Angle between force and displacement

---

## SI Unit

```
joule (J)
```

```
1 J = 1 N m
```

---

## Dimensional Formula

```
[ML²T⁻²]
```

---

# 2. Nature of Work

---

## Positive Work

When force and displacement are in the same direction.

```
θ = 0°

W = Fs
```

Example

- Pulling a cart

---

## Negative Work

When force acts opposite to displacement.

```
θ = 180°

W = -Fs
```

Example

- Friction

---

## Zero Work

When

- Force is perpendicular to displacement, or
- Displacement is zero.

```
θ = 90°

W = 0
```

Example

- Satellite in circular motion
- Carrying a bag horizontally

---

# 3. Work Done by a Variable Force

When force varies with displacement,

```
W = ∫F dx
```

Graphically,

**Work done equals the area under the Force-Displacement graph.**

# 5. Kinetic Energy

## Definition

The energy possessed by a body due to its motion.

---

## Formula

```
KE = ½mv²
```

---

## SI Unit

```
joule (J)
```

---

## Dimensional Formula

```
[ML²T⁻²]
```

---

# 6. Work-Energy Theorem

## Statement

The work done by the net force acting on a body is equal to the change in its kinetic energy.

Mathematically,

```
W = ΔKE
```

or

```
W = KE₂ − KE₁
```

---

## Proof

Using

```
v² = u² + 2as
```

Multiply by

```
m/2
```

```
½mv²

−

½mu²

=

mas
```

Since

```
F = ma
```

```
Fs

=

ΔKE
```

Hence,

```
W = ΔKE
```

---

# 7. Potential Energy

## Definition

Potential energy is the energy possessed by a body due to its position or configuration.

---

# 8. Gravitational Potential Energy

For a body near Earth's surface,

```
PE = mgh
```

where

- m = Mass
- g = Acceleration due to gravity
- h = Height

---

# 9. Elastic Potential Energy

When a spring is stretched or compressed,

Hooke's Law

```
F = kx
```

where

- k = Spring constant
- x = Extension

Potential Energy stored

```
PE = ½kx²
```

---

# 10. Conservative Forces

## Definition

A force is conservative if the work done depends only on the initial and final positions, not on the path followed.

---

## Examples

- Gravitational force
- Electrostatic force
- Spring force

---

## Characteristics

- Work done in a closed path is zero.
- Mechanical energy remains constant.

---

# 11. Non-Conservative Forces

## Definition

A force is non-conservative if the work done depends on the path followed.

---

## Examples

- Friction
- Air resistance
- Viscous force

---

## Characteristics

- Mechanical energy is not conserved.
- Work done in a closed path is non-zero.

---

# 12. Conservation of Mechanical Energy

## Statement

If only conservative forces act on a system,

```
Total Mechanical Energy

=

Constant
```

Mathematically,

```
KE + PE

=

Constant
```

---

# 13. Freely Falling Body

At the highest point,

```
KE = 0

PE = Maximum
```

---

At the ground,

```
KE = Maximum

PE = 0
```

---

At any intermediate point,

```
KE + PE = Constant
```

# Solved Examples

### Example 1

A force of **50 N** moves a body through **4 m** in the same direction. Calculate the work done.

**Solution**

Using

```
W = Fs cos0°
```

```
= 50 × 4

= 200 J
```

---

### Example 2

A **5 kg** body moves with a speed of **6 m s⁻¹**. Find its kinetic energy.

**Solution**

```
KE = ½mv²
```

```
= ½ × 5 × 36

= 90 J
```

---

### Example 3

A **2 kg** object is raised through **10 m**. Calculate its potential energy.

Take

```
g = 9.8 m s⁻²
```

**Solution**

```
PE = mgh
```

```
= 2 × 9.8 × 10

= 196 J
```

---

### Example 4

A spring of spring constant **400 N m⁻¹** is compressed by **0.10 m**. Find the elastic potential energy stored.

**Solution**

```
PE = ½kx²
```

```
= ½ × 400 × (0.10)²

= 2 J
```

---

### Example 5

A machine performs **6000 J** of work in **30 s**. Calculate its power.

**Solution**

```
P = W/t
```

```
= 6000/30

= 200 W
```

---

### Example 6

A **1000 kg** car moving at **20 m s⁻¹** is brought to rest by brakes. Calculate the work done by the braking force.

**Solution**

Using the Work-Energy Theorem,

```
W = ΔKE
```

```
= 0 − ½ × 1000 × 20²

= −200000 J
```

The negative sign indicates that the braking force removes kinetic energy from the car.

# Common Mistakes

- Assuming work is done whenever a force acts; **displacement** must also occur.
- Forgetting the **cosθ** factor in the work formula.
- Confusing **kinetic energy** with **potential energy**.
- Applying the **conservation of mechanical energy** when non-conservative forces such as friction are present.
- Assuming **momentum** and **kinetic energy** are both conserved in every collision; only **momentum** is always conserved in isolated systems.
- Ignoring the sign of work done by **gravity** or **friction**.
- Using **P = W/t** for situations involving changing force without considering **instantaneous power (P = F·v)**.
- Forgetting that **work done equals the area under the force-displacement graph** for variable forces.

---

# Chapter Summary

- **Work** is done when a force causes displacement and is given by **W = Fs cosθ** for a constant force.
- **Energy** is the capacity to do work and exists in many forms, with **kinetic** and **potential energy** being the primary forms of mechanical energy.
- The **Work-Energy Theorem** states that the net work done on a body equals the change in its kinetic energy.
- **Gravitational potential energy** is given by **mgh**, while the energy stored in a stretched or compressed spring is **½kx²**.
- **Conservative forces** conserve mechanical energy and perform zero work over a closed path, whereas **non-conservative forces** depend on the path and dissipate mechanical energy.
- In the absence of non-conservative forces, the total **mechanical energy (KE + PE)** of a system remains constant.
- **Power** is the rate of doing work and is measured in **watts**, with instantaneous power given by **P = F·v**.
- During **collisions**, the total momentum of an isolated system is always conserved, while kinetic energy is conserved only in **elastic collisions**.
- The principles of work, energy, and power provide powerful tools for solving mechanical problems without directly applying Newton's laws of motion.
