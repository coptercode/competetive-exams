# Introduction

Algebraic identities are special algebraic equations that are true for **all values** of the variables involved. Unlike ordinary equations, identities do not depend on finding the value of a variable; they remain true regardless of the values substituted.

Algebraic identities simplify calculations, help in factorization, and form the foundation for solving quadratic equations, polynomial multiplication, and many advanced mathematical concepts.

For example,

```
(a + b)² = a² + 2ab + b²
```

This identity is true for every value of **a** and **b**.

---

# 1. What is an Algebraic Identity?

An **algebraic identity** is an equality that holds true for every permissible value of the variables.

### Example

```
(a + b)² = a² + 2ab + b²
```

Let

```
a = 2
```

```
b = 3
```

LHS

```
(2 + 3)² = 25
```

RHS

```
2² + 2(2)(3) + 3²
```

```
=4+12+9
```

```
=25
```

Hence,

```
LHS = RHS
```

---

# 2. Difference Between an Identity and an Equation

| Equation                        | Identity                    |
| ------------------------------- | --------------------------- |
| True only for particular values | True for all values         |
| May have one or more solutions  | Always true                 |
| Example: x + 2 = 7              | Example: (a+b)² = a²+2ab+b² |

# 3. Square of a Binomial

One of the most important identities is the square of a sum.

### Identity

```
(a + b)² = a² + 2ab + b²
```

### Example

Expand

```
(x + 5)²
```

Solution

```
=x²+2(x)(5)+25
```

```
=x²+10x+25
```

---

# 4. Square of a Difference

### Identity

```
(a − b)² = a² − 2ab + b²
```

### Example

Expand

```
(y − 4)²
```

Solution

```
=y²−8y+16
```

---

# 5. Product of Sum and Difference

The product of the sum and difference of two numbers gives the difference of their squares.

### Identity

```
(a + b)(a − b) = a² − b²
```

### Example

Expand

```
(x + 6)(x − 6)
```

Solution

```
=x²−36
```

---

# 6. Cube of a Binomial

### Cube of a Sum

```
(a+b)³=a³+3a²b+3ab²+b³
```

### Example

Expand

```
(x+2)³
```

Solution

```
=x³+6x²+12x+8
```

---

### Cube of a Difference

```
(a−b)³=a³−3a²b+3ab²−b³
```

### Example

Expand

```
(y−1)³
```

Solution

```
=y³−3y²+3y−1
```

---

# 7. Sum of Cubes

### Identity

```
a³+b³=(a+b)(a²−ab+b²)
```

### Example

Factorize

```
x³+8
```

Since

```
8=2³
```

```
=x³+2³
```

```
=(x+2)(x²−2x+4)
```

---

# 8. Difference of Cubes

### Identity

```
a³−b³=(a−b)(a²+ab+b²)
```

### Example

Factorize

```
x³−27
```

Since

```
27=3³
```

```
=(x−3)(x²+3x+9)
```

# 9. Applications of Algebraic Identities

Algebraic identities are useful for:

- Expanding algebraic expressions.
- Factorizing polynomials.
- Mental calculations.
- Solving algebraic equations.
- Simplifying lengthy expressions.
- Higher mathematics such as quadratic equations and calculus.

# Common Mistakes

- Forgetting the middle term **2ab** while expanding `(a+b)²`.
- Writing `(a−b)²` as `a²−b²`.
- Using incorrect signs in cube identities.
- Confusing identities with ordinary equations.
- Forgetting to square the coefficients while expanding.

# Chapter Summary

- An algebraic identity is true for every value of the variables.
- Identities simplify expansion and factorization of algebraic expressions.
- The identities `(a+b)²`, `(a−b)²`, and `(a+b)(a−b)` are the most frequently used.
- Cube identities help expand and factorize cubic expressions.
- Difference of squares and sum/difference of cubes are powerful tools in algebra.
- Algebraic identities are widely used in higher mathematics, science, and engineering.
- Regular practice of these identities improves speed and accuracy in solving algebraic problems.
