# Introduction

Many chemical reactions involve the **transfer of electrons** from one substance to another. Such reactions are called **redox (reduction–oxidation) reactions**.

Redox reactions play an essential role in:

- Respiration
- Photosynthesis
- Corrosion
- Combustion
- Electrochemical cells
- Metallurgy
- Industrial chemical processes

---

# 1. Oxidation

## Definition (Classical Concept)

Oxidation is the:

- Addition of oxygen.
- Removal of hydrogen.

Examples

```
2Mg + O₂ → 2MgO
```

```
H₂S + Cl₂ → 2HCl + S
```

---

## Modern Definition

Oxidation is:

- Loss of electrons.
- Increase in oxidation number.

Example

```
Na → Na⁺ + e⁻
```

---

# 2. Reduction

## Definition (Classical Concept)

Reduction is the:

- Removal of oxygen.
- Addition of hydrogen.

Example

```
CuO + H₂ → Cu + H₂O
```

---

## Modern Definition

Reduction is:

- Gain of electrons.
- Decrease in oxidation number.

Example

```
Cl₂ + 2e⁻ → 2Cl⁻
```

---

# 3. Redox Reaction

## Definition

A reaction in which oxidation and reduction occur simultaneously.

Example

```
Zn + CuSO₄

↓

ZnSO₄ + Cu
```

Oxidation

```
Zn → Zn²⁺ + 2e⁻
```

Reduction

```
Cu²⁺ + 2e⁻ → Cu
```

---

# 4. Oxidizing Agent

## Definition

A substance which:

- Oxidizes another substance.
- Itself undergoes reduction.
- Accepts electrons.

Examples

- O₂
- KMnO₄
- K₂Cr₂O₇
- Cl₂
- H₂O₂

---

# 5. Reducing Agent

## Definition

A substance which:

- Reduces another substance.
- Itself undergoes oxidation.
- Donates electrons.

Examples

- H₂
- CO
- Zn
- Fe
- Na

# 10. Types of Redox Reactions

---

## (A) Combination Reaction

Two or more reactants combine.

Example

```
2Mg + O₂

↓

2MgO
```

---

## (B) Decomposition Reaction

One compound breaks into simpler substances.

Example

```
2HgO

↓

2Hg + O₂
```

---

## (C) Displacement Reaction

A more reactive element displaces a less reactive element.

Example

```
Zn + CuSO₄

↓

ZnSO₄ + Cu
```

---

## (D) Disproportionation Reaction

The same element undergoes oxidation and reduction simultaneously.

Example

```
2H₂O₂

↓

2H₂O + O₂
```

Oxidation number of oxygen

```
−1

↓

−2

and

0
```

---

## (E) Comproportionation Reaction

Two oxidation states combine to form an intermediate oxidation state.

Example

```
Cu + Cu²⁺

↓

2Cu⁺
```

# 12. Oxidation Number Method

### Steps

1. Write skeletal equation.
2. Assign oxidation numbers.
3. Identify oxidation and reduction.
4. Equalize oxidation number changes.
5. Balance atoms.
6. Balance oxygen using H₂O.
7. Balance hydrogen using H⁺.
8. Balance charge.

# 13. Ion-Electron (Half-Reaction) Method

| Oxidation                    | Reduction                    |
| ---------------------------- | ---------------------------- |
| Loss of electrons            | Gain of electrons            |
| Increase in oxidation number | Decrease in oxidation number |
| Addition of oxygen           | Removal of oxygen            |

| ------------------- | ------------------- |

# Solved Examples

### Example 1

Determine the oxidation number of sulfur in **H₂SO₄**.

**Solution**

Let oxidation number of sulfur = x.

```
2(+1) + x + 4(−2) = 0

2 + x − 8 = 0

x = +6
```

---

### Example 2

Identify the oxidizing and reducing agents in the reaction

```
Zn + CuSO₄ → ZnSO₄ + Cu
```

**Solution**

- Zn changes from 0 to +2 (oxidation), so **Zn is the reducing agent**.
- Cu²⁺ changes from +2 to 0 (reduction), so **CuSO₄ (Cu²⁺)** is the oxidizing agent.

---

### Example 3

Calculate the oxidation number of manganese in **KMnO₄**.

**Solution**

Let the oxidation number of Mn = x.

```
(+1) + x + 4(−2) = 0

1 + x − 8 = 0

x = +7
```

---

### Example 4

State whether the following is oxidation or reduction:

```
Fe²⁺ → Fe³⁺ + e⁻
```

**Solution**

The oxidation number of iron increases from +2 to +3 and an electron is lost.

Therefore, it is **oxidation**.

---

### Example 5

Why is hydrogen peroxide (H₂O₂) considered a disproportionation reagent in the reaction

```
2H₂O₂ → 2H₂O + O₂
```

**Solution**

In H₂O₂, the oxidation number of oxygen is −1.

During the reaction:

- Oxygen changes from −1 to −2 in H₂O (reduction).
- Oxygen changes from −1 to 0 in O₂ (oxidation).

Thus, the same element undergoes both oxidation and reduction, making it a **disproportionation reaction**.

---

### Example 6

Balance the following reaction in acidic medium using the ion-electron method:

```
Fe²⁺ + MnO₄⁻ → Fe³⁺ + Mn²⁺
```

**Solution**

Half-reactions:

Oxidation:

```
Fe²⁺ → Fe³⁺ + e⁻
```

Reduction:

```
MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O
```

Multiply the oxidation half-reaction by 5 and add:

```
5Fe²⁺ + MnO₄⁻ + 8H⁺

↓

5Fe³⁺ + Mn²⁺ + 4H₂O
```

This is the balanced redox equation.

# Common Mistakes

- Confusing **oxidation** with the addition of oxygen only; oxidation also includes **loss of electrons** or **increase in oxidation number**.
- Assigning incorrect oxidation numbers in compounds such as **peroxides**, **superoxides**, and **OF₂**.
- Forgetting that **fluorine always has an oxidation number of −1** in its compounds.
- Mixing up the **oxidizing agent** and the **reducing agent**; the oxidizing agent is itself reduced, while the reducing agent is itself oxidized.
- Ignoring the balancing of **charge** when using the **ion-electron method**.
- Forgetting to add **H₂O** and **H⁺** while balancing redox reactions in acidic medium.
- Confusing **disproportionation** with **comproportionation** reactions.
- Using oxidation numbers instead of actual ionic charges in half-reactions.

---

# Chapter Summary

- **Redox reactions** involve the simultaneous occurrence of **oxidation** and **reduction**, accompanied by electron transfer.
- **Oxidation** is the loss of electrons or increase in oxidation number, whereas **reduction** is the gain of electrons or decrease in oxidation number.
- The **oxidizing agent** accepts electrons and undergoes reduction, while the **reducing agent** donates electrons and undergoes oxidation.
- **Oxidation numbers** are assigned using a set of standard rules and are essential for identifying redox changes.
- Redox reactions can be classified as **combination**, **decomposition**, **displacement**, **disproportionation**, and **comproportionation** reactions.
- Redox equations can be balanced using the **oxidation number method** or the **ion-electron (half-reaction) method**, especially in acidic or basic media.
- Redox processes are fundamental to **corrosion**, **combustion**, **respiration**, **photosynthesis**, **electrochemistry**, and many industrial processes.
- Understanding oxidation numbers, electron transfer, and balancing methods provides the foundation for studying electrochemistry and oxidation–reduction processes in higher chemistry.
