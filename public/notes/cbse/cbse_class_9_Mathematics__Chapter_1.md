# 1. Introduction

Numbers are used everywhere—from counting objects to measuring distances, temperatures, money, and time. As mathematics developed, new kinds of numbers were introduced to solve increasingly complex problems.

The main types of numbers covered in this chapter are:

- Natural Numbers
- Whole Numbers
- Integers
- Rational Numbers
- Irrational Numbers
- Real Numbers

---

# 2. Classification of Numbers

| Number Set           | Definition                                | Examples                       |
| -------------------- | ----------------------------------------- | ------------------------------ |
| Natural Numbers (N)  | Counting numbers                          | 1, 2, 3, ...                   |
| Whole Numbers (W)    | Natural numbers and zero                  | 0, 1, 2, 3                     |
| Integers (Z)         | Positive, negative numbers and zero       | -4, 0, 8                       |
| Rational Numbers (Q) | Numbers that can be written as p/q, q ≠ 0 | 2/3, -5, 0.25                  |
| Irrational Numbers   | Cannot be written as p/q                  | √2, √3, π                      |
| Real Numbers (R)     | All rational and irrational numbers       | Every point on the number line |

# 3. Rational Numbers

## Definition

A rational number is any number that can be expressed in the form:

```math
p/q, q ≠ 0
```

where **p** and **q** are integers.

### Examples

- 5 = 5/1
- -3 = -3/1
- 3/8
- 0.75 = 3/4
- 0.333... = 1/3

### Characteristics

- Can be positive, negative, or zero.
- Decimal expansion is either terminating or non-terminating repeating.

---

# 4. Irrational Numbers

## Definition

An irrational number cannot be expressed as **p/q**.

Its decimal expansion is:

- Non-terminating
- Non-repeating

### Examples

- √2
- √5
- π
- √7

---

# 5. Rational vs Irrational Numbers

| Rational                      | Irrational               |
| ----------------------------- | ------------------------ |
| Can be written as p/q         | Cannot be written as p/q |
| Decimal terminates or repeats | Decimal never repeats    |
| Examples: 2/5, 4, 0.125       | Examples: √2, π          |

---

# 6. Decimal Expansions

## Terminating Decimal

Examples:

- 0.5
- 3.25
- 12.875

These are always rational numbers.

## Non-Terminating Repeating Decimal

Examples:

- 0.333...
- 0.727272...
- 4.121212...

These are also rational numbers.

## Non-Terminating Non-Repeating Decimal

Examples:

- √2 = 1.414213...
- π = 3.141592...

These are irrational numbers.

# 7. Converting Repeating Decimals into Fractions

### Example

Convert **0.666...** into p/q.

Let:

```text
x = 0.666...
10x = 6.666...

10x − x = 6
9x = 6
x = 2/3
```

Therefore:

**0.666... = 2/3**

# 8. Laws of Exponents

| Law               | Formula             |
| ----------------- | ------------------- |
| Product Rule      | a^m × a^n = a^(m+n) |
| Quotient Rule     | a^m ÷ a^n = a^(m−n) |
| Power Rule        | (a^m)^n = a^(mn)    |
| Zero Exponent     | a^0 = 1             |
| Negative Exponent | a^−n = 1/a^n        |

# 9. Rationalization

### Example

Simplify:

```text

```

Multiply numerator and denominator by √2:

```text
(3√2)/2
```

# 10. Locating √2 on the Number Line

1. Draw OA = 1 unit.
2. Draw AB perpendicular to OA with AB = 1 unit.
3. Join OB.
4. OB = √2.
5. Using O as the centre and OB as the radius, mark √2 on the number line.

# Common Mistakes

- Thinking every non-terminating decimal is irrational.
- Forgetting that repeating decimals are rational.
- Applying exponent laws incorrectly.
- Rationalizing only the denominator.

# Formula Sheet

- Real Numbers = Rational + Irrational
- a^m × a^n = a^(m+n)
- a^m ÷ a^n = a^(m−n)
- (a^m)^n = a^(mn)
- a^0 = 1
- a^−n = 1/a^n

# Chapter Summary

- Rational numbers can be written as p/q.
- Irrational numbers cannot be expressed as p/q.
- Every real number is either rational or irrational.
- Terminating and repeating decimals are rational.
- Exponent laws simplify calculations.
- Rationalization removes irrational numbers from denominators.
