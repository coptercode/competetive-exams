# Introduction

Probability is the branch of mathematics that deals with **chance** or the **likelihood of an event occurring**. It helps us predict how likely an event is to happen, although it does not guarantee the outcome.

In everyday life, probability is used in weather forecasting, sports, insurance, medical research, genetics, economics, games, and decision-making.

The value of probability always lies between **0 and 1**, where **0** indicates an impossible event and **1** indicates a certain event.

---

# 1. Random Experiment

A **random experiment** is an experiment whose outcome cannot be predicted with certainty in advance.

### Examples

- Tossing a coin.
- Rolling a die.
- Drawing a card from a deck.
- Picking a coloured ball from a bag.
- Selecting a student from a class.

Each experiment may produce different outcomes even when repeated under the same conditions.

---

# 2. Outcome

An **outcome** is a possible result of a random experiment.

### Example

When a coin is tossed,

Possible outcomes are

```
Head (H)
```

or

```
Tail (T)
```

---

# 3. Sample Space

The **sample space** is the set of all possible outcomes of a random experiment.

It is usually represented by **S**.

### Examples

#### Tossing a Coin

```
S = {H, T}
```

---

#### Rolling a Die

```
S = {1, 2, 3, 4, 5, 6}
```

---

#### Tossing Two Coins

```
S = {HH, HT, TH, TT}
```

---

# 4. Event

An **event** is a collection of one or more outcomes from a sample space.

### Example

Rolling a die.

Event:

Getting an even number.

```
E = {2, 4, 6}
```

---

# 5. Types of Events

## Certain Event

A **certain event** always occurs.

Probability

```
=1
```

Example:

Getting a number less than

```
7
```

when rolling a standard die.

---

## Impossible Event

An **impossible event** never occurs.

Probability

```
=0
```

Example:

Getting

```
8
```

on a standard die.

---

## Simple Event

A **simple event** contains exactly one outcome.

Example:

Getting

```
3
```

on a die.

---

## Compound Event

A **compound event** contains more than one outcome.

Example:

Getting an odd number.

```
{1,3,5}
```

---

# 6. Experimental Probability

Experimental probability is determined by conducting an experiment.

### Formula

```
Experimental Probability
=
Number of Times the Event Occurred
-----------------------------------
Total Number of Trials
```

---

### Example

A coin is tossed

```
20
```

times.

Heads appear

```
12
```

times.

```
Probability of Head
=
12/20
```

```
=3/5
```

---

# 7. Theoretical Probability

Theoretical probability is based on logical reasoning when all outcomes are equally likely.

### Formula

```
P(Event)
=
Number of Favourable Outcomes
-----------------------------
Total Number of Possible Outcomes
```

---

### Example

Find the probability of getting

```
4
```

on a die.

Favourable outcomes

```
=1
```

Total outcomes

```
=6
```

```
P(4)=1/6
```

---

# 8. Properties of Probability

For any event **E**,

```
0 ≤ P(E) ≤ 1
```

Special cases:

Impossible event

```
P(E)=0
```

Certain event

```
P(E)=1
```

---

# 9. Complementary Events

The complement of an event **E** is the event that **E does not occur**.

If

```
P(E)
```

is the probability of an event,

then

```
P(Not E)=1−P(E)
```

---

### Example

If

```
P(Rain)=0.3
```

then

```
P(No Rain)
```

```
=1−0.3
```

```
=0.7
```

# Common Mistakes

- Confusing experimental probability with theoretical probability.
- Forgetting to list all possible outcomes in the sample space.
- Counting favourable outcomes incorrectly.
- Writing probabilities greater than **1** or less than **0**.
- Assuming every event is equally likely without checking the conditions.
- Forgetting to simplify probability fractions.

# Formula Sheet

| Concept                  | Formula                                       |
| ------------------------ | --------------------------------------------- |
| Theoretical Probability  | `P(E) = Favourable Outcomes / Total Outcomes` |
| Experimental Probability | `Number of Successful Trials / Total Trials`  |
| Impossible Event         | `P(E) = 0`                                    |
| Certain Event            | `P(E) = 1`                                    |
| Complement of an Event   | `P(Not E) = 1 − P(E)`                         |
| Range of Probability     | `0 ≤ P(E) ≤ 1`                                |

# Chapter Summary

- Probability measures the likelihood of an event occurring.
- A **random experiment** is one whose outcome cannot be predicted with certainty.
- The **sample space** is the set of all possible outcomes of an experiment.
- An **event** is a subset of the sample space.
- Theoretical probability is calculated using equally likely outcomes.
- Experimental probability is calculated using actual observations from repeated experiments.
- The probability of an impossible event is **0**, while the probability of a certain event is **1**.
- The probability of any event always lies between **0** and **1**.
- The complement of an event is given by **1 − P(E)**.
- Probability is widely used in science, economics, medicine, engineering, weather forecasting, and everyday decision-making.
