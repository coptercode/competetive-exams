# Introduction

In many real-life situations, two quantities are related to each other. For example, the cost of buying books depends on the number of books purchased, and the distance travelled depends on speed and time. Such relationships can often be represented using **linear equations in two variables**.

A **linear equation in two variables** contains two unknown quantities (usually represented by **x** and **y**) and each variable has the highest power of **1**. These equations represent straight lines when plotted on a graph and are widely used in mathematics, science, economics, engineering, and statistics.

---

Examples:

```

```

```

---

# 2. Linear Equation in Two Variables

A **linear equation in two variables** is an equation of the form

```
ax + by + c = 0
```

where

- **a**, **b**, and **c** are real numbers.
- **a** and **b** are not both zero.

Examples:

```
2x + 3y = 6
```

```
x - y = 5
```

```
4x + y - 9 = 0
```

Non-examples:

```
x² + y = 5
```

```
xy = 8
```

```
√x + y = 6
```

These are not linear equations because the variables have powers greater than 1, are multiplied together, or appear under radicals.

---

# 3. Solution of a Linear Equation

A **solution** of a linear equation is an ordered pair **(x, y)** that satisfies the equation.

### Example

Find whether **(2, 1)** is a solution of

```
2x + 3y = 7
```

Substitute

```
x = 2
```

```
y = 1
```

```
2(2) + 3(1)
```

```
=4+3
```

```
=7
```

Since the left-hand side equals the right-hand side,

```
(2,1)
```

is a solution.

---

# 4. Finding Solutions

A linear equation in two variables has infinitely many solutions.

To find solutions:

1. Choose any value of **x**.
2. Substitute it into the equation.
3. Find the corresponding value of **y**.

### Example

Find three solutions of

```
x + y = 6
```

| x   | y   |
| --- | --- |
| 0   | 6   |
| 2   | 4   |
| 5   | 1   |

Each ordered pair satisfies the equation.

---

# 5. Graphical Representation

Every linear equation in two variables represents a **straight line** on the Cartesian plane.

To draw the graph:

1. Find two or more solutions.
2. Plot the corresponding points.
3. Join them using a ruler.
4. Extend the line on both sides.

### Example

For

```
x + y = 4
```

Choose values:

| x   | y   |
| --- | --- |
| 0   | 4   |
| 1   | 3   |
| 2   | 2   |
| 4   | 0   |

Plot these points and join them to obtain the required straight line.

---

# 6. Intercepts of a Line

The points where a line cuts the coordinate axes are called **intercepts**.

### x-intercept

Set

```
y = 0
```

and solve for **x**.

### y-intercept

Set

```
x = 0
```

and solve for **y**.

### Example

Find the intercepts of

```
2x + y = 8
```

**x-intercept**

```
2x = 8
```

```
x = 4
```

Point:

```
(4,0)
```

**y-intercept**

```
y = 8
```

Point:

```
(0,8)
```

# 7. Applications of Linear Equations

Linear equations are used in many practical situations, such as:

- Calculating the cost of items.
- Determining profit and loss.
- Finding relationships between distance, speed, and time.
- Budget planning.
- Population growth.
- Business and economics.
- Scientific measurements.

### Example

A notebook costs ₹40.

If **x** notebooks are purchased, the total cost **y** is

```

# Common Mistakes

- Confusing a linear equation with a quadratic equation.
- Forgetting that the highest power of each variable must be **1**.
- Substituting incorrect values while checking solutions.
- Plotting points inaccurately on the graph.
- Assuming a linear equation has only one solution.
- Mixing the x-coordinate and y-coordinate of an ordered pair.

# Chapter Summary

- A linear equation in two variables has the general form **ax + by + c = 0**.
- The highest power of each variable is **1**.
- Every solution is represented as an ordered pair **(x, y)**.
- A linear equation has infinitely many solutions.
- The graph of a linear equation is always a straight line.
- The x-intercept is obtained by putting **y = 0**, while the y-intercept is obtained by putting **x = 0**.
- Linear equations are used extensively to represent relationships between two changing quantities in mathematics and real-life applications.
