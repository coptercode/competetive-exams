# Introduction

Probability is the branch of mathematics that deals with the chance or likelihood of occurrence of events.

This chapter covers:

- Random experiments
- Sample space
- Events
- Classical probability
- Experimental probability

---

# PART A: BASIC CONCEPTS OF PROBABILITY

---

# 1. Random Experiment

## Definition

An experiment whose outcome cannot be predicted with certainty before performing it is called a random experiment.

---

Examples:

- Tossing a coin
- Rolling a die
- Drawing a card

---

# 2. Outcome

## Definition

A possible result of a random experiment is called an outcome.

---

Example:

When a coin is tossed:

Possible outcomes:

\[
\boxed{H,T}
\]

---

# 3. Sample Space

## Definition

The set of all possible outcomes of a random experiment is called the sample space.

---

Symbol:

\[
\boxed{S}
\]

---

Example:

For tossing a coin:

\[
S=\{H,T\}
\]

---

For throwing a die:

\[
S=\{1,2,3,4,5,6\}
\]

---

# 4. Event

## Definition

A collection of one or more outcomes of a sample space is called an event.

---

Symbol:

\[
\boxed{E}
\]

---

Example:

Rolling an even number on a die:

\[
E=\{2,4,6\}
\]

---

# PART B: TYPES OF EVENTS

---

# 5. Simple Event

## Definition

An event containing only one outcome is called a simple event.

---

Example:

Getting 5 when a die is thrown.

\[
E=\{5\}
\]

---

# 6. Compound Event

## Definition

An event containing more than one outcome is called a compound event.

---

Example:

Getting an even number on a die.

\[
E=\{2,4,6\}
\]

---

# 7. Sure Event

## Definition

An event that always occurs is called a sure event.

---

Probability:

\[
\boxed{1}
\]

---

Example:

Getting a number between 1 and 6 when a die is thrown.

---

# 8. Impossible Event

## Definition

An event that can never occur is called an impossible event.

---

Probability:

\[
\boxed{0}
\]

---

Example:

Getting 7 on a normal die.

---

# PART C: CLASSICAL APPROACH TO PROBABILITY

---

# 9. Classical Probability

## Definition

Probability based on equally likely outcomes is called classical probability.

---

Formula:

\[
\boxed{
P(E)=
\frac{\text{Number of favourable outcomes}}
{\text{Total number of outcomes}}
}
\]

---

Where:

\[
0\leq P(E)\leq1
\]

---

# 10. Probability of an Event

If:

n(E) = number of favourable outcomes

n(S) = total number of outcomes

Then:

\[
\boxed{
P(E)=\frac{n(E)}{n(S)}
}
\]

---

# PART F: COMPLEMENTARY EVENTS

---

# 14. Complement of an Event

## Definition

The event that does not occur when an event occurs is called its complementary event.

---

Symbol:

\[
\boxed{E'}
\]

---

Formula:

\[
\boxed{
P(E)+P(E')=1
}
\]

---

Example:

If probability of rain:

\[
P(R)=0.3
\]

Probability of no rain:

\[
P(R')=1-0.3
\]

\[
=0.7
\]

---

# PART G: EXPERIMENTAL PROBABILITY

---

# 15. Experimental Probability

## Definition

Probability calculated from actual experiments is called experimental probability.

---

Formula:

\[
\boxed{
P(E)=
\frac{\text{Number of times event occurs}}
{\text{Total number of trials}}
}
\]

---

Example:

A coin is tossed 100 times.

Heads occur 55 times.

Experimental probability:

\[
P(H)=\frac{55}{100}
\]

\[
\boxed{0.55}
\]

---

# 16. Difference Between Classical and Experimental Probability

| Classical Probability        | Experimental Probability    |
| ---------------------------- | --------------------------- |
| Based on theory              | Based on actual trials      |
| Uses equally likely outcomes | Uses observed results       |
| Calculated before experiment | Calculated after experiment |

---

# Important Formula Sheet

## Classical Probability

\[
\boxed{
P(E)=\frac{n(E)}{n(S)}
}
\]

---

## Complementary Probability

\[
\boxed{
P(E')=1-P(E)
}
\]

---

## Experimental Probability

\[
\boxed{
P(E)=
\frac{\text{Number of successful trials}}
{\text{Total trials}}
}
\]

# Common Mistakes

- Forgetting to count total outcomes correctly.
- Using favourable outcomes in denominator.
- Confusing impossible and sure events.
- Forgetting probability values must lie between 0 and 1.
- Mixing classical and experimental probability formulas.

---

# Chapter Summary

- Probability measures the chance of occurrence of an event.
- Random experiments have uncertain outcomes.
- Sample space contains all possible outcomes.
- Classical probability uses favourable and total outcomes.
- Experimental probability is based on actual observations.
- Probability values range from 0 to 1.

\[
\boxed{
\text{Probability helps predict the likelihood of future events.}
}
\]
