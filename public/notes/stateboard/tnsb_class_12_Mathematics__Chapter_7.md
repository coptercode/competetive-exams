# Introduction

Differential calculus studies the rate of change of quantities.

Applications of derivatives help us to:

- Find maximum and minimum values
- Study increasing and decreasing functions
- Determine tangent behaviour
- Analyse curves
- Solve optimisation problems

---

# 1. Rate of Change

If:

\[
y=f(x)
\]

then the rate of change of y with respect to x is:

\[
\boxed{
\frac{dy}{dx}
}
\]

---

# 2. Increasing and Decreasing Functions

A function is studied using its first derivative.

---

# Increasing Function

A function is increasing in an interval if:

\[
\boxed{
f'(x)>0
}
\]

---

# Decreasing Function

A function is decreasing in an interval if:

\[
\boxed{
f'(x)<0
}
\]

---

# 3. Critical Points

## Definition

A point where:

\[
\boxed{
f'(x)=0
}
\]

or derivative does not exist is called a critical point.

---

Critical points are used to find:

- Maximum values
- Minimum values
- Points of inflection

---

# 4. Mean Value Theorems

Mean Value Theorems connect the value of a function at two points with its derivative at an intermediate point.

Two important theorems:

1. Rolle's Theorem
2. Lagrange's Mean Value Theorem

---

# 5. Rolle's Theorem

## Statement

If a function f(x) satisfies:

### Condition 1:

f(x) is continuous in:

\[
[a,b]
\]

---

### Condition 2:

f(x) is differentiable in:

\[
(a,b)
\]

---

### Condition 3:

\[
\boxed{
f(a)=f(b)
}
\]

---

Then there exists at least one point:

\[
c\in(a,b)
\]

such that:

\[
\boxed{
f'(c)=0
}
\]

---

# Geometrical Meaning

The tangent at some point between a and b becomes parallel to the x-axis.

---

# Example

Verify Rolle's theorem for:

\[
f(x)=x^2-4x+3
\]

in:

\[
[1,3]
\]

---

Check:

\[
f(1)=0
\]

\[
f(3)=0
\]

Conditions satisfied.

Derivative:

\[
f'(x)=2x-4
\]

For Rolle's theorem:

\[
f'(c)=0
\]

\[
2c-4=0
\]

\[
\boxed{c=2}
\]

---

# 6. Lagrange's Mean Value Theorem (LMVT)

## Statement

If f(x) is:

1. Continuous in:

\[
[a,b]
\]

2. Differentiable in:

\[
(a,b)
\]

then there exists:

\[
c\in(a,b)
\]

such that:

\[
\boxed{
f'(c)=
\frac{f(b)-f(a)}{b-a}
}
\]

---

# Geometrical Meaning

There exists a point where:

\[
\text{tangent slope}
=

\text{chord slope}
\]

---

# 7. Extrema of Functions

## Definition

The maximum or minimum values of a function are called extrema.

Types:

1. Local maximum
2. Local minimum
3. Absolute maximum
4. Absolute minimum

---

# 8. Local Maximum

A function has local maximum at:

\[
x=a
\]

if:

\[
f(a)>f(x)
\]

for nearby values of x.

---

Condition:

\[
\boxed{
f'(a)=0
}
\]

and:

\[
\boxed{
f''(a)<0
}
\]

---

# 9. Local Minimum

A function has local minimum at:

\[
x=a
\]

if:

\[
f(a)<f(x)
\]

for nearby values.

---

Condition:

\[
\boxed{
f'(a)=0
}
\]

and:

\[
\boxed{
f''(a)>0
}
\]

---

# 10. First Derivative Test

Steps:

### Step 1

Find:

\[
f'(x)=0
\]

---

### Step 2

Find critical points.

---

### Step 3

Check sign changes.

---

If:

\[
+\rightarrow-
\]

then:

\[
\boxed{\text{Maximum}}
\]

---

If:

\[
-\rightarrow+
\]

then:

\[
\boxed{\text{Minimum}}
\]

---

# 11. Second Derivative Test

At critical point:

\[
f'(a)=0
\]

---

## Case 1

If:

\[
\boxed{
f''(a)<0
}
\]

Function has maximum.

---

## Case 2

If:

\[
\boxed{
f''(a)>0
}
\]

Function has minimum.

---

## Case 3

If:

\[
f''(a)=0
\]

Test fails.

---

# 12. Concavity

Concavity describes the shape of a curve.

---

# Concave Upward

If:

\[
\boxed{
f''(x)>0
}
\]

Curve bends upward.

---

# Concave Downward

If:

\[
\boxed{
f''(x)<0
}
\]

Curve bends downward.

---

# 13. Point of Inflection

## Definition

A point where the curve changes its concavity is called a point of inflection.

---

Condition:

\[
\boxed{
f''(x)=0
}
\]

with change in sign of second derivative.

---

# Example

For:

\[
f(x)=x^3
\]

First derivative:

\[
f'(x)=3x^2
\]

Second derivative:

\[
f''(x)=6x
\]

At:

\[
x=0
\]

\[
f''(0)=0
\]

Concavity changes.

Therefore:

\[
\boxed{x=0\text{ is point of inflection}}
\]

---

# 14. Optimisation Problems

Differentiation helps find maximum or minimum values in real situations.

Applications:

- Maximum area
- Minimum cost
- Maximum profit
- Minimum distance

---

# Steps for Optimisation

---

### Step 2

---

### Step 3

Differentiate.

---

### Step 4

Set:

\[
f'(x)=0
\]

---

### Step 5

Use second derivative test.

---

# Important Formula Sheet

## Increasing Function

\[
f'(x)>0
\]

---

## Decreasing Function

\[
f'(x)<0
\]

---

## Critical Point

\[
f'(x)=0
\]

---

## Rolle's Theorem

\[
f'(c)=0
\]

---

## Lagrange Mean Value Theorem

\[
f'(c)=
\frac{f(b)-f(a)}{b-a}
\]

---

## Maximum Condition

\[
f'(a)=0,\quad f''(a)<0
\]

---

## Minimum Condition

\[
f'(a)=0,\quad f''(a)>0
\]

---

## Inflection Point

\[
f''(x)=0
\]

with sign change.

---

# Solved Examples

## Example 1

Find maximum/minimum of:

\[
f(x)=x^2-4x+5
\]

Derivative:

\[
f'(x)=2x-4
\]

Set:

\[
2x-4=0
\]

\[
x=2
\]

Second derivative:

\[
f''(x)=2
\]

Since:

\[
f''(2)>0
\]

minimum occurs.

Value:

\[
f(2)=4-8+5
\]

\[
\boxed{=1}
\]

Minimum value:

\[
\boxed{1}
\]

---

## Example 2

Find intervals where:

\[
f(x)=x^3
\]

is increasing.

Derivative:

\[
f'(x)=3x^2
\]

Since:

\[
3x^2\geq0
\]

function is increasing for:

\[
\boxed{(-\infty,\infty)}
\]

---

## Example 3

Verify Rolle's theorem for:

\[
f(x)=x^2-1
\]

in:

\[
[-1,1]
\]

Since:

\[
f(-1)=f(1)=0
\]

Derivative:

\[
f'(x)=2x
\]

\[
2c=0
\]

\[
\boxed{c=0}
\]

# Common Mistakes

- Forgetting continuity and differentiability conditions in Mean Value Theorems.
- Using second derivative test without checking:

\[
f'(x)=0
\]

- Confusing maximum with minimum.
- Assuming:

\[
f''(x)=0
\]

always gives inflection point.

- Forgetting sign change requirement for inflection points.
- Making errors in optimisation function formation.

---

# Chapter Summary

- Derivatives help study the behaviour of functions.
- Rolle's theorem states that a horizontal tangent exists when endpoint values are equal.
- Lagrange's theorem connects average and instantaneous rates of change.
- First and second derivatives help find maxima and minima.
- The second derivative determines concavity.
- Points of inflection occur when concavity changes.
- Differential calculus has major applications in optimisation problems.

\[
\boxed{
\text{Derivative is the tool for analysing change and optimisation.}
}
\]
